# 入门系列（第 01-03 集）

> 本页为入门系列视频的链接索引与要点速览。

> [!WARNING]
> 以下视频链接当前为**占位地址**，正式教程发布后将更新为真实观看链接。

## 第 01 集：安装与第一个项目

[查看视频](https://www.bilibili.com/video/BV1m4x) → [🕒 5 分钟]

1. 前往官网 **下载** 页面获取安装包。
2. 双击安装包，跟随向导选择安装路径。
3. 勾选创建桌面快捷方式。
4. 首次启动跟随向导完成工作区初始化与模块加载。

## 第 02 集：添加一个按钮

[查看视频](https://www.bilibili.com/video/BV1m4y) → [🕒 8 分钟]

1. 打开窗口设计器。
2. 在设计器左侧的 **控件** 面板中单击 **按钮** 添加到画布，把 **显示内容** 设为“点击我”。
3. 双击按钮，编辑器生成事件处理器 `_按钮1_被单击`：

```lcpp
事件 _按钮1_被单击()
    信息框("你点了我", 64, "提示")
结束
```

## 第 03 集：第一个可运行程序

[查看视频](https://www.bilibili.com/video/BV1m4z) → [🕒 10 分钟]

1. 保存项目（`Ctrl+S`）。
2. 点击 **构建**（`Ctrl+B`），观察输出面板。
3. 点击 **运行**（`F5`），运行程序。
4. 点击 **停止**（`Shift+F5`）结束运行。
