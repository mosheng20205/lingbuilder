## 浏览器模块三合集（已发布）

三个独立合集，分别讲 EdgeView（WebView2）、CEF3（原生内核）与 FBro（指纹浏览器）三个浏览器模块。推荐按 EdgeView → CEF3 → FBro 的顺序学习：先用 WebView2 低门槛建立浏览器控件和事件模型，再进阶原生内核与指纹浏览器。

建议前置：主系列第 3～7 集和「窗口设计器与控件实战」合集。
