# 进阶系列（第 04-06 集）

> 本页为进阶系列视频的链接索引与要点速览。

> [!WARNING]
> 以下视频链接当前为**占位地址**，正式教程发布后将更新为真实观看链接。

## 第 04 集：模块市场与第三方模块

[查看视频](https://www.bilibili.com/video/BV1m5a) → [🕒 12 分钟]

1. 打开 **模块市场**。
2. 搜索 `excel-utils`，进入详情页。
3. 点击 **安装**，确认依赖后等待完成。
4. 在项目 **模块管理** 中添加引用，即可使用模块功能。

## 第 05 集：AI 对话式编程

[查看视频](https://www.bilibili.com/video/BV1m5b) → [🕒 15 分钟]

1. 打开 **工具** > **AI Bridge**，配置模型服务。
2. 打开 **AI 聊天** 面板。
3. 输入中文需求，例如“生成一个登录窗口”。
4. 点击 **插入**，将 AI 生成的代码放入编辑器。

## 第 06 集：调试器使用实战

[查看视频](https://www.bilibili.com/video/BV1m5c) → [🕒 12 分钟]

1. 在代码行左侧点击添加断点。
2. 按 `F9` 开始调试。
3. 使用 `F10` / `F11` 单步执行。
4. 在监视窗口查看变量变化。
