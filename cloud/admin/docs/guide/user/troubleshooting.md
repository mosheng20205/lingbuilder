# 问题排查

> [🕒 预计 10 分钟] | 难度：入门

## 1. 编译错误

| 错误 | 常见原因 | 处理 |
|---|---|---|
| 未定义的标识符 | 变量或函数未声明 | 检查拼写与作用域 |
| 类型不匹配 | 赋值类型不一致 | 使用类型转换 |
| 缺少分号 | 语句未正确结束 | 让编辑器自动补全 |

## 2. 运行时错误

### 2.1 程序闪退

- 检查是否有**空引用**调用（对 `空` 的对象访问属性）。
- 查看 **输出面板** 的异常堆栈，定位崩溃位置。
- 使用调试器（`F9` 断点）逐步排查。

### 2.2 中文乱码

- 确认源码文件保存为 **UTF-8 编码**。
- 确认窗口字体支持中文字符。

## 3. 环境问题

| 问题 | 处理 |
|---|---|
| 缺少 Visual C++ 运行库 | 官方网站下载并安装 Redistributable |
| 杀毒软件误报 | 将安装目录加入白名单 |
| 权限不足 | 以管理员身份运行 |
