# 安装与启动

> [🕒 预计 15 分钟] | 难度：入门 | 适用于：Windows 10/11

![安装流程导览](./assets/placeholder-install.png)

## 1. 系统要求

安装 LingBuilder 前，请确认本机满足以下最低配置：

| 项目 | 最低要求 | 推荐配置 |
|---|---|---|
| 操作系统 | Windows 10 1809 (64 位) | Windows 11 22H2 (64 位) |
| 处理器 | 双核 2.0 GHz | 四核 3.0 GHz 及以上 |
| 内存 | 4 GB | 8 GB 及以上 |
| 磁盘空间 | 2 GB 可用空间 | SSD，预留 5 GB |
| 运行库 | Microsoft Visual C++ Redistributable 2015-2022 | 最新版 |

> [!TIP]
> 如果系统未安装 Microsoft Visual C++ Redistributable，安装向导会自动检测并提示下载，请按照提示完成后再继续安装 LingBuilder。

## 2. 下载安装包

1. 打开浏览器，访问 LingBuilder 官网首页。
2. 在页面顶部导航栏点击 **下载**。
3. 根据系统架构选择对应的安装包：
   - **x64 版本**：适用于绝大多数 64 位 Windows 系统。
   - **Win32 版本**：适用于 32 位 Windows 系统。
4. 将安装包保存到本地任意位置（建议保存到 **下载** 文件夹）。

> [!WARNING]
> 请务必从官网或官方发布的下载链接获取安装包，切勿从第三方网站下载，以免造成安全风险或损坏的安装包。

## 3. 运行安装向导

1. 双击下载好的安装包文件。
2. 如果系统弹出 **用户账户控制 (UAC)** 窗口，点击 **是** 允许安装程序运行。
3. 选择界面语言（默认 **简体中文**），点击 **确定**。
4. 阅读 **许可协议**，勾选 **我接受许可协议中的条款**，点击 **下一步**。
5. 选择安装路径：
   - 默认路径为 `C:\Program Files\LingBuilder`。
   - 如需自定义路径，点击 **浏览** 选择目标文件夹。
6. 选择是否创建 **桌面快捷方式**（建议勾选）。
7. 点击 **安装**，等待进度条完成。
8. 安装完成后，点击 **完成** 退出向导。

## 4. 首次启动向导

首次启动 LingBuilder 时会进入 **首次启动向导**，引导用户完成基础配置：

1. 选择 **界面主题**：
   - **深色主题**（默认）
   - **浅色主题**
2. 设置 **工作区目录**：选择用于存放项目的文件夹。
3. 选择 **默认语言**（默认跟随系统）。
4. 等待 **模块加载** 完成（首次加载可能需要 30 秒至 1 分钟）。
5. 点击 **进入工作台**，即完成首次配置。

![首次启动向导](./assets/placeholder-screen.png)

## 5. 验证安装是否成功

安装并完成首次启动后，可以通过以下方式确认 LingBuilder 正常工作：

1. 在工作台顶部菜单选择 **文件** > **新建项目**。
2. 在弹出的对话框中选择 **空白窗口项目**，输入项目名称，点击 **创建**。
3. 在主工具栏点击 **运行**（绿色 ▶ 按钮）。
4. 如果程序窗口正常弹出且无报错，说明安装成功。

## 6. 常见安装问题

### 6.1 运行时提示缺少 DLL

如果启动时提示缺少 `VCRUNTIME140.dll` 等文件，说明系统缺少 Visual C++ 运行库。

1. 打开官网 **下载** 页面，在 **运行库** 区域下载并安装 **Microsoft Visual C++ Redistributable 2015-2022**。
2. 安装完成后重启 LingBuilder。

### 6.2 杀毒软件拦截

- LingBuilder 为本地编译型开发工具，部分杀毒软件可能将首次编译产生的临时文件误报为风险程序。
- 请将 LingBuilder 安装目录加入杀毒软件的白名单，或暂时关闭实时防护后重试。

### 6.3 安装后无法启动

- 检查系统是否满足最低配置要求。
- 尝试右键 LingBuilder 快捷方式，选择 **以管理员身份运行**。
- 若仍无法启动，请查看安装目录下的日志文件，或联系技术支持。
