# 版本发布说明

> [🕒 浏览约 3 分钟] | 主要版本变更记录。详细日志见 `更新记录/` 目录。

## 0.6.x

| 版本 | 亮点 |
|---|---|
| 0.6.0 | 新增 AI 对话式编程、AI Bridge 多模型接入、模块市场增强 |
| 0.6.1 | 完善模块依赖冲突检测、新增窗口设计器容器布局、AI 代码审查 |

## 0.5.x

| 版本 | 亮点 |
|---|---|
| 0.5.8 | 新增工具箱、快捷键自定义、性能分析器 |
| 0.5.5 | 可视化窗口设计器 GA、模块市场上线 |
| 0.5.0 | 首次公开预览版发布 |

## 升级建议

- 0.5.x 用户可以跨版本升级到 0.6.x。升级前备份项目，升级后首次构建可能需要重新索引模块。
- 历史版本（低于 0.5.0）的 IDE 不再维护，建议尽快升级。

> [!NOTE]
> 详细版本日志（含 API 变更、已修复问题）请参见各版本 `更新记录/` 目录下的对应文件。
