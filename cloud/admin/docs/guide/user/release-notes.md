## 更早版本

0.2.x 系列持续迭代了窗口设计器、模块生态、AI Bridge 与构建链路等基础能力（0.2.8 → 0.2.1），详见 IDE 内置的"关于"面板中的版本说明。

## 升级建议

- 升级前备份项目目录；升级后首次 `F5` 构建会重新物化模块依赖，耗时略长属正常现象。
- 旧版 `.lbmod` 模块包（schemaVersion 1）不再兼容，请使用模块迁移工具或从模块市场重新获取 v2 包。
- 历史版本的 IDE 不再维护，建议保持升级到最新版。

> [!NOTE]
> 详细版本日志（含 API 变更、已修复问题）请参见各版本 `更新记录/` 目录下的对应文件。
