## 更早版本

### 0.6.3（2026-09-04）

- EdgeView 浏览器模块补齐 271 条中文命令的完整参考与可复制示例，补充异步任务、Runtime 要求和安全边界说明。
- AI 模块导入、校验和 `.lbmod` 导出统一使用严格门禁，重复文件、危险路径、缺少命令绑定或缺少文档示例时会阻止导入/导出，失败不会留下半成品。
- 窗口设计器新增复选框、单选框的选中填充色和选中标记色配置，修复未选中控件显示为实心的问题。
- 修复动态图像控件播放 GIF 时旧帧位图未释放造成的 GDI/内存资源增长；修复 FBro SDK 安装被短暂占用时的重命名失败。
- 管理后台令牌支持跨标签页安全刷新；应用内在线更新补齐分片下载、断点续传、完整性校验、取消和失败回退状态。

### 0.6.2（2026-09-02）

- 发布 Windows x64 stable 安装包，包含 CEF3 Bridge4 生成修复、云端 SDK 清单验签/sequence 展示和 IDE 在线更新链路修复。
- 正式联网安装包使用 `https://api.lingbuilder.com`，不内置 CEF3/FBro SDK，浏览器 SDK 按需下载。

0.2.x 系列持续迭代了窗口设计器、模块生态、AI Bridge 与构建链路等基础能力（0.2.8 → 0.2.1），详见 IDE 内置的"关于"面板中的版本说明。

## 升级建议

- 升级前备份项目目录；升级后首次 `F5` 构建会重新物化模块依赖，耗时略长属正常现象。
- 旧版 `.lbmod` 模块包（schemaVersion 1）不再兼容，请使用模块迁移工具或从模块市场重新获取 v2 包。
- 历史版本的 IDE 不再维护，建议保持升级到最新版。

> 详细版本日志（含 API 变更、已修复问题）请参见各版本 `更新记录/` 目录下的对应文件。
