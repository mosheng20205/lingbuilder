# 术语表

> [🕒 浏览约 3 分钟] | LingBuilder 常见术语与概念说明。

## A

### AI Bridge

LingBuilder 内置的模型服务连接中心，用于管理多个 AI 模型供应商的 API 连接与权限设定。

## B

### BYOK（Bring Your Own Key）

用户使用自有模型服务商 API Key 的模式，替代内置云端配额。参见 [AI Bridge 配置](/guide/ai/bridge-config)。

## C

### CDP（Chrome DevTools Protocol）

Chrome DevTools 协议，通过 WebSocket 与 Chromium 浏览器通信，实现自动化控制与调试。

## L

### LingCpp

LingBuilder 面向中文开发者的编程语言，使用中文关键字编写 Windows 桌面程序，同时兼容标准 C++。

### `.lbmod`

LingBuilder 模块打包格式，扩展名为 `.lbmod`，包含模块代码与元数据。

### `.lbsln` / `.lbproj`

LingBuilder 项目文件格式。`.lbsln` 为解决方案文件，`.lbproj` 为项目文件。

## M

### MCP（Model Context Protocol）

模型上下文协议，连接 AI 模型与外部工具的标准协议。参见 [MCP 工具协议](/guide/ai/mcp)。

## W

### 窗口设计器

LingBuilder 可视化表单设计工具，支持拖放控件、配置属性、绑定事件。

## 模块

LingBuilder 的可扩展功能单元，通过模块市场安装和使用。每个模块可提供控件、函数或 API 封装。

## 模块市场

LingBuilder 内置的在线模块商店，支持搜索、浏览、一键安装第三方模块。
