# 数据类型手册

> [🕒 预计 20 分钟] | 难度：入门

本节介绍 LingCpp 中常用数据类型的声明、转换与使用要点。

## 1. 基本类型

| 类型 | 描述 | 默认值 |
|---|---|---|
| `整数` | 32 位有符号整数 | `0` |
| `长整数` | 64 位有符号整数 | `0` |
| `小数` | 双精度浮点数 | `0.0` |
| `文本` | 字符串 | `""` |
| `逻辑` | 布尔值 | `假` |
| `字节` | 8 位无符号整 | `0` |

## 2. 类型转换

### 2.1 显式转换

```lcpp
文本 数字文本 = "42"
整数 数字 = 转换到整数(数字文本)

整数 计数值 = 5
文本 结果文本 = "计数：" + 计数值
```

### 2.2 常用转换函数

| 函数 | 转换 |
|---|---|
| `转换到整数(文本)` | 文本 → 整数 |
| `转换到小数(文本)` | 文本 → 小数 |
| `转换到文本(任意)` | 任意 → 文本 |

## 3. 文本操作

```lcpp
文本 问候 = "hello"
文本 大写 = 问候.变大写()      // "HELLO"
文本 拼接 = 大写 + " LingBuilder"
整数 长度 = 拼接.长度           // 16
逻辑 包含 = 拼接.包含("Ling")   // 真
```

## 4. 数组与列表

```lcpp
数组<整数> 分数 = { 90, 85, 95 }
分数.追加(88)

整数 总数 = 分数.数量           // 4
整数 第一项 = 分数.取(0)        // 90
循环 (整数 i = 0; i < 分数.数量; i = i + 1)
{
    调试输出(分数.取(i))
}
```

## 5. 常见陷阱

- 用 `+` 拼接文本与整数时，LingCpp 会自动做文本转换。
- 直接比较 `文本` 类型时使用 `==`，判断为空使用 `如果 (名称 == "")`。
- 访问数组越界索引会抛出运行时错误，访问前请检查 `数量`。
