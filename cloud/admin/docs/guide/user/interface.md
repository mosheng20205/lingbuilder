# 界面导航

> [🕒 预计 10 分钟] | 难度：入门

![主窗口布局](./assets/placeholder-interface.png)

## 1. 主窗口布局

LingBuilder 工作台采用 **左侧导航 + 中央编辑区 + 右侧面板** 的三栏布局：

| 区域 | 名称 | 用途 |
|---|---|---|
| 顶部 | **菜单栏** | 文件(F)、编辑(E)、视图(V)、项目(P)、工具(T)、帮助(H) 六个菜单入口 |
| 顶部 | **工具栏** | 常用操作快捷按钮（新建、保存、编译并热运行等） |
| 左侧 | **解决方案资源管理器** | 展示项目文件树，双击打开文件 |
| 中央 | **代码编辑器** | 编辑 `.lingcpp` / `.lcpp` 源文件 |
| 中央 | **窗口设计器** | 可视化拖放控件并配置属性 |
| 右侧 | **工具箱** | 可拖入窗体的控件列表 |
| 右侧 | **属性面板** | 显示并编辑当前选中控件的属性 |
| 底部 | **状态栏** | 显示当前行号、编码、光标位置、构建状态 |
| 底部 | **输出面板** | 显示编译输出、运行日志、调试信息 |

## 2. 菜单栏概览

### 2.1 文件

- **文件** > **新建项目**：创建新的 LingBuilder 项目。
- **文件** > **打开项目**：打开已有项目文件。
- **文件** > **保存**：保存当前文件（快捷键 `Ctrl+S`）。
- **文件** > **全部保存**：保存所有未保存文件。
- **文件** > **原生导出**：将当前窗口项目导出为可编译的 C++ / Visual Studio 工程。

### 2.2 编辑

- **编辑** > **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`。
- **编辑** > **查找 / 替换**：`Ctrl+F` / `Ctrl+H`。
- **编辑** > **转到行**：`Ctrl+G`。

### 2.3 项目（构建与运行）

构建与运行命令集中在 **项目(P)** 菜单：

- **项目** > **编译并热运行游戏**：一键编译并运行当前项目（快捷键 `F5`）。
- **项目** > **强制停止游戏调试**：终止正在运行的程序（快捷键 `Shift+F5`）。
- **项目** > **生成解决方案 / 重新生成解决方案 / 清理解决方案**：标准构建三件套。
- **项目** > **设为启动项目**：多项目解决方案中指定默认运行目标。

## 3. 底部状态栏

状态栏从左到右依次显示：

| 指示项 | 说明 |
|---|---|
| **就绪 / 正在构建** | 当前工作台状态 |
| **行号 : 列号** | 代码编辑器光标位置 |
| **编码** | 当前文件编码，默认 UTF-8 |
| **语言** | 当前文件语言（LingCpp / C++ / Markdown） |
| **Git 分支**（如有） | 当前所在分支与变更数 |

## 4. 常用快捷键速查表

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存当前文件 |
| `Ctrl+Shift+S` | 全部保存 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | 复制 / 粘贴 / 剪切 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |
| `F5` | 编译并热运行游戏 |
| `Shift+F5` | 强制停止游戏调试 |
| `Ctrl+空格` | 触发代码补全 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+,` | 打开设置 |

> [!TIP]
> 快捷键可在 **工具(T)** > **设置...** 中自定义。部分快捷键与扩展输入法冲突时，可在同一界面调整。

## 5. 首次使用建议

1. 打开任意示例项目，熟悉 **解决方案资源管理器** 与 **代码编辑器** 的联动。
2. 将鼠标悬停到每个工具栏按钮上，查看其功能提示。
3. 点击右侧 **工具箱** 中的控件并拖入窗口设计器，体验可视化设计流程。
