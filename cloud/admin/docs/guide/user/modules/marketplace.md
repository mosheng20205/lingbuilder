# 模块市场

> [🕒 预计 10 分钟] | 难度：入门

![模块市场界面](./assets/placeholder-modules.png)

## 1. 打开模块市场

模块市场用于浏览、搜索和安装可复用的功能扩展模块。打开方式：

在左侧边栏底部的 **模块** 组中打开模块检查器，切换到 **模块市场** 区域。

## 2. 浏览与分类

模块市场提供分类筛选，可用分类包括：

| 分类 | 说明 |
|---|---|
| **界面** | 扩展控件与界面组件（如 new_emoji 界面库） |
| **系统** | 文件、进程等系统能力 |
| **网络** | HTTP 客户端、嵌入式浏览器等网络能力 |
| **数据库** | 数据存储与访问 |
| **图像** | 图片处理与显示 |
| **AI** | 人工智能相关能力 |
| **构建** | 构建链路与工具链扩展 |
| **其他** | 以上分类之外的模块 |

> [!TIP]
> 选择 **全部** 分类可查看市场上的所有模块。

## 3. 搜索模块

在市场顶部 **搜索框** 输入关键字（例如 `浏览器`、`http`），结果会实时过滤展示匹配的模块卡片。

## 4. 查看模块信息

每个模块卡片展示模块的 **名称 / ID**、**版本号**、**所属分类** 与 **简介**。点击卡片上的 **详情** 可查看更完整的模块信息，包括命令清单、文档与示例入口。

## 5. 安装模块

1. 在模块卡片上点击 **预览安装**。
2. LingBuilder 会解析模块包并弹出**预览确认**：模块 ID、版本、提供的中文命令、依赖与平台目标。
3. 确认后等待下载安装完成，状态变为 **已安装**。
4. 新模块提供的控件会进入设计器左侧的 **控件** 面板，中文命令会进入编辑器补全；项目还需启用该模块才会参与构建，详见 [安装与管理模块](/guide/user/modules/install-module)。

> [!IMPORTANT]
> **new_emoji 界面库** 安装并在项目中启用后，控件面板会出现 **New_Emoji 控件** 分组；但要往窗口里添加这些控件，还必须选中该窗口（不选中控件即显示窗口属性），把 **当前窗口 / 布局** 里的 **设计后端** 切换为 **new_emoji 模块**。窗口已有控件时后端锁定不能切换，需新建窗口再选后端。控件一览与用法详见 [new_emoji 原生界面库模块](/guide/user/modules/new-emoji)，后端切换见 [窗口设计器](/guide/user/window-designer)。
