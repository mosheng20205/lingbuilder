# 模块市场

> [🕒 预计 10 分钟] | 难度：入门

![模块市场界面](./assets/placeholder-modules.png)

## 1. 打开模块市场

在 LingBuilder 中，模块市场用于浏览、搜索和安装可复用的功能扩展模块。打开方式：

1. 点击主窗口右侧 **工具箱** 面板底部的 **模块市场** 按钮。
2. 或通过菜单 **工具** > **模块市场**。

## 2. 浏览与分类

模块市场顶部提供分类筛选，常见分类包括：

| 分类 | 说明 |
|---|---|
| **界面** | 扩展控件与界面组件 |
| **网络浏览器** | 嵌入式 Web 浏览、HTTP 客户端 |
| **数据文件** | Excel、JSON、CSV 等数据读写 |
| **系统自动化** | 文件、注册表、进程操作 |
| **图像媒体** | 图片处理、音视频播放 |
| **实用能力** | 加密、压缩、定时任务等 |

## 3. 搜索模块

1. 在市场顶部 **搜索框** 输入关键字，例如 `excel`。
2. 回车后市场会展示相关模块列表。
3. 结果支持按 **名称**、**作者**、**流行度**、**更新时间** 排序。

## 4. 查看模块详情

点击任意模块卡片，进入详情页，包含：

- **模块名** 与 **版本号**
- **作者** 与 **更新时间**
- **依赖** 列表（该模块依赖的其他模块）
- **适用平台**（Win32 / x64）
- **使用说明** 与 **发布历史**

## 5. 一键安装

1. 在模块详情页点击 **安装** 按钮。
2. 若模块有依赖，LingBuilder 会弹出依赖确认列表，点击 **确认并安装**。
3. 等待下载安装完成，状态变为 **已安装**。
4. 关闭市场，在 **工具箱** 中即可看到新模块提供的控件或函数。

> [!TIP]
> 安装模块后，旧项目可能需要在 **模块管理** 中手动添加引用。点击 **项目** > **模块管理** 查看当前项目已引用的模块。
