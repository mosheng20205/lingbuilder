# 安装与管理模块

> [🕒 预计 15 分钟] | 难度：入门

模块的安装与管理入口位于左侧边栏底部的 **模块** 组（模块检查器面板），所有操作都在这里完成。

## 1. 从市场安装模块

1. 在侧边栏 **模块** 组中打开模块检查器，切换到 **模块市场** 区域。
2. 按分类浏览或搜索目标模块。
3. 点击模块卡片上的 **预览安装**，确认模块信息与依赖后等待下载完成。
4. 状态变为 **已安装** 即表示模块可用。

## 2. 手动导入模块

部分模块以 `.lbmod` 文件形式离线分发，可通过手动导入安装：

1. 在侧边栏 **模块** 组中打开模块检查器。
2. 点击 **导入 .lbmod 模块包**（预览安装）入口，选择本地 `.lbmod` 文件。
3. LingBuilder 会先解析模块清单并展示**预览确认**信息（模块 ID、版本、命令、依赖、平台目标）。
4. 确认无误后完成安装。

> [!NOTE]
> `.lbmod` 本质是 zip 包，根目录必须包含 v2 格式的 `lingbuilder.module.json`。导入失败时请确认文件未被损坏、清单符合 v2 规范，且平台目标包含当前系统架构。旧版 v1 模块包需先用模块迁移工具重新打包。

## 3. 管理已安装模块

在侧边栏 **模块** 组的已安装列表中可以：

- **查看模块详情**：命令清单、binding、文档与示例。
- **启用 / 禁用模块**：禁用后模块功能不会参与补全与构建。
- **卸载模块**：从环境中移除模块。
- **更新模块**：检测到市场有更新版本时升级。

## 4. 在项目中使用模块

模块安装后，需要确保当前项目启用了该模块：

1. 在 **解决方案资源管理器** 的项目节点下展开 **模块** 组。
2. 点击 **配置项目所使用模块**，勾选目标模块。
3. 项目启用的模块会保存到 `.lingbuilder/project-modules.json`，编辑器补全与构建都会随之生效。
4. 按 `F5` 编译并热运行验证，模块运行时依赖会自动复制到构建目录。
