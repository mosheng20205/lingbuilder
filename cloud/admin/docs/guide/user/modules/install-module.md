# 安装与管理模块

> [🕒 预计 15 分钟] | 难度：入门

## 1. 从市场安装模块

1. 打开 **模块市场**。
2. 搜索目标模块并进入详情页。
3. 点击 **安装**，确认依赖后等待下载完成。
4. 状态变为 **已安装** 即表示模块可用。

## 2. 手动导入模块

部分模块以 `.lbmod` 文件形式离线分发，可通过手动导入安装：

1. 点击 **工具** > **模块管理**。
2. 点击 **导入模块**。
3. 选择本地 `.lbmod` 文件。
4. LingBuilder 会校验文件完整性，校验通过后自动安装。

> [!NOTE]
> `.lbmod` 是 LingBuilder 模块的标准打包格式。导入失败时请确认文件未被损坏，且模块架构与当前系统匹配。

## 3. 管理已安装模块

在 **项目** > **模块管理** 中可以：

- **查看已安装模块**：列出当前环境中的所有模块。
- **启用 / 禁用模块**：禁用后模块功能不会加载，但不会被卸载。
- **卸载模块**：从环境中移除模块。
- **更新模块**：检测到市场有更新版本时，可点击升级。

## 4. 在项目中使用模块

模块安装后，需要确保当前项目引用了该模块：

1. 打开 **项目** > **模块管理**。
2. 在 **已引用模块** 列表中确认目标模块已在列。
3. 若缺失，点击 **添加引用**，从已安装模块中选择。
4. 重新构建项目（`Ctrl+B`），模块功能即可生效。
