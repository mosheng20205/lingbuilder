# CEF3 浏览器模块

> [🕒 预计 8 分钟] | 难度：入门

CEF3 模块把 CEF（Chromium Embedded Framework）浏览器嵌入你的 Win32 窗口，提供导航、JavaScript 执行、代理与缓存设置、96 项中文事件，以及事件、会话、网络、传输、自动化、开发者工具、视图、平台工具等子模块能力。适合需要经典 CEF 内核、离线分发完整运行时的场景。

| 项目 | 说明 |
|---|---|
| 模块 ID | `lingbuilder.cef3.browser`（另含 CEF3 事件 / 会话 / 网络 / 传输 / 自动化 / 开发者工具 / 视图 / 平台工具等子模块） |
| 当前版本 | 3.0.0-alpha.3（alpha 阶段，接口以后续正式版为准；实时版本以 IDE 模块详情为准） |
| 设计器控件 | **CEF3浏览器** |
| SDK 依赖 | **CEF3 环境 SDK**（Chromium 150，体积大，首次构建时按需下载） |
| 平台 | Windows（Win32 / x64，MSVC 工具链） |

## 启用模块与 SDK 下载

1. 在活动栏「模块」页安装并启用 **CEF3浏览器模块**（见[安装与管理模块](/guide/user/modules/install-module)）。
2. 首次在项目中使用该模块构建（F5）、运行、原生预览或导出工程时，IDE 会弹出安装对话框，说明 SDK 名称、版本与体积，下载完成并校验 SHA-256 后自动继续。
3. 下载失败、代理配置、完全离线安装的完整流程见 [SDK 按需下载](/guide/user/advanced/sdk-download)。

## 设计器控件

在窗口设计器工具箱的模块分组中找到 **CEF3浏览器** 控件，拖到窗口上即可。窗口创建时，运行时会自动按设计器属性创建全部 CEF3 浏览器控件，然后才触发「创建完毕」事件——因此可以直接在「创建完毕」里导航。

## 快速上手

在窗口的「创建完毕」事件里导航：

```text
包 CEF3演示
使用 Win32窗口基础模块
使用 CEF3浏览器模块

类 MainWindow : 窗口
公开
  事件 _MainWindow_创建完毕()
    CEF3_导航(浏览器1, "https://www.baidu.com")
  结束
结束类
```

绑定事件（控件参数是裸 `controlRef`，处理器参数用 `&处理器名`）：

```text
绑定结果 = CEF3_绑定事件(浏览器1, "新窗口打开前", &处理新窗口)
结束

事件 处理新窗口()
    目标地址 = CEF3_取事件字段(浏览器1, "url")
    CEF3_设置事件结果(浏览器1, 2)
    调试输出(目标地址)
结束
```

- `CEF3_取事件数据` 返回当前或最近事件的主要文本；复杂事件用 `CEF3_取事件字段` 按字段名读取。
- 同步决策处理器内可调用 `CEF3_设置事件结果`：`0=默认`、`1=允许/继续`、`2=拒绝/取消`、`3=已处理`。
- 需要返回下载路径、修改后的 URL、对话框输入或认证文本时，在处理器返回前调用 `CEF3_设置事件返回文本`。
- 高频事件由 Bridge 受控采样，回调不保证运行在 Win32 窗口线程；不要在事件处理器中执行长时间阻塞操作。

## 常用命令参考

| 命令 | 说明 |
|---|---|
| `CEF3_创建(控件名)` | 按设计器属性创建指定 CEF3 浏览器；窗口创建时运行时已自动以空控件名创建全部设计器控件 |
| `CEF3_导航(控件名, 地址)` | 导航到目标地址 |
| `CEF3_刷新(控件名)` / `CEF3_停止(控件名)` | 刷新 / 停止加载 |
| `CEF3_后退(控件名)` / `CEF3_前进(控件名)` | 历史记录导航（可先用 `是否可后退/前进` 判断） |
| `CEF3_执行JS(控件名, 脚本)` | 在页面中执行 JavaScript |
| `CEF3_取标题(控件名)` / `CEF3_取地址(控件名)` | 读取当前页面标题 / 地址 |
| `CEF3_设置代理(控件名, 代理地址)` | 设置该浏览器代理（如 `http://127.0.0.1:7890`） |
| `CEF3_设置缓存目录(控件名, 目录)` | 设置独立缓存目录，实现会话隔离 |
| `CEF3_绑定事件(控件名, 事件名, &处理器名)` | 绑定中文事件处理器 |
| `CEF3_打开原生UI浏览器(控件名, 地址)` | 基于当前会话打开独立的 Chrome 原生 UI 浏览器窗口 |
| `CEF3_关闭(控件名)` | 关闭并释放浏览器 |

完整命令清单与各子模块（事件 / 会话 / 网络 / 传输 / 自动化 / 开发者工具 / 视图 / 平台工具）接口在 IDE「模块详情 → 接口 → 模块公开信息」中查看。

## 事件

事件目录共 **96 项**：通知 45 项、同步决策 47 项、高频通知 4 项，覆盖生命周期、加载与显示、网络与资源、下载、对话框、音频与打印、开发者工具协议等分类。事件名、CEF 回调对照和字段说明以模块详情内置文档《CEF3 模块事件与接口参考》为准。

## 依赖与平台限制

- 仅支持 Windows（Win32 / x64，MSVC 工具链）。
- **CEF3 环境 SDK 不随安装包内置**，首次使用按需下载；SDK 的 include / lib / runtime 必须来自同一套发布包，不要只替换单个 DLL。
- 目标机器需要随 exe 分发 CEF 运行时 DLL 组（构建产物已自动复制到 exe 同目录）。
