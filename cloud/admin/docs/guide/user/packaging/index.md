## 发布清单

向用户发布前，建议按以下清单确认：

1. **构建配置**：优化等级设置为 **发布**。
2. **运行库**：确认目标机器安装 Microsoft Visual C++ Redistributable 2015-2022。
3. **依赖模块**：确认程序引用的模块已随程序分发或可运行时检查。
4. **签名**（推荐）：对发布的可执行文件进行代码签名，降低杀毒软件误报概率。
5. **版本号**：在项目属性中更新版本号与产品名称。
