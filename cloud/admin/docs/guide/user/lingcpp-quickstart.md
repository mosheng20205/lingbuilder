# LingCpp 快速上手

> [🕒 预计 30 分钟] | 难度：入门

LingCpp 是 LingBuilder 面向中文开发者的编程语言，使用中文关键字编写 Windows 桌面程序，同时保留了对标准 C++ 的完整兼容。

## 1. 语言结构

一个最基本的 LingCpp 程序由 `程序_启动` 入口组成：

```lcpp
程序_启动()
{
    调试输出("Hello, LingBuilder!")
}
```

## 2. 数据类型

```lcpp
整数 年龄 = 18
小数 价格 = 19.99
文本 名称 = "张三"
逻辑 是否完成 = 真
```

| 类型 | 说明 | 示例 |
|---|---|---|
| `整数` | 32 位有符号整数 | `整数 年龄 = 18` |
| `小数` | 双精度浮点数 | `小数 价格 = 19.99` |
| `文本` | 字符串 | `文本 名称 = "张三"` |
| `逻辑` | 布尔值 `真` / `假` | `逻辑 完成 = 真` |

## 3. 条件与循环

```lcpp
如果 (年龄 >= 18)
{
    调试输出("已成年")
}
否则
{
    调试输出("未成年")
}

循环 (整数 i = 0; i < 5; i = i + 1)
{
    调试输出("第 " + i + " 次循环")
}
```

## 4. 函数定义

```lcpp
整数 加法(整数 a, 整数 b)
{
    返回 a + b
}

程序_启动()
{
    整数 结果 = 加法(3, 4)
    调试输出("结果：" + 结果)
}
```

## 5. 与 C++ 的关系

LingCpp 源码在编译过程中会转换为中间表示，并最终生成原生机器码。对于熟悉 C++ 的用户，可以在 `.cpp` 文件中编写标准的 C++ 代码，与 `.lcpp` 文件混用：

```cpp
#include <iostream>

void native_hello() {
    std::cout << "Native C++ code" << std::endl;
}
```

> [!TIP]
> LingCpp 使用中文括号 `（` `）` 或英文括号皆可；行尾分号可以省略，LingBuilder 会自动补全。关键字不区分大小写。
