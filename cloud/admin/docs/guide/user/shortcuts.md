# 快捷键速查表

> [🕒 预计 5 分钟] | 难度：入门

## 1. 文件与编辑

| 快捷键 | 功能 |
|---|---|
| `Ctrl+N` | 新建子程序（新手模式） |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 全部保存 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | 复制 / 粘贴 / 剪切 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |

## 2. 构建与运行

| 快捷键 | 功能 |
|---|---|
| `F5` | 编译并热运行游戏 |
| `Shift+F5` | 强制停止游戏调试 |

## 3. 调试

调试操作当前以**界面按钮**为主，未绑定全局快捷键：

| 操作 | 方式 |
|---|---|
| 设置/取消断点 | 点击编辑器左侧圆点区域；`Shift+点击` 设置条件断点 |
| 单步跳过 / 单步进入 / 单步跳出 | 使用底部 **调试** 面板中的对应按钮 |
| 继续运行到下一断点 | 调试面板 **继续** 按钮 |

## 4. 代码导航

| 快捷键 | 功能 |
|---|---|
| `F12` | 转到定义 |
| `Shift+F12` | 查找引用 |
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+G` | 转到行 |
| `Ctrl+空格` | 触发补全 |

## 5. 窗口与视图

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+`` ` ` | 切换终端面板 |

> [!NOTE]
> 快捷键可在 **工具(T)** > **设置...** 中自定义。若快捷键与输入法冲突，可在同一界面重新绑定。
