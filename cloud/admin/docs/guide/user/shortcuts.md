# 快捷键速查表

> [🕒 预计 5 分钟] | 难度：入门

## 1. 文件与编辑

| 快捷键 | 功能 |
|---|---|
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 全部保存 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | 复制 / 粘贴 / 剪切 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |

## 2. 构建与运行

| 快捷键 | 功能 |
|---|---|
| `Ctrl+B` | 构建项目 |
| `F5` | 运行当前项目 |
| `Shift+F5` | 停止运行 |

## 3. 调试

| 快捷键 | 功能 |
|---|---|
| `F9` | 切换断点 |
| `F10` | 单步跳过 |
| `F11` | 单步进入 |
| `Shift+F11` | 单步跳出 |

## 4. 代码导航

| 快捷键 | 功能 |
|---|---|
| `F12` | 转到定义 |
| `Shift+F12` | 查找引用 |
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+G` | 转到行 |
| `Ctrl+空格` | 触发补全 |

## 5. 窗口与视图

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+B` | 切换侧边栏可见性 |
| `Ctrl+`` ` | 切换终端面板 |

> [!NOTE]
> 快捷键可在 **工具** > **选项** > **键盘** 中自定义。若快捷键与输入法冲突，可在同一界面重新绑定。
