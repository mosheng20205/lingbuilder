# 调试技巧

> [🕒 预计 20 分钟] | 难度：进阶

## 1. 设置断点

1. 在代码编辑器左侧空白处点击，添加断点（红色圆点）。
2. 点击 **调试** > **开始调试** 或按 `F9`，程序运行到断点处暂停。

## 2. 单步执行

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 单步跳过 | `F10` | 执行当前语句，不进入函数 |
| 单步进入 | `F11` | 进入被调用函数内部 |
| 单步跳出 | `Shift+F11` | 跳出当前函数 |
| 继续运行 | `F5` | 运行到下一个断点 |

## 3. 变量监视

调试暂停时，可以在 **监视窗口** 中查看和修改变量值：

1. 鼠标悬停在变量名上，可查看当前值。
2. 右键变量，选择 **添加监视**，将变量固定到监视窗口。
3. 在监视窗口中双击值列，可手动**修改**变量值以测试不同分支。

## 4. 输出日志

在代码中使用 `调试输出` 函数输出调试信息：

```lcpp
调试输出("当前循环次数：" + i)
```

日志会显示在 **输出面板** 的 **调试** 页签中。

## 5. 异常定位

程序崩溃时，**输出面板** 会显示异常类型与调用堆栈。点击堆栈中的行号可跳转到对应源码位置。
