# 调试技巧

> [🕒 预计 20 分钟] | 难度：进阶

LingBuilder 提供**原生调试**能力：程序运行到断点处会真实暂停，你可以在调试面板中查看状态、单步执行，定位逻辑问题。

## 1. 设置断点并开始调试

1. 在代码编辑器**左侧圆点区域**单击，即可在该行添加断点；`Shift+点击` 可设置**条件断点**。
2. 点击 **开始原生调试** 按钮（或使用 **项目(P)** 菜单的构建运行命令），程序会先编译，成功后启动并在断点处暂停。

> [!TIP]
> 断点在编辑器行号左侧以圆点标记显示；再次单击同一位置可取消断点。

## 2. 单步执行

调试暂停后，使用底部 **调试** 面板中的按钮控制执行流程：

| 操作 | 方式 | 说明 |
|---|---|---|
| 继续 | 调试面板按钮 | 运行到下一个断点或程序结束 |
| 单步跳过 | 调试面板按钮 | 执行当前语句，不进入函数内部 |
| 单步进入 | 调试面板按钮 | 进入被调用函数内部 |
| 停止调试 | 调试面板 / `Shift+F5` | 结束本次调试会话 |

> [!NOTE]
> 单步操作当前通过调试面板按钮完成，暂未绑定键盘快捷键。`F5` 始终表示"编译并热运行游戏"，不要在调试暂停时用它继续运行。

## 3. 查看调试信息

调试暂停期间，底部调试区域会展示当前会话状态与输出。结合 `调试输出` 日志（见下节）可以快速确认变量取值与执行路径。

## 4. 输出日志

在代码中使用 `调试输出` 函数输出调试信息：

```lcpp
调试输出("当前循环次数：" + i)
```

日志会显示在底部 **输出面板** 的调试页签中，是定位循环、事件触发顺序问题的最快手段。

## 5. 异常定位

程序崩溃时，**输出面板** 会显示异常类型与调用堆栈。点击堆栈中的行号可跳转到对应源码位置。
