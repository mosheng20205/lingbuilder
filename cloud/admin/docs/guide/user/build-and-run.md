# 构建与运行

> [🕒 预计 15 分钟] | 难度：入门

## 1. 一键编译并运行

1. 点击工具栏的 **调试 (F5)** 按钮，或按 `F5`（对应菜单 **项目(P)** > **编译并热运行游戏**）。
2. **输出面板** 会显示编译进度与结果。
3. 编译成功后程序立即启动；失败时会定位到首个错误位置。
4. 程序运行中可按 `Shift+F5` 或点击 **强制停止** 终止。

## 2. 标准构建命令

在 **项目(P)** 菜单中还提供标准构建命令：

| 命令 | 说明 |
|---|---|
| **生成解决方案** | 编译当前解决方案 |
| **重新生成解决方案** | 先清理再完整编译 |
| **清理解决方案** | 删除中间产物与输出文件 |
| **设为启动项目** | 多项目解决方案中指定默认运行目标 |

## 3. 输出类型与平台

- **输出类型**：窗口项目生成 EXE 可执行程序；选择 **Windows 动态链接库** 模板创建的项目会生成 DLL 并以 `DllApi.lcpp` 作为接口入口。
- **平台**：当前构建闭环基于 Windows，支持 Win32 / x64 目标。
- 需要交付 Visual Studio 工程时，使用 **原生导出** 生成可直接用 VS 打开编译的工程目录。

> [!NOTE]
> 发布程序供他人使用时，请确认目标机器已安装 Microsoft Visual C++ Redistributable；模块依赖的运行时 DLL 会自动复制到 exe 同目录。

## 4. 常见构建错误

| 错误提示 | 处理方法 |
|---|---|
| 未找到头文件 / 模块依赖缺失 | 在侧边栏 **模块** 组中确认项目已启用所需模块；模块的头文件与库会在构建时自动物化 |
| 链接失败：无法解析的外部符号 | 检查是否调用了未启用模块中的命令；确认命令名拼写与补全一致 |
| 控件引用不存在 | 设计器中删除或改名控件后，代码里的引用需同步更新（诊断会标红提示） |
