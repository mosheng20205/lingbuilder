# 构建与运行

> [🕒 预计 15 分钟] | 难度：入门

## 1. 构建项目

1. 点击工具栏 **构建** 按钮，或按 `Ctrl+B`。
2. **输出面板** 会显示编译进度与结果。
3. 构建成功后显示 **构建成功**；失败时会定位到首个错误位置。

## 2. 运行项目

- 点击 **运行** 按钮（或按 `F5`）：先构建，成功后启动程序。
- 点击 **停止**（或按 `Shift+F5`）：终止正在运行的程序。

## 3. 构建配置

在 **项目** > **项目属性** 中可修改：

| 设置项 | 说明 |
|---|---|
| **输出类型** | EXE（可执行程序）或 DLL（动态链接库） |
| **平台** | Win32 或 x64 |
| **优化等级** | 调试 / 发布 / 最快速度 / 最小体积 |

> [!NOTE]
> 发布程序供他人使用时，建议将 **优化等级** 设置为 **发布**，并确认目标机器已安装 Microsoft Visual C++ Redistributable。

## 4. 常见构建错误

| 错误提示 | 处理方法 |
|---|---|
| 未找到头文件 | 检查 **项目属性** > **包含目录** 是否正确 |
| 链接失败：无法解析的外部符号 | 确认引用的库已在 **项目属性** > **链接** 中添加 |
| 内存不足 | 关闭无关程序，或调整编译器内存限制 |
