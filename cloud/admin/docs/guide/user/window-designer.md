# 窗口设计器

> [🕒 预计 30 分钟] | 难度：入门

![窗口设计器界面](./assets/placeholder-window-designer.png)

## 1. 打开窗口设计器

在 **项目资源管理器** 中双击任意 `.lcpp` 文件，编辑器上方会出现 **可视化设计** 与 **源代码** 两个视图选项卡。

- 点击 **可视化设计**：进入窗口设计器，可在所见即所得画布上拖放控件。
- 点击 **源代码**：进入代码编辑器，可手写 LingCpp 代码。

> [!TIP]
> 在可视化设计模式下修改控件后，切回源代码可看到对应代码自动生成；在源代码模式下书写控件声明后，切回设计视图也会同步渲染控件。

## 2. 拖放控件

1. 在右侧 **工具箱** 面板中，展开 **常用控件** 分类。
2. 单击选择一个控件（例如 **按钮**），将其拖拽到中央设计画布上。
3. 松开鼠标，控件即放置到窗体上。

工具箱中包含以下常用控件：

| 控件 | 说明 |
|---|---|
| **按钮** | 触发点击事件 |
| **标签** | 显示静态文本 |
| **文本框** | 单行输入 |
| **多行文本框** | 多行文本输入 |
| **下拉框** | 下拉选择列表 |
| **单选框 / 复选框** | 单选 / 多选选项 |
| **列表框** | 显示条目列表 |
| **进度条** | 显示任务进度 |
| **图片框** | 显示图片 |
| **表格** | 展示数据的二维网格 |

## 3. 调整控件布局

- **选中控件**：单击画布上的控件，控件四周出现可拖动的调节手柄。
- **移动控件**：按住控件拖到新位置，或用键盘方向键微调（按住 `Shift` 可加快步进）。
- **调整大小**：拖拽控件四角的调节手柄。
- **对齐**：同时选中多个控件（按住 `Ctrl` 多选），使用工具栏中的 **对齐** 按钮统一对齐。

> [!NOTE]
> 初次放置的控件使用默认尺寸与位置。建议在 **属性面板** 中为控件设置精确的 `左边`、`顶边`、`宽度`、`高度` 数值，保证不同分辨率下布局一致。

## 4. 配置属性

选中任一控件后，右侧 **属性面板** 会显示该控件的全部可选属性。常用的窗口级属性包括：

| 属性 | 说明 |
|---|---|
| **标题** | 窗口/控件上的显示文本 |
| **左边 / 顶边** | 控件相对父容器的位置 |
| **宽度 / 高度** | 控件尺寸（单位：像素） |
| **可视** | 是否显示，`真` 或 `假` |
| **可用** | 是否可交互，`真` 或 `假` |
| **背景色** | 背景颜色 |
| **字体** | 字体名称、大小与样式 |

修改属性后点击 **回车** 或切换视图，改动即写入代码。

## 5. 绑定事件

1. 在 **属性面板** 顶部点击 **事件** 选项卡，列出该控件支持的事件。
2. 双击任意事件（例如 `点击`），编辑器自动生成事件处理函数。
3. 在函数体中编写响应逻辑：

```lcpp
事件 按钮1_点击(按钮 发送者)
{
    标签1.标题 = "按钮已被点击"
}
```

LingBuilder 支持以下常见事件：

| 事件 | 触发时机 |
|---|---|
| **点击** | 用户单击控件 |
| **双击** | 用户双击控件 |
| **内容改变** | 文本框内容变化 |
| **按下 / 抬起** | 在控件上按下 / 松开鼠标或键盘 |
| **创建 / 销毁** | 控件被创建 / 销毁时 |

## 6. 使用布局容器

当界面控件较多时，建议配合布局容器管理控件位置：

- **横向容器**：子控件从左到右排列，宽度改变时自动重排。
- **纵向容器**：子控件从上到下排列。
- **网格容器**：按行列网格排列，适合对齐表单。

将普通控件拖入容器后，容器会自动接管其布局计算。
