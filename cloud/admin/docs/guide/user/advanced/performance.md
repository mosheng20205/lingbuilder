# 性能优化

> [🕒 预计 20 分钟] | 难度：进阶

## 1. 界面卡顿优化

### 1.1 大量控件

- 避免在单个窗口中放置过多静态控件；优先使用 **列表控件** 渲染列表数据。
- 界面更新时，使用 **挂起刷新** 批量修改控件属性，最后一次性恢复：

```lcpp
窗口.挂起刷新()
循环 (整数 i = 0; i < 1000; i = i + 1)
{
    列表框1.添加条目("第 " + i + " 条")
}
窗口.恢复刷新()
```

### 1.2 异步处理耗时操作

文件读写、网络请求等耗时操作放入异步任务，避免阻塞界面线程。

## 2. 内存优化

- 及时释放不再使用的对象，为大型对象及时置空引用。
- 列表或缓存频繁增长时，注意清理过期数据。
- 图片资源尽量压缩尺寸后再加载。

## 3. 构建优化

| 优化手段 | 说明 |
|---|---|
| 增量构建 | 仅编译修改过的文件 |
| 优化等级 | 发布模式开启最高优化 |
| 最小体积 | 压缩输出，减少加载时间 |

在 **项目** > **项目属性** > **优化** 中调整。

## 4. 分析工具

LingBuilder 提供内置的性能分析器（**调试** > **性能分析**），可查看：

- **CPU 占用**最高的函数
- **内存分配**热点
- **界面渲染**帧率
