# 新建窗口项目

> [🕒 预计 20 分钟] | 难度：入门

![创建项目流程](./assets/placeholder-screen.png)

## 1. 创建项目

1. 启动 LingBuilder，进入工作台。
2. 点击 **文件** > **新建项目**（也可在左侧 **解决方案资源管理器** 或欢迎页中点击 **新建项目**）。
3. 在 **新建项目** 对话框中选择模板并填写信息：
   - **项目模板**：选择 **空白 Win32 窗口**（也可选 **你好 LingBuilder** 示例、**new_emoji FBro 浏览器外壳** 或 **Windows 动态链接库**）。
   - **项目名称**：输入项目名称，例如 `HelloWorld`。
4. 点击 **创建**，LingBuilder 将自动生成项目骨架文件。

## 2. 项目文件结构

创建完成后，**解决方案资源管理器** 中会生成以下内容：

| 文件 / 目录 | 说明 |
|---|---|
| `项目名.lbsln` | 解决方案文件 |
| `main.lcpp` | 窗口项目的程序源码入口 |
| `.lingbuilder/` 目录 | 保存解决方案配置与项目模块引用等数据 |

> [!NOTE]
> 选择 **Windows 动态链接库** 模板时不会生成窗口设计器模型，工作台会直接定位到 `DllApi.lcpp` 接口入口文件。

## 3. 在设计器中布置界面

1. 双击 `main.lcpp` 打开编辑器，切换到 **可视化设计** 模式进入窗口设计器。
2. 从工具箱拖入一个 **按钮** 控件放到窗体上。
3. 切回源代码视图，可以看到控件声明已自动同步到代码。

## 4. 给按钮添加点击事件

1. 在 **窗口设计器** 中选中按钮，为其指定事件处理器名（如 `开始按钮_点击`），或在代码中使用 `&处理器名` 引用语法绑定。
2. 在事件函数中编写以下代码：

```lcpp
事件 开始按钮_点击()
{
    调试输出("按钮被点击了")
    信息框("你好，LingBuilder！", "提示")
}
```

3. 按 `Ctrl+S` 保存。

## 5. 运行项目

1. 点击工具栏 **调试 (F5)** 按钮，或按 `F5`。
2. 首次运行会自动编译项目，编译完成后弹出程序窗口。
3. 点击窗口中的按钮，应看到信息弹窗 **你好，LingBuilder！**。

## 6. 常见问题

> [!NOTE]
> 如果事件没有触发，请检查代码中的处理器引用是否使用了 `&处理器名` 语法，且处理器名与代码中的定义完全一致。

> 如果编译报错 **缺少模块**，请在左侧 **解决方案资源管理器** 的 **模块** 组中点击 **配置项目所使用模块**，确认对应模块已启用。
