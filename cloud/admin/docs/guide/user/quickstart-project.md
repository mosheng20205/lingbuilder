# 新建窗口项目

> [🕒 预计 20 分钟] | 难度：入门

![创建项目流程](./assets/placeholder-screen.png)

## 1. 创建项目

1. 启动 LingBuilder，进入工作台。
2. 点击 **文件** > **新建项目**，或按 `Ctrl+N`。
3. 在 **新建项目** 对话框中：
   - **项目类型**：选择 **窗口项目 (Window Project)**。
   - **项目名称**：输入项目名称，例如 `HelloWorld`。
   - **位置**：选择项目保存目录。
   - **解决方案**：选择加入现有解决方案或新建。
4. 点击 **创建**，LingBuilder 将自动生成项目骨架文件。

## 2. 项目文件结构

创建完成后，**项目资源管理器** 中会生成以下文件：

| 文件 | 说明 |
|---|---|
| `main.lcpp` | 程序入口文件，包含 `主窗口` 类定义与 `程序_启动` 入口 |
| `项目名.lbsln` | 解决方案文件 |
| `项目名.lbproj` | 项目文件 |
| `依赖/` 目录 | 存放模块依赖 |

## 3. 在代码中声明主窗口

打开 `main.lcpp`，可以看到 LingBuilder 自动生成的窗口模板：

```lcpp
// 程序入口文件
窗口 主窗口
{
    标签 标题文本 = "你好，LingBuilder！"
    按钮 开始按钮 = "点击我"
}
```

> 代码块使用 **LingCpp 扩展名** `.lcpp` 标识，LingBuilder 会为 LingCpp 提供关键字高亮与补全。

## 4. 给按钮添加点击事件

1. 在 **窗口设计器** 中，双击任意一个按钮控件，编辑器会自动插入事件处理函数。
2. 在事件函数中编写以下代码：

```lcpp
事件 开始按钮_点击(按钮 发送者)
{
    调试输出("按钮被点击了")
    信息框("你好，LingBuilder！", "提示")
}
```

3. 按 `Ctrl+S` 保存。

## 5. 运行项目

1. 点击工具栏 **运行** 按钮，或按 `F5`。
2. 首次运行会自动编译项目，编译完成后弹出程序窗口。
3. 点击窗口中的按钮，应看到信息弹窗 **你好，LingBuilder！**。

## 6. 常见问题

> [!NOTE]
> 如果运行时报错提示 **未找到主窗口**，请检查 `main.lcpp` 中是否声明了至少一个 `窗口` 类型，且 `程序_启动` 中已创建该窗口实例。

> 如果编译报错 **缺少模块**，请在 **工具箱** 或 **模块市场** 中确认对应模块已安装。
