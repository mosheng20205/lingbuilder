# 常见问题

> [🕒 浏览约 5 分钟] | 汇总使用 LingBuilder 的常见问题与解答。

## 安装与启动

### 安装时提示需要 Visual C++ 运行库

LingBuilder 依赖 Microsoft Visual C++ Redistributable 2015-2022。请从官网下载并安装最新版，安装后重试。

### 安装后桌面没有快捷方式

启动安装向导，在 **安装选项** 页面勾选 **创建桌面快捷方式**，或安装完成后手动从安装目录创建。

### 首次启动模块加载时间过长

首次加载模块需要下载并索引，视网络情况约需 30 秒至 1 分钟。后续启动不会再重复下载。

## 项目与构建

### 构建成功后双击 EXE 无法运行

双击运行前请确保：
1. 目标机器已安装 Visual C++ 运行库。
2. 程序依赖的所有模块文件与 EXE 在相同目录或已注册路径下。
3. 若杀毒软件拦截，将程序加入白名单。

### 提示“未找到主窗口”

检查 `main.lcpp` 或项目入口文件中是否声明了 `窗口` 类型，并在 `程序_启动` 函数中创建了窗口实例。

## AI 功能

### AI 对话一直提示“等待响应”

1. 检查网络连接是否正常。
2. 若使用 BYOK 模式，确认 API Key 有效且未超限速。
3. 若使用内置云端服务，确认账户配额充足。

### AI 返回的代码构建报错

将报错信息粘贴回 AI 对话，AI 会依据上下文给出修正建议。也可手动检查代码中引用的控件名、模块名是否与当前项目一致。

## 模块

### 安装模块后工具箱中未显示

在 **解决方案资源管理器** 的项目节点下展开 **模块** 组，点击 **配置项目所使用模块** 确认目标模块已被启用。部分模块安装后需重新构建项目才会更新工具箱。

### 模块市场无法连接

检查网络是否可访问市场服务器。若在受限网络内，请咨询网络管理员开放相关域名。
