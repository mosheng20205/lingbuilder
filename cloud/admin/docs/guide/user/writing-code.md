# 编写代码

> [🕒 预计 15 分钟] | 难度：入门

## 1. 代码编辑器

LingBuilder 内置代码编辑器支持：

- **语法高亮**：LingCpp、C++、C#、Markdown 等语言。
- **代码补全**：输入时自动提示关键字、变量、函数（`Ctrl+空格`）。
- **括号匹配**：悬停可查看匹配的括号。
- **多光标编辑**：按住 `Alt` 点击可添加多个光标。

## 2. 格式化代码

选中代码后，点击 **编辑** > **格式化** 或按 `Shift+Alt+F`，LingBuilder 会自动整理缩进与空格。

## 3. 代码折叠

- 点击代码左侧空白处的折叠箭头，可折叠或展开函数或代码块。
- 快捷键：`Ctrl+Shift+[` 折叠、`Ctrl+Shift+]` 展开。

## 4. 文件编码

默认保存为 UTF-8 编码。如需导入其他编码的源码，可在 **文件** > **打开** 时选择编码，或通过右下角状态栏的编码按钮切换。

## 5. 快速导航

- **转到定义**（`F12`）：跳转到函数或变量的定义位置。
- **查找引用**（`Shift+F12`）：查找所有引用位置。
- **文件搜索**（`Ctrl+P`）：按文件名快速打开文件。

## 6. 功能代码：用功能库复用中文代码

在项目树的 **功能代码** 节点新建功能库，把可被窗口和其他功能库复用的代码集中存放。功能库是无状态的，一个 `.lcpp` 文件声明一个功能库：

```lcpp
功能库 数学工具
公开:
  整数型 求和(整数型 左数, 整数型 右数)
      返回 左数 + 右数
  结束
结束功能库
```

调用约定：

- 调用必须带功能库名称，写成 `功能库名.功能名(...)`，例如 `数学工具.求和(1, 2)`；功能库之间的相互调用和库内递归调用同样要带库名。
- 功能用 `公开:` / `私有:` 划分可见性；私有功能只能在同一个功能库文件内调用。
- 功能库名称应与文件名保持一致（建议通过项目树重命名功能库，让文件名、声明和调用保持一致）。
- 功能库内不能声明类、项目变量、常量或数据类型；首版功能库不支持参数默认值，调用时需显式传参。
- 复用到其他项目时，把功能库 `.lcpp` 文件复制进目标项目即可；构建时功能库与窗口代码一起确定性生成真实 C++ 函数。
