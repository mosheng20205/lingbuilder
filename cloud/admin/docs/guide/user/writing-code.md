# 编写代码

> [🕒 预计 15 分钟] | 难度：入门

## 1. 代码编辑器

LingBuilder 内置代码编辑器支持：

- **语法高亮**：LingCpp、C++、C#、Markdown 等语言。
- **代码补全**：输入时自动提示关键字、变量、函数（`Ctrl+空格`）。
- **括号匹配**：悬停可查看匹配的括号。
- **多光标编辑**：按住 `Alt` 点击可添加多个光标。

## 2. 格式化代码

选中代码后，点击 **编辑** > **格式化** 或按 `Shift+Alt+F`，LingBuilder 会自动整理缩进与空格。

## 3. 代码折叠

- 点击代码左侧空白处的折叠箭头，可折叠或展开函数或代码块。
- 快捷键：`Ctrl+Shift+[` 折叠、`Ctrl+Shift+]` 展开。

## 4. 文件编码

默认保存为 UTF-8 编码。如需导入其他编码的源码，可在 **文件** > **打开** 时选择编码，或通过右下角状态栏的编码按钮切换。

## 5. 快速导航

- **转到定义**（`F12`）：跳转到函数或变量的定义位置。
- **查找引用**（`Shift+F12`）：查找所有引用位置。
- **文件搜索**（`Ctrl+P`）：按文件名快速打开文件。
