# MCP 能做什么

> [🕒 预计 8 分钟] | 难度：入门

一句话：LingBuilder 内置一个本地服务 **AI Bridge**，把你的工作区能力以 **23 个受控工具**（MCP 标准协议）开放给外部 AI——Claude Code、Codex CLI、Gemini CLI、灵码等。接入之后，AI 就像坐在你电脑前的助手：**能看项目、改代码、建项目、编译运行、生成 DLL、封装模块**，但每一步都受控、可预览、可撤销。

本文只讲「AI 能帮你干什么」；工具的参数写法与协议细节见 [MCP 工具协议](/guide/ai/mcp)。

## 开始之前：唯一的前提

- AI Bridge **随 IDE 自动启动**，你不需要手动开服务；
- 让外部 AI 连上它：在 **帮助 > AI Bridge 连接中心** 复制连接配置，粘给 AI 客户端即可，步骤见 [AI Bridge 连接配置](/guide/ai/bridge-config)；
- 默认权限是**预览模式**：AI 的写操作先出预览，你批准才真正生效。

接好以后，AI 能帮你做下面这八件事。

## 一、看懂你的项目

AI 可以列出工作区的文件树、读取源码、做全文搜索，还能知道你有哪些项目、每个项目启用了哪些模块。所以你不用手动复制粘贴代码给它——直接说「看看我的 MainWindow.lcpp」就行。

*用到的工具：`workspace.list` · `file.read` · `file.search`*

## 二、帮你写代码、改代码

这是最常用的能力。AI 修改代码的方式是**提交修改提案**：哪几行改成什么样，先给你预览，确认后才落盘。改完它会自动跑一遍**中文语法诊断**——比如源码里引用了设计器中不存在的控件，会在编译前就被中文报错拦下，并给出修法。

*用到的工具：`edit.propose` · `edit.apply` · `lingcpp.diagnostics`*

## 三、从零新建项目

不用自己点菜单，AI 可以直接用受控中文模板建好项目：空白窗口、最小示例、SQLite 会员管理（增删改查）、FBro 浏览器外壳、Windows 控制台、Windows 动态链接库。建错了、或者你不满意，还能**一键撤销**这次创建。

*用到的工具：`project.templates` · `project.create` · `project.create.undo`*

## 四、编译并运行

AI 调用的是你电脑上的真实编译器（MSVC），**真编译、真运行，不是模拟输出**。编译失败时它能看到编译器原样日志并自动修复；运行起来后可以读输出、等退出码、随时停止。这和你在 IDE 里按 F5 走的是同一条链路。

*用到的工具：`build.run` · `run.wait` · `run.log` · `build.stop`*

## 五、生成真正的 DLL

需要一个给易语言、C/C++ 程序调用的 DLL？AI 可以把项目建成 DLL 项目（专用模板，或窗口项目加 `outputType: "dll"`），源码里声明为「公开」的子程序就是导出函数，编译产出 **`.dll` 与导入库 `.lib`**。约定很简单：导出名用英文或拼音。

*用到的工具：`project.create` + `build.run`*

## 六、做你自己的模块

想把一组中文命令做成可复用、可分发的模块？AI 端到端走完六步：**建骨架 → 写源码 → 校验 → 打包 `.lbmod` → 预检 → 安装并启用**。装好后反过来问它「这个模块有哪些命令、怎么调」，它也能给出完整签名和示例。教程见 [用 AI 生成模块](/guide/user/modules/ai-module-dev)。

*用到的工具：`module.scaffold` → `writeFiles` → `validate` → `pack` → `installPreview` → `install`，查询用 `modules.list` / `module.info`*

## 七、导出 Visual Studio 工程

想脱离 AI、回到 Visual Studio 继续开发？AI 可以把生成的 C++ 工程完整导出（`.sln` / `.vcxproj`），在 VS 里打开、编译、调试都可以；只想看看 AI 生成的 C++ 长什么样，用预览模式即可，不会写进导出目录。

*用到的工具：`native.export` · `native.preview`*

## 八、排查界面与代码组织

「窗口里到底有哪些控件？」「为什么 exe 打开是空白？」「代码太长了要不要拆？」——AI 能读到设计器组件清单和代码组织建议（比如提醒把公共逻辑拆成功能库），给出中文答案，而不是让你猜。

*用到的工具：`lingcpp.diagnostics`（附带组件清单与代码组织视图）*

## 你可以这样用它

几个马上能试的说法：

- 「帮我做一个带按钮的窗口，点按钮弹出中文问候。」
- 「把这个字符串工具做成 DLL，我要在易语言里调用。」
- 「封装一个文本工具模块，提供 文本_统计字符数、文本_反转 两个命令。」
- 「编译报错了，读一下构建日志帮我修。」
- 「工作区里有个模块我没用过，先查查它有哪些命令再写个示例。」

## 为什么可以放心

- **只在你的电脑上**：AI Bridge 只监听 `127.0.0.1` 回环地址，外网连不上；
- **写操作逐项批准**：默认预览模式下，改文件、建项目、装模块都要你显式确认；只读模式则全部不可写；
- **AI 开不了任意命令**：就算切到 yolo 模式，AI 也只能用这 23 个受控工具，不能执行任意系统命令；
- **全程留痕**：每次调用都写入审计日志；项目创建可撤销，文件修改走提案预览；
- **AI 只出文本**：真正写盘、编译、安装都由本地确定性流程执行，结果可复查。
