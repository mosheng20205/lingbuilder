# AI 代码审查

> [🕒 预计 10 分钟] | 难度：入门

## 1. 审查当前文件

1. 打开需要审查的 `.lcpp` 或 `.cpp` 文件。
2. 点击工具栏 **AI 审查** 按钮，或右键编辑器选择 **AI 审查当前文件**。
3. AI 会在侧边 **审查面板** 中按严重程度列出问题：
   - **错误**：可能导致崩溃或逻辑错误。
   - **警告**：潜在风险或性能问题。
   - **建议**：改善可读性与代码风格。

## 2. 审查选中代码

只希望审查部分代码时：

1. 在编辑器中选中目标代码段。
2. 右键选择 **AI 审查选中代码**。
3. 审查结果仅针对当前选区。

## 3. 审查报告说明

每个审查条目包含：

| 字段 | 说明 |
|---|---|
| **位置** | 问题所在的行号 |
| **严重程度** | 错误 / 警告 / 建议 |
| **说明** | 问题描述与可能影响 |
| **修复建议** | AI 给出的修改方案（可一键应用） |

## 4. 应用修复

1. 在审查面板中点击某一条目，编辑器自动定位到对应位置。
2. 点击 **应用修复**，查看 AI 生成的替换代码。
3. 确认无误后点击 **应用**，代码即被替换。
4. 审查完毕后重新构建（`Ctrl+B`）验证。

> [!WARNING]
> AI 审查是辅助工具而非替代人工审查。对涉及资金、安全等关键逻辑的修改，建议由开发者人工复核后再应用。

## 5. 审查范围与配额

- 单次审查消耗一定量的 AI 配额（内置服务）或自有 Key 额度。
- 大型文件建议分段审查，既节省配额又便于定位。
