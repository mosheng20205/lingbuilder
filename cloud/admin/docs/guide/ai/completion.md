# AI 代码补全

> [🕒 预计 10 分钟] | 难度：入门

## 1. 启用 AI 补全

1. 打开 **工具** > **选项** > **AI 设置**。
2. 在 **智能补全** 区域打开 **启用 AI 代码补全**。
3. 选择补全触发的模式：
   - **自动**：输入过程中自动给出建议。
   - **手动**：按 `Alt+\`，仅在请求时显示建议。

> [!NOTE]
> AI 补全消耗与对话相同来源的配额（内置服务）或自有 API Key 额度（BYOK）。

## 2. 使用 AI 补全

1. 在代码编辑器中输入代码，当光标停留约 1 秒，AI 会给出灰色建议文本。
2. 按 `Tab` **接受建议**，按 `Esc` 取消。
3. 如果需要查看多个候选，按 `Alt+\` 展开候选列表，用方向键选择后回车确认。

## 3. 补全示例

输入：
```lcpp
程序_启动()
{
    // 用户输入姓名后弹出欢迎信息
```

AI 补全建议：
```lcpp
程序_启动()
{
    文本 姓名 = 输入框("请输入姓名", "")
    如果 (姓名 != "")
    {
        信息框("欢迎，" + 姓名, "提示")
    }
}
```

## 4. 提高补全准确度

- AI 补全会参考当前文件与项目上下文，保持文件命名和注释规范有助于提升准确度。
- 在补全前先写出函数的关键逻辑注释，能引导 AI 生成更贴合意图的代码。
