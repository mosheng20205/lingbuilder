# 代码补全

> [🕒 预计 10 分钟] | 难度：入门

LingBuilder 的代码编辑器内置了面向中文代码的**本地补全**：根据当前项目启用的模块、设计器控件和语言关键字，在输入时直接给出可插入的候选项。所有补全部在本地完成，不消耗 AI 点数，也不依赖网络。

> [!NOTE]
> 由云端模型逐字续写代码的"AI 智能补全"正在规划中，当前版本尚未提供。

## 1. 触发方式

- **自动触发**：输入中文命令名、控件名或类型名时自动弹出候选列表。
- **手动触发**：按 `Ctrl+Space` 随时唤出补全。
- 用方向键选择候选，按 `Enter` 或 `Tab` 确认插入，`Esc` 关闭列表。

## 2. 补全内容

### 2.1 模块命令

补全列表会包含当前项目**已启用模块**的全部中文命令（如 `HTTP客户端_GET异步`、`线程_提交完成`），并显示参数签名与说明。未启用模块的命令不会出现在候选里，避免误调用。

### 2.2 控件引用（controlRef）

在窗口项目中，凡是需要引用设计器控件或资源的参数位置：

- 补全只列出当前作用域内**类型兼容的控件**；
- 插入的是不带引号的裸控件名；
- 引用不存在的控件会被诊断标红，详见 [代码诊断](/guide/ai/review)。

### 2.3 事件处理器引用

在需要回调处理器的位置（如异步完成的处理器参数），补全会列出当前文件中以 `&` 引用的处理器名，选择后自动插入 `&处理器名` 形式。

### 2.4 类型与关键字

输入数据类型或语句关键字时有对应候选；新手模式下还支持**拼音缩写**快速定位，例如输入 `zss` 可匹配 `整数型`，输入 `lj` 可匹配 `逻辑型`。

## 3. 补全示例

在已启用网络模块的项目中输入 `HTTP客户端_`：

```lcpp
客户端 = HTTP客户端_创建客户端()
```

编辑器会在输入过程中列出该前缀下的全部命令（创建客户端、设置超时、GET 异步……），选中后自动补全名称与参数括号。

## 4. 让补全更好用

- 在 **解决方案资源管理器** 的模块组中配置项目所使用的模块——补全范围随之变化。
- 控件命名保持唯一且见名知意，控件引用补全才更精准。
- 处理器先定义、后引用，处理器引用补全才会出现对应名称。
