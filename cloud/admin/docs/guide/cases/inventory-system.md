# 进销存管理软件

> 优秀案例 · [🕒 阅读约 2 分钟]

![进销存系统封面](./assets/placeholder-case.png)

**一句话介绍**：面向中小型商户的一体化进销存管理系统，覆盖采购、销售、库存全流程。

## 核心模块

| 模块 | 版本 | 用途 |
|---|---|---|
| `lingbuilder.win32.basic` | 内置 | 主界面与业务表单 |
| `datagrid-utils` | v1.8.2 | 商品列表分页与排序展示 |
| `xlsx-reader` | v0.9.0 | 供货单模板导入 |

## 亮点功能

- **库存预警**：低于安全库存自动标红并生成采购建议。
- **条码扫码录入**：支持扫码枪快速添加商品。
- **多仓库调拨**：按仓库维度跟踪库存数量。
- **进销存报表**：日报、月报一键统计毛利与销售额。

## 技术栈

| 项目 | 版本 |
|---|---|
| LingBuilder | v0.6.0 |
| SQLite | 3.45 |
| 报表引擎 | 内置 |

## 开发者心得

“进销存业务里最繁琐的表格交互，在 LingBuilder 中用 **数据表格** 控件配合少量代码就能实现排序、筛选和编辑。扫码录入部分用控件事件驱动，完全不需要处理底层输入法细节。”
