# 桌面效率工具箱

> 优秀案例 · [🕒 阅读约 2 分钟]

![桌面工具箱封面](./assets/placeholder-case.png)

**一句话介绍**：集合截图、OCR 文字识别、划词翻译等高频操作的桌面效率套件，通过全局热键快速唤起。

## 核心模块

| 模块 | 版本 | 用途 |
|---|---|---|
| `lingbuilder.win32.basic` | 内置 | 悬浮窗口与托盘图标 |
| `screen-capture` | v1.2.0 | 区域截图 |
| `ocr-engine` | v0.5.0 | 本地 OCR 识别 |
| `translate-client` | v1.0.3 | 调用在线翻译接口 |

## 亮点功能

- **全局热键呼出**：任意界面按 `Alt+X` 唤起截图。
- **离线优先**：OCR 在本地完成，翻译结果缓存于本地库。
- **剪贴板增强**：识别结果自动写入剪贴板，支持一键格式清理。
- **低内存常驻**：常驻内存占用控制在 80 MB 以内。

## 技术栈

| 项目 | 版本 |
|---|---|
| LingBuilder | v0.5.8 |
| ONNX Runtime | 1.17 |

## 开发者心得

“全局热键和托盘图标让工具类应用的使用体验很关键。LingBuilder 对系统级 API 做了封装，我们只写业务逻辑，不处理底层的窗口消息。本地 OCR 用到了模块对 ONNX 模型加载的支持，几行代码即可推理。”
