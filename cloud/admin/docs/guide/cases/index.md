# 优秀案例

> [🕒 浏览约 5 分钟] | 展示基于 LingBuilder 构建的真实应用。

本栏目收录使用 LingBuilder 开发的优秀案例，展示窗口程序、AI 能力、模块生态的落地成果。每个案例仅公开技术亮点与效果截图，不包含完整实现细节。

## 实战案例

| 案例 | 一句话介绍 |
|---|---|
| [蓝奏云纯协议下载器](/guide/cases/lanzou-downloader) | 不开浏览器，TLS 指纹仿真直连蓝奏云解析直链并落盘 |
| [局域网快传](/guide/cases/lan-transfer) | 局域网设备自动发现，文字文件互传，手机扫码即用 |
| [Cloak 指纹浏览器](/guide/cases/cloak-fingerprint-browser) | 多开防关联：每窗口独立指纹、独立代理、独立缓存 |
| [PDD 多账号浏览器](/guide/cases/pdd-multi-account-browser) | 拼多多商家多账号指纹浏览器与采集工作台 |
| [DLL 导出查看器](/guide/cases/dll-export-viewer) | 拖入 DLL 列出全部导出函数，中文导出名正确显示 |
| [小红书 Web 纯协议客户端](/guide/cases/xhs-pure-protocol-client) | 零浏览器依赖：签名离线计算 + 带签名直连业务接口 |
| [抖音工具箱](/guide/cases/douyin-toolbox) | 抖音多账号管理与纯协议私信工作台 |
| [AI Agent 智能助手](/guide/cases/ai-agent-assistant) | 无边框网页壳桌面 AI 助手：对话 / 图片 / 视频 / Web 服务 |
| [SunnyNet 进程代理](/guide/cases/process-proxy-workbench) | 按进程把指定程序流量透明转发到 SOCKS5/HTTP/HTTPS 代理 |
| [进程变速工作台](/guide/cases/process-speed-control) | 指定进程时间流速 0.01~10000 倍率热调 |
| [抓包工作台](/guide/cases/capture-workbench) | Fiddler 式中文抓包：HTTPS 解密、检查器、构造发送与改写规则 |
| [任务管理器](/guide/cases/task-manager) | new_emoji 设计器模型复刻 Win10 任务管理器六页签，每秒实时监控 |
