# 多媒体播放器

> 优秀案例 · [🕒 阅读约 2 分钟]

![多媒体播放器封面](./assets/placeholder-case.png)

**一句话介绍**：基于 LingBuilder 开发的本地媒体播放器，支持多格式音视频、外挂字幕与播放列表。

## 核心模块

| 模块 | 版本 | 用途 |
|---|---|---|
| `lingbuilder.win32.basic` | 内置 | 播放主界面与控件 |
| `media-core` | v2.0.1 | 音视频解码与渲染 |
| `subtitle-parser` | v0.4.0 | 外挂字幕解析 |

## 亮点功能

- **多格式支持**：主流音视频容器与编码格式。
- **外挂字幕**：支持 SRT / ASS 字幕与编码自动识别。
- **播放列表**：拖拽排序、记忆播放进度。
- **硬件加速**：调用显卡硬解，低功耗流畅播放 4K。

## 技术栈

| 项目 | 版本 |
|---|---|
| LingBuilder | v0.6.0 |
| FFmpeg（模块内置） | 6.1 |
