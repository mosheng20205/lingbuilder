# 进阶实战系列

学完[零基础入门系列](/guide/tutorials/beginner)之后的下一站：每集围绕**一个内置模块**做出一个真正能用的小软件——数据能存下来、网络能连出去、耗时任务不卡界面。本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。
