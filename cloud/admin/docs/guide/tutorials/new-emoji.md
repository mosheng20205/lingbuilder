# new_emoji 合集

依托 **new_emoji 原生界面库（lingbuilder.new_emoji.ui）**：基于 Direct2D/DirectWrite 的自绘 UI 引擎，**93 个现代风格组件**——容器布局、输入选择、导航、数据展示、图表、弹层反馈一应俱全，还原生支持**彩色 Emoji 表情**，让易语言界面彻底告别 Windows 98 风格。合集共 25 集，本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。

> new_emoji 是收费模块：第一次启用时会弹出登录框，用 LingBuilder 账号登录完成授权即可（授权一次，全合集通用）。

前置要求：学完[零基础入门系列](/guide/tutorials/beginner)即可。四集连学约 2 小时，学完你就掌握了 NE 开发的地基：把窗口切成 new-emoji 后端、用容器与布局组织界面、用输入类控件收数据、用选择类控件做设置面板——所有控件文字直接写彩色 Emoji。

## 选择类（05~07，制作中）

下拉与级联：Select/SelectV2 虚拟选择器/Cascader/TreeSelect · 日期与时间：DatePicker/TimePicker/DateTimePicker/Calendar · 特殊输入：InputTag/Mentions/Upload/ColorPicker。

## 导航篇（08~10，制作中）

标签页 Tabs 与分段控制 Segmented · 菜单 Menu 与侧边栏 Aside · 面包屑/锚点/步骤条/分页/回到顶部/固钉。

## 数据展示篇（11~17，制作中）

列表三件套 ListBox/RichList/Descriptions · 表格 Table 两集（列定义与行数据/单元格交互）· 树与折叠面板 · 统计与进度 · 图表两集（折线柱状/环形仪表盘）。

## 反馈篇（18~20，制作中）

消息与通知 Message/Notification/Alert · 弹层家族 Dialog/Drawer/Popover/Tooltip · 加载与状态 Loading/Skeleton/Empty/Result。

## 高级篇（21~25，制作中）

展示杂项 Carousel/Timeline/Watermark/Tour · 窗口结构件 Header/PageHeader/Omnibox/BrowserViewport · 主题定制亮暗换肤 · 综合实战两集（现代风数据看板/个人信息管理系统界面换装）。
