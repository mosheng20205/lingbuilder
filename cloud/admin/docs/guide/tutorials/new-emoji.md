# new_emoji 合集

依托 **new_emoji 原生界面库（lingbuilder.new_emoji.ui）**：基于 Direct2D/DirectWrite 的自绘 UI 引擎，**93 个现代风格组件**——容器布局、输入选择、导航、数据展示、图表、弹层反馈一应俱全，还原生支持**彩色 Emoji 表情**，让易语言界面彻底告别 Windows 98 风格。合集共 25 集，本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。

> new_emoji 是收费模块：第一次启用时会弹出登录框，用 LingBuilder 账号登录完成授权即可（授权一次，全合集通用）。
