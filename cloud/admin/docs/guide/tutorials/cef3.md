# CEF3 浏览器合集

依托 **CEF3 浏览器模块（lingbuilder.cef3.browser）**：Chromium 官方嵌入式框架 CEF（Chromium Embedded Framework），命令规模为三大浏览器内核之最（500+ 条），老系统兼容性与协议层能力是它的立身之本。合集共 30 集，本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。

> CEF3 浏览器模块是收费模块：第一次启用时会弹出登录框，用 LingBuilder 账号登录完成授权即可（授权一次，全合集通用）；Chromium 运行时由随包「CEF3 内核 SDK 包」自动补齐，无需单独下载。
