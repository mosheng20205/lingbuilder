# FBro 指纹浏览器合集

依托 **FBro 指纹浏览器模块（lingbuilder.fbro.browser）**：CEF 深度定制内核（Chrome 135），465 条命令、30 个命令族，核心卖点两句话——**浏览器指纹伪装**＋**多开防关联**，基于隔离 RequestContext 的独立档案体系。合集共 29 集，本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。

> FBro 指纹浏览器模块是收费模块：第一次启用时会弹出登录框，用 LingBuilder 账号登录完成授权即可（授权一次，全合集通用）；Chrome 135 运行时由随包「FBro 内核 SDK 包」自动补齐，无需单独下载。`FBroVIP_` 开头的赞助会员命令从进阶集数才登场，基础篇全部命令普通授权即可跟做。

## 指纹与多开篇（05~10，制作中）

指纹配置入门（设计器属性方式）· 指纹 JSON 桥 schema 详解（权威键表、「键名错＝没设」红线）· 五步纯代码多开链 · 实例代理一账号一代理一指纹 · VIP 能力（新窗口转标签页与原生 UI）· 批量多实例工作台。

## 自动化篇（11~19，制作中）

CDP 调试端口与连接 · CDP 自动化实战 · 网页填表两集（填表族 22）· DOM 遍历快照两集（遍历族 16）· JS 交互与本地页面 · 同步辅助类两集（HsValue/HsDom/HsList/HsBool/HsInt/HsStr）。

## 拦截与协议篇（20~24，制作中）

获取资源响应正文（响应族 19）· 修改资源响应与提交数据 · WS 拦截与内嵌服务器（五钩子）· 异步请求与网络族 · 纯协议请求实战（TLS 指纹级过风控）。

## 界面与杂项篇（25~29，制作中）

右键菜单定制（菜单族 35＋右键参数族 19）· 下载管理（下载族 16）· 证书与图像 · 字典/列表/值/缓冲/消息/流 · 综合实战：多账号矩阵管理器。
