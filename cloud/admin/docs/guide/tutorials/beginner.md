# 零基础入门实战系列

这是为「完全没接触过编程」的读者准备的系列图文教程：从安装 LingBuilder 开始，一路做出自己的第一个 exe、学会写中文代码，直到能独立做出登录界面这样像模像样的小软件。

系列特点：

- 每集只讲一件事，讲完立刻上手；全部截图来自真机，红框和序号标出要点哪里。
- 全程使用**新手模式**（中文结构编辑器），不需要任何编程基础。
- 每一集做完都有一个看得见的小成果，集与集之间循序渐进。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。
