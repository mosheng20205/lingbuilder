# Edge 浏览器合集

依托 **EdgeView 浏览器模块（WebView2 内核）**：把一整个 Microsoft Edge 装进你自己的窗口，205 条命令覆盖导航、取数、填表、会话、下载、脚本注入等 21 个命令族。合集共 26 集，**已全部上线**——从「把浏览器摆进窗口」一路学到「网页监控机器人」。本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。
