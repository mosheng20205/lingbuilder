# Edge 浏览器合集

依托 **EdgeView 浏览器模块（WebView2 内核）**：把一整个 Microsoft Edge 装进你自己的窗口，205 条命令覆盖导航、取数、填表、会话、下载、脚本注入等 21 个命令族。合集共 26 集，从「把浏览器摆进窗口」一路学到「网页监控机器人」。本系列每集都提供**一键导入的 .lcpppkg 源码包**，在官网「示例源码」里按集数名称即可下载。

**页面里的截图都可以点击放大**，放大后点击空白处或按 `Esc` 关闭。

前置要求：学完[零基础入门系列](/guide/tutorials/beginner)即可；**EdgeView 浏览器模块是内置模块**，随项目自动启用（需 Windows 10/11 自带的 WebView2 运行时）。四集连学约 2 小时，学完你就掌握了内嵌浏览器开发的地基：把控件摆进窗口、用导航族命令操作它、用事件让它主动汇报、用 JavaScript 深入页面。

## 网页操作篇（05~09，制作中）

网页取数实战 · 网页填表三部曲（输入点击/下拉选择/自动登录）· 页内查找与定位。

## JS 双向桥篇（10~12，制作中）

## 会话与多开篇（13~17，制作中）

## 下载与媒体篇（18~20，制作中）

## 高级篇（21~26，制作中）

无头实例适用边界 · 资源与缓冲 · 异步任务与工作线程 · 通知/扩展/对象 · 开发者工具协作 · 综合实战「网页监控机器人」。
