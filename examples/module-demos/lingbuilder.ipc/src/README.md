# 进程通信模块完整演示

- 模块 ID：`lingbuilder.ipc`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：8
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供单连接命名管道 UTF-8 文本通信和命名互斥体单实例判断。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `IPC_创建管道服务端` | `IPC_创建管道服务端(名称)` | bool | 创建本机命名管道服务端。 |
| 2 | `IPC_等待管道客户端` | `IPC_等待管道客户端()` | bool | 等待一个管道客户端连接。 |
| 3 | `IPC_连接管道` | `IPC_连接管道(名称, 超时毫秒)` | bool | 连接本机命名管道。 |
| 4 | `IPC_发送文本` | `IPC_发送文本(文本)` | bool | 发送一条长度前缀 UTF-8 文本。 |
| 5 | `IPC_接收文本` | `IPC_接收文本()` | wideString | 接收一条长度前缀 UTF-8 文本。 |
| 6 | `IPC_创建单实例锁` | `IPC_创建单实例锁(名称)` | bool | 创建命名互斥体；首次创建返回真。 |
| 7 | `IPC_取错误` | `IPC_取错误()` | wideString | 返回最近 IPC 错误。 |
| 8 | `IPC_关闭` | `IPC_关闭()` | void | 关闭管道和单实例锁。 |
