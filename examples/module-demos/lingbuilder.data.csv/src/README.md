# CSV数据模块完整演示

- 模块 ID：`lingbuilder.data.csv`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 RFC 4180 风格的 CSV 字段转义、行生成和字段读取。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `CSV_转义字段` | `CSV_转义字段(字段)` | wideString | 按需添加双引号并转义字段。 |
| 2 | `CSV_生成两列` | `CSV_生成两列(第一列, 第二列)` | wideString | 生成包含两个字段的一行 CSV。 |
| 3 | `CSV_生成三列` | `CSV_生成三列(第一列, 第二列, 第三列)` | wideString | 生成包含三个字段的一行 CSV。 |
| 4 | `CSV_字段数量` | `CSV_字段数量(行文本)` | int | 解析一行 CSV 并返回字段数。 |
| 5 | `CSV_取字段` | `CSV_取字段(行文本, 索引)` | wideString | 按从 0 开始索引读取字段。 |
