# CSV数据模块完整演示

- 模块 ID：`lingbuilder.data.csv`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：18
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

RFC 4180 风格 CSV：字段转义与行生成、按文件整体读取、记录级解析（支持引号内换行、双写引号、CRLF/CR/LF、自定义分隔符、空行跳过）与 UTF-8/GBK/GB18030/UTF-16/UTF-32 编码自动识别；解析结果用 表格数据 快照按行列读取。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `CSV_转义字段` | `CSV_转义字段(字段)` | wideString | 按需添加双引号并转义字段。 |
| 2 | `CSV_生成两列` | `CSV_生成两列(第一列, 第二列)` | wideString | 生成包含两个字段的一行 CSV。 |
| 3 | `CSV_生成三列` | `CSV_生成三列(第一列, 第二列, 第三列)` | wideString | 生成包含三个字段的一行 CSV。 |
| 4 | `CSV_字段数量` | `CSV_字段数量(行文本)` | int | 解析一行 CSV 并返回字段数。 |
| 5 | `CSV_取字段` | `CSV_取字段(行文本, 索引)` | wideString | 按从 0 开始索引读取字段。 |
| 6 | `CSV_打开文件` | `CSV_打开文件(文件路径, 编码名称, 分隔符, 含表头)` | 表格数据 | 按整个文件读取 CSV 并返回 表格数据 快照；引号内的换行属于字段内容，不会被当成换行。 |
| 7 | `CSV_解析文本` | `CSV_解析文本(CSV文本, 分隔符, 含表头)` | 表格数据 | 把多行 CSV 文本解析成 表格数据 快照；用于内容已在内存里的场景。 |
| 8 | `数据表_取错误` | `数据表_取错误()` | wideString | 返回当前线程最近一次表格操作失败的中文说明；每次进入 数据表_ 或 CSV_ 命令时清空。 |
| 9 | `数据表_行数` | `数据表_行数(表格)` | int | 返回数据行数量，不含表头行；句柄无效返回 0。 |
| 10 | `数据表_列数` | `数据表_列数(表格)` | int | 返回列数量，取所有记录的最大宽度；句柄无效返回 0。 |
| 11 | `数据表_列名` | `数据表_列名(表格, 列号)` | wideString | 返回指定列的名称；无表头或表头缺名时为 列N。 |
| 12 | `数据表_取文本` | `数据表_取文本(表格, 行号, 列号)` | wideString | 按行列读取单元格文本；越界返回空文本。 |
| 13 | `数据表_单元格类型` | `数据表_单元格类型(表格, 行号, 列号)` | int | 返回单元格内容形态：0=空，1=整数，2=小数，3=布尔，4=文本；用于决定建表列类型与绑定哪个取值命令。 |
| 14 | `数据表_取整数` | `数据表_取整数(表格, 行号, 列号)` | longLong | 把单元格按 64 位整数读取；内容不是整数时返回 0 并记录中文错误。 |
| 15 | `数据表_取小数` | `数据表_取小数(表格, 行号, 列号)` | double | 把单元格按双精度小数读取；内容不是小数时返回 0 并记录中文错误。 |
| 16 | `数据表_取布尔` | `数据表_取布尔(表格, 行号, 列号)` | bool | 把单元格读取为逻辑值：TRUE/真/1/YES/是 为真，FALSE/假/0/NO/否 为假，其它内容按假。 |
| 17 | `数据表_单元格为空` | `数据表_单元格为空(表格, 行号, 列号)` | bool | 判断单元格是否为空文本或越界；越界同样返回真。 |
| 18 | `数据表_关闭` | `数据表_关闭(表格)` | bool | 释放表格快照；句柄不存在或重复关闭返回假。 |
