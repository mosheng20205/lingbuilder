# 图标处理模块完整演示

- 模块 ID：`lingbuilder.image.icon`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：3
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提取 EXE/DLL 图标并保存为 PNG，同时提供图标数量查询。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `图标_取数量` | `图标_取数量(文件路径)` | int | 返回 EXE、DLL 或 ICO 中可提取图标数量。 |
| 2 | `图标_提取大图标到PNG` | `图标_提取大图标到PNG(文件路径, 索引, 目标路径)` | bool | 提取大图标并保存 PNG。 |
| 3 | `图标_提取小图标到PNG` | `图标_提取小图标到PNG(文件路径, 索引, 目标路径)` | bool | 提取小图标并保存 PNG。 |
