# 基础识图模块完整演示

- 模块 ID：`lingbuilder.image.recognition`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供文件图像中的颜色查找和小模板匹配，结果坐标通过状态命令读取。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `识图_查找颜色` | `识图_查找颜色(图片路径, ARGB, 容差)` | bool | 从左到右、从上到下查找接近指定颜色的像素。 |
| 2 | `识图_模板匹配` | `识图_模板匹配(图片路径, 模板路径, 容差)` | bool | 执行朴素像素模板匹配，适合小图和测试。 |
| 3 | `识图_取结果横坐标` | `识图_取结果横坐标()` | int | 返回最近识图结果横坐标，失败为 -1。 |
| 4 | `识图_取结果纵坐标` | `识图_取结果纵坐标()` | int | 返回最近识图结果纵坐标，失败为 -1。 |
| 5 | `识图_颜色相似度` | `识图_颜色相似度(ARGB一, ARGB二)` | int | 返回 RGB 最大通道差值，0 表示完全相同。 |
