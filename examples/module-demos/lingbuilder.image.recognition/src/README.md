# 基础识图模块完整演示

- 模块 ID：`lingbuilder.image.recognition`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：16
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供文件与字节集（内存图片）两种入口的颜色查找、区域限定模板匹配、多处匹配与轮询等待，结果坐标通过状态命令读取；配合 截图/投屏帧 字节集可做屏幕自动化找图找色。

| 9 | `识图_等待消失` | `识图_等待消失(图片路径, 模板路径, 容差, 超时毫秒, 间隔毫秒, 区域X, 区域Y, 区域宽, 区域高)` | bool | 轮询查找模板直到画面中不再命中；消失返回真，超时仍命中返回假。⚠️ 阻塞当前线程，其余语义与 识图_等待出现 一致。 |
