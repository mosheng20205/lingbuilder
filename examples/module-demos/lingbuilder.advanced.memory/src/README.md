# 受控内存模块完整演示

- 模块 ID：`lingbuilder.advanced.memory`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

只允许访问本模块登记的本进程内存块，拒绝任意裸地址。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `内存_申请` | `内存_申请(字节数)` | handle | 申请清零内存并返回受控句柄。 |
| 2 | `内存_写整数` | `内存_写整数(内存句柄, 偏移, 数值)` | bool | 在边界内写入 32 位整数。 |
| 3 | `内存_读整数` | `内存_读整数(内存句柄, 偏移)` | int | 在边界内读取 32 位整数。 |
| 4 | `内存_写UTF8文本` | `内存_写UTF8文本(内存句柄, 偏移, 文本)` | bool | 在边界内写入带零结尾 UTF-8 文本。 |
| 5 | `内存_读UTF8文本` | `内存_读UTF8文本(内存句柄, 偏移, 最大字节数)` | wideString | 在边界内读取 UTF-8 文本。 |
| 6 | `内存_释放` | `内存_释放(内存句柄)` | bool | 释放受控内存块。 |
