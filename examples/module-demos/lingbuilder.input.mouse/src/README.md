# 鼠标输入模块完整演示

- 模块 ID：`lingbuilder.input.mouse`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取鼠标位置并通过 SendInput 执行受控移动和单击。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `鼠标_取横坐标` | `鼠标_取横坐标()` | int | 返回鼠标当前屏幕横坐标。 |
| 2 | `鼠标_取纵坐标` | `鼠标_取纵坐标()` | int | 返回鼠标当前屏幕纵坐标。 |
| 3 | `鼠标_移动` | `鼠标_移动(横坐标, 纵坐标)` | bool | 把鼠标移动到指定屏幕坐标。 |
| 4 | `鼠标_左键单击` | `鼠标_左键单击()` | bool | 模拟鼠标左键按下并释放。 |
| 5 | `鼠标_右键单击` | `鼠标_右键单击()` | bool | 模拟鼠标右键按下并释放。 |
| 6 | `鼠标_滚轮` | `鼠标_滚轮(滚动量)` | bool | 模拟垂直滚轮，常用单位为 120。 |
