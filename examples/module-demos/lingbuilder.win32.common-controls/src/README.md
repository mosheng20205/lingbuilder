# Win32高级控件模块完整演示

- 模块 ID：`lingbuilder.win32.common-controls`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：220
- 设计器控件数：26
- 分组数：11

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供非可视文件对话框、列表视图、树形视图、选项卡、日期、工具栏、状态栏、富文本和系统通用对话框等标准 Win32 能力。
