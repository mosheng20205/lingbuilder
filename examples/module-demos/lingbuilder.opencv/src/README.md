# OpenCV 图像处理模块完整演示

- 模块 ID：`lingbuilder.opencv`
- 版本：`1.2.0`
- 类型：LingBuilder 内置模块
- 命令数：47
- 设计器控件数：0
- 分组数：3

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 OpenCV 4.14.0 的 x64 本地图像处理、模板匹配、轮廓分析、单/双缺口候选分析与视频帧读取写出模块，支持文件与内存字节集双入口；读出的帧直接流入既有图像命令链。
