# 农历日期模块完整演示

- 模块 ID：`lingbuilder.std.lunar`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：14
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供公历农历互转、闰月与月天数查询、属相干支六十甲子、二十四节气（天文算法，精确到分钟）与四柱（生辰八字）计算。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `农历_公历转农历年` | `农历_公历转农历年(时间)` | int | 返回公历日期时间对应的农历年份；无效时间返回 0。 |
| 2 | `农历_公历转农历月` | `农历_公历转农历月(时间)` | int | 返回农历月份（1～12），闰月返回负数（如闰六月得 -6）；无效时间返回 0。 |
| 3 | `农历_公历转农历日` | `农历_公历转农历日(时间)` | int | 返回农历日（1～30）；无效时间返回 0。 |
| 4 | `农历_农历转公历` | `农历_农历转公历(农历年, 农历月, 农历日)` | longLong | 把农历日期转为公历日期时间；农历月传负数表示闰月，超出年历表范围或日期不存在返回 0。 |
| 5 | `农历_公历转农历文本` | `农历_公历转农历文本(时间, 是否含属相)` | wideString | 把公历日期时间转为“丙午年七月初五”风格的中文农历文本。 |
| 6 | `农历_取闰月月份` | `农历_取闰月月份(公历年)` | int | 返回指定公历年份的农历闰月月份（1～12）；无闰月返回 0。 |
| 7 | `农历_取月天数` | `农历_取月天数(公历年, 农历月)` | int | 返回农历某月的天数（29 或 30）；农历月传负数表示闰月。 |
| 8 | `农历_取年天数` | `农历_取年天数(公历年)` | int | 返回农历全年天数（353～355 天，含闰月）。 |
| 9 | `农历_取属相` | `农历_取属相(公历年)` | wideString | 返回年份对应的属相名称。 |
| 10 | `农历_取天干地支` | `农历_取天干地支(公历年)` | wideString | 返回年份的干支文本（如 丙午），按立春分界。 |
| 11 | `农历_取六十甲子` | `农历_取六十甲子(公历年)` | wideString | 返回年份在六十甲子中的序位（1～60，如 第41甲辰），按立春分界。 |
| 12 | `农历_取节气` | `农历_取节气(公历年, 节气序号)` | longLong | 返回指定节气的日期时间（北京时间，精确到分钟）；序号 1～24 依次为小寒、大寒、立春……冬至。 |
| 13 | `农历_取节气名称` | `农历_取节气名称(节气序号)` | wideString | 返回节气序号对应的中文名称；序号超出 1～24 返回空文本。 |
| 14 | `农历_取四柱` | `农历_取四柱(时间)` | wideString | 返回日期时间的四柱（生辰八字）文本，如 甲子年 丙寅月 戊午日 庚子时；年柱月柱按节气分界。 |
