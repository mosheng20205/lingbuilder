# CPU指令能力模块完整演示

- 模块 ID：`lingbuilder.advanced.assembly`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 CPUID 和位运算封装，不执行用户提供的机器码。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `CPU_取厂商` | `CPU_取厂商()` | wideString | 返回 CPUID 厂商标识。 |
| 2 | `CPU_是否支持SSE2` | `CPU_是否支持SSE2()` | bool | 检查 SSE2。 |
| 3 | `CPU_是否支持AVX` | `CPU_是否支持AVX()` | bool | 检查 CPU 和操作系统是否启用 AVX。 |
| 4 | `位运算_统计一位数量` | `位运算_统计一位数量(数值)` | int | 统计 64 位数值中的 1 位数量。 |
| 5 | `位运算_循环左移` | `位运算_循环左移(数值, 位数)` | longLong | 执行 64 位循环左移。 |
