# 正则表达式模块完整演示

- 模块 ID：`lingbuilder.std.regex`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：10
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 C++ ECMAScript 正则语法提供匹配、查找和替换；非法表达式安全返回失败。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `正则_完全匹配` | `正则_完全匹配(文本, 表达式)` | bool | 判断整个文本是否匹配表达式。 |
| 2 | `正则_是否包含` | `正则_是否包含(文本, 表达式)` | bool | 判断文本中是否存在匹配内容。 |
| 3 | `正则_取首个` | `正则_取首个(文本, 表达式)` | wideString | 返回首个匹配文本，没有匹配或表达式非法时返回空文本。 |
| 4 | `正则_替换` | `正则_替换(文本, 表达式, 替换内容)` | wideString | 替换全部正则匹配。 |
| 5 | `正则_匹配数量` | `正则_匹配数量(文本, 表达式)` | int | 返回不重叠匹配数量。 |
| 6 | `正则_取所有匹配` | `正则_取所有匹配(文本, 表达式, 分隔符)` | wideString | 返回全部匹配文本并按分隔符依次拼接；无匹配或表达式非法时返回空文本。 |
| 7 | `正则_取第N个匹配` | `正则_取第N个匹配(文本, 表达式, 序号)` | wideString | 返回第 N 个匹配文本（序号从 0 起）；越界、无匹配或表达式非法时返回空文本。 |
| 8 | `正则_取分组` | `正则_取分组(文本, 表达式, 组序号)` | wideString | 返回首个匹配中第 N 个分组的文本（0 表示整个匹配）；分组未参与匹配、越界或表达式非法时返回空文本。 |
| 9 | `正则_取所有分组` | `正则_取所有分组(文本, 表达式, 组序号, 分隔符)` | wideString | 把每个匹配中第 N 个分组的文本（0 表示整个匹配）按分隔符依次拼接；无匹配或表达式非法时返回空文本。 |
| 10 | `正则_取匹配位置` | `正则_取匹配位置(文本, 表达式, 序号)` | int | 返回第 N 个匹配的起始位置（从 0 起，按字符计）；无匹配、越界或表达式非法时返回 -1。 |
