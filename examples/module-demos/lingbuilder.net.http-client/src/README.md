# HTTP客户端模块完整演示

- 模块 ID：`lingbuilder.net.http-client`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 WinHTTP 提供同步 HTTP/HTTPS 请求，并保留状态码、响应正文和中文错误。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `HTTP客户端_请求` | `HTTP客户端_请求(方法, 地址, 正文, 超时毫秒)` | bool | 发送一次 UTF-8 HTTP 请求。 |
| 2 | `HTTP客户端_GET` | `HTTP客户端_GET(地址)` | bool | 发送 GET 请求。 |
| 3 | `HTTP客户端_POST` | `HTTP客户端_POST(地址, 正文)` | bool | 发送 application/json UTF-8 POST 请求。 |
| 4 | `HTTP客户端_取状态码` | `HTTP客户端_取状态码()` | int | 返回最近响应的 HTTP 状态码。 |
| 5 | `HTTP客户端_取响应文本` | `HTTP客户端_取响应文本()` | wideString | 返回最近响应正文，按 UTF-8 解码。 |
| 6 | `HTTP客户端_取错误` | `HTTP客户端_取错误()` | wideString | 返回最近请求的中文错误信息。 |
| 7 | `HTTP客户端_清空状态` | `HTTP客户端_清空状态()` | void | 清空最近状态码、响应和错误。 |
