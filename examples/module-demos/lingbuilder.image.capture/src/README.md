# 屏幕截图模块完整演示

- 模块 ID：`lingbuilder.image.capture`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

截取主屏、屏幕区域或指定窗口，输出 PNG 文件或 PNG 字节集；字节集出口可直接交给 识图/OpenCV 模块做屏幕自动化找图，免临时文件。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `截图_主屏到PNG` | `截图_主屏到PNG(目标路径)` | bool | 截取主显示器并保存 PNG。 |
| 2 | `截图_区域到PNG` | `截图_区域到PNG(目标路径, 横坐标, 纵坐标, 宽度, 高度)` | bool | 截取指定屏幕区域。 |
| 3 | `截图_窗口到PNG` | `截图_窗口到PNG(目标路径, 窗口句柄)` | bool | 截取窗口边界区域。 |
| 4 | `截图_主屏到字节集` | `截图_主屏到字节集()` | bytes | 截取主显示器并返回 PNG 字节集；可直接传给 识图_模板匹配字节集 或 OpenCV_加载图像字节集，免临时文件。 |
| 5 | `截图_区域到字节集` | `截图_区域到字节集(横坐标, 纵坐标, 宽度, 高度)` | bytes | 截取指定屏幕区域并返回 PNG 字节集。 |
| 6 | `截图_窗口到字节集` | `截图_窗口到字节集(窗口句柄)` | bytes | 截取窗口边界区域并返回 PNG 字节集；配合 窗口_取自身句柄 可把本窗口画面直接交给识图模块。 |
