# 文件目录模块完整演示

- 模块 ID：`lingbuilder.fs.core`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：11
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 UTF-8 文本文件和常用文件目录操作，所有路径均使用 Unicode。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `文件_是否存在` | `文件_是否存在(路径)` | bool | 判断指定路径是否为普通文件。 |
| 2 | `目录_是否存在` | `目录_是否存在(路径)` | bool | 判断指定路径是否为目录。 |
| 3 | `文件_读取文本` | `文件_读取文本(路径)` | wideString | 按 UTF-8 读取完整文本；失败返回空文本。 |
| 4 | `文件_写入文本` | `文件_写入文本(路径, 内容)` | bool | 按 UTF-8 覆盖写入文本文件。 |
| 5 | `文件_追加文本` | `文件_追加文本(路径, 内容)` | bool | 按 UTF-8 向文件末尾追加文本。 |
| 6 | `文件_复制` | `文件_复制(来源, 目标, 允许覆盖)` | bool | 复制文件并可选择是否覆盖。 |
| 7 | `文件_移动` | `文件_移动(来源, 目标, 允许覆盖)` | bool | 移动或重命名文件。 |
| 8 | `文件_删除` | `文件_删除(路径)` | bool | 删除一个普通文件。 |
| 9 | `文件_取大小` | `文件_取大小(路径)` | longLong | 返回文件字节数，失败返回 -1。 |
| 10 | `目录_创建` | `目录_创建(路径)` | bool | 递归创建目录；目录已经存在也返回真。 |
| 11 | `目录_删除空目录` | `目录_删除空目录(路径)` | bool | 只删除空目录，不执行递归删除。 |
