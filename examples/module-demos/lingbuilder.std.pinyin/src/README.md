# 拼音处理模块完整演示

- 模块 ID：`lingbuilder.std.pinyin`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：8
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于内置汉字码表（含多音字）提供全拼、首字母、声母韵母与发音比较能力，适合中文检索与排序场景。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `拼音_取全拼` | `拼音_取全拼(文本, 分隔符)` | wideString | 把文本中每个汉字转换为小写全拼（多音字取最常用读音），非汉字字符原样保留。 |
| 2 | `拼音_取首字母` | `拼音_取首字母(文本)` | wideString | 取每个汉字读音的首个小写字母，非汉字字符原样保留，常用于首字母检索。 |
| 3 | `拼音_取所有发音` | `拼音_取所有发音(汉字, 结果数组)` | int | 取出单个汉字的全部读音（多音字返回多条，按常用度排序），返回读音数量。 |
| 4 | `拼音_取发音数目` | `拼音_取发音数目(汉字)` | int | 返回单个汉字的读音数量；非汉字字符返回 0。 |
| 5 | `拼音_取声母` | `拼音_取声母(文本)` | wideString | 取每个汉字读音的声母（zh、ch、sh 算一个声母，无声母的音节输出空）；非汉字字符原样保留。 |
| 6 | `拼音_取韵母` | `拼音_取韵母(文本)` | wideString | 取每个汉字读音的韵母（去掉声母后的部分）；非汉字字符原样保留。 |
| 7 | `拼音_发音比较` | `拼音_发音比较(汉字一, 汉字二)` | int | 按最常用读音比较两个汉字：小于返回 -1，相等返回 0，大于返回 1；非汉字按字符编码比较。 |
| 8 | `拼音_首字母匹配` | `拼音_首字母匹配(文本, 首字母序列)` | bool | 判断文本的拼音首字母序列是否以指定字母序列开头（不区分大小写），用于中文输入检索。 |
