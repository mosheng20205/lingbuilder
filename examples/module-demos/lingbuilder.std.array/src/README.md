# 数组操作模块完整演示

- 模块 ID：`lingbuilder.std.array`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：13
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

为 LingCpp 数组提供成员数、增删改查、排序和重定义能力。命令对元素类型透明，索引统一从 0 开始，越界一律安全返回而不崩溃。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `数组_取成员数` | `数组_取成员数(数组)` | int | 返回数组当前成员数量。 |
| 2 | `数组_是否为空` | `数组_是否为空(数组)` | bool | 判断数组是否没有任何成员。 |
| 3 | `数组_取成员` | `数组_取成员(数组, 索引)` | arrayElement | 按从 0 开始的索引读取成员；索引越界时返回元素类型的默认值。 |
| 4 | `数组_置成员` | `数组_置成员(数组, 索引, 值)` | bool | 覆盖指定索引的成员；索引越界时返回假且不修改数组。 |
| 5 | `数组_加入成员` | `数组_加入成员(数组, 值)` | int | 在数组末尾追加一个成员，返回追加后的成员数。 |
| 6 | `数组_插入成员` | `数组_插入成员(数组, 索引, 值)` | bool | 在指定索引前插入成员；索引等于成员数时等价于追加，越界时返回假。 |
| 7 | `数组_删除成员` | `数组_删除成员(数组, 索引)` | bool | 删除指定索引的成员，后续成员依次前移；索引越界时返回假。 |
| 8 | `数组_清空` | `数组_清空(数组)` | bool | 删除数组全部成员。 |
| 9 | `数组_查找` | `数组_查找(数组, 值)` | int | 返回首个相等成员的从 0 开始索引；未找到或元素类型不支持相等比较时返回 -1。 |
| 10 | `数组_是否包含` | `数组_是否包含(数组, 值)` | bool | 判断数组是否包含相等成员；元素类型不支持相等比较时返回假。 |
| 11 | `数组_排序` | `数组_排序(数组, 升序)` | bool | 按元素自身顺序稳定排序；元素类型不支持大小比较时返回假且不改动数组。 |
| 12 | `数组_倒序` | `数组_倒序(数组)` | bool | 把数组成员按当前顺序整体反转。 |
| 13 | `数组_重定义` | `数组_重定义(数组, 新成员数)` | bool | 调整数组成员数：变小时截断，变大时用元素类型默认值补齐；新成员数为负时返回假。 |
