# ZIP压缩模块完整演示

- 模块 ID：`lingbuilder.archive`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：4
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 Windows 自带 tar.exe 的受控参数封装创建、解压和列出 ZIP，不开放任意命令行。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `压缩_ZIP创建` | `压缩_ZIP创建(来源路径, ZIP路径)` | bool | 把文件或目录创建为 ZIP。 |
| 2 | `压缩_ZIP解压` | `压缩_ZIP解压(ZIP路径, 目标目录)` | bool | 解压 ZIP 到目标目录。 |
| 3 | `压缩_ZIP列出` | `压缩_ZIP列出(ZIP路径)` | wideString | 返回 ZIP 内文件列表。 |
| 4 | `压缩_取错误` | `压缩_取错误()` | wideString | 返回最近压缩错误。 |
