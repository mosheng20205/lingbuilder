# FBro VIP 指纹模块完整演示

- 模块 ID：`lingbuilder.fbro.vip`
- 版本：`2.0.0`
- 类型：LingBuilder 内置模块
- 命令数：3
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供不泄露授权信息的结构化 VIP 指纹入口。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `FBroVIP_应用指纹JSON` | `FBroVIP_应用指纹JSON(控件名, JSON)` | int | 通过 UTF-16 JSON 应用受控 VIP 指纹配置；不会暴露 Key。 |
| 2 | `FBroVIP_取调用次数` | `FBroVIP_取调用次数(控件名)` | wideString | 查询 VIP 指纹调用次数。 |
| 3 | `FBroVIP_清空调用次数` | `FBroVIP_清空调用次数(控件名)` | int | 清空 VIP 指纹调用次数。 |
