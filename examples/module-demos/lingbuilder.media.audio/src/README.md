# 基础音频模块完整演示

- 模块 ID：`lingbuilder.media.audio`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：17
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

使用 Windows 多媒体 API 异步播放 WAV 文件、系统声音并控制主音量。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `音频_播放WAV` | `音频_播放WAV(路径, 循环)` | bool | 异步播放 WAV 文件。 |
| 2 | `音频_停止` | `音频_停止()` | void | 停止当前 PlaySound 音频。 |
| 3 | `音频_播放系统提示` | `音频_播放系统提示()` | bool | 播放系统通知声音。 |
| 4 | `音频_取主音量` | `音频_取主音量()` | int | 返回 waveOut 主音量 0 到 100。 |
| 5 | `音频_设置主音量` | `音频_设置主音量(音量)` | bool | 设置 waveOut 主音量 0 到 100。 |
| 6 | `音频_置静音` | `音频_置静音(静音)` | void | 设置系统默认输出设备的静音状态。 |
| 7 | `音频_取静音` | `音频_取静音()` | bool | 返回系统默认输出设备是否处于静音状态。 |
| 8 | `音频_播放MP3` | `音频_播放MP3(路径, 循环)` | bool | 异步播放 MP3 音频文件（同一时间只有一个 MP3 播放通道，再次播放会替换当前曲目）。 |
| 9 | `音频_暂停MP3` | `音频_暂停MP3()` | bool | 暂停当前 MP3 播放。 |
| 10 | `音频_继续MP3` | `音频_继续MP3()` | bool | 继续被暂停的 MP3 播放。 |
| 11 | `音频_停止MP3` | `音频_停止MP3()` | bool | 停止当前 MP3 播放（播放位置归零，文件保持打开以便查询状态）。 |
| 12 | `音频_取MP3状态` | `音频_取MP3状态()` | wideString | 返回 MP3 当前状态文本：播放中、已暂停或已停止。 |
| 13 | `音频_取MP3长度` | `音频_取MP3长度()` | int | 返回当前 MP3 总时长（毫秒）；未打开文件返回 0。 |
| 14 | `音频_取MP3位置` | `音频_取MP3位置()` | int | 返回当前 MP3 播放位置（毫秒）。 |
| 15 | `音频_跳转MP3` | `音频_跳转MP3(位置毫秒)` | bool | 把 MP3 播放位置跳到指定毫秒并继续播放。 |
| 16 | `音频_播放MIDI` | `音频_播放MIDI(路径, 循环)` | bool | 异步播放 MIDI 音乐（同一时间只有一个 MIDI 通道）。 |
| 17 | `音频_停止MIDI` | `音频_停止MIDI()` | bool | 停止当前 MIDI 播放。 |
