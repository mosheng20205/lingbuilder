# INI 配置模块完整演示

- 模块 ID：`lingbuilder.config.ini`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

使用 Windows Unicode 配置 API 读取和写入 INI 文件。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `INI_读文本` | `INI_读文本(文件, 节, 键, 默认值)` | wideString | 读取 INI 文本值。 |
| 2 | `INI_读整数` | `INI_读整数(文件, 节, 键, 默认值)` | int | 读取 INI 整数值。 |
| 3 | `INI_写文本` | `INI_写文本(文件, 节, 键, 值)` | bool | 写入 INI 文本值。 |
| 4 | `INI_写整数` | `INI_写整数(文件, 节, 键, 值)` | bool | 写入 INI 整数值。 |
| 5 | `INI_删除键` | `INI_删除键(文件, 节, 键)` | bool | 删除指定 INI 键。 |
| 6 | `INI_删除节` | `INI_删除节(文件, 节)` | bool | 删除整个 INI 节。 |
