# Word文档模块完整演示

- 模块 ID：`lingbuilder.data.word`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：27
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读写 .docx 文档：标题/段落/表格/图片追加、{{占位符}} 模板批量替换、一键生成报告、导出 PDF（本模块子集）与表格 Excel 互转，无需安装 Microsoft Word。

## 命令清单

|---:|---|---|---|---|
| 1 | `Word_创建文档` | `Word_创建文档()` | Word文档 | 新建一个仅存在于内存的 .docx 文档；调用 Word_保存文档 才写出文件。 |
| 2 | `Word_打开文档` | `Word_打开文档(文件路径)` | Word文档 | 打开既有 .docx 文档：可读段落表格、替换占位符、追加内容后另存。 |

| 5 | `Word_释放全部` | `Word_释放全部()` | void | 释放当前进程内全部文档句柄。 |
| 6 | `Word_取全文本` | `Word_取全文本(文档)` | wideString | 返回全部段落与表格单元格文本：段落之间换行分隔，单元格之间制表符分隔。 |

| 15 | `Word_添加段落` | `Word_添加段落(文档, 文本, 样式)` | bool | 在文档末尾追加一个文本段落。 |
| 16 | `Word_添加表格` | `Word_添加表格(文档, 行数, 列数)` | bool | 在文档末尾追加一个带边框的空表格，之后用 Word_设置单元格文本 填内容。 |
| 17 | `Word_设置单元格文本` | `Word_设置单元格文本(文档, 表格索引, 行, 列, 文本)` | bool | 覆写表格单元格文本。 |
| 18 | `Word_添加图片` | `Word_添加图片(文档, 图片路径, 宽度, 高度)` | bool | 在文档末尾插入一张内联图片。 |
| 19 | `Word_替换占位符` | `Word_替换占位符(文档, 占位名, 替换值)` | int | 全文替换一处占位符，返回替换次数（0 表示模板中没有该占位符）。段落级合并 run 后替换，IME/拼写检查把 {{名称}} 拆进多个文本片段也能正确命中；表格单元格内同样生效。 |
| 20 | `Word_批量替换占位符` | `Word_批量替换占位符(文档, 替换JSON)` | int | 按 JSON 对象批量替换全部占位符，返回总替换次数。 |

| 22 | `Word_导出PDF` | `Word_导出PDF(文档, 输出路径)` | bool | 把文档导出为 PDF：中文走 CID 字体方案（查看器字体替换，Chrome/Edge/WPS 可直接显示），表格自动分页并重复表头，图片按比例嵌入。仅支持本模块内容子集（段落/表格/图片）；文档含文本框、浮动图形等未支持元素时明确报错并指出元素类型，不会静默丢内容。 |

| 26 | `Word_取版本` | `Word_取版本()` | wideString | 返回随附运行桥版本与内置组件信息。 |
