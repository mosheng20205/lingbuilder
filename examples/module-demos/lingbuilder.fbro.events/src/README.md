# FBro事件模块完整演示

- 模块 ID：`lingbuilder.fbro.events`
- 版本：`2.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 UTF-16 JSON 事件包、同步决策与动态处理器绑定。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `FBro_取事件数据` | `FBro_取事件数据(控件名)` | wideString | 取得当前处理中的事件主数据。 |
| 2 | `FBro_取事件字段` | `FBro_取事件字段(控件名, 字段名)` | wideString | 从 UTF-16 JSON 事件包读取结构化字段。 |
| 3 | `FBro_设置事件结果` | `FBro_设置事件结果(控件名, 动作)` | int | 设置同步事件动作；未设置时使用事件目录默认动作。 |
| 4 | `FBro_设置事件返回文本` | `FBro_设置事件返回文本(控件名, 文本)` | int | 设置同步事件返回文本。 |
| 5 | `FBro_取事件对象` | `FBro_取事件对象(控件名)` | longLong | 取得 CertificateError 或 DragEnter 事件携带的受管对象句柄。 |
| 6 | `FBro_绑定事件` | `FBro_绑定事件(控件名, 事件名, 处理器)` | int | 动态绑定 FBro 事件处理器。 |
