# FBro事件模块完整演示

- 模块 ID：`lingbuilder.fbro.events`
- 版本：`2.1.0`
- 类型：LingBuilder 内置模块
- 命令数：12
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 UTF-16 JSON 事件包、同步决策与动态处理器绑定。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `FBro_取事件数据` | `FBro_取事件数据(控件名)` | wideString | 取得当前处理中的事件主数据。 |
| 2 | `FBro_取事件字段` | `FBro_取事件字段(控件名, 字段名)` | wideString | 从 UTF-16 JSON 事件包读取结构化字段。 |
| 3 | `FBro_设置事件结果` | `FBro_设置事件结果(控件名, 动作)` | int | 设置同步事件动作；未设置时使用事件目录默认动作。 |
| 4 | `FBro_设置事件返回文本` | `FBro_设置事件返回文本(控件名, 文本)` | int | 设置同步事件返回文本。 |
| 5 | `FBro_设置事件响应JSON` | `FBro_设置事件响应JSON(控件名, 响应JSON)` | int | 设置 C ABI v3 事件结构化响应；回调返回后 Bridge 会立即复制。 |
| 6 | `FBro_取事件对象` | `FBro_取事件对象(控件名)` | longLong | 取得 CertificateError 或 DragEnter 事件携带的受管对象句柄。 |
| 7 | `FBro_取事件延续` | `FBro_取事件延续(控件名)` | longLong | 取得当前延迟决策事件的受管延续句柄；只允许传给完成或取消命令。 |
| 8 | `FBro_取事件对象字段` | `FBro_取事件对象字段(控件名, 字段名)` | wideString | 读取事件包中复制后的对象字段或受管句柄字段。 |
| 9 | `FBro事件_完成延续` | `FBro事件_完成延续(延续句柄, 响应JSON)` | int | 完成认证、权限、查询或下载等延迟决策；重复完成返回稳定错误码。 |
| 10 | `FBro事件_取消延续` | `FBro事件_取消延续(延续句柄)` | int | 取消尚未完成的受管事件延续。 |
| 11 | `FBro_设置事件采样率` | `FBro_设置事件采样率(控件名, 事件名, 每秒次数)` | int | 按浏览器和事件设置高频事件采样率；零表示暂停投递。 |
| 12 | `FBro_绑定事件` | `FBro_绑定事件(控件名, 事件名, 处理器)` | int | 动态绑定 FBro 事件处理器。 |
