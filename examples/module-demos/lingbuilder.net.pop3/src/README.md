# 邮件接收模块完整演示

- 模块 ID：`lingbuilder.net.pop3`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：18
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 POP3 协议接收邮件：连接后取回邮件并解析主题、发件人、日期、正文与附件，支持 SSL(TLS) 加密连接（不校验服务器证书）。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `POP3_连接` | `POP3_连接(服务器, 端口, 用户名, 密码, 是否SSL)` | bool | 连接 POP3 收信服务器并完成登录；失败返回假，用 POP3_取错误 查看原因。 |
| 2 | `POP3_断开` | `POP3_断开()` | void | 断开与收信服务器的连接。 |
| 3 | `POP3_是否已连接` | `POP3_是否已连接()` | bool | 判断当前是否已连接收信服务器。 |
| 4 | `POP3_取邮件数量` | `POP3_取邮件数量()` | int | 返回邮箱中的邮件数量；未连接返回 -1。 |
| 5 | `POP3_取邮箱总大小` | `POP3_取邮箱总大小()` | int | 返回邮箱中全部邮件的总字节数；未连接返回 -1。 |
| 6 | `POP3_取邮件大小` | `POP3_取邮件大小(序号)` | int | 返回指定邮件的字节数。 |
| 7 | `POP3_接收邮件` | `POP3_接收邮件(序号)` | bool | 取回指定邮件的完整内容并解析为当前邮件上下文，之后用 取主题/取发件人/取正文文本/附件族 命令读取。 |
| 8 | `POP3_删除邮件` | `POP3_删除邮件(序号)` | bool | 把指定邮件标记为删除；真正删除发生在 QUIT 时，可用 POP3_复位删除 撤销。 |
| 9 | `POP3_复位删除` | `POP3_复位删除()` | bool | 撤销本次连接中所有删除标记。 |
| 10 | `POP3_取主题` | `POP3_取主题()` | wideString | 返回已接收邮件的主题（自动解码编码字）。 |
| 11 | `POP3_取发件人` | `POP3_取发件人()` | wideString | 返回已接收邮件的发件人。 |
| 12 | `POP3_取日期` | `POP3_取日期()` | wideString | 返回已接收邮件的日期头。 |
| 13 | `POP3_取正文文本` | `POP3_取正文文本()` | wideString | 返回已接收邮件的纯文本正文。 |
| 14 | `POP3_取网页正文` | `POP3_取网页正文()` | wideString | 返回已接收邮件的 HTML 正文。 |
| 15 | `POP3_取附件个数` | `POP3_取附件个数()` | int | 返回已接收邮件的附件数量。 |
| 16 | `POP3_取附件名称` | `POP3_取附件名称(附件序号)` | wideString | 返回指定附件的文件名。 |
| 17 | `POP3_保存附件` | `POP3_保存附件(附件序号, 保存路径)` | bool | 把指定附件内容写入目标文件。 |
| 18 | `POP3_取错误` | `POP3_取错误()` | wideString | 返回最近一次 POP3 错误或服务端响应。 |
