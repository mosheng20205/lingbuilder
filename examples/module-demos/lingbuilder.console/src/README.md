# 控制台模块完整演示

- 模块 ID：`lingbuilder.console`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：12
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

为控制台程序提供标准输入输出、光标与文本颜色控制；命令只能在控制台程序（含「整数型 启动()」入口）中使用，窗口应用中会给出阻断诊断。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `控制台_输出` | `控制台_输出(内容)` | void | 向控制台标准输出写入文本（不换行）。 |
| 2 | `控制台_输出行` | `控制台_输出行(内容)` | void | 向控制台标准输出写入一行文本并换行。 |
| 3 | `控制台_读行` | `控制台_读行()` | wideString | 从控制台读取一行输入，遇到回车返回（结果不含回车）；流被重定向或读取失败返回空文本。 |
| 4 | `控制台_清屏` | `控制台_清屏()` | void | 清空控制台屏幕并把光标移回左上角。 |
| 5 | `控制台_置光标位置` | `控制台_置光标位置(列, 行)` | void | 把控制台光标移动到指定字符位置（后续输出从该位置开始）。 |
| 6 | `控制台_取光标列` | `控制台_取光标列()` | int | 返回控制台光标当前列号（从 0 起）。 |
| 7 | `控制台_取光标行` | `控制台_取光标行()` | int | 返回控制台光标当前行号（从 0 起）。 |
| 8 | `控制台_取宽度` | `控制台_取宽度()` | int | 返回控制台屏幕缓冲区的字符宽度。 |
| 9 | `控制台_取高度` | `控制台_取高度()` | int | 返回控制台屏幕窗口的字符高度。 |
| 10 | `控制台_显示光标` | `控制台_显示光标(可见)` | void | 设置控制台光标是否可见。 |
| 11 | `控制台_置颜色` | `控制台_置颜色(前景色, 背景色)` | void | 设置控制台后续输出的前景色与背景色（0～15 编号组合）。 |
| 12 | `控制台_恢复颜色` | `控制台_恢复颜色()` | void | 把控制台颜色恢复为默认（灰字黑底）。 |
