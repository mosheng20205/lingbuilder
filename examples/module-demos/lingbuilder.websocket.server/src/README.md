# WebSocket 服务端模块完整演示

- 模块 ID：`lingbuilder.websocket.server`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供基于 Windows Winsock 的本地 WebSocket 服务端监听、握手、收发文本和关闭能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `WSS_启动服务` | `WSS_启动服务(端口)` | int | 在 127.0.0.1 指定端口启动单连接 WebSocket 服务端，成功返回 1。 |
| 2 | `WSS_等待连接` | `WSS_等待连接()` | int | 等待一个 WebSocket 客户端连接并完成标准握手。 |
| 3 | `WSS_接收文本` | `WSS_接收文本()` | wideString | 从当前 WebSocket 客户端接收一条 UTF-8 文本消息。 |
| 4 | `WSS_接收到调试输出` | `WSS_接收到调试输出()` | int | 接收一条 WebSocket 文本消息并写入调试输出。 |
| 5 | `WSS_发送文本` | `WSS_发送文本(内容)` | int | 向当前 WebSocket 客户端发送一条文本消息。 |
| 6 | `WSS_关闭服务` | `WSS_关闭服务()` | void | 关闭当前 WebSocket 服务端监听和客户端连接。 |
