# new_emoji FBro 浏览器外壳完整演示

- 模块 ID：`lingbuilder.new_emoji.fbro-shell`
- 版本：`1.4.0`
- 类型：LingBuilder 内置模块
- 命令数：64
- 设计器控件数：0
- 分组数：4

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

在 new_emoji 浏览器框架窗口中按稳定 ID 管理 FBro x64 独立会话、RichList、原生 HWND 和隔离 Profile。
