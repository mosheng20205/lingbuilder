# SMTP邮件模块完整演示

- 模块 ID：`lingbuilder.net.mail`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：2
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供普通 SMTP 或局域网调试服务发送；当前版本不支持 TLS，遇到要求 STARTTLS 的服务会明确失败。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `SMTP_发送普通邮件` | `SMTP_发送普通邮件(主机, 端口, 用户名, 密码, 发件人, 收件人, 主题, 正文)` | bool | 通过不加密 SMTP 发送 UTF-8 文本邮件。 |
| 2 | `SMTP_取错误` | `SMTP_取错误()` | wideString | 返回最近 SMTP 错误或服务端响应。 |
