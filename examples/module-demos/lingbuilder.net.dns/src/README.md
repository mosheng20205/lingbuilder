# DNS与IP模块完整演示

- 模块 ID：`lingbuilder.net.dns`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供域名解析、本机名、IP 格式检查和反向查询。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `DNS_解析首个地址` | `DNS_解析首个地址(主机名)` | wideString | 解析并返回首个 IPv4 或 IPv6 地址。 |
| 2 | `DNS_反向查询` | `DNS_反向查询(IP地址)` | wideString | 对 IP 地址执行反向名称查询。 |
| 3 | `网络_取本机名` | `网络_取本机名()` | wideString | 返回 Winsock 本机主机名。 |
| 4 | `网络_是否IPv4` | `网络_是否IPv4(地址)` | bool | 检查是否为合法 IPv4 文本。 |
| 5 | `网络_是否IPv6` | `网络_是否IPv6(地址)` | bool | 检查是否为合法 IPv6 文本。 |
