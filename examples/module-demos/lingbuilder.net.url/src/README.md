# URL解析模块完整演示

- 模块 ID：`lingbuilder.net.url`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

使用 WinHTTP 解析 URL 的协议、主机、端口和路径。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `URL_是否有效` | `URL_是否有效(地址)` | bool | 判断 URL 是否可被 WinHTTP 解析。 |
| 2 | `URL_取协议` | `URL_取协议(地址)` | wideString | 返回 http 或 https 等协议名。 |
| 3 | `URL_取主机` | `URL_取主机(地址)` | wideString | 返回 URL 主机名。 |
| 4 | `URL_取端口` | `URL_取端口(地址)` | int | 返回 URL 端口。 |
| 5 | `URL_取路径` | `URL_取路径(地址)` | wideString | 返回 URL 路径和附加信息。 |
| 6 | `URL_是否HTTPS` | `URL_是否HTTPS(地址)` | bool | 判断 URL 是否使用 HTTPS。 |
