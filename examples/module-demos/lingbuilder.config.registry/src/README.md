# 用户注册表模块完整演示

- 模块 ID：`lingbuilder.config.registry`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

只访问当前用户 HKEY_CURRENT_USER 下的注册表键值，避免默认要求管理员权限。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `注册表_读文本` | `注册表_读文本(子键, 值名, 默认值)` | wideString | 读取当前用户注册表字符串值。 |
| 2 | `注册表_读整数` | `注册表_读整数(子键, 值名, 默认值)` | int | 读取当前用户注册表 DWORD 值。 |
| 3 | `注册表_写文本` | `注册表_写文本(子键, 值名, 值)` | bool | 写入当前用户注册表字符串值。 |
| 4 | `注册表_写整数` | `注册表_写整数(子键, 值名, 值)` | bool | 写入当前用户注册表 DWORD 值。 |
| 5 | `注册表_删除值` | `注册表_删除值(子键, 值名)` | bool | 删除当前用户注册表值。 |
| 6 | `注册表_值是否存在` | `注册表_值是否存在(子键, 值名)` | bool | 判断当前用户注册表值是否存在。 |
