# Win32菜单模块完整演示

- 模块 ID：`lingbuilder.win32.menu`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：8
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

封装 HMENU 创建、菜单项、窗口菜单和弹出菜单返回命令。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `菜单_创建` | `菜单_创建()` | handle | 创建菜单栏。 |
| 2 | `菜单_创建弹出菜单` | `菜单_创建弹出菜单()` | handle | 创建弹出菜单。 |
| 3 | `菜单_添加项目` | `菜单_添加项目(菜单句柄, 命令ID, 标题)` | bool | 添加普通菜单项。 |
| 4 | `菜单_添加子菜单` | `菜单_添加子菜单(菜单句柄, 子菜单句柄, 标题)` | bool | 添加子菜单。 |
| 5 | `菜单_添加分隔线` | `菜单_添加分隔线(菜单句柄)` | bool | 添加分隔线。 |
| 6 | `菜单_设置到窗口` | `菜单_设置到窗口(窗口句柄, 菜单句柄)` | bool | 把菜单设置为窗口菜单栏。 |
| 7 | `菜单_弹出并取命令` | `菜单_弹出并取命令(菜单句柄, 窗口句柄, 横坐标, 纵坐标)` | int | 显示弹出菜单并返回选择的命令 ID。 |
| 8 | `菜单_销毁` | `菜单_销毁(菜单句柄)` | bool | 销毁未附加或不再使用的菜单。 |
