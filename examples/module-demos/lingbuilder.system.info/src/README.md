# 系统信息模块完整演示

- 模块 ID：`lingbuilder.system.info`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取当前 Windows、计算机、用户、处理器和内存信息。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `系统_取用户名` | `系统_取用户名()` | wideString | 返回当前登录用户名。 |
| 2 | `系统_取计算机名` | `系统_取计算机名()` | wideString | 返回本机计算机名。 |
| 3 | `系统_取Windows版本` | `系统_取Windows版本()` | wideString | 返回真实 Windows 主版本、次版本和内部版本号。 |
| 4 | `系统_取处理器数量` | `系统_取处理器数量()` | int | 返回系统逻辑处理器数量。 |
| 5 | `系统_取内存总量MB` | `系统_取内存总量MB()` | longLong | 返回物理内存总量，单位 MB。 |
| 6 | `系统_取内存可用MB` | `系统_取内存可用MB()` | longLong | 返回当前可用物理内存，单位 MB。 |
| 7 | `系统_取环境变量` | `系统_取环境变量(名称)` | wideString | 读取当前进程可见的环境变量。 |
