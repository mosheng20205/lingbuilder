# 路径处理模块完整演示

- 模块 ID：`lingbuilder.fs.path`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供不访问或少量访问文件系统的路径组合、规范化和组成部分读取。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `路径_合并` | `路径_合并(基础路径, 子路径)` | wideString | 组合两个路径并进行词法规范化。 |
| 2 | `路径_取文件名` | `路径_取文件名(路径)` | wideString | 返回路径中的文件名。 |
| 3 | `路径_取目录` | `路径_取目录(路径)` | wideString | 返回路径中的父目录。 |
| 4 | `路径_取扩展名` | `路径_取扩展名(路径)` | wideString | 返回包含点号的文件扩展名。 |
| 5 | `路径_改扩展名` | `路径_改扩展名(路径, 新扩展名)` | wideString | 替换文件扩展名。 |
| 6 | `路径_转绝对路径` | `路径_转绝对路径(路径)` | wideString | 以当前工作目录为基准生成绝对路径。 |
| 7 | `路径_规范化` | `路径_规范化(路径)` | wideString | 移除路径中的点段并规范分隔结构。 |
