# IMAP邮件接收模块完整演示

- 模块 ID：`lingbuilder.net.imap`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：15
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 IMAP 协议接收邮件：连接后选择文件夹、取回邮件并解析主题、发件人、日期、正文与附件，支持 SSL(TLS) 加密连接（不校验服务器证书）。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `IMAP_连接` | `IMAP_连接(服务器, 端口, 用户名, 密码, 是否SSL)` | bool | 连接 IMAP 收信服务器并完成登录；失败返回假，用 IMAP_取错误 查看原因。 |
| 2 | `IMAP_断开` | `IMAP_断开()` | void | 断开与收信服务器的连接。 |
| 3 | `IMAP_是否已连接` | `IMAP_是否已连接()` | bool | 判断当前是否已连接收信服务器。 |
| 4 | `IMAP_选择文件夹` | `IMAP_选择文件夹(文件夹名称)` | bool | 打开指定邮件文件夹；之后的取件命令都作用于该文件夹。 |
| 5 | `IMAP_取邮件数量` | `IMAP_取邮件数量()` | int | 返回当前文件夹中的邮件数量；未连接或未选择文件夹返回 -1。 |
| 6 | `IMAP_接收邮件` | `IMAP_接收邮件(序号)` | bool | 取回指定邮件的完整内容并解析为当前邮件上下文，之后用 取主题/取发件人/取正文文本/附件族 命令读取。 |
| 7 | `IMAP_取主题` | `IMAP_取主题()` | wideString | 返回已接收邮件的主题（自动解码编码字）。 |
| 8 | `IMAP_取发件人` | `IMAP_取发件人()` | wideString | 返回已接收邮件的发件人。 |
| 9 | `IMAP_取日期` | `IMAP_取日期()` | wideString | 返回已接收邮件的日期头。 |
| 10 | `IMAP_取正文文本` | `IMAP_取正文文本()` | wideString | 返回已接收邮件的纯文本正文。 |
| 11 | `IMAP_取网页正文` | `IMAP_取网页正文()` | wideString | 返回已接收邮件的 HTML 正文。 |
| 12 | `IMAP_取附件个数` | `IMAP_取附件个数()` | int | 返回已接收邮件的附件数量。 |
| 13 | `IMAP_取附件名称` | `IMAP_取附件名称(附件序号)` | wideString | 返回指定附件的文件名。 |
| 14 | `IMAP_保存附件` | `IMAP_保存附件(附件序号, 保存路径)` | bool | 把指定附件内容写入目标文件。 |
| 15 | `IMAP_取错误` | `IMAP_取错误()` | wideString | 返回最近一次 IMAP 错误或服务端响应。 |
