# 缓冲区模块完整演示

- 模块 ID：`lingbuilder.std.buffer`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：17
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供句柄制可增长二进制缓冲区：顺序读写游标、字节集/文本/整数编解码与文件互转；单缓冲区上限 256 MiB，跨线程传递请先转为字节集。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `缓冲区_创建` | `缓冲区_创建(初始容量)` | longLong | 创建可增长二进制缓冲区；初始容量 0～268435456，返回缓冲区句柄（0 表示失败）。 |
| 2 | `缓冲区_销毁` | `缓冲区_销毁(缓冲区)` | bool | 销毁缓冲区并回收句柄；销毁后句柄不可再用。 |
| 3 | `缓冲区_取长度` | `缓冲区_取长度(缓冲区)` | longLong | 返回缓冲区当前总字节数；句柄无效返回 -1。 |
| 4 | `缓冲区_写字节集` | `缓冲区_写字节集(缓冲区, 字节集)` | bool | 把字节集追加到缓冲区末尾；单个缓冲区上限 268435456 字节。 |
| 5 | `缓冲区_写文本` | `缓冲区_写文本(缓冲区, 文本)` | bool | 把文本按 UTF-8 编码追加到缓冲区末尾。 |
| 6 | `缓冲区_写整数` | `缓冲区_写整数(缓冲区, 整数, 字节数, 大端)` | bool | 把整数按指定字节数（1/2/4/8）写入缓冲区末尾；超出范围的字节数返回假。 |
| 7 | `缓冲区_读字节集` | `缓冲区_读字节集(缓冲区, 长度)` | bytes | 从读取游标处取出字节集并前进游标；长度小于 0 表示读取全部剩余字节。 |
| 8 | `缓冲区_读文本` | `缓冲区_读文本(缓冲区, 长度)` | wideString | 从读取游标处按 UTF-8 解码文本并前进游标；长度小于 0 表示读取全部剩余字节。 |
| 9 | `缓冲区_读整数` | `缓冲区_读整数(缓冲区, 字节数, 大端)` | longLong | 从读取游标处按指定字节数（1/2/4/8）读取整数并前进游标；数据不足返回 0。 |
| 10 | `缓冲区_取剩余` | `缓冲区_取剩余(缓冲区)` | longLong | 返回读取游标到缓冲区末尾的剩余字节数；句柄无效返回 -1。 |
| 11 | `缓冲区_重置读取` | `缓冲区_重置读取(缓冲区)` | bool | 把读取游标移回缓冲区开头。 |
| 12 | `缓冲区_到字节集` | `缓冲区_到字节集(缓冲区)` | bytes | 把缓冲区全部内容复制为字节集。 |
| 13 | `缓冲区_从字节集` | `缓冲区_从字节集(字节集)` | longLong | 用字节集内容创建新缓冲区并返回句柄。 |
| 14 | `缓冲区_清空` | `缓冲区_清空(缓冲区)` | bool | 清空缓冲区内容并把读取游标归零。 |
| 15 | `缓冲区_保存文件` | `缓冲区_保存文件(缓冲区, 路径)` | bool | 把缓冲区全部内容写入目标文件（覆盖写入）。 |
| 16 | `缓冲区_从文件` | `缓冲区_从文件(路径)` | longLong | 读取文件内容创建新缓冲区；失败或超过 268435456 字节返回 0。 |
| 17 | `缓冲区_寻找` | `缓冲区_寻找(缓冲区, 欲寻找, 起始位置)` | int | 在缓冲区全部内容中从起始位置（从 0 起）查找字节集，返回内容中的位置；读取游标不动；未找到或句柄无效返回 -1。 |
