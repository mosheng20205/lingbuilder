# FTP客户端模块完整演示

- 模块 ID：`lingbuilder.net.ftp`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 WinINet 提供 FTP/FTPS 连接、上传、下载、删除、改名和关闭。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `FTP_连接` | `FTP_连接(主机, 端口, 用户名, 密码, 安全连接)` | bool | 连接 FTP 或 FTPS 服务端。 |
| 2 | `FTP_上传文件` | `FTP_上传文件(本地文件, 远程文件)` | bool | 以二进制模式上传文件。 |
| 3 | `FTP_下载文件` | `FTP_下载文件(远程文件, 本地文件, 允许覆盖)` | bool | 以二进制模式下载文件。 |
| 4 | `FTP_删除文件` | `FTP_删除文件(远程文件)` | bool | 删除远程文件。 |
| 5 | `FTP_重命名` | `FTP_重命名(原名称, 新名称)` | bool | 重命名远程文件。 |
| 6 | `FTP_取错误` | `FTP_取错误()` | wideString | 返回最近 FTP 中文错误。 |
| 7 | `FTP_关闭` | `FTP_关闭()` | void | 关闭 FTP 连接和会话。 |
