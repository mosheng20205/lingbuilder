# 磁盘信息模块完整演示

- 模块 ID：`lingbuilder.system.disk`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：28
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

完整读取逻辑驱动器、卷、容量、文件系统、物理磁盘、SSD/TRIM、扇区和分区信息。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `磁盘_总容量MB` | `磁盘_总容量MB(路径)` | longLong | 返回路径所在卷的总容量 MB，失败返回 -1；兼容旧源码。 |
| 2 | `磁盘_可用容量MB` | `磁盘_可用容量MB(路径)` | longLong | 返回当前用户配额下可用容量 MB，失败返回 -1；兼容旧源码。 |

| 4 | `磁盘_取文件系统` | `磁盘_取文件系统(根路径)` | wideString | 返回 NTFS、ReFS、FAT32 等文件系统名称。 |
| 5 | `磁盘_取驱动器类型` | `磁盘_取驱动器类型(根路径)` | int | 返回 Win32 DRIVE_* 类型编号。 |
| 6 | `磁盘_取总容量字节` | `磁盘_取总容量字节(路径)` | longLong | 返回路径所在卷的精确总容量字节数，失败返回 -1。 |

| 8 | `磁盘_取总空闲字节` | `磁盘_取总空闲字节(路径)` | longLong | 返回卷上所有用户合计可见的空闲字节数，失败返回 -1。 |
| 9 | `磁盘_取已用容量字节` | `磁盘_取已用容量字节(路径)` | longLong | 返回总容量减去总空闲容量的字节数，失败返回 -1。 |
| 10 | `磁盘_取使用率` | `磁盘_取使用率(路径)` | double | 返回卷使用率百分比，失败返回 -1。 |
| 11 | `磁盘_取容量信息` | `磁盘_取容量信息(路径)` | 磁盘容量信息 | 一次返回精确容量、空闲容量、已用容量和使用率。 |
| 12 | `磁盘_取卷信息` | `磁盘_取卷信息(路径)` | 磁盘卷信息 | 返回路径所在卷的容量、标识、文件系统、类型和挂载点快照。 |
| 13 | `磁盘_枚举逻辑驱动器` | `磁盘_枚举逻辑驱动器()` | 磁盘卷信息列表 | 枚举当前会话可见的盘符和网络映射驱动器；未就绪设备也会保留并携带错误代码。 |
| 14 | `磁盘_枚举全部卷` | `磁盘_枚举全部卷()` | 磁盘卷信息列表 | 使用 Windows 卷枚举 API 返回包含无盘符卷在内的全部卷。 |
| 15 | `磁盘_取挂载点列表` | `磁盘_取挂载点列表(卷GUID路径)` | 磁盘路径列表 | 返回卷对应的全部盘符和目录挂载点。 |
| 16 | `磁盘_取路径卷根` | `磁盘_取路径卷根(路径)` | wideString | 把任意本地路径解析为所属卷根路径。 |
| 17 | `磁盘_取卷GUID路径` | `磁盘_取卷GUID路径(路径)` | wideString | 返回路径所属卷的稳定 \\?\Volume{GUID}\ 名称。 |
| 18 | `磁盘_取驱动器类型名称` | `磁盘_取驱动器类型名称(根路径)` | wideString | 返回未知、无效根路径、可移动、固定、网络、光盘或内存盘。 |
| 19 | `磁盘_取卷序列号` | `磁盘_取卷序列号(根路径)` | longLong | 返回文件系统卷序列号，失败返回 -1。 |
| 20 | `磁盘_取文件系统标志` | `磁盘_取文件系统标志(根路径)` | longLong | 返回 GetVolumeInformationW 的 FILE_* 能力标志位，失败返回 -1。 |
| 21 | `磁盘_取最大文件名长度` | `磁盘_取最大文件名长度(根路径)` | int | 返回文件系统支持的单个名称最大字符数，失败返回 -1。 |
| 22 | `磁盘_卷是否就绪` | `磁盘_卷是否就绪(根路径)` | bool | 判断卷是否存在且介质可读取。 |

| 24 | `磁盘_枚举物理磁盘` | `磁盘_枚举物理磁盘()` | 物理磁盘信息列表 | 枚举 Windows PhysicalDrive 设备并返回只读存储描述、容量、扇区、分区、SSD 和 TRIM 信息。 |

| 26 | `磁盘_取分区列表` | `磁盘_取分区列表(磁盘编号)` | 磁盘分区信息列表 | 读取物理磁盘的 MBR/GPT/RAW 分区布局，失败返回空数组并记录错误。 |

| 28 | `磁盘_取最近错误` | `磁盘_取最近错误()` | wideString | 返回当前线程最近一次磁盘模块失败的中文上下文和系统错误文本。 |
