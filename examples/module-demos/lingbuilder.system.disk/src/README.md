# 磁盘信息模块完整演示

- 模块 ID：`lingbuilder.system.disk`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取磁盘容量、卷标、文件系统和驱动器类型。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `磁盘_总容量MB` | `磁盘_总容量MB(路径)` | longLong | 返回路径所在卷的总容量 MB，失败返回 -1。 |
| 2 | `磁盘_可用容量MB` | `磁盘_可用容量MB(路径)` | longLong | 返回当前用户可用容量 MB，失败返回 -1。 |
| 3 | `磁盘_取卷标` | `磁盘_取卷标(根路径)` | wideString | 返回卷标，例如传入 C:\。 |
| 4 | `磁盘_取文件系统` | `磁盘_取文件系统(根路径)` | wideString | 返回 NTFS、FAT32 等文件系统名称。 |
| 5 | `磁盘_取驱动器类型` | `磁盘_取驱动器类型(根路径)` | int | 返回 Win32 DRIVE_* 类型编号。 |
