# PDF文档模块完整演示

- 模块 ID：`lingbuilder.data.pdf`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：21
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取与加工 PDF：逐页/全文文本提取（行序重建）、无文本层判断（扫描件分流 OCR）、页面渲染 PNG、内嵌图片提取、拆分与合并、转 Word 文本流，以及经本机 Office/WPS 的外部文档转 PDF（docx/xlsx 高保真）。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `PDF_打开` | `PDF_打开(文件路径)` | PDF文档 | 打开本地 PDF 文档；加密 PDF（需要密码）会被明确拒绝。 |
| 2 | `PDF_打开字节集` | `PDF_打开字节集(数据)` | PDF文档 | 从内存字节集打开 PDF；字节集必须以 %PDF- 开头。 |
| 3 | `PDF_关闭` | `PDF_关闭(文档)` | bool | 关闭并释放文档；失效句柄返回假。 |
| 4 | `PDF_释放全部` | `PDF_释放全部()` | void | 释放当前进程内全部 PDF 文档句柄。 |
| 5 | `PDF_取页数` | `PDF_取页数(文档)` | int | 返回文档总页数。 |
| 6 | `PDF_取页面宽度` | `PDF_取页面宽度(文档, 页号)` | double | 返回页面宽度（pt 坐标）；页号越界返回 0。 |
| 7 | `PDF_取页面高度` | `PDF_取页面高度(文档, 页号)` | double | 返回页面高度（pt 坐标）；页号越界返回 0。 |
| 8 | `PDF_取页面文本` | `PDF_取页面文本(文档, 页号)` | wideString | 提取一页文本：按字符坐标 y 聚类成行、行内按 x 排序重建阅读顺序（双栏 PDF 也能得到正确行序），CJK 不乱码。 |
| 9 | `PDF_取全部文本` | `PDF_取全部文本(文档)` | wideString | 提取全部页文本，页与页之间换行分隔。 |
| 10 | `PDF_是否有文本层` | `PDF_是否有文本层(文档, 页号)` | bool | 判断页面是否含可选择文本：扫描件返回假，应配合 OCR 模块（lingbuilder.ocr）识别后再提取。 |
| 11 | `PDF_渲染页面PNG` | `PDF_渲染页面PNG(文档, 页号, 缩放倍率, 输出路径)` | bool | 把页面渲染为 PNG 图片（白底、RGB）；渲染上限 6400 万像素。 |
| 12 | `PDF_取图片数` | `PDF_取图片数(文档, 页号)` | int | 返回页面内嵌图片数量。 |
| 13 | `PDF_提取图片` | `PDF_提取图片(文档, 页号, 图片索引, 输出路径)` | bool | 把页面内嵌图片提取保存为 PNG。 |
| 14 | `PDF_拆分页面` | `PDF_拆分页面(文档, 起始页, 结束页, 输出路径)` | bool | 把指定页码区间拆分为一个新 PDF。 |
| 15 | `PDF_合并文档` | `PDF_合并文档(文档, 文档乙, 输出路径)` | bool | 合并两个已打开的 PDF：文档甲在前、文档乙在后。 |
| 16 | `PDF_转Word文本流` | `PDF_转Word文本流(文档, 输出路径)` | bool | 内容级转换：PDF 文本按行聚类成段落写成可编辑 .docx（每页前插入「— 第 N 页 —」分隔）。描述定位是内容可编辑、版面近似不保真，复杂排版请在 Word 中调整；图片与表格结构不迁移。无文本层的扫描件会明确报错并提示改走 OCR。 |
| 17 | `PDF_外部文档转PDF` | `PDF_外部文档转PDF(输入路径, 输出路径)` | bool | 经本机 Office/WPS 把 docx/xlsx 高保真转成 PDF：引擎自动检测链 Word → WPS（docx）/ Excel → WPS 表格（xlsx），转换在独立脚本进程执行、引擎崩溃不拖垮主程序、单文件 180 秒超时。未安装 Office/WPS 时给出明确中文提示。 |
| 18 | `PDF_取Office转换引擎` | `PDF_取Office转换引擎()` | wideString | 返回外部转换可用引擎：Word、Excel、WPS；空文本表示本机不可用。 |
| 19 | `PDF_取错误` | `PDF_取错误()` | wideString | 返回当前线程最近一次 PDF 模块错误的中文说明。 |
| 20 | `PDF_取版本` | `PDF_取版本()` | wideString | 返回运行桥与 PDFium 内核版本信息。 |
| 21 | `PDF_是否可用` | `PDF_是否可用()` | bool | 检查 pdfium.dll 与 LingBuilderPdf.dll 是否可加载（lingbuilder.pdf.sdk 模块资产是否就位）。 |
