# TCP通信模块完整演示

- 模块 ID：`lingbuilder.net.tcp`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供单连接 TCP 客户端的连接、UTF-8 文本收发、超时和关闭能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `TCP_连接` | `TCP_连接(主机, 端口, 超时毫秒)` | bool | 连接 TCP 服务端。 |
| 2 | `TCP_发送文本` | `TCP_发送文本(内容)` | int | 发送完整 UTF-8 文本，返回字节数，失败返回 -1。 |
| 3 | `TCP_接收文本` | `TCP_接收文本(最大字节数)` | wideString | 接收一批 UTF-8 文本。 |
| 4 | `TCP_是否已连接` | `TCP_是否已连接()` | bool | 判断当前 TCP 句柄是否处于连接状态。 |
| 5 | `TCP_取错误` | `TCP_取错误()` | wideString | 返回最近 TCP 中文错误。 |
| 6 | `TCP_关闭` | `TCP_关闭()` | void | 关闭当前 TCP 连接。 |
