# 微信OCR识别模块完整演示

- 模块 ID：`lingbuilder.ocr`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：19
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

借用本机微信 4.x 自带 OCR 组件的离线文字识别：首次识别自动探测微信安装并拉起其 OCR 组件进程（Weixin.exe --type=wxocr），返回行级文本、坐标与置信度，JSON 另含字符级坐标。不随包分发任何腾讯文件，需要用户已安装 Windows 版微信并完成过一次截图文字识别（触发组件下载）；仅支持 64 位构建（x64），32 位下命令返回中文错误。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `OCR_取版本` | `OCR_取版本()` | wideString | 返回模块版本与实现口径（借用本机微信 4.x OCR 组件，仅 64 位）。 |
| 2 | `OCR_取微信状态` | `OCR_取微信状态()` | wideString | 探测本机微信与 OCR 组件（不启动进程），返回 JSON：found、versionDir、pluginVersion、wxocrDll 或 error。微信未下载 OCR 组件时错误里带触发下载的操作指引。 |
| 3 | `OCR_取错误` | `OCR_取错误()` | wideString | 读取当前线程最近一次 OCR 操作的中文错误。 |
| 4 | `OCR_停止` | `OCR_停止()` | bool | 停止 OCR 组件进程并复位会话；下次识别自动重新探测启动。组件长时间不用或识别失败后可用。 |
| 5 | `OCR_识别` | `OCR_识别(图片路径)` | OCR结果句柄 | 识别图片中的全部文字并返回受管结果句柄；首次调用自动探测微信并启动其 OCR 组件（握手 15 秒、单图识别 120 秒超时）。失败返回 0，原因读 OCR_取错误()。 |
| 6 | `OCR_识别字节集` | `OCR_识别字节集(图片数据)` | OCR结果句柄 | 识别字节集图片中的全部文字并返回受管结果句柄；前置与超时同 OCR_识别，结果读取/释放命令共用。失败返回 0，原因读 OCR_取错误()。 |
| 7 | `OCR结果_取行数` | `OCR结果_取行数(结果)` | int | 返回识别行数；句柄无效返回 0。 |
| 8 | `OCR结果_取文本` | `OCR结果_取文本(结果, 索引)` | wideString | 返回指定行的识别文本；越界返回空文本。 |
| 9 | `OCR结果_取全部文本` | `OCR结果_取全部文本(结果, 换行分隔)` | wideString | 一次性取回全部识别文本；句柄无效返回空文本。 |
| 10 | `OCR结果_取置信度` | `OCR结果_取置信度(结果, 索引)` | double | 返回指定行识别置信度（0～1）；越界返回 0。 |
| 11 | `OCR结果_取左坐标` | `OCR结果_取左坐标(结果, 索引)` | int | 返回指定行包围盒左边界横坐标（像素）；越界返回 -1。 |
| 12 | `OCR结果_取上坐标` | `OCR结果_取上坐标(结果, 索引)` | int | 返回指定行包围盒上边界纵坐标（像素）；越界返回 -1。 |
| 13 | `OCR结果_取右坐标` | `OCR结果_取右坐标(结果, 索引)` | int | 返回指定行包围盒右边界横坐标（像素）；越界返回 -1。 |
| 14 | `OCR结果_取下坐标` | `OCR结果_取下坐标(结果, 索引)` | int | 返回指定行包围盒下边界纵坐标（像素）；越界返回 -1。 |
| 15 | `OCR结果_取宽度` | `OCR结果_取宽度(结果)` | int | 返回原图宽度像素；句柄无效返回 0。 |
| 16 | `OCR结果_取高度` | `OCR结果_取高度(结果)` | int | 返回原图高度像素；句柄无效返回 0。 |
| 17 | `OCR结果_取JSON` | `OCR结果_取JSON(结果)` | wideString | 返回完整识别结果 JSON：errcode、width、height、lines[]（text、rate、left/top/right/bottom、chars[] 字符级坐标）。 |
| 18 | `OCR结果_释放` | `OCR结果_释放(结果)` | bool | 释放一个识别结果句柄；句柄无效返回假。 |
| 19 | `OCR结果_释放全部` | `OCR结果_释放全部()` | void | 释放当前进程内全部识别结果句柄。 |
