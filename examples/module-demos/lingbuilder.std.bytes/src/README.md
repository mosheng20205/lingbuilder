# 字节与十六进制模块完整演示

- 模块 ID：`lingbuilder.std.bytes`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：13
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过安全文本接口提供 UTF-8 字节长度与十六进制编解码，不暴露裸内存指针。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `字节_UTF8长度` | `字节_UTF8长度(文本)` | int | 返回文本编码为 UTF-8 后的字节数。 |
| 2 | `字节_文本转十六进制` | `字节_文本转十六进制(文本)` | wideString | 把文本的 UTF-8 字节转换为大写十六进制文本。 |
| 3 | `字节_十六进制转文本` | `字节_十六进制转文本(十六进制)` | wideString | 把十六进制字节文本按 UTF-8 解码，格式错误返回空文本。 |
| 4 | `字节_十六进制是否有效` | `字节_十六进制是否有效(十六进制)` | bool | 判断文本是否由偶数个十六进制字符组成。 |
| 5 | `字节集_长度` | `字节集_长度(数据)` | int | 返回字节集长度。 |
| 6 | `字节集_截取` | `字节集_截取(数据, 起始位置, 长度)` | bytes | 按 0 起始位置安全截取字节集。 |
| 7 | `字节集_拼接` | `字节集_拼接(前段, 后段)` | bytes | 拼接两个字节集，溢出时返回空字节集。 |
| 8 | `字节集_取字节` | `字节集_取字节(数据, 位置)` | int | 读取指定位置的 0～255 字节，越界返回 -1。 |
| 9 | `字节集_置字节` | `字节集_置字节(数据, 位置, 数值)` | bool | 写入一个字节，位置或数值无效时返回假。 |
| 10 | `字节集_Base64编码` | `字节集_Base64编码(数据)` | wideString | 把字节集编码为 Base64 文本。 |
| 11 | `字节集_Base64解码` | `字节集_Base64解码(Base64文本)` | bytes | 把 Base64 文本解码为字节集，格式错误返回空字节集。 |
| 12 | `字节集_十六进制编码` | `字节集_十六进制编码(数据)` | bytes | 把字节集编码为 ASCII 十六进制字节集。 |
| 13 | `字节集_十六进制解码` | `字节集_十六进制解码(十六进制)` | bytes | 把十六进制文本解码为字节集。 |
