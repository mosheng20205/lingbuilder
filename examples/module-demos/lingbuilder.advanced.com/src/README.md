# COM自动化模块完整演示

- 模块 ID：`lingbuilder.advanced.com`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 ProgID 创建 IDispatch 自动化对象，支持文本属性和无参方法。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `COM_创建对象` | `COM_创建对象(ProgID)` | bool | 创建一个 COM 自动化对象。 |
| 2 | `COM_取文本属性` | `COM_取文本属性(属性名)` | wideString | 读取文本或可转文本属性。 |
| 3 | `COM_置文本属性` | `COM_置文本属性(属性名, 值)` | bool | 设置 BSTR 文本属性。 |
| 4 | `COM_调用无参方法` | `COM_调用无参方法(方法名)` | bool | 调用无参数方法。 |
| 5 | `COM_取错误` | `COM_取错误()` | wideString | 返回最近 COM 错误。 |
| 6 | `COM_关闭` | `COM_关闭()` | void | 释放当前自动化对象。 |
