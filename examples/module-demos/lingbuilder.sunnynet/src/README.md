# 网络中间件模块完整演示

- 模块 ID：`lingbuilder.sunnynet`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块

- 设计器控件数：0
- 分组数：4

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 SunnyNet 的网络抓包与改写中间件：捕获并查看、修改本机 HTTP/HTTPS/WebSocket/TCP/UDP 收发数据，支持根证书 HTTPS 解密、按进程代理（高级）与系统代理；事件处理器在窗口 UI 线程执行。
