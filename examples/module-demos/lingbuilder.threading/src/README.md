# 多线程模块完整演示

- 模块 ID：`lingbuilder.threading`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：9
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供受控后台任务、等待回收、活动任务查询、硬件并发数和线程休眠能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `线程_启动延时输出` | `线程_启动延时输出(内容, 延时毫秒)` | int | 启动后台线程，等待指定毫秒后写入调试输出，并返回任务编号。 |
| 2 | `线程_等待全部` | `线程_等待全部()` | void | 等待当前窗口启动的全部后台任务结束并回收线程。 |
| 3 | `线程_活动数量` | `线程_活动数量()` | int | 返回当前仍在执行的后台任务数量。 |
| 4 | `线程_硬件并发数` | `线程_硬件并发数()` | int | 返回 C++ 运行时建议的并行线程数量。 |
| 5 | `线程_休眠` | `线程_休眠(毫秒)` | void | 让当前线程休眠指定毫秒；界面线程中使用会暂停界面响应。 |
| 6 | `线程_启动延时设置文本` | `线程_启动延时设置文本(控件名, 文本, 延时毫秒)` | int | 启动后台线程，延时后线程安全地设置指定控件的显示文本。 |
| 7 | `线程_启动延时添加行` | `线程_启动延时添加行(控件名, Tab分隔单元格, 延时毫秒)` | int | 启动后台线程，延时后线程安全地向列表视图追加一行。 |
| 8 | `线程_启动延时添加项目` | `线程_启动延时添加项目(控件名, 文本, 延时毫秒)` | int | 启动后台线程，延时后线程安全地向列表框追加一条日志。 |
| 9 | `线程_批量启动` | `线程_批量启动(任务数控件, 线程数控件, 列表视图, 日志列表, 状态标签)` | void | 读取输入框中的任务数和线程数，动态创建多线程并行执行任务，实时更新列表视图和日志。 |
