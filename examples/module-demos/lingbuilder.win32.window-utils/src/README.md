# Win32窗口操作模块完整演示

- 模块 ID：`lingbuilder.win32.window-utils`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 HWND 安全封装常用窗口查找、标题、显示和位置操作。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `窗口_按标题查找` | `窗口_按标题查找(标题)` | handle | 按完整窗口标题查找顶层窗口。 |
| 2 | `窗口_句柄是否有效` | `窗口_句柄是否有效(窗口句柄)` | bool | 判断 HWND 是否仍然有效。 |
| 3 | `窗口_取标题` | `窗口_取标题(窗口句柄)` | wideString | 读取窗口标题。 |
| 4 | `窗口_设置标题` | `窗口_设置标题(窗口句柄, 标题)` | bool | 设置窗口标题。 |
| 5 | `窗口_显示` | `窗口_显示(窗口句柄, 显示方式)` | bool | 按 Win32 SW_* 编号显示、隐藏、最小化或最大化窗口。 |
| 6 | `窗口_移动` | `窗口_移动(窗口句柄, 横坐标, 纵坐标, 宽度, 高度)` | bool | 移动窗口并设置尺寸。 |
| 7 | `窗口_置前台` | `窗口_置前台(窗口句柄)` | bool | 请求将窗口切换到前台。 |
