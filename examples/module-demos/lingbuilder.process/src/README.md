# 进程管理模块完整演示

- 模块 ID：`lingbuilder.process`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：10
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供受控的程序启动、等待、进程状态、按名称枚举进程 ID、枚举系统全部进程和显式进程终止能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `程序_启动` | `程序_启动(命令行, 工作目录)` | int | 启动程序并返回进程 ID，失败返回 0。 |
| 2 | `程序_启动并等待` | `程序_启动并等待(命令行, 工作目录, 超时毫秒)` | int | 启动程序并等待，返回退出码；超时或失败返回 -1。 |
| 3 | `进程_取当前ID` | `进程_取当前ID()` | int | 返回当前进程 ID。 |
| 4 | `进程_是否运行` | `进程_是否运行(进程ID)` | bool | 判断指定进程是否仍在运行。 |
| 5 | `进程_终止` | `进程_终止(进程ID, 退出码)` | bool | 显式终止指定进程；不能用于当前进程。 |
| 6 | `进程_按名称取ID列表` | `进程_按名称取ID列表(进程名, 结果数组)` | int | 按 exe 名称枚举匹配进程的 ID 列表，返回命中数量。 |
| 7 | `进程_按名称取ID列表JSON` | `进程_按名称取ID列表JSON(进程名)` | wideString | 按 exe 名称枚举进程 ID 并返回 JSON 数组文本（如 ["4321","890"]），可直接落盘或交给 JSON 模块解析。 |
| 8 | `进程_枚举全部` | `进程_枚举全部(名称数组, PID数组)` | int | 枚举系统当前全部进程（含 System 等系统进程），返回进程数量；两个数组按下标一一对应，可直接用来填充「进程名 + 进程ID」列表界面。 |
| 9 | `程序_执行并取输出` | `程序_执行并取输出(命令行, 超时毫秒)` | wideString | 执行命令行并等待结束，把标准输出与错误输出合并读回为文本；命令无法启动返回空文本，用 程序_上次执行退出码 查询退出码。 |
| 10 | `程序_上次执行退出码` | `程序_上次执行退出码()` | int | 返回本线程上一次 程序_执行并取输出 的子进程退出码；尚未执行过或命令无法启动返回 -1。 |
