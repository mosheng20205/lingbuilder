# 日期时间模块完整演示

- 模块 ID：`lingbuilder.std.datetime`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：22
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供日期时间值（64 位打包的本地年月日时分秒）与时间戳、格式化、分量读取、增减、间隔和高精度计时。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `时间_当前时间戳` | `时间_当前时间戳()` | longLong | 返回当前 Unix 秒级时间戳。 |
| 2 | `时间_当前毫秒` | `时间_当前毫秒()` | longLong | 返回当前 Unix 毫秒级时间戳。 |
| 3 | `时间_单调毫秒` | `时间_单调毫秒()` | longLong | 返回适合计算耗时的单调时钟毫秒值。 |
| 4 | `时间_格式化当前` | `时间_格式化当前(格式)` | wideString | 使用 wcsftime 格式格式化当前本地时间。 |
| 5 | `时间_格式化时间戳` | `时间_格式化时间戳(时间戳, 格式)` | wideString | 格式化指定 Unix 秒级时间戳。 |
| 6 | `时间_取现行` | `时间_取现行()` | longLong | 返回当前系统日期及时间（本地时区）。 |
| 7 | `时间_置现行` | `时间_置现行(时间)` | bool | 设置当前系统日期及时间（本地时区）；需要系统权限，普通权限下返回假。 |
| 8 | `时间_从文本` | `时间_从文本(文本)` | longLong | 把文本解析为日期时间；支持“2026年9月16日12时30分25秒”“2026-09-16 12:30:25”“20260916123025”等书写格式，时间部分可以省略。 |
| 9 | `时间_到文本` | `时间_到文本(时间, 转换部分)` | wideString | 把日期时间转为“2026年09月16日12时30分25秒”风格的中文文本。 |
| 10 | `时间_指定` | `时间_指定(年, 月, 日, 小时, 分钟, 秒)` | longLong | 用指定年月日时分秒构造日期时间；超出范围的分量自动取最相近的有效值。 |
| 11 | `时间_取年份` | `时间_取年份(时间)` | int | 返回日期时间中的年份。 |
| 12 | `时间_取月份` | `时间_取月份(时间)` | int | 返回日期时间中的月份（1～12）。 |
| 13 | `时间_取日` | `时间_取日(时间)` | int | 返回日期时间中的日（1～31）。 |
| 14 | `时间_取星期几` | `时间_取星期几(时间)` | int | 返回日期时间是星期几：星期日为 1，星期一为 2，依此类推，星期六为 7。 |
| 15 | `时间_取小时` | `时间_取小时(时间)` | int | 返回日期时间中的小时（0～23）。 |
| 16 | `时间_取分钟` | `时间_取分钟(时间)` | int | 返回日期时间中的分钟（0～59）。 |
| 17 | `时间_取秒` | `时间_取秒(时间)` | int | 返回日期时间中的秒（0～59）。 |
| 18 | `时间_增减` | `时间_增减(时间, 被增减部分, 增减值)` | longLong | 返回增减一段时间间隔后的新时间；结果无效时自动靠拢到最近的有效时间。 |
| 19 | `时间_取间隔` | `时间_取间隔(时间一, 时间二, 间隔单位)` | double | 返回“时间一”减去“时间二”的间隔数量；按指定单位取完整间隔数。 |
| 20 | `时间_取某月天数` | `时间_取某月天数(年份, 月份)` | int | 返回指定月份的天数；月份无效返回 0。 |
| 21 | `时间_取日期` | `时间_取日期(时间)` | longLong | 返回日期时间值的日期部分，时分秒固定为 0 时 0 分 0 秒。 |
| 22 | `时间_取时间` | `时间_取时间(时间)` | longLong | 返回日期时间值的时间部分，年月日固定为 2000 年 1 月 1 日。 |
