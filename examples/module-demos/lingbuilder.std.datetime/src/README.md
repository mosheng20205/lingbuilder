# 日期时间模块完整演示

- 模块 ID：`lingbuilder.std.datetime`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供本地时间格式化、Unix 时间戳和高精度单调计时。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `时间_当前时间戳` | `时间_当前时间戳()` | longLong | 返回当前 Unix 秒级时间戳。 |
| 2 | `时间_当前毫秒` | `时间_当前毫秒()` | longLong | 返回当前 Unix 毫秒级时间戳。 |
| 3 | `时间_单调毫秒` | `时间_单调毫秒()` | longLong | 返回适合计算耗时的单调时钟毫秒值。 |
| 4 | `时间_格式化当前` | `时间_格式化当前(格式)` | wideString | 使用 wcsftime 格式格式化当前本地时间。 |
| 5 | `时间_格式化时间戳` | `时间_格式化时间戳(时间戳, 格式)` | wideString | 格式化指定 Unix 秒级时间戳。 |
