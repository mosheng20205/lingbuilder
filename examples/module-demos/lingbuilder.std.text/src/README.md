# 文本处理模块完整演示

- 模块 ID：`lingbuilder.std.text`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：10
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 Unicode 文本查找、截取、替换、修剪和大小写转换能力。索引统一从 0 开始。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `文本_取长度` | `文本_取长度(文本)` | int | 返回 Unicode 文本的字符数量。 |
| 2 | `文本_寻找` | `文本_寻找(文本, 目标)` | int | 返回目标文本首次出现的从 0 开始索引，未找到返回 -1。 |
| 3 | `文本_是否包含` | `文本_是否包含(文本, 目标)` | bool | 判断文本是否包含目标内容。 |
| 4 | `文本_开头为` | `文本_开头为(文本, 前缀)` | bool | 判断文本是否以指定前缀开头。 |
| 5 | `文本_结尾为` | `文本_结尾为(文本, 后缀)` | bool | 判断文本是否以指定后缀结尾。 |
| 6 | `文本_取中间` | `文本_取中间(文本, 起始位置, 长度)` | wideString | 按从 0 开始的索引截取文本，超出范围时安全截断。 |
| 7 | `文本_替换` | `文本_替换(文本, 查找内容, 替换内容)` | wideString | 替换文本中的全部匹配内容。 |
| 8 | `文本_删首尾空白` | `文本_删首尾空白(文本)` | wideString | 删除文本首尾的 Unicode 空白字符。 |
| 9 | `文本_转大写` | `文本_转大写(文本)` | wideString | 把文本转换为大写。 |
| 10 | `文本_转小写` | `文本_转小写(文本)` | wideString | 把文本转换为小写。 |
