# 文本处理模块完整演示

- 模块 ID：`lingbuilder.std.text`
- 版本：`1.4.0`
- 类型：LingBuilder 内置模块
- 命令数：31
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 Unicode 文本查找、截取、替换、修剪、大小写转换、定宽填充（按显示列数）与数组合并能力。索引统一从 0 开始。
