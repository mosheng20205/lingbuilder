# 消息推送模块完整演示

- 模块 ID：`lingbuilder.notify`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：17
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

把文本、Markdown、图文、文件等消息主动 POST 到国内主流群机器人 webhook：企业微信群机器人、钉钉自定义机器人、飞书自定义机器人，另提供万能 推送_发JSON 兜底 Server酱/Bark/Qmsg/自建服务。内容转义、@ 人、钉钉/飞书 HMAC-SHA256 加签、企微图片 Base64/MD5 与文件 multipart 上传全部由运行时代劳，失败返回假并经 推送_取错误() 给出中文原因。只做出站推送，不做消息接收。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `推送_发JSON` | `推送_发JSON(地址, JSON文本, 超时毫秒)` | bool | 把一段现成 JSON 以 POST（Content-Type: application/json）发给任意 webhook 地址。三平台结构化命令（发企业微信文本/发钉钉文本等）能满足的场景优先用它们——内容转义、@ 人和加签都由运行时代劳；本命令是万能兜底：企微模板卡片、飞书交互卡片、Server酱/Bark/Qmsg 等第三方服务都走这里。成功指 HTTP 200，业务层是否送达请读 推送_取响应文本() 核对。 |
| 2 | `推送_取错误` | `推送_取错误()` | wideString | 返回最近一次推送命令失败或被平台拒绝时的中文原因（参数校验、网络错误、HTTP 非 200、平台 errcode 非 0、加签失败等）；最近一次成功时为空文本。所有推送命令失败都返回假、不抛异常，错误一律到这里读。 |
| 3 | `推送_取响应文本` | `推送_取响应文本()` | wideString | 返回最近一次推送请求的平台响应原文（JSON），排障刚需：errcode/errmsg、StatusCode、code 都在这里。发JSON 等自定义服务也用它核对业务返回。 |
| 4 | `推送_发企业微信文本` | `推送_发企业微信文本(地址, 内容, 手机号列表, 是否所有人)` | bool | 发企业微信群机器人文本消息，可按手机号 @ 人或 @ 所有人。红线：文本上限 2048 字节（UTF-8）；@ 只支持手机号（mentioned_mobile_list）；带引号/换行的内容由运行时自动转义，直接给原文即可。 |
| 5 | `推送_发企业微信Markdown` | `推送_发企业微信Markdown(地址, 内容)` | bool | 发企业微信群机器人 Markdown 消息。红线：企业微信的 Markdown 类型不支持 @ 人（官方限制），需要 @ 人请改用 推送_发企业微信文本。 |
| 6 | `推送_发企业微信图片` | `推送_发企业微信图片(地址, 图片路径)` | bool | 发企业微信群机器人图片消息。只需给本地路径，运行时自动读文件、算 Base64 与 MD5（小写十六进制）并组包；格式（jpg/png）、大小（≤2MB）在本地预校验，失败给中文原因。 |
| 7 | `推送_发企业微信图文` | `推送_发企业微信图文(地址, 图文条目文本)` | bool | 发企业微信群机器人图文消息（news 卡片链接），一次 1~8 条。条目按行拆、字段按竖线拆，全部由运行时组装与转义；条数不在 1~8 内或跳转链接缺失直接失败并给中文原因。 |
| 8 | `推送_上传企业微信文件` | `推送_上传企业微信文件(地址, 文件路径)` | wideString | 上传本地文件到企业微信临时素材，返回 media_id（供 推送_发企业微信文件 发送）；multipart/form-data 组包由运行时完成。失败返回空文本，原因读 推送_取错误()。media_id 三天有效，过期需重新上传。 |
| 9 | `推送_发企业微信文件` | `推送_发企业微信文件(地址, media_id)` | bool | 发企业微信群机器人文件消息（先 推送_上传企业微信文件 拿 media_id，再用本命令发送）。文件上限 20MB、media_id 三天有效。注意：语音（voice）类型 webhook 不支持，本模块未提供。 |
| 10 | `推送_发钉钉文本` | `推送_发钉钉文本(地址, 内容, 手机号列表, 是否所有人, 加签密钥)` | bool | 发钉钉自定义机器人文本消息（atMobiles/isAtAll 语义），时间戳与 sign 由运行时拼进地址。红线：约 20 条/分钟限流；机器人安全设置三选一——关键词（内容里带关键词）、加签（传本密钥）、IP 白名单；关键词与加签可以叠加，叠加时内容既要带关键词签名也要合法。 |
| 11 | `推送_发钉钉Markdown` | `推送_发钉钉Markdown(地址, 内容, 手机号列表, 是否所有人, 加签密钥)` | bool | 发钉钉自定义机器人 Markdown 消息。与企微相反：钉钉的 Markdown 能 @ 人——运行时把 atMobiles/isAtAll 组进 at 字段，并自动在正文末尾补上缺失的 @手机号 文本（钉钉要求正文里出现 @手机号 才显示 @）；会话列表标题（title）自动取正文首个非空行（去掉行首井号，截 20 字）。机器人开了关键词校验时，关键词要出现在 Markdown 正文里。 |
| 12 | `推送_发钉钉链接` | `推送_发钉钉链接(地址, 标题, 内容, 跳转链接, 图片链接, 加签密钥)` | bool | 发钉钉自定义机器人 Link 消息（标题 + 描述 + 跳转 + 可选配图），适合推送带跳转的通知。跳转链接不能为空。 |
| 13 | `推送_发钉钉卡片单按钮` | `推送_发钉钉卡片单按钮(地址, 标题, 内容, 按钮标题, 跳转链接, 加签密钥)` | bool | 发钉钉自定义机器人 ActionCard 整体跳转卡片（单按钮），典型用法：构建失败卡片 + 「查看日志」按钮。 |
| 14 | `推送_发钉钉卡片多按钮` | `推送_发钉钉卡片多按钮(地址, 标题, 内容, 按钮列表文本, 是否横排, 加签密钥)` | bool | 发钉钉自定义机器人 ActionCard 独立跳转卡片（多按钮），按钮按行拆、字段按竖线拆，由运行时组装转义。 |
| 15 | `推送_发钉钉图文` | `推送_发钉钉图文(地址, 图文条目文本, 加签密钥)` | bool | 发钉钉自定义机器人 FeedCard 多图文卡片，适合一次推多条带图资讯。红线：钉钉 webhook 不支持直接发图片消息（那是接口方式的权限），带图只能用本命令的图片 URL 形式。 |
| 16 | `推送_发飞书文本` | `推送_发飞书文本(地址, 内容, 用户ID列表, 是否所有人, 加签密钥)` | bool | 发飞书自定义机器人文本消息。@ 人语义与另两家都不同：飞书按 open_id 内联标签（<at user_id="...">），不是手机号——运行时把列表包成标签追加到正文末尾，@ 所有人追加 <at user_id="all">所有人</at>。签名校验的密钥（开启时）由运行时计算并写进请求体 timestamp/sign 字段。 |
| 17 | `推送_发飞书富文本` | `推送_发飞书富文本(地址, 多行文本)` | bool | 发飞书自定义机器人富文本（post）消息，本命令封装「每行一个文本段落」的最常用形态：一行变一个 text 元素，段落转义由运行时完成。链接、图片、@ 提醒等嵌套元素走 推送_发JSON。 |
