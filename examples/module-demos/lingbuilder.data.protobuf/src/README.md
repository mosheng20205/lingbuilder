# Protocol Buffers 模块完整演示

- 模块 ID：`lingbuilder.data.protobuf`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：20
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

无 schema 的 protobuf wire 编解码（不需要 .proto 与 SDK，适合抓包逆向）+ 受控 protoc descriptor 反射消息序列化。

| 11 | `PB_写字段_固定32` | `PB_写字段_固定32(数据, 字段号, 值)` | bytes | 在字节集末尾追加一个 32 位固定宽度字段（wire type 5，小端），值按位模式处理，返回新字节集。 |

| 13 | `PB_写字段_字节集` | `PB_写字段_字节集(数据, 字段号, 值)` | bytes | 在字节集末尾追加一个长度分隔字段（wire type 2），返回新字节集；字节集内容原样写入。 |

| 18 | `PB_字段信息JSON` | `PB_字段信息JSON(数据)` | wideString | 无 schema 解析顶层字段，返回 JSON 数组，每个元素含 字段号/wire/varint（有符号十进制）/hex（载荷十六进制）/utf8（载荷是合法可打印 UTF-8 时给出文本）；数据非法或截断时返回空文本，可用 PB_取最后错误 查看原因。 |
| 19 | `PB_字节集转文本树` | `PB_字节集转文本树(数据, 缩进)` | wideString | 无 schema 调试打印（protoc --decode_raw 风格）：逐字段递归展开为多行文本树，wire2 载荷先尝试按嵌套消息解析（成功递归），否则可打印 UTF-8 按文本显示，否则按十六进制显示；数据非法或截断时返回以 [非法] 开头的说明文本。缩进为每层嵌套空格数（1 到 8，其它值按 2）。 |
| 20 | `PB_导出Proto草稿` | `PB_导出Proto草稿(数据)` | wideString | 按观察到的顶层字段号与线型推断 .proto 草稿（varint→int64、wire1→fixed64、wire5→fixed32、wire2→bytes），供人工判读与 protoc 交叉核对；同一字段出现多种线型时在注释里标注。数据非法或截断时返回空文本。 |
