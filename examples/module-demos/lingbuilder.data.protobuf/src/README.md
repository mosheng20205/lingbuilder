# Protocol Buffers 模块完整演示

- 模块 ID：`lingbuilder.data.protobuf`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：9
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

使用受控 protoc 生成 C++ 消息代码，并通过字节集和反射句柄完成序列化。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `PB_加载描述集` | `PB_加载描述集(路径)` | handle | 加载 protoc 生成的 descriptor set，成功返回描述集句柄。 |
| 2 | `PB_创建消息` | `PB_创建消息(描述集, 类型名)` | handle | 按完整消息类型名创建反射消息句柄。 |
| 3 | `PB_从字节集解析` | `PB_从字节集解析(消息, 数据)` | bool | 把字节集解析到消息句柄。 |
| 4 | `PB_序列化为字节集` | `PB_序列化为字节集(消息)` | bytes | 把消息序列化为正式字节集。 |
| 5 | `PB_从JSON` | `PB_从JSON(消息, JSON)` | bool | 按 Protobuf JSON 语义填充消息。 |
| 6 | `PB_到JSON` | `PB_到JSON(消息)` | wideString | 按 Protobuf JSON 语义导出消息。 |
| 7 | `PB_取最后错误` | `PB_取最后错误()` | wideString | 返回当前线程最近一次 Protobuf 错误。 |
| 8 | `PB_释放消息` | `PB_释放消息(消息)` | void | 释放消息句柄。 |
| 9 | `PB_释放描述集` | `PB_释放描述集(描述集)` | void | 释放描述集句柄。 |
