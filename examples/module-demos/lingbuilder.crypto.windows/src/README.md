# Windows数据保护模块完整演示

- 模块 ID：`lingbuilder.crypto.windows`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

使用当前 Windows 用户的 DPAPI 保护文本和原始字节集，不暴露密钥。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `数据保护_加密文本` | `数据保护_加密文本(文本)` | wideString | 使用当前用户 DPAPI 加密 UTF-8 文本并返回 Base64。 |
| 2 | `数据保护_解密文本` | `数据保护_解密文本(Base64密文)` | wideString | 解密当前用户 DPAPI Base64 密文。 |
| 3 | `数据保护_加密字节集` | `数据保护_加密字节集(数据)` | bytes | 使用当前用户 DPAPI 加密原始字节集，返回未经 Base64 包装的密文字节集。 |
| 4 | `数据保护_解密字节集` | `数据保护_解密字节集(密文)` | bytes | 解密 DPAPI 原始密文字节集并返回原始明文字节集，不做 UTF-8 解释；自动剥离 Chromium 的 "DPAPI" 前缀。二进制密钥必须用本命令，不要用 数据保护_解密文本。 |
| 5 | `数据保护_机器级加密文本` | `数据保护_机器级加密文本(文本)` | wideString | 使用本机范围 DPAPI 加密文本。 |
| 6 | `数据保护_取错误` | `数据保护_取错误()` | wideString | 返回最近一次文本或字节集数据保护命令的中文错误。 |
