# 显示器与DPI模块完整演示

- 模块 ID：`lingbuilder.win32.monitor`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取显示器数量、主屏尺寸、工作区尺寸和系统 DPI。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `显示器_数量` | `显示器_数量()` | int | 返回当前桌面连接的显示器数量。 |
| 2 | `显示器_主屏宽度` | `显示器_主屏宽度()` | int | 返回主显示器像素宽度。 |
| 3 | `显示器_主屏高度` | `显示器_主屏高度()` | int | 返回主显示器像素高度。 |
| 4 | `显示器_工作区宽度` | `显示器_工作区宽度()` | int | 返回主显示器排除任务栏后的工作区宽度。 |
| 5 | `显示器_工作区高度` | `显示器_工作区高度()` | int | 返回主显示器排除任务栏后的工作区高度。 |
| 6 | `显示器_系统DPI` | `显示器_系统DPI()` | int | 返回系统 DPI，无法读取时返回 96。 |
