# 辅助功能模块完整演示

- 模块 ID：`lingbuilder.win32.accessibility`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：4
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

通过 Microsoft Active Accessibility 读取窗口对象名称、值、角色和状态。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `辅助_取名称` | `辅助_取名称(窗口句柄)` | wideString | 读取窗口可访问对象名称。 |
| 2 | `辅助_取值` | `辅助_取值(窗口句柄)` | wideString | 读取窗口可访问对象值。 |
| 3 | `辅助_取角色` | `辅助_取角色(窗口句柄)` | wideString | 返回本地化角色文本。 |
| 4 | `辅助_取状态值` | `辅助_取状态值(窗口句柄)` | longLong | 返回 MSAA 状态位。 |
