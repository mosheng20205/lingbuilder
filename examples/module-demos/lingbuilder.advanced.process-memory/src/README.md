# 进程内存模块完整演示

- 模块 ID：`lingbuilder.advanced.process-memory`
- 版本：`1.2.0`
- 类型：LingBuilder 内置模块
- 命令数：12
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

显式打开目标进程，读写整数与字节集、枚举已提交内存区域并做字节集特征扫描；打开失败时区分"拒绝访问（需要管理员）"等中文错误。属于高风险模块，默认随新项目启用，可按项目禁用。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `进程内存_打开` | `进程内存_打开(进程ID, 允许写入)` | handle | 打开目标进程句柄；失败返回 0，错误码与中文原因可用 进程内存_取错误码/取错误 读取。 |
| 2 | `进程内存_读整数` | `进程内存_读整数(进程句柄, 地址, 默认值)` | int | 读取目标地址 32 位整数。 |
| 3 | `进程内存_写整数` | `进程内存_写整数(进程句柄, 地址, 数值)` | bool | 写入目标地址 32 位整数。 |
| 4 | `进程内存_写字节集` | `进程内存_写字节集(进程句柄, 地址, 数据)` | bool | 按地址向目标进程批量写入字节集（WriteProcessMemory 语义）；句柄、长度或地址非法时返回假，中文原因可用 进程内存_取错误 读取。 |
| 5 | `进程内存_读字节集` | `进程内存_读字节集(进程句柄, 地址, 长度)` | bytes | 按地址从目标进程批量读取字节集；句柄、长度或地址非法，以及完全读不到时返回空字节集。 |
| 6 | `进程内存_读到缓冲区` | `进程内存_读到缓冲区(进程句柄, 地址, 长度)` | longLong | 读取目标进程内存并直接装入 缓冲区模块 的缓冲区，返回缓冲区句柄；本模块依赖 lingbuilder.std.buffer，启用时自动带上。 |
| 7 | `进程内存_枚举区域JSON` | `进程内存_枚举区域JSON(进程句柄, 只列已提交可读区域)` | wideString | 用 VirtualQueryEx 枚举目标进程内存区域，返回 JSON 数组，每个元素含 baseAddress/regionSize/state/protect/type（十进制数值）。 |
| 8 | `进程内存_扫描字节集` | `进程内存_扫描字节集(进程句柄, 特征字节集, 最大命中数, 结果数组)` | int | 在目标进程已提交可读内存中扫描特征字节集（内部自动分块读取），返回命中数量；需要管理员权限的进程要先以管理员身份运行。 |
| 9 | `进程内存_扫描字节集JSON` | `进程内存_扫描字节集JSON(进程句柄, 特征字节集, 最大命中数)` | wideString | 同 进程内存_扫描字节集，但把升序去重后的命中地址返回为 JSON 数组文本（如 [819200, 991232]），可直接落盘；失败返回空文本。 |
| 10 | `进程内存_取错误码` | `进程内存_取错误码()` | int | 返回本线程最近一次进程内存操作的 Win32 错误码：5=拒绝访问（通常需要管理员）、87=参数无效、299=部分读取成功；0 表示成功或尚未执行操作。 |
| 11 | `进程内存_取错误` | `进程内存_取错误()` | wideString | 返回最近一次进程内存操作的中文错误说明（含"需要以管理员身份运行"等指引）；没有错误时返回空文本。 |
| 12 | `进程内存_关闭` | `进程内存_关闭(进程句柄)` | bool | 关闭目标进程句柄。 |
