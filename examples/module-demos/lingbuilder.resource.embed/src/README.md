# 内嵌资源模块完整演示

- 模块 ID：`lingbuilder.resource.embed`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：8
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

按逻辑名读取构建期以 RCDATA 打进 EXE 的项目内嵌资源（任意格式：图片、文本、zip、DLL 字节集等），全程不落盘。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `资源_取字节集` | `资源_取字节集(逻辑名)` | bytes | 把内嵌资源读成字节集（失败返回空字节集，原因见 资源_取错误信息）。可直接喂给 内存DLL_加载、图片控件或网络上传。 |
| 2 | `资源_取文本` | `资源_取文本(逻辑名)` | wideString | 把内嵌资源按 UTF-8 解码为文本（失败返回空文本）。适合内嵌的 txt/json/html 等文本文件。 |
| 3 | `资源_是否存在` | `资源_是否存在(逻辑名)` | bool | 判断内嵌资源是否存在（资源清单里声明且 EXE 里能取到）。 |
| 4 | `资源_取大小` | `资源_取大小(逻辑名)` | int | 返回内嵌资源的字节数；资源不存在时返回 0 并写入中文错误信息。 |
| 5 | `资源_列表` | `资源_列表()` | wideString | 返回全部内嵌资源的逻辑名（每行一个），用于自检与调试。 |
| 6 | `资源_保存到文件` | `资源_保存到文件(逻辑名, 路径)` | wideString | 把内嵌资源写成真实文件（覆盖写），返回文件路径；失败返回空文本。供只接受磁盘路径的第三方 API 使用。 |
| 7 | `资源_释放到临时目录` | `资源_释放到临时目录(逻辑名)` | wideString | 把内嵌资源释放到 %TEMP%\lingbuilder-embedded\<工程ID>\ 下（保持逻辑名的子目录结构），返回文件路径；适合"必须给磁盘文件"的库。 |
| 8 | `资源_取错误信息` | `资源_取错误信息()` | wideString | 返回最近一次内嵌资源操作的中文错误原因（例如逻辑名未声明、EXE 里没有该资源）。 |
