# XML 文本模块完整演示

- 模块 ID：`lingbuilder.data.xml`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供 XML 文本转义、节点生成和简单节点内容读取，不执行外部实体。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `XML_转义文本` | `XML_转义文本(文本)` | wideString | 转义 XML 文本节点中的特殊字符。 |
| 2 | `XML_反转义文本` | `XML_反转义文本(文本)` | wideString | 还原本模块支持的五种预定义 XML 实体。 |
| 3 | `XML_生成节点` | `XML_生成节点(节点名, 内容)` | wideString | 生成包含安全转义文本的简单 XML 节点；非法节点名返回空文本。 |
| 4 | `XML_是否包含节点` | `XML_是否包含节点(XML文本, 节点名)` | bool | 判断 XML 文本是否包含指定简单节点。 |
| 5 | `XML_取节点文本` | `XML_取节点文本(XML文本, 节点名)` | wideString | 读取第一个指定简单节点的文本内容并反转义。 |
