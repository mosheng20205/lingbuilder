# 数学与随机模块完整演示

- 模块 ID：`lingbuilder.std.math`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供常用数学函数、范围限制和线程安全随机整数。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `数学_绝对值` | `数学_绝对值(数值)` | double | 返回数值的绝对值。 |
| 2 | `数学_最小值` | `数学_最小值(数值一, 数值二)` | double | 返回两个数值中的较小值。 |
| 3 | `数学_最大值` | `数学_最大值(数值一, 数值二)` | double | 返回两个数值中的较大值。 |
| 4 | `数学_限制范围` | `数学_限制范围(数值, 最小值, 最大值)` | double | 将数值限制在指定闭区间内。 |
| 5 | `数学_平方根` | `数学_平方根(数值)` | double | 返回非负数值的平方根，负数返回 0。 |
| 6 | `数学_乘方` | `数学_乘方(底数, 指数)` | double | 返回底数的指定次方。 |
| 7 | `数学_随机整数` | `数学_随机整数(最小值, 最大值)` | int | 返回指定闭区间内的随机整数，参数顺序可交换。 |
