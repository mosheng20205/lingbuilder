# ODBC数据库模块完整演示

- 模块 ID：`lingbuilder.database.odbc`
- 版本：`1.1.0`
- 类型：LingBuilder 内置模块
- 命令数：15
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供单连接 ODBC 打开、执行、查询首值、多行结果集遍历、SQL 文本转义、事务和错误状态。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `ODBC_连接` | `ODBC_连接(连接字符串)` | bool | 使用 ODBC 连接字符串打开数据库。 |
| 2 | `ODBC_执行` | `ODBC_执行(SQL语句)` | int | 执行 SQL 并返回受影响行数，失败返回 -1。 |
| 3 | `ODBC_转义文本` | `ODBC_转义文本(文本)` | wideString | 把文本中的半角单引号成对翻倍，用于把用户输入安全拼进 SQL 字符串字面量；数值等非文本值直接拼接即可，不需要转义。 |
| 4 | `ODBC_查询首值` | `ODBC_查询首值(SQL语句)` | wideString | 执行查询并返回首行首列文本；超长值自动分段读取，没有固定长度上限。失败或查询无结果行时返回空文本，失败原因用 ODBC_取错误 读取。 |
| 5 | `ODBC_查询打开` | `ODBC_查询打开(SQL语句)` | longLong | 执行查询并返回结果集编号（从 1 起，0 表示失败，失败原因用 ODBC_取错误 读取）。配合 ODBC_取下一行/ODBC_取列文本 逐行读取，用完必须 ODBC_查询关闭；重新 ODBC_连接 或 ODBC_关闭 会作废全部已打开编号。 |
| 6 | `ODBC_取下一行` | `ODBC_取下一行(结果集编号)` | bool | 把结果集游标推进到下一行；有下一行返回真，正常读完返回假（此时 ODBC_取错误 为空），失败也返回假（ODBC_取错误 给中文原因）。 |
| 7 | `ODBC_取列文本` | `ODBC_取列文本(结果集编号, 列序号)` | wideString | 读取当前行指定列的文本值；NULL 与失败都返回空文本，失败用 ODBC_取错误 区分；超长列自动分段读取，没有固定长度上限。 |
| 8 | `ODBC_取列数` | `ODBC_取列数(结果集编号)` | int | 返回当前结果集的列数，编号无效返回 0。 |
| 9 | `ODBC_取列名` | `ODBC_取列名(结果集编号, 列序号)` | wideString | 返回当前结果集指定列的列名，编号无效或列不存在返回空文本。 |
| 10 | `ODBC_查询关闭` | `ODBC_查询关闭(结果集编号)` | bool | 关闭 ODBC_查询打开 返回的结果集并释放资源；编号无效返回假。 |
| 11 | `ODBC_设置自动提交` | `ODBC_设置自动提交(启用)` | bool | 启用或禁用自动提交。 |
| 12 | `ODBC_提交` | `ODBC_提交()` | bool | 提交当前事务。 |
| 13 | `ODBC_回滚` | `ODBC_回滚()` | bool | 回滚当前事务。 |
| 14 | `ODBC_取错误` | `ODBC_取错误()` | wideString | 返回最近 ODBC 错误。 |
| 15 | `ODBC_关闭` | `ODBC_关闭()` | void | 关闭 ODBC 连接和环境，同时作废全部已打开的结果集编号。 |
