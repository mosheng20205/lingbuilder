# ODBC数据库模块完整演示

- 模块 ID：`lingbuilder.database.odbc`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：8
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供单连接 ODBC 打开、执行、查询首值、事务和错误状态。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `ODBC_连接` | `ODBC_连接(连接字符串)` | bool | 使用 ODBC 连接字符串打开数据库。 |
| 2 | `ODBC_执行` | `ODBC_执行(SQL语句)` | int | 执行 SQL 并返回受影响行数，失败返回 -1。 |
| 3 | `ODBC_查询首值` | `ODBC_查询首值(SQL语句)` | wideString | 执行查询并返回首行首列文本。 |
| 4 | `ODBC_设置自动提交` | `ODBC_设置自动提交(启用)` | bool | 启用或禁用自动提交。 |
| 5 | `ODBC_提交` | `ODBC_提交()` | bool | 提交当前事务。 |
| 6 | `ODBC_回滚` | `ODBC_回滚()` | bool | 回滚当前事务。 |
| 7 | `ODBC_取错误` | `ODBC_取错误()` | wideString | 返回最近 ODBC 错误。 |
| 8 | `ODBC_关闭` | `ODBC_关闭()` | void | 关闭 ODBC 连接和环境。 |
