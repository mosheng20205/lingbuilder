# 网页访问模块完整演示

- 模块 ID：`lingbuilder.web.http`
- 版本：`1.1.1`
- 类型：外置/资产模块
- 命令数：12
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 Windows WinHTTP 封装易语言风格的网页_访问_对象命令，支持 GET、POST、Cookie、请求头、响应头、状态码、代理、超时和重定向控制。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `网页_异步访问` | `网页_异步访问(网址, 访问方式, 完成处理器)` | int | 在受控后台线程中访问网页，立即返回请求编号；完成处理器使用 &处理器名 引用，并在 UI 主线程执行。 |
| 2 | `网页_异步取返回文本` | `网页_异步取返回文本(请求编号)` | wideString | 按请求编号读取异步网页访问的 UTF-8 文本结果。 |
| 3 | `网页_异步取状态代码` | `网页_异步取状态代码(请求编号)` | int | 按请求编号读取 HTTP 状态代码。 |
| 4 | `网页_异步取错误信息` | `网页_异步取错误信息(请求编号)` | wideString | 按请求编号读取异步访问的中文错误信息。 |
| 5 | `网页_异步取当前请求编号` | `网页_异步取当前请求编号()` | int | 在异步完成处理器中读取当前正在分发的请求编号。 |
| 6 | `网页_异步取消` | `网页_异步取消(请求编号)` | bool | 标记取消指定异步请求；当前 WinHTTP 请求返回后会以已取消状态分发完成处理器。 |
| 7 | `网页_访问_对象` | `网页_访问_对象(网址, 访问方式, 提交信息, 提交Cookies, 返回Cookies, 附加协议头, 返回协议头, 返回状态代码, 禁止重定向, 字节集提交, 代理地址, 超时, 代理用户名, 代理密码, 代理标识, 对象继承, 是否自动合并更新Cookie, 是否补全必要协议头, 是否处理协议头大小写)` | bytes | 使用 WinHTTP 对象方式访问网页。访问方式：0=GET，1=POST，2=HEAD，3=PUT，4=OPTIONS，5=DELETE，6=TRACE，7=CONNECT，8=PATCH。 |
| 8 | `网页_取返回文本` | `网页_取返回文本()` | wideString | 读取最近一次网页_访问_对象返回的 UTF-8 文本内容。 |
| 9 | `网页_取返回Cookies` | `网页_取返回Cookies()` | wideString | 读取最近一次网页_访问_对象返回的 Cookie。 |
| 10 | `网页_取返回协议头` | `网页_取返回协议头()` | wideString | 读取最近一次网页_访问_对象返回的响应协议头。 |
| 11 | `网页_取返回状态代码` | `网页_取返回状态代码()` | int | 读取最近一次网页_访问_对象返回的 HTTP 状态代码。 |
| 12 | `网页_取错误信息` | `网页_取错误信息()` | wideString | 读取最近一次网页访问失败时的中文错误信息。 |
