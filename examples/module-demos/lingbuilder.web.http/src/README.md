# 网页访问模块完整演示

- 模块 ID：`lingbuilder.web.http`
- 版本：`1.3.0`
- 类型：LingBuilder 内置模块
- 命令数：13
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 Windows WinHTTP 封装易语言风格的网页_访问_对象命令，支持 GET、POST、Cookie、请求头、响应头、状态码、代理、超时和重定向控制，并提供回到 UI 主线程的网页_异步访问后台线程命令族（1.3.0 起异步命令支持请求头/正文/代理/超时/重定向等完整参数）。
