# 系统外壳模块完整演示

- 模块 ID：`lingbuilder.system.shell`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供打开文件或网址、资源管理器定位和常用系统目录读取。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `系统_打开` | `系统_打开(目标)` | bool | 使用系统默认程序打开文件、目录或网址。 |
| 2 | `系统_定位文件` | `系统_定位文件(路径)` | bool | 在资源管理器中选中指定文件。 |
| 3 | `系统_取临时目录` | `系统_取临时目录()` | wideString | 返回当前用户临时目录。 |
| 4 | `系统_取桌面目录` | `系统_取桌面目录()` | wideString | 返回当前用户桌面目录。 |
| 5 | `系统_取文档目录` | `系统_取文档目录()` | wideString | 返回当前用户文档目录。 |
