# 对称加密模块完整演示

- 模块 ID：`lingbuilder.crypto.symmetric`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：32
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供认证加密、传统分组加密和兼容流加密；普通命令密钥使用严格十六进制文本、密文使用带算法和随机数的自描述封装，带 裸 后缀的 AES-GCM/RC4 命令密钥/随机数/密文全部使用字节集且不含自描述头，用于兼容 Chromium 等外部密文格式或协议级流加密。
