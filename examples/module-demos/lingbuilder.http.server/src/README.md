# HTTP 服务端模块完整演示

- 模块 ID：`lingbuilder.http.server`
- 版本：`2.3.0`
- 类型：LingBuilder 内置模块
- 命令数：63
- 设计器控件数：0
- 分组数：4

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供受管 HTTP/1.1 服务端、后台多连接处理、路由（含工作线程直回的静态路由）、完整请求读取、可配置响应、SSE 单向推送（服务端 → 客户端持续下发事件流）、离线接口文档（OpenAPI 3.0.3 规范 + Swagger UI 可交互调试页）、资源限制、连接轮转和运行状态。
