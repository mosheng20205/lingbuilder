# HTTP 服务端模块完整演示

- 模块 ID：`lingbuilder.http.server`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供基于 Windows Winsock 的本地 HTTP 服务端启动、等待请求、返回文本和关闭能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `HTTP_启动服务` | `HTTP_启动服务(端口)` | int | 在 127.0.0.1 指定端口启动单连接 HTTP 服务端，成功返回 1。 |
| 2 | `HTTP_等待请求` | `HTTP_等待请求()` | wideString | 等待并读取一个 HTTP 请求头，返回最近请求文本。 |
| 3 | `HTTP_等待请求到调试输出` | `HTTP_等待请求到调试输出()` | int | 等待一个 HTTP 请求并把请求头写入调试输出。 |
| 4 | `HTTP_回复文本` | `HTTP_回复文本(内容)` | int | 向当前 HTTP 请求返回 UTF-8 文本响应，并关闭该请求连接。 |
| 5 | `HTTP_关闭服务` | `HTTP_关闭服务()` | void | 关闭当前 HTTP 服务端监听和请求连接。 |
