# 键盘输入模块完整演示

- 模块 ID：`lingbuilder.input.keyboard`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读取键盘状态并通过 SendInput 执行受控按键操作。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `键盘_键是否按下` | `键盘_键是否按下(虚拟键码)` | bool | 判断指定 Win32 虚拟键当前是否按下。 |
| 2 | `键盘_大小写锁定状态` | `键盘_大小写锁定状态()` | bool | 读取 Caps Lock 切换状态。 |
| 3 | `键盘_数字锁定状态` | `键盘_数字锁定状态()` | bool | 读取 Num Lock 切换状态。 |
| 4 | `键盘_单击` | `键盘_单击(虚拟键码)` | bool | 模拟一次按下并释放。 |
| 5 | `键盘_组合按键` | `键盘_组合按键(修饰键码, 主键码)` | bool | 模拟修饰键与主键组合。 |
