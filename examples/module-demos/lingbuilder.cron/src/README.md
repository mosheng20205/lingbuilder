# 定时任务模块完整演示

- 模块 ID：`lingbuilder.cron`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：29
- 设计器控件数：0
- 分组数：2

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供标准 cron 表达式的周期调度、crontab 表文件管理、进程内守护线程、开机自启和 MAILTO 邮件通知；命令型任务经 cmd.exe 执行外部命令。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `cron_定时_启动` | `cron_定时_启动(表达式, &处理器)` | longLong | 按 cron 表达式注册周期任务；到点后在注册窗口 UI 线程执行处理器，窗口关闭时任务自动停止。 |
| 2 | `cron_定时_提交线程` | `cron_定时_提交线程(表达式, &工作处理器, &完成处理器)` | longLong | 按 cron 表达式注册周期任务；到点后在 cron 后台线程执行工作处理器，结束后在注册窗口 UI 线程执行完成处理器。 |
| 3 | `cron_定时_停止` | `cron_定时_停止(任务)` | bool | 停止指定的定时任务；正在执行中的本轮触发不会被中断。 |

| 8 | `cron_定时_取状态` | `cron_定时_取状态(任务)` | wideString | 返回任务状态的中文说明：等待中、已暂停、已停止或不存在。 |
| 9 | `cron_定时_下次触发时间` | `cron_定时_下次触发时间(任务)` | wideString | 返回任务下次触发的本地时间（格式 2026-09-21 18:30:00）；已暂停、已停止或不存在时返回空文本。 |

| 11 | `cron_定时_校验表达式` | `cron_定时_校验表达式(表达式)` | bool | 校验 cron 表达式是否合法；具体原因用 cron_定时_取表达式错误 查询。 |
| 12 | `cron_定时_取表达式错误` | `cron_定时_取表达式错误(表达式)` | wideString | 返回表达式的中文错误说明；表达式合法时返回空文本。 |
| 13 | `cron_定时_表达式说明` | `cron_定时_表达式说明(表达式)` | wideString | 把 cron 表达式翻译成人话（例如「每 5 分钟」「每天 02:00」）；表达式非法时返回空文本。 |
| 14 | `cron_定时_取任务数量` | `cron_定时_取任务数量()` | int | 返回当前进程内未停止的定时任务数量（含表载入的命令型任务）。 |
| 15 | `cron_定时_取错误` | `cron_定时_取错误()` | wideString | 返回最近一次 cron 模块操作失败的中文原因；无失败时返回空文本。 |
| 16 | `cron_定时_表路径` | `cron_定时_表路径()` | wideString | 返回系统默认 crontab 表文件的完整路径（目录不存在时会自动创建）。 |
| 17 | `cron_定时_表读取` | `cron_定时_表读取(路径)` | wideString | 读取 crontab 表文件全部内容；文件不存在时返回空文本。 |
| 18 | `cron_定时_表保存` | `cron_定时_表保存(内容, 路径)` | bool | 把内容整体写入 crontab 表文件（UTF-8，覆盖保存）；目录不存在会自动创建。 |
| 19 | `cron_定时_表添加` | `cron_定时_表添加(表达式, 命令行, 注释, 路径)` | bool | 向 crontab 表追加一行「表达式 命令行」；表达式不合法或命令行为空时返回假，不写入。 |
| 20 | `cron_定时_表删除` | `cron_定时_表删除(行号, 路径)` | bool | 按任务行号删除表中的一行；行号按「非空且非 # 注释」的行从 1 计数。 |
| 21 | `cron_定时_表清空` | `cron_定时_表清空(路径)` | bool | 清空 crontab 表文件内容；已载入运行的任务不受影响，需要另外 cron_定时_停止全部。 |

| 24 | `cron_定时_守护停止` | `cron_定时_守护停止()` | bool | 停止守护调度线程；已注册的任务保留，正在执行的外部命令不会被中断。 |

| 26 | `cron_定时_开机自启` | `cron_定时_开机自启(是否启用)` | bool | 把本程序注册/注销为开机自启（当前用户注册表 Run 键，参数 --lingbuilder-cron-daemon）；登录后系统静默拉起本程序进入守护模式，不需要管理员权限。 |

| 29 | `cron_定时_邮件测试` | `cron_定时_邮件测试()` | bool | 用当前配置发送一封测试邮件，验证 SMTP 账号是否可用；失败原因用 cron_定时_取错误 查询。 |
