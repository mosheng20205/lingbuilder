# CEF3事件模块完整演示

- 模块 ID：`lingbuilder.cef3.events`
- 版本：`3.0.0-alpha.3`
- 类型：LingBuilder 内置模块
- 命令数：6
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供浏览器事件数据、同步决策和处理器引用绑定。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `CEF3事件_取最近事件` | `CEF3事件_取最近事件(控件名)` | wideString | 取得指定浏览器最近事件名。 |
| 2 | `CEF3事件_取数据` | `CEF3事件_取数据(控件名)` | wideString | 取得当前或最近事件的主要文本。 |
| 3 | `CEF3事件_取字段` | `CEF3事件_取字段(控件名, 字段名)` | wideString | 读取当前事件的结构化字段。 |
| 4 | `CEF3事件_设置结果` | `CEF3事件_设置结果(控件名, 动作)` | int | 设置当前同步事件动作。 |
| 5 | `CEF3事件_设置返回文本` | `CEF3事件_设置返回文本(控件名, 文本)` | int | 设置当前同步事件返回文本。 |
| 6 | `CEF3事件_绑定` | `CEF3事件_绑定(控件名, 事件名, 处理器)` | int | 把浏览器事件绑定到当前类的无参数处理器。 |
