# 键盘Hook模块完整演示

- 模块 ID：`lingbuilder.advanced.hook`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：4
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供当前桌面低级键盘 Hook 状态读取；不支持注入或修改其他进程。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `键盘钩子_启动` | `键盘钩子_启动()` | bool | 启动 WH_KEYBOARD_LL 钩子。 |
| 2 | `键盘钩子_取最后键码` | `键盘钩子_取最后键码()` | int | 读取最近键盘消息虚拟键码。 |
| 3 | `键盘钩子_取消息数量` | `键盘钩子_取消息数量()` | longLong | 读取钩子收到的消息数量。 |
| 4 | `键盘钩子_停止` | `键盘钩子_停止()` | void | 卸载键盘钩子。 |
