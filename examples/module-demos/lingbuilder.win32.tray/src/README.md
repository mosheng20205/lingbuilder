# 托盘图标模块完整演示

- 模块 ID：`lingbuilder.win32.tray`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

向通知区域添加、修改、显示气泡和删除托盘图标。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `托盘_添加` | `托盘_添加(窗口句柄, 编号, 提示文本)` | bool | 使用应用默认图标添加托盘图标。 |
| 2 | `托盘_修改提示` | `托盘_修改提示(窗口句柄, 编号, 提示文本)` | bool | 修改托盘提示文本。 |
| 3 | `托盘_显示通知` | `托盘_显示通知(窗口句柄, 编号, 标题, 内容)` | bool | 显示托盘气泡通知。 |
| 4 | `托盘_删除` | `托盘_删除(窗口句柄, 编号)` | bool | 删除托盘图标。 |
| 5 | `托盘_取回调消息号` | `托盘_取回调消息号()` | int | 返回固定回调消息 WM_APP+77。 |
