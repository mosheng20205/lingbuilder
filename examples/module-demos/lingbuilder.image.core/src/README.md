# 图像基础模块完整演示

- 模块 ID：`lingbuilder.image.core`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：7
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 GDI+ 提供图片尺寸、格式转换、缩放、裁剪和旋转。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `图像_取宽度` | `图像_取宽度(路径)` | int | 返回图片像素宽度，失败返回 0。 |
| 2 | `图像_取高度` | `图像_取高度(路径)` | int | 返回图片像素高度，失败返回 0。 |
| 3 | `图像_转换格式` | `图像_转换格式(来源, 目标, 格式)` | bool | 转换为 png、jpg、bmp、gif 或 tif。 |
| 4 | `图像_缩放` | `图像_缩放(来源, 目标, 宽度, 高度)` | bool | 高质量缩放并按目标扩展名保存。 |
| 5 | `图像_裁剪` | `图像_裁剪(来源, 目标, 横坐标, 纵坐标, 宽度, 高度)` | bool | 裁剪图像区域。 |
| 6 | `图像_旋转90度` | `图像_旋转90度(来源, 目标, 顺时针)` | bool | 顺时针或逆时针旋转 90 度。 |
| 7 | `图像_取错误` | `图像_取错误()` | wideString | 返回最近图像错误。 |
