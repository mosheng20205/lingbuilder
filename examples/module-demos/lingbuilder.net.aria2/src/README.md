# Aria2 下载模块完整演示

- 模块 ID：`lingbuilder.net.aria2`
- 版本：`1.37.0`
- 类型：LingBuilder 内置模块
- 命令数：12
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

基于 aria2 1.37.0 的受控异步下载模块，支持多连接、分段、断点续传、速度/进度/目录查询和安全打开目录。生成项目会携带经过许可声明的 aria2c.exe。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `Aria2_下载` | `Aria2_下载(地址, 保存目录, 文件名, 连接数, 最小分段MB, [下载进度处理器])` | Aria2任务 | 使用随项目分发的 aria2c 创建异步下载任务。仅接受 HTTP、HTTPS、FTP、FTPS 或 magnet 地址；连接数范围为 1 至 16，分段范围为 1 至 64 MB。可选下载进度处理器会在窗口线程接收实时任务快照。 |
| 2 | `Aria2_等待` | `Aria2_等待(任务, 超时毫秒)` | bool | 等待下载结束。返回真表示任务成功完成；超时、停止或下载失败均返回假。超时毫秒为 0 时只检查当前状态。 |
| 3 | `Aria2_取状态` | `Aria2_取状态(任务)` | wideString | 返回“下载中”“已完成”“已失败”或“已停止”。 |
| 4 | `Aria2_取进度` | `Aria2_取进度(任务)` | int | 返回 aria2 已报告的下载进度百分比；未知时为 0，成功完成时为 100。 |
| 5 | `Aria2_取已下载字节` | `Aria2_取已下载字节(任务)` | longLong | 读取当前目标文件的实际字节数，适合显示下载量。 |
| 6 | `Aria2_取总字节` | `Aria2_取总字节(任务)` | longLong | 返回任务结束后确认的文件总字节数；下载尚未结束或服务器未报告时可能为 0。 |
| 7 | `Aria2_取错误` | `Aria2_取错误(任务)` | wideString | 读取任务最近一次中文错误或 aria2 输出尾部。任务成功时返回空文本。 |
| 8 | `Aria2_取下载速度` | `Aria2_取下载速度(任务)` | longLong | 按目标文件最近一次采样返回下载速度，单位为字节/秒；适合定时刷新下载面板。 |
| 9 | `Aria2_取保存目录` | `Aria2_取保存目录(任务)` | wideString | 返回任务实际使用的绝对保存目录；任务不存在时返回空文本。 |
| 10 | `Aria2_打开目录` | `Aria2_打开目录(任务)` | bool | 使用系统文件管理器打开任务的实际保存目录；目录来自任务句柄，不接受任意外部路径。 |
| 11 | `Aria2_停止` | `Aria2_停止(任务)` | bool | 停止 aria2 子进程并保留 aria2 的断点续传元数据；再次创建同目录同文件名任务可继续下载。 |
| 12 | `Aria2_释放` | `Aria2_释放(任务)` | bool | 停止仍在运行的任务并释放其本地句柄和状态记录。 |
