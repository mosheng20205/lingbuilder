# WebSocket 客户端模块完整演示

- 模块 ID：`lingbuilder.websocket.client`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：5
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

提供基于 Windows WinHTTP 的 WebSocket 客户端连接、发送、接收和关闭能力。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `WS_连接` | `WS_连接(地址)` | int | 连接到 ws:// 或 wss:// WebSocket 服务端，成功返回 1，失败返回 0 并输出中文调试信息。 |
| 2 | `WS_发送文本` | `WS_发送文本(内容)` | int | 向当前 WebSocket 连接发送一条文本消息，成功返回 1。 |
| 3 | `WS_接收到调试输出` | `WS_接收到调试输出()` | int | 从当前 WebSocket 连接接收一条文本消息，并写入调试输出。 |
| 4 | `WS_接收文本` | `WS_接收文本()` | wideString | 接收一条文本消息并返回最近接收内容；可在原生 C++ 语句中读取返回值。 |
| 5 | `WS_关闭` | `WS_关闭()` | void | 关闭当前 WebSocket 连接并释放网络句柄。 |
