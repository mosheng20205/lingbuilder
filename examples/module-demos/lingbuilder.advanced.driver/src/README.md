# 设备驱动通信模块完整演示

- 模块 ID：`lingbuilder.advanced.driver`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：4
- 设计器控件数：0
- 分组数：1

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

打开显式设备路径并执行无缓冲区 IOCTL；需要相应驱动权限，不负责安装或提权。

## 命令清单

| # | 命令 | 签名 | 返回 | 说明 |
|---:|---|---|---|---|
| 1 | `设备_打开` | `设备_打开(设备路径, 允许写入)` | handle | 打开 \.\DeviceName 形式设备。 |
| 2 | `设备_无参数控制` | `设备_无参数控制(设备句柄, 控制码)` | bool | 执行无输入输出缓冲区 DeviceIoControl。 |
| 3 | `设备_关闭` | `设备_关闭(设备句柄)` | bool | 关闭设备句柄。 |
| 4 | `设备_取错误码` | `设备_取错误码()` | int | 返回最近设备操作 Win32 错误码。 |
