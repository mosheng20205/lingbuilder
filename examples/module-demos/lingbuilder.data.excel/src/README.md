# Excel 表格模块完整演示

- 模块 ID：`lingbuilder.data.excel`
- 版本：`1.0.0`
- 类型：LingBuilder 内置模块
- 命令数：45
- 设计器控件数：0
- 分组数：3

## 使用方式

打开项目后按标签页查看命令分组。源码默认只展示并记录，不执行有副作用的调用；确认演示参数和运行环境后，勾选“允许实际执行”再点击对应分组按钮。

每条命令在 `MainWindow.lcpp` 中包含签名、功能、参数、返回类型和真实调用；结构化清单位于 `模块命令清单.json`。

## 模块说明

读写 .xlsx 工作簿：多工作表、按单元格坐标读写、公式、日期、追加行、常用格式和插入删除行列，无需安装 Microsoft Excel。创建模式支持全部格式能力，打开模式可保真修改既有报表数值。
