# 源码说明

`MainWindow.lcpp` 是本示例唯一的窗口源码，按演示分组排列：

- `_MainWindow_创建完毕`：写入开场说明。
- `输出全部成员`：公共辅助子程序，演示**数组参数**写法 `文本型[] 数组值` 和 `枚举循环首` 遍历。
- `_新增成员按钮_被单击` 起的 7 个事件：分别对应窗口上的 7 组按钮。
- `_清空日志按钮_被单击` / `_退出按钮_被单击`：清理与退出。

## 新手模式提示

新手模式默认只显示事件列表，不展开代码体。请在事件列表里单击对应事件展开“事件实现”，或在结构区域右键选择“展开全部子程序”。切到专业模式可以直接看完整源码。

## 声明数组的三种位置

```lcpp
局部 文本型 名单[]          // 局部数组：随子程序结束释放
全局 文本型 收藏夹[]        // 项目全局数组：写在 项目全局变量.lcpp
空 输出全部成员(文本型[] 数组值, 文本型 标题)   // 数组参数：类型后缀 []
```

三种写法都只能使用默认空数组，不能在声明处写初始值；内容全部通过 `数组_加入成员` 等命令填充。

记录字段的数组维度写在字段上，见 `项目数据类型.lcpp`。
