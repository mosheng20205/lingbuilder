# 数组操作全命令 Demo

这是一个可直接运行的 LingBuilder 示例，覆盖 `lingbuilder.std.array@1.0.0` 的**全部 13 条数组命令**，外加语言自带的数组下标和 `枚举循环首` 遍历。

请打开 `src/数组操作演示.lbsln`，入口源码是 `src/src/array-demo/MainWindow.lcpp`。

## 覆盖内容

窗口上的 7 组按钮各演示一类操作，结果逐条写入下方的“演示日志”列表。每一步都会把**命令的真实返回值**打印出来，包括越界时的失败值。

| 按钮 | 覆盖命令 |
| --- | --- |
| 1 新增成员 | `数组_是否为空`、`数组_取成员数`、`数组_加入成员`、`数组_插入成员` |
| 2 读取与遍历 | `数组_取成员`、数组下标 `名单[0]`、`枚举循环首/尾` |
| 3 修改与重定义 | `数组_置成员`、`数组_重定义` |
| 4 删除与清空 | `数组_删除成员`、`数组_清空` |
| 5 查找与排序 | `数组_查找`、`数组_是否包含`、`数组_排序`、`数组_倒序` |
| 6 记录型数组 | 记录数组的增删读，以及比较类命令的能力边界 |
| 7 项目全局数组 | 数组型项目全局变量跨事件保留内容 |

## 三个容易踩的点

**索引从 0 开始，越界不会崩溃。** `数组_取成员` 越界返回元素类型的默认值，`数组_置成员`、`数组_插入成员`、`数组_删除成员` 越界返回假且不改动数组。第 1、3、4 组都专门点了越界这一下给你看。

**数组下标不做越界检查。** `名单[0]` 语法更短，也参与类型推断（结果是元素类型），但不检查范围。需要安全读取时用 `数组_取成员`。第 2 组把两种写法放在一起对比。

**记录型数组不能直接查找和排序。** 记录默认不带 `==` 和 `<` 运算，所以 `数组_查找`、`数组_是否包含`、`数组_排序` 对记录数组会**稳定返回 -1 / 假**，而不是编译失败。第 6 组演示了这个边界，并给出了按字段手工查找的正确写法。

## 运行方式

在 LingBuilder 中打开本示例后直接运行；也可以在仓库的 `electron` 目录执行受控构建：

```powershell
node dist/cli.cjs project build --request ../examples/array-operations-demo/build-request.json --workspace ../examples/array-operations-demo/src --yes --json
```

注意 `--workspace` 指向的是本示例的 `src` 目录，这样 CLI 才能读到示例自己的解决方案、模块清单以及 `项目全局变量.lcpp` 和 `项目数据类型.lcpp`。把 `project build` 换成 `project run` 即可直接启动窗口，点击“退出”会调用显式的 `结束()`。

## 项目结构

```
src/数组操作演示.lbsln            解决方案入口
src/.lingbuilder/
  solution.json                   项目列表与源码根
  project-modules.json            启用 win32.basic + common-controls + std.array
  window-designer.json            窗口与 12 个控件
src/src/array-demo/
  MainWindow.lcpp                 7 组演示事件 + 一个数组参数辅助子程序
  项目全局变量.lcpp               演示标题常量、收藏夹全局数组
  项目数据类型.lcpp               联系人记录，用于第 6 组
```
