# LingBuilder 全部控制流命令详细演示

这是一个可直接运行、阅读和复制的中文 `.lcpp` 控制流示例项目。

界面按四个 TabControl 页面组织：

1. 条件与选择：`如果真`、`否则如果`、`否则`、`如果`、`选择`、`分支`、`默认`。
2. 基础循环：`循环`、`跳出循环`、`判断循环首/尾`、`循环判断首/尾`。
3. 计次与枚举：`计次循环首/尾`、`继续循环`、`变量循环首/尾`、`到循环尾`、`枚举循环首/尾`。
4. 异常与返回：`尝试`、`抛出`、`捕获`、`最终`、`返回`、`结束()`。

每个页面都提供独立运行按钮和结果列表。源码中的注释解释每组命令的执行顺序与用途。
