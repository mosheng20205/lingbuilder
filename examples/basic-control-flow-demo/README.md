# 基础控制类命令 Demo

这是一个面向 LingBuilder 新手模式的完整 `.lcpp` 示例。请直接打开 `src/未命名解决方案.lbsln`，项目中的有效入口源码是 `src/src/MainWindow.lcpp`。新手编辑器会为条件、选择、循环和异常结构显示 `┌ / ├ / │ / └` 括号流程线，并为跳出、继续和抛出显示 `↳` 标记。

## 打开后先展开事件实现

新手模式默认先显示事件列表，不会把每个事件的代码体全部展开。请在事件列表中单击 `_运行演示按钮_被单击`，展开下方的“事件实现”；基础控制类命令都在这个事件中。也可以在结构区域右键选择“展开全部子程序”。如果切换到专业模式，则可直接查看完整源码。

不要只查看空的 `构造()` 或“创建完毕”事件；演示代码从 `src/src/MainWindow.lcpp` 第 15 行的 `_运行演示按钮_被单击()` 开始。若标签页仍显示修改前的三行默认代码，请关闭该标签后重新打开，或重新打开解决方案以从磁盘刷新。

## 覆盖内容

- `如果`、`如果真`、`否则如果`、`否则`
- `选择`、`分支`、`默认`
- `循环`、`判断循环首/尾`、`循环判断首/尾`
- `计次循环首/尾`、`变量循环首/尾`、`枚举循环首/尾`
- `跳出循环`、`继续循环`、`到循环尾`
- `尝试`、`抛出`、`捕获`、`最终`
- 带返回值方法和 `返回`
- 退出按钮中的显式 `结束()`

## 运行方式

在 LingBuilder 中打开本示例，选择新手模式并运行项目；点击“运行完整演示”，结果会依次写入窗口中的“演示日志”列表。

也可在仓库的 `electron` 目录执行受控构建：

```powershell
node dist/cli.cjs project build --request ../examples/basic-control-flow-demo/build-request.json --workspace .. --yes --json
```

如需直接运行，把 `project build` 改为 `project run`。运行窗口会保持打开，点击“退出”调用明确的 `结束()`。

## 新手注意事项

- 独立一行 `结束` 用于结束事件或方法，不代表退出程序。
- `如果结束`、`选择结束`、各类循环尾和 `尝试结束` 必须与开始命令配对。
- 循环变量、枚举当前项必须先声明。本示例将它们放在事件顶部的局部变量区。
- `继续循环` 与 `到循环尾` 等价；示例分别演示了两种写法。
