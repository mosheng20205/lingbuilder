## FBro 弹窗顶层窗口控制三命令 + 浏览器创建形态总览（lingbuilder.fbro.browser 2.13.0）

### 更新内容

**背景**：外部 AI（经灵码 MCP）误报「FBro 模块没有创建独立顶层弹窗的命令」——它只看到 `FBro_后台创建` 无窗口、`FBro_创建` 依赖设计器控件，漏掉了实例族的 `FBro_实例打开原生UI`。用户要求：① MCP 文档强调弹窗链并说明 FBro 浏览器创建的几种形态；② 给 FBro 弹窗加位置/尺寸控制。

1. **MCP_INSTRUCTIONS 第 22 条扩写**（`electron/src/services/aiBridge/mcpServer.ts`）：
   - 新增「FBro 浏览器创建形态总览」：四种创建入口（①设计器控件进程内嵌入＝`FBroBrowser` 控件+`FBro_创建`；②动态内嵌区域＝`FBro_创建区域`；③后台无窗口实例＝`FBro_后台创建`；④独立顶层弹窗＝③+`FBro_实例打开原生UI`），另注多标签独立进程 Host 走 new_emoji 外壳。
   - 新增「反误解红线」：FBro 弹独立顶层窗没有名字带「创建」的命令，形态④是同一条弹窗链的先后两步。
   - 新增弹窗边界命令口径（设置/回读/取 HWND）。
2. **新增三命令**（生成器运行时两后端同步：标准 Win32 窗口类成员函数 + new_emoji 后端自由函数）：
   - `FBro_实例取窗口句柄(实例句柄)` → 长整数型：顶层（承载）窗口 HWND。
   - `FBro_实例取窗口边界JSON(实例句柄)` → 文本型：`{"x","y","width","height"}` 外框边界（逻辑坐标，按窗口所在显示器 DPI 换算，与设置命令同口径可往返）。
   - `FBro_实例设置窗口边界(实例句柄, X, Y, 宽度, 高度)` → 整数型：移动并缩放顶层窗口；内部只认窗口句柄轮询等就绪（上限约 5 秒），SetWindowPos 后复核一次防内核默认布局覆盖；同步等待，批量弹窗逐个调用。
3. **命令描述交叉引用**：`FBro_后台创建` 描述补「要可见窗口请紧接着 FBro_实例打开原生UI 弹出」；snippet「FBro 纯代码谷歌原生UI浏览器」补边界设置演示。
4. **全链同步**：fbro README 命令表（145 条）+ 家族统计句（用户接口数 704→707）+ 模块总览表、`docs/MODULE_ENCAPSULATION_CHECKLIST.md`（144 条行 + 头部总数 4626）、`LingBuilder AI 规则手册.md`（形态总览+三命令条目）、`tests/modules.test.ts`（版本 2.13.0 钉子、家族 713→716、公开命令 704→707、内置/全量审计基线实算写回）、`tests/aiBridge.test.ts`（7 条 instructions 关键词钉子）。

### 真机探针结论（smoke:fbro-popup-bounds，控制台项目 x64 MSVC 真机跑通）

- **后台实例与弹窗的浏览器都是异步启动**：`FBro_后台创建` 登记即返回句柄，`IsInstanceAlive` 一度为假；`FBro_实例打开原生UI` 要求来源浏览器真已启动（未就绪返回 0 带中文提示），调用前需轮询存活。
- **弹窗顶层窗口就绪在浏览器启动之后**：`CreateChromeUi` 返回瞬间 HWND 尚未就绪（取句柄=0），`FBro_实例设置窗口边界` 内部轮询等到后设置成功。
- **边界设置后内核不覆盖**：设置 (100,100,960,640) 后回读 JSON 精确一致（DPI 150% 下逻辑↔物理往返无损）。
- **后台实例的承载窗是 0×0 离屏窗口**：`FBro_后台创建` 实例的取窗口句柄返回离屏承载窗 HWND（尺寸 0×0），对它设置边界无显示意义——文档口径改为「边界控制以弹窗为目标」。
- 实现据此修正两处：轮询不按 `IsInstanceAlive` 提前退（启动期会误判「已关闭」）；语义文档不再写「后台实例无窗口」。
