灵码 LingBuilder 是面向中文用户的 C++ / .lcpp 集成开发环境。

核心价值：
1. 使用中文界面、中文命令和中文代码降低 C++ 与 Windows 桌面开发门槛。
2. 中文源码与可视化窗口设计器模型通过本地确定性规则生成真实、可阅读、可复制的 C++ 源码与 Visual Studio 工程，不依赖 AI 才能运行。
3. 提供专业 IDE 工作台、Monaco 编辑器、多文件、搜索、Diff、诊断、终端、构建、调试与 Git 管理。
4. 可视化 Win32 设计器支持拖放控件、属性编辑、事件绑定、布局工具和真实原生窗口生成。
5. .lbmod 模块生态支持安装、卸载、启用、禁用，并可封装原生 C++ 库为中文命令。
6. AI 助手支持解释错误、生成代码、创建项目和提出可审查的 Diff 修改草稿；核心编译链路仍可离线使用。

目标用户：中文编程初学者、易语言经验用户、Windows 小工具与 Win32 应用开发者、C++ 模块作者。
当前状态：持续开发与测试中。
视频行动入口：https://gitee.com/MoSheng2020/LingBuilder。
