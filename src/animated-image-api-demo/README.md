# Win32 动态图像控件完整接口示例

这是 `lingbuilder.win32.basic` 内置模块中 `AnimatedImage`（动态图像控件）的完整能力演示项目。

## 覆盖内容

- GIF 文件资源：`properties.gifSource`
- 填充方式：原始大小、拉伸填满、等比适应、等比填满
- 播放配置：自动播放、循环播放、自动播放单次完成、手动播放配置
- 通用属性：工具提示文字和工具提示延迟
- 事件：被单击、鼠标按下、鼠标移入、鼠标移出、播放完毕
- 标准控件操作：显示/隐藏、启用/禁用、选项卡切换和状态反馈

界面使用 4 个 TabControl 页面分组，避免一次性展示全部接口造成拥挤。启动后点击“运行全部演示”，再逐页操作 GIF 控件；事件反馈会显示在页面状态文字和调试输出中。

## 资源

示例 GIF 位于 `assets/animated-image-api-demo/animated-image-demo.gif`，项目可以脱离当前工作区复制和迁移。

## 导入

最终源码包位于 `exports/动态图像控件-完整接口演示.lcpppkg`。使用 LingBuilder 的“文件 → 打开 LCPP 源码包…”导入即可。
