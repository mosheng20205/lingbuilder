# Win32 滑块 TrackBar 完整接口示例

这是一个面向中文用户的 `TrackBar / 滑块` 全能力演示项目。由于属性和操作较多，界面使用 TabControl 分成三页，避免单页拥挤。

## 覆盖内容

### 设计器属性

- 最小值、最大值、当前值
- 刻度间隔
- 水平与垂直方向的真实 Win32 TrackBar 控件
- 不同数值范围：0–100、10–90、0–1000

### 运行时接口

| 接口 | 演示内容 |
| --- | --- |
| `控件_取数值` | 读取水平、垂直、自定义范围和联动滑块当前值 |
| `控件_设置数值` | 设置最小值、中间值、最大值和联动值 |
| `控件_设置启用` | 禁用与重新启用滑块 |
| `控件_设置可见` | 隐藏与显示滑块 |
| `控件_设置位置大小` | 移动并恢复滑块位置与大小 |
| `数值被改变` | 拖动滑块时实时触发，并用于两个滑块联动 |

选项卡本身也提供 `控件_取选择项` 和 `控件_设置选择项`，用于展示分组页面的读取与跳转。

## 运行

1. 在解决方案资源管理器中选择“Win32 滑块 TrackBar 完整接口示例”。
2. 打开 `MainWindow.lcpp`，按 F5 生成并运行。
3. 按选项卡顺序逐项点击按钮，并直接拖动滑块观察“接口状态”和输出面板。
4. “事件与联动”页中拖动源滑块，目标滑块会由真实“数值被改变”事件同步。

源码包位于 `exports/Win32滑块TrackBar完整接口示例.lcpppkg`，可通过“文件 → 打开 LCPP 源码包…”导入。
