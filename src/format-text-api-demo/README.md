# `格式化文本` 全接口与全能力演示

这是 LingBuilder `.lcpp` 新手模式内置命令 `格式化文本(格式模板, 参数...)` 的完整、可运行示例。

## 分组与覆盖范围

1. **基础替换**：读取真实输入框，演示一个模板中的多个 `{}` 按顺序替换，以及返回值赋给文本变量、写入标签。
2. **全部值类型**：文本、整数、长整数、小数、双精度小数、逻辑真值和逻辑假值；同时验证中文与 emoji。
3. **花括号与边界**：`{{`、`}}` 字面量花括号，参数不足保留 `{}`，参数多余自动忽略，零占位符模板原样返回。
4. **实际界面应用**：读取商品、单价和数量，计算小计，嵌套格式化，并把结果用于控件文本、信息框和调试输出。

## 命令规则

```lcpp
格式化文本("姓名：{}，年龄：{}", "小林", 18)
格式化文本("花括号：{{}}")
```

- `{}` 从左到右消费参数。
- `{{` 输出 `{`，`}}` 输出 `}`，两者不消费参数。
- 参数不足时，尚未替换的 `{}` 原样保留。
- 参数多余时，多余值被忽略。
- 当前支持文本、整数、长整数、小数、双精度小数和逻辑值；转换语义与 `到文本` 一致。

项目只启用 `lingbuilder.win32.basic` 和承载分组界面的 `lingbuilder.win32.common-controls`，不依赖 AI、第三方模块或隐藏的原生 C++ 代码。
