# Win32 组合框 ComboBox 全接口示例

这是一个面向初学者的 `ComboBox / 组合框` 实验项目。界面使用 4 个选项卡分组，避免在一个页面堆叠全部能力。每个操作按钮只调用一条组合框相关命令，运行时可在输出面板和窗口内的“操作结果 / 事件日志”查看结果。

## 覆盖范围

### 设计器属性和模式

- 项目集合、默认选中项
- 下拉列表高度、表项高度
- 自动排序
- 允许编辑（`CBS_DROPDOWN`）和不可编辑（`CBS_DROPDOWNLIST`）
- 禁用状态、边框颜色和选中颜色
- 选择项被改变、内容被改变两个事件

### 中文运行时接口

| 接口 | 演示位置 | 作用 |
| --- | --- | --- |
| `控件_设置文本` | 查询与选择 | 设置当前文本 |
| `控件_取文本` | 查询与选择、事件 | 读取当前文本 |
| `控件_设置选择项` | 查询与选择 | 按 0 起始索引设置选中项 |
| `控件_取选择项` | 查询与选择、事件 | 读取当前选中项索引 |
| `控件_添加项目` | 项目管理 | 运行时追加项目并观察返回索引 |
| `控件_清空项目` | 项目管理 | 清空全部项目 |
| `控件_设置启用` | 状态与事件 | 禁用或启用组合框 |
| `控件_设置可见` | 状态与事件 | 隐藏或显示组合框 |
| `控件_设置位置大小` | 状态与事件 | 运行时移动并调整大小 |

## 运行

1. 在解决方案资源管理器中选择“Win32 组合框 ComboBox 全接口示例”。
2. 打开 `MainWindow.lcpp`，按 F5。
3. 先在“属性与模式”观察普通、可编辑、自动排序和禁用组合框。
4. 再按选项卡顺序逐个点击操作按钮；“项目管理”中的清空操作会改变当前运行实例，重新按 F5 可恢复设计器初始数据。
5. 在“状态与事件”中输入或选择，观察“事件日志”。
