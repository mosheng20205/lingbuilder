# Win32 Header（表头）完整接口演示

这是独立的 Win32 `Header`（`SysHeader32`）控件演示项目。界面使用选项卡分组，避免把列模型、通用控件接口和通知事件挤在同一页。

## 演示范围

| 分组 | 覆盖内容 |
| --- | --- |
| 属性与列模型 | 列标题、列宽、文字对齐（居左/居中/居右）、图片索引、ImageList 引用、中文列标题 |
| 通用接口 | `控件_设置文本`、`控件_取文本`、`控件_设置启用`、`控件_设置可见`、`控件_设置位置大小` |
| 事件演示 | `列被单击`、`列宽被改变`；可直接点击表头或拖动列分隔线触发 |
| 接口边界 | 说明列集合是设计期结构属性；当前没有伪造的运行时增删列命令 |

## 重要说明

Header 的可见文字来自列集合，不是普通窗口标题文字。因此通用 `控件_设置文本/控件_取文本` 只演示 HWND 文本接口，列标题仍应在设计器的“列集合”中维护。当前 Header 事件契约为无参数事件，事件处理器不会收到列索引或新宽度参数。

图片列使用项目 ImageList 资源 `header-demo-images`，首列的图片索引为 `0`。如果运行环境没有有效图像资源，文字列和事件演示仍可正常运行。

## 运行和导出

- 在 LingBuilder 中打开本项目或根解决方案中的“Win32 Header 表头完整接口演示”。
- 使用 F5 构建运行。
- 源码包位于项目根目录的 `exports/表头Header完整接口演示.lcpppkg`。
