# PopupMenu 弹出菜单完整接口示例

这是一个可直接在 LingBuilder 中打开、编辑、构建和再次导出的 Win32 `PopupMenu` 非可视资源示例项目。

## 覆盖范围

- 设计器属性：所属窗口、菜单项集合，以及非可视资源在设计器中的位置。
- 菜单项数据：稳定项目 ID、显示文字、分隔线、启用/禁用状态、勾选状态和逐项事件处理器。
- 运行时接口：`弹出菜单_显示`、`弹出菜单_在坐标显示`、`菜单_取最后项目`。
- 返回值能力：选择有效项目时显示接口返回真；点击空白处取消时返回假。
- 坐标能力：`弹出菜单_在坐标显示` 使用屏幕像素坐标，示例基于当前鼠标位置增加偏移。
- 事件能力：六个可选菜单项分别绑定独立处理器；禁用项和分隔线不可触发。
- 布局能力：使用 `TabControl` 将“当前位置显示”“坐标与返回值”“菜单项与事件”分为三个页面，避免界面拥挤。

## 使用方式

1. 在“当前位置显示”页点击按钮，验证 `弹出菜单_显示`。
2. 在“坐标与返回值”页点击“在指定屏幕坐标显示”，观察菜单出现在鼠标右下方。
3. 选择任意有效项目，再点击“读取最后项目 ID”，验证返回的是稳定 ID，而不是显示文字。
4. 在“菜单项与事件”页对照结构化清单，验证普通项、禁用项、勾选项、两条分隔线和逐项事件。

`PopupMenu` 是主动显示的菜单资源，不提供 `ContextMenu` 的右键目标绑定；如需控件右键自动弹出，请使用 `ContextMenu`。
