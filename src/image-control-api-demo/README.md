# Win32 图片框 Image 全接口示例

这个项目把图片框 Image 的设计器能力和运行时能力集中到一个可运行窗口中，并用选项卡避免界面拥挤。

## 演示范围

- 设计器属性：`图片源`、`原始大小`、`拉伸填满`、`等比适应`、`等比填满`。
- 图片接口：`图片框.设置图片(图片路径)`，以及 `控件_设置图片(控件名, 图片路径)`。
- 通用控件接口：`控件_设置文本`、`控件_取文本`、`控件_设置启用`、`控件_设置可见`、`控件_设置位置大小`。
- 事件：`Click`、`MouseDown`、`MouseEnter`、`MouseLeave`。

示例资源位于 `assets/image-control-api-demo/示例图片.png`，使用项目相对路径，便于复制、迁移和导出源码包。
