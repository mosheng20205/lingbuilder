# 多线程模块 2.0 完整交互演示

这是 `lingbuilder.threading@2.0.0` 的可运行源码示例。主窗口使用 5 个 TabControl 标签页分组，底部共享一个只读多行日志框。

## 运行方式

1. 在 LingBuilder 解决方案中打开“多线程模块 2.0 完整交互演示”。
2. 按 `F5` 构建运行。
3. 先点击标题栏右侧的“运行推荐演示”，再按标签页执行专项场景。
4. “事件与信号量”页需要先启动等待，再点击“置位事件”或“释放 1 个许可”。
5. 关闭窗口时，项目级 owner 会协作取消本窗口未完成任务并丢弃未分发回调。

## 参数与回调示例

- “记录 + 数组 + 多参数”同时传入整数、文本、逻辑值、嵌套项目记录和整数数组。
- 提交后立即修改原记录和数组，完成回调仍会收到提交瞬间的深拷贝。
- `多参数工作` 返回 `线程演示结果` 记录，记录内部还包含数组。
- `数组翻倍工作` 直接返回 `整数型[]`，由类型完全匹配的 `数组完成` 接收。
- 工作处理器不访问任何 UI/controlRef；日志只在按钮事件、进度回调和完成回调中写入。

## 操作顺序提示

- 自定义池：“创建” -> “三种提交” -> “状态” -> “调整并发” -> “关闭后重启” -> “销毁”。
- 协作停止：“提交长任务并请求停止” -> “关闭后重启”。
- 手动事件：“启动事件等待” -> “置位事件”。“销毁 / 自动重置事件”会重建并连续执行两次零超时等待，展示自动重置只消费一次信号。
- 信号量：“启动信号量等待” -> “释放 1 个许可”。“销毁并重建信号量”会重建为初始值 1、最大值 3。
- 任务记录：等待任务完成后点击“释放任务 / 清理已完成”。运行中任务不会被强制释放。

源码中的少量 `@` 行只用于当前 DSL 尚未提供中文构造器的数组字面量、数组遍历和主动抛出测试异常；线程提交、同步、状态和 UI 交互均使用公开中文命令。
