# FlatScrollBar（平面滚动条）完整接口示例

这是一个面向中文用户的 `FlatScrollBar / 平面滚动条` 全能力演示项目。界面使用三个 `TabControl / 选项卡` 页面分组，确保所有公开属性、运行时接口和事件都能在窗口内清晰操作。

## 运行方式

1. 在解决方案资源管理器中把“Win32 FlatScrollBar 完整接口示例”设为启动项目。
2. 打开 `MainWindow.lcpp`，按 F5 生成并运行。
3. 在“基础读写”拖动水平/垂直平面滚动条，测试数值读取、设置边界、启用/禁用和显示/隐藏。
4. 在“范围与方向”观察自定义范围 `10 - 90` 与 `-50 - 50`，测试运行时移动和调整大小。
5. 在“事件与联动”拖动垂直条，观察真实“数值被改变”事件把值同步到水平条。

## FlatScrollBar 公开能力覆盖

| 类型 | 覆盖内容 |
| --- | --- |
| 设计器属性 | 方向：水平/垂直；最小值；最大值；当前值 |
| 运行时数值 | `控件_设置数值`、`控件_取数值` |
| 通用控件能力 | `控件_设置文本`、`控件_取文本`、`控件_设置启用`、`控件_设置可见`、`控件_设置位置大小` |
| 事件 | `ValueChanged` / 中文事件名“数值被改变” |
| 边界行为 | 最小值、最大值、范围内中间值、负数范围和拖动实时变化 |
| 联动场景 | 一个平面滚动条的事件驱动另一个平面滚动条同步数值 |

## 选项卡分组

- `基础读写`：同时展示水平和垂直方向，覆盖默认范围 `0 - 100` 的读取、设置数值、边界、启用/禁用、显示/隐藏以及通用内容设置/读取自检。
- `范围与方向`：展示垂直 `10 - 90` 与水平 `-50 - 50` 两种自定义范围，覆盖属性初始化和位置大小调整。
- `事件与联动`：展示两个平面滚动条的真实 `ValueChanged` 事件和代码联动，并提供选项卡读取/跳转操作。

## 生成边界

`FlatScrollBar` 由 `lingbuilder.win32.common-controls` 提供，生成到 Win32 C++ 时使用 `InitializeFlatSB`、`FlatSB_SetScrollRange`、`FlatSB_SetScrollPos` 和 `FlatSB_GetScrollPos` 等真实 FlatSB API。设计器属性在创建窗口时写入原生控件；运行时接口和“数值被改变”事件由生成器统一处理。

源码包位于仓库 `exports/FlatScrollBar平面滚动条完整接口示例.lcpppkg`，可通过“文件 → 打开 LCPP 源码包…”导入为独立工作区。
