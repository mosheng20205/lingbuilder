# Win32 ListView 完整 API 示例包

本项目完整覆盖 LingBuilder 已正式封装的 **87 条 `列表视图_*` 高层命令**：16 条数据/虚拟列表/结构化行命令，加上 71 条 Win32 高级命令。示例同时包含普通 ListView 和真正的 `LVS_OWNERDATA` 15000 行虚拟 ListView。

## 一键验证

运行后点击右侧“运行全部 87 接口自检”。也可以用上方 4 个分类自检按钮分别观察列与状态、视图与样式、分组与标签、图像与布局接口。返回值输出到“输出”面板，当前分类结果同步显示在窗口右下角。

普通列表区的“修改第一行第 2 列”和“读取选中行第 2 列”是两个独立示例。先在普通列表选择一行，再点击读取按钮，程序会调用 `列表视图_取单元格(普通列表, 选中行, 1)` 并用信息框弹出读取值。

“读取选中行接口”是独立的选择 API 示例。普通列表已开启多选，可按住 Ctrl 选择多行；按钮会同时调用 `控件_取选择项`、`列表视图_取选中行数` 和 `列表视图_取下一个选中行`，再用信息框显示单选索引、选中数量、首个选中行和该行第 1 列内容。所有行、列索引均从 0 开始。

## 截图中“序号 + 三列数据”的推荐写法

```text
计次循环首 (15000, i)
    列表视图_设置虚拟行(虚拟列表, i - 1, 列表视图_创建行(i, "代码段", 128, 5))
计次循环尾 ()
```

`列表视图_创建行` 会按现有 `到文本` 规则确定性转换文本、整数、小数和逻辑值，不再需要手工拼接 `\t`。批量添加时使用 `列表视图_创建行集合` 组合多个类型化行。旧式 Tab/TSV 文本仍可运行，仅用于兼容已有源码。行、列索引均从 0 开始。

## 完整性边界

“完整 API”指 LingBuilder 模块已公开、已绑定、已生成真实 C++ 运行时的 87 条安全高层命令全部有示例。Win32 SDK 中依赖指针结构、自定义回调、自定义绘制通知、工作区数组、Tile/Footer 复合结构等原始 `LVM_*` 消息没有伪装为 DSL 文本参数；需要这些 ABI 级能力时，应封装为 v2 原生 C++ 模块。

## 导出分享

在解决方案资源管理器右键本项目，选择“一键导出 LCPP 源码包…”。生成的 `.lcpppkg` 可直接复制给别人，对方使用“文件 → 打开 LCPP 源码包…”导入。

运行要求：使用生成器 0.2.7 或更新版 LingBuilder，以支持全部 87 条 ListView 命令和 `win32.listview.structured-rows.v1`。如果多个 `列表视图_*` 命令同时报 C3861，说明当前运行的仍是旧版 IDE 生成器，需关闭旧版后用新版重新打开工作区并构建。
