# 网页访问使用demo

本项目启用 `lingbuilder.web.http` 网页访问模块，`MainWindow.lcpp` 按独立子程序展示模块的全部公开能力。启动窗口只输出使用提示，不会自动联网。

## 示例覆盖范围

- GET、POST。
- HEAD、PUT、OPTIONS、DELETE、TRACE、CONNECT、PATCH。
- 提交 Cookie、读取 `Set-Cookie`。
- 自定义请求头、读取响应协议头和状态码。
- 返回 UTF-8 文本、原始字节集和中文错误信息。
- 禁止自动重定向。
- 字节集请求体。
- 命名代理、代理账号密码、系统代理模式。
- 普通超时和 `-1` 无限等待参数。
- Cookie 自动合并、必要协议头补全、协议头大小写处理。
- `对象继承` 兼容参数；当前示例传入 `0`，模块暂不复用外部 WinHTTP 对象。

## 建议测试顺序

1. 启动程序后点击“GET 与结果读取”，在 LingBuilder 调试输出中检查结果。
2. GET 验证成功后，依次点击 POST、Cookie、请求头和其他 HTTP 方法按钮。
3. 高级代理示例中的 `127.0.0.1:8888`、用户名和密码只是占位值，实际运行前必须替换。
4. 示例公共地址可能受当前网络环境影响；失败时使用 `网页_取错误信息()` 查看中文错误。

`.lcpp` 当前不直接回写易语言风格的参考参数；请使用 `网页_取返回文本()`、`网页_取返回Cookies()`、`网页_取返回协议头()`、`网页_取返回状态代码()` 和 `网页_取错误信息()` 读取最近一次请求结果。
