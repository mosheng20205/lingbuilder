# 网页_访问_对象兼容说明

本模块参考易语言命令 `网页_访问_对象` 的参数顺序和语义实现。

## 已支持

- HTTP/HTTPS URL。
- GET、POST、HEAD、PUT、OPTIONS、DELETE、TRACE、CONNECT、PATCH。
- POST 文本自动转 UTF-8。
- 自定义请求头，一行一个。
- Cookie 提交、Set-Cookie 提取和简单合并。
- 响应头读取、状态码读取。
- 禁止自动重定向。
- 命名代理、代理用户名和密码。
- 秒级超时，`-1` 表示尽量无限等待。
- 请求头键名首字母大写规范化。

## 当前限制

- `.lcpp` 生成器暂未完整支持易语言“参考参数”回写，所以中文代码里请用 `网页_取返回文本()`、`网页_取返回Cookies()`、`网页_取返回协议头()` 和 `网页_取返回状态代码()` 读取最近一次请求结果。
- `对象继承` 作为兼容参数保留，当前不会复用外部 WinHTTP 对象。
- Cookie 合并采用常见的 `名称=值` 简化策略，不解析 Domain、Path、Expires 等完整 Cookie Jar 规则。
- 响应文本默认按 UTF-8 转换；原始响应体由 `网页_访问_对象` 的字节集返回值保留。

## C++ 完整接口

如果直接写 C++，可以调用 `LB_网页_访问_对象_完整` 并传入指针参数以获得类似参考参数的回写行为。
