# Win32 ScrollBar 完整接口示例

这是一个面向中文用户的 `ScrollBar / 滚动条` 全能力演示项目。界面使用三个选项卡分组，避免在一个窗口内堆叠所有接口。

## 运行方式

1. 在解决方案资源管理器中把“Win32 ScrollBar 完整接口示例”设为启动项目。
2. 打开 `MainWindow.lcpp`，按 F5 生成并运行。
3. 先在“基础读写”拖动水平/垂直滚动条，再点击读取、设置中间值、最小值和最大值按钮。
4. 在“范围与方向”观察最小值为 10、最大值为 90 的垂直滚动条，并测试位置大小调整。
5. 在“事件与联动”拖动垂直滚动条，观察真实 `数值被改变` 事件把值同步到水平滚动条。

## ScrollBar 接口覆盖

| 类型 | 覆盖内容 |
| --- | --- |
| 设计器属性 | 方向：水平/垂直；最小值；最大值；当前值 |
| 运行时读写 | `控件_设置数值`、`控件_取数值` |
| 通用控件能力 | `控件_设置启用`、`控件_设置可见`、`控件_设置位置大小` |
| 事件 | `ValueChanged` / 中文事件名“数值被改变” |
| 边界行为 | 最小值、最大值、范围内中间值、拖动实时变化 |
| 联动场景 | 一个滚动条的事件驱动另一个滚动条同步数值 |

## 选项卡分组

- `基础读写`：同时展示水平和垂直方向，覆盖读取、设置数值、边界值、禁用/启用。
- `范围与方向`：展示自定义 10-90 范围，覆盖范围属性和运行时位置大小调整。
- `事件与联动`：展示两个滚动条的真实 `ValueChanged` 事件和代码联动，并提供选项卡跳转操作。

## 生成边界

滚动条目前由 `lingbuilder.win32.basic` 的 Win32 `SCROLLBAR` 控件提供。它公开的专用运行时接口是数值设置、数值读取和数值改变事件；最小值、最大值、方向属于设计器/模型属性，在生成窗口时写入原生控件初始化参数。

源码包位于仓库 `exports/ScrollBar完整接口示例.lcpppkg`，可通过“文件 → 打开 LCPP 源码包…”导入为独立工作区。
