# 选项卡 TabControl 完整接口示例

这是一个可直接在 LingBuilder 中打开、编辑和构建的 Win32 `TabControl` 示例项目。

## 覆盖范围

- 设计器属性：`tabs` 标签页集合、`selectedIndex` 默认页、`hideHeader` 隐藏表头、`imageListId` 图像列表绑定（示例资源 ID 为 `tab-icons`）。
- 通用选项卡接口：`控件_设置选择项`、`控件_取选择项`、`控件_清空项目`。
- 选项卡专属接口：`选项卡_添加页`、`选项卡_设置隐藏表头`、`选项卡_取隐藏表头`。
- 容器能力：多个标签页分别承载标签、编辑框、列表框和按钮等真实子控件；切换页时只显示当前页面内容。
- 事件能力：`标签页被改变` 事件会读取当前选中页并更新状态。

右侧“接口操作台”中的每个按钮只负责演示一条或一组紧密相关的 TabControl 接口。可以先按编号操作，再切换左侧页面观察页面内容；“清空全部页”后点击“恢复初始页”即可继续演示。

所有接口均使用当前 Win32 高级控件模块的确定性中文命令，未使用隐藏的原生 C++ 语句。
