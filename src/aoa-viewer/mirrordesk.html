手机端安装与连接指引（USB 直传）

1. 安装投屏伴侣 APK（v1.4.7 起，必须）

安装包在本工程源码目录：lingbuilder-companion-v1.4.7.apk（与 MainWindow.lcpp 同目录）。v1.4.3 及更早缺包可见性声明——「启动App」对第三方应用恒报「未安装或无启动入口」；v1.4.4 及更早没有剪贴板指令（中文粘贴不可用）；v1.4.5 及更早没有应用列表指令（启动App 无下拉）；v1.4.6 及更早没有按需截图与 USB 控制模式（批量找图不可用）；v1.2.6~v1.4.0 没有部分 USB 推帧代码。用微信/QQ/数据线任意方式发到手机安装（允许「未知来源/安装未知应用」）。首次安装只此一次，之后插线即用。

2. 首次授权（每台一次）

手机上打开「LingBuilder 投屏伴侣」→ 点「开始投屏」→ 系统弹窗选「立即开始」。建议加入后台白名单（MIUI：最近任务卡片上锁；鸿蒙：电池-启动管理改手动允许），否则后台被杀后需要重新打开。

3. 插线即用

数据线插上电脑即自动出现在本页并排队接通，无需任何网络（手机不连 Wi-Fi 也能投屏和群控，移动数据照常用）。多台并发请用带独立供电的 USB Hub；普通模式下打开会切换配件模式，每台需数秒，属正常现象。

4. 黑屏 / 无画面时

磁贴显示「USB 已通 · 等手机侧投屏」= 电脑到手机的 USB 链路已通，但手机上的投屏会话没在跑：解锁手机，打开投屏伴侣重新「开始投屏」，或点磁贴「唤醒」按钮。拔线重插会自动重新接通。

批量找图点击（不依赖持续投屏）

选择一张小模板图（要点的按钮/图标的截图），对目标集合（勾选∩已接通）逐台执行：发唤醒+截图 → 模板匹配 → 坐标换算 → 真实点击 → 汇总。手机上无需持续投屏（伴侣 v1.4.7+ 的控制模式或投屏推流都可用）。

设备分组（按手机序列号记忆，重插不漂移）

先在磁贴上勾选目标设备，再保存为组。应用分组=自动勾选该组成员（分组对所有批量动作生效：同步操控/启动App/唤醒/截图/回放/粘贴）。

回放群控剧本

对全部已接通设备异步回放 群控剧本.csv（录制生成于 exe 目录）。每台独立任务，进度显示在页面横幅。

文本输入 · 槽位

先在磁贴画面点一下目标输入框（让手机获得焦点），再在这里输入发送。仅支持英文/数字/英文符号（中文请用手机输入法手打）。

输入中文？中文用下面的粘贴按钮：写入手机剪贴板 → 手机输入框长按/PC 发 Ctrl+V 粘贴（需伴侣 v1.4.5+）。
