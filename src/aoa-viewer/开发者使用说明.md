# USB 多机投屏群控 · 开发者使用说明

> 适用工程：`aoa-viewer`（MirrorDesk USB 投屏台 v4 · USB 直传专用版）
> 配套手机端：LingBuilder 投屏伴侣 **v1.4.3+**（本工程源码目录内已捆 `lingbuilder-companion-v1.4.3.apk`）
> 读者：把本工程分发给最终用户部署的开发者 / 排查「USB 直连连不上」的人。

---

## 0. 快速上手（TL;DR）

一台全新 Windows + 一台全新 Android，从零到出画面一共五步：

| 步骤 | 机器 | 动作 | 一次性？ |
|---|---|---|---|
| 1 | PC | 安装 WinUSB 驱动（见 §2.1，三种方式任选） | ✅ 每台 PC 一次 |
| 2 | 手机 | 安装投屏伴侣 APK v1.4.3+（微信/QQ/MTP 任意方式发过去） | ✅ 每台手机一次 |
| 3 | 手机 | 打开投屏伴侣 →「开始投屏」→ 系统弹窗「立即开始」 | ✅ 每台手机一次（授权） |
| 4 | 手机 | **保持投屏伴侣在前台**，USB 数据线插上 PC | 每次连接 |
| 5 | PC | 磁贴自动出现 → 排队接通 → 画面上墙 | —— |

日常使用之后只剩第 4 步：**插线即用**，全程无 Wi-Fi、无 adb、无 root、无手抄地址。

## 1. 系统组成

```
┌─ PC（aoa-viewer，本工程 F5 构建）──────────────────────┐
│  设备池（并行数组，槽号=会话内首次见到顺序）              │
│  ├ 自动接入巡检：每 ~2s 扫 AOA_取设备列表，新机入池入队   │
│  ├ 打开队列：一次一台串行 AOA_打开设备（切配件最长 45s）  │
│  ├ 轮询泵 15ms/拍：预算巡游排空 USB 数据通道（≤16 通道/拍）│
│  ├ 帧管线：JPEG 双缓冲落盘 aoa_d<槽号>_0/1.jpg           │
│  └ WebUI：mirrordesk.html（EdgeView file:// 直载）       │
└──────────────┬──────────────────────────────────────────┘
               │ USB：视频帧 LBAC 通道1 / 控制 JSON 通道2 / AOA HID 触控
┌──────────────┴──────────────────────────────────────────┐
│  手机（投屏伴侣 v1.4.3+）                                │
│  MediaProjection 采集 → JPEG（默认缩放 0.5 / 质量 70）    │
│  USB 直传：投屏运行+配件在位 → 自动接通 bulk 通道推帧      │
│  HID 触控：PC 经 AOA HID 注入（免调试免 root）            │
└──────────────────────────────────────────────────────────┘
```

三个部件各司其职，**都不可缺**：

| 部件 | 载体 | 版本要求 | 缺了会怎样 |
|---|---|---|---|
| PC 查看器 | 本工程 F5 构建 / 分享包导入 | — | —— |
| 投屏伴侣 APK | 手机 | **v1.4.3+（硬性）** | ≤1.4.1 无 USB 推帧代码，画面永远走 Wi-Fi，纯 USB 形态**必黑屏** |
| WinUSB 驱动 | PC | 1.1.0.5（随包 `driver/`） | 设备列表显示「需驱动」，**一台都连不上**（见 §2.1） |

## 2. 全新机器部署（排障请直接跳 §5）

### 2.1 安装 WinUSB 驱动（PC，一次性，最常见失败点）

手机切到配件模式后是一个自定义 USB 设备（`18D1:2D00` 等），Windows **不会**自动给它装 WinUSB——没有驱动，`AOA_打开设备` 直接打不开。验证当前机器是否已装：

```powershell
pnputil /enum-drivers   # 找「原始名称: lingbuilder-aoa.inf」
```

设备管理器里插上手机（配件模式）应出现「**LingBuilder AOA Accessory (WinUSB)**」而不是黄色感叹号。

**方式 A · 离线强配（推荐，随包自带，需管理员）**

```powershell
# 驱动在导入后的工程目录：src\aoa-viewer 同级的模块目录下
# .lingbuilder\modules\lingbuilder.aoahid\driver\
pnputil /add-driver "lingbuilder-aoa.inf" /install
```

INF 已签名（签名者 LingBuilder AOA Driver，1.1.0.5），覆盖四类硬件 ID：
`2717:FF40`（小米普通模式）、`18D1:2D00`（AOA 配件）、`18D1:2D01&MI_00`（配件+调试）、`12D1:107E`（华为配件）。
装完**重插一次数据线**生效。

**方式 B · Zadig 引导（有网机器）**

模块命令 `AOA_安装驱动(序列号)` 会自动下载并拉起 Zadig，分步中文指引写在 `AOA_取错误()`。
红线：Zadig 里的安装动作需人工确认（UAC 提权），命令返回假属正常。
手动等价操作：Zadig → 菜单 Options 勾「List All Devices」→ 下拉选「LingBuilder AOA Accessory / Android Accessory Interface」→ 驱动选 **WinUSB** → Replace Driver。

**方式 C · 检查表（两种方式装完仍不行）**

- 设备管理器该节点是否报错代码：Code 10（CM_PROB_FAILED_START）= 描述符僵死，禁用/启用该设备或换口重插；
- 换一条**数据线**（市场上大量线是纯充电线，无数据脚，枚举不出来什么都白搭）；
- 直插主板后置口，别经过劣质 hub。

### 2.2 安装投屏伴侣（手机，一次性）

APK 在本工程源码目录 `lingbuilder-companion-v1.4.3.apk`（分享包已捆）。微信/QQ/MTP 任意方式发到手机安装（允许「未知来源」）。**旧版 ≤1.4.1 没有 USB 推帧代码**——这是历史上「装了也黑屏」的第一大根因，务必核对版本（app 标题栏显示 v1.4.3）。

### 2.3 手机侧准备

1. 打开投屏伴侣 →「开始投屏」→ 系统弹窗「立即开始」（MediaProjection 授权，每台一次）。
2. 后台白名单：MIUI 最近任务卡片上锁；鸿蒙 电池-启动管理 改手动允许。MIUI 杀后台是隔夜掉线的第一原因。
3. 手机**不需要**连 Wi-Fi——投屏和触控流量全部走 USB 线，移动数据照常独立使用。

## 3. 日常使用

### 3.1 自动接入（默认开）

- 泵每约 2 秒巡检一次 USB 设备列表；「配件模式+可打开」和「普通模式（有序列号）」的手机自动入池排队。
- 「打开队列」一次一台串行接通：普通模式机型要切配件模式，**每台需 5~45 秒**（界面上队列数字递减）。
- 页面顶栏「自动接入：开/关」可挂起；「全部断开」会同时挂起自动接入（防止立刻被接回去），点「接收全部设备」或磁贴「接通」恢复。

### 3.2 操控

- 磁贴画面：单击=真实点击，按住拖动=真实滑动（AOA HID 硬件级注入）。
- 工具条：接通 / 唤醒 / 主页 / 返回 / 通知栏（远程拉下手机通知栏）/ 截图 / 找图点击（识图→坐标映射→真实点击，需伴侣 v1.4.0+ 的 queryScreen）。
- 底部批量条：**同步操控**（开群控：任一画面的手势广播到全部已接通手机）/ 全部唤醒 / 批量截图。

### 3.3 规模

架构支持几百台槽位。规模化三板斧已内置：轮询预算巡游（每拍最多排空 16 通道）、不可视磁贴 2 秒一帧节流（页面只轮询视口内磁贴）、打开队列串行。真实并发上限取决于 USB 控制器与 **HUB 供电**——多台务必用带独立供电的 Hub。

## 4. 工作原理（开发者视角）

### 4.1 设备池（`项目全局变量.lcpp` + `功能/群控库.lcpp`）

- 并行数组：`池设备[]`（AOA设备 句柄）/ `池序列号[]` / `池通道[]` / `池已开[]` / `池可见[]` / `池待重试[]` / `池错误[]` …，下标=槽号-1。
- 槽号=会话内首次见到该手机的顺序，**整场稳定**；拔线只标「USB 已拔出」不清条目，重插复用。
- 序列号查找一律 `_wcsicmp` 大小写不敏感（MIUI/驱动层回报大小写不稳定，精确比较会重复入池）。
- MIUI 配件模式读不到序列号的机型用产品名占位，模块侧「唯一空序列号配件」兜底打开。

### 4.2 连接状态机

```
巡检发现新序列号 → 入池 → 入队
队列（一次一台）→ AOA_打开设备(序列号)   ← 同步阻塞，切配件最长 45s，禁止并发
  成功 → 池已开 → AOA_打开数据通道 → 发 wakeScreen → 等手机推帧
  失败 → 池错误=原因 → 消费「待重试」标志（防风暴）
会话死（拔出/重枚举）→ 池掉线：关通道+关设备 → 池待重试=真 → 巡检见到设备回来自动重接
```

### 4.3 帧管线（红线）

- 泵 15ms 一拍，**预算巡游**每拍最多排空 16 个通道（空轮询一次约 1ms），泵游标轮转保证每台都被持续排水。
- **手机侧发送端在 PC 停止收帧时会阻塞**——所有已开通道必须被持续读取，不许只挑着收；`AOA_数据通道收帧` 超时**禁传 0**（libusb 0=永久等待）。
- 帧判别：首字节 255=JPEG（>1KB 才收），否则=控制 JSON（env 心跳 / 指令回执 / screenInfo，UTF-8 经 std.buffer 解码）。
- 落盘：`帧基址`（exe 目录）+ `aoa_d<槽号>_0/1.jpg` 双缓冲；可视槽每帧写，不可视槽 2 秒一帧（页面 IntersectionObserver 上报名单 `{action:'visible', list:"1,3,7"}`）。
- 页面解析顺序（全便携）：exe 同目录 → CWD → 从 exe 目录向上 ≤6 级找 `src\aoa-viewer\mirrordesk.html`。**源码里禁止出现本机绝对路径回退**（分享包在别的机器必死）。

### 4.4 手机侧 USB 直传触发条件（APK 1.4.3）

1. 投屏会话运行中检测到配件附着（ATTACHED 广播）→ 自动接通；
2. 投屏会话启动完成且配件已在位（`accessoryList` 兜底）→ 自动接通；
3. 主界面轻量通道在投屏运行时自动让位（前台持有 fd 会锁死服务通道——1.4.3 修复）；
4. 失败原因直接显示在 app「USB 直传」按钮上（失败(原因)），不再静默；
5. 手动按钮保留：手机上点「USB 直传」可强制开/关。

### 4.5 坐标回映射（找图点击）

`queryScreen`（需伴侣 v1.4.0+）→ `screenInfo{realWidth,realHeight,frameWidth,frameHeight}` →
手机坐标=帧坐标×realWidth/frameWidth → HID 逻辑坐标=手机坐标×32767/realWidth。
实现全在 `功能/坐标映射.lcpp`，未校准时换算一律返回 -1，调用方必须判负。

## 5. 故障排查手册（按症状）

### 5.1 插上手机，墙上完全没反应

按顺序查：

1. **线**：换一条确认能传数据的线（充电线枚举不出来，占此故障的大头）。
2. **手机上选 USB 用途**：部分机型插线弹「仅充电/传输文件」，选**传输文件（MTP）**。
3. **列表里有没有它**：`viewer.log` 或页面控制台看 `AOA_取设备列表`——行格式 `序列号|产品名|模式|驱动状态`：
   - 完全没有该机 → 线/口/手机 USB 模式问题；
   - 有，但模式=配件模式、驱动状态=**需驱动** → §2.1 装驱动；
   - 有，模式=普通模式 → 正常，自动排队切配件（等待即可）。
4. **USB 调试是否开着**：开着 = `2717:FF48` 复合设备，Windows 拒绝用户态驱动接管，三路全堵。**目标形态必须关闭 USB 调试**（装了 UsbDk 时模块有后备通道，但不要依赖）。
5. **adb/scrcpy 是否在跑**：libusb 与 adb 互斥，打开前必须退出 adb、scrcpy/QtScrcpy。

### 5.2 `AOA_打开设备` 失败文案对照表

| 文案（viewer.log / 磁贴） | 含义 | 处置 |
|---|---|---|
| 手机未保持配件模式（设备已回退） | 切换成功但手机退回了普通模式 | **多为投屏伴侣没在运行**——解锁手机打开 app，或重插（app 活着时重插会自动接通） |
| 配件设备驱动绑定未完成 | 配件节点出现了但驱动没绑上 | 等 30 秒自动重试；仍不行 → §2.1 重装驱动 |
| 等待配件设备重枚举超时（45 秒预算用尽） | 手机拒绝/忽略 AOA 切换 | 重插一次（手机保持解锁）；重插仍失败 = 机型限制（见 §5.6） |

### 5.3 磁贴显示「USB 已通 · 等手机侧投屏」

USB 链路已通，手机侧投屏会话不在跑：解锁手机 → 打开投屏伴侣 →「开始投屏」。伴侣 v1.4.3+ 装好后这一步之后是全自动的。隔夜后普遍发生（MIUI 杀后台）。

### 5.4 手机上「USB 直传：失败（…）」

1.4.3 起失败原因直接显示在 app 按钮上。常见：
- 「未找到 USB 配件」→ 手机不在配件模式（PC 端还没打开它）→ 重插一次线，让 app 收到配件附着事件；
- 「打开 USB 通道失败」→ 多半 PC 端会话还没建立或刚断，等自动重试；
- 更多细节点 app 里「日志（排查通道问题）」（最近 300 条环形日志）。

### 5.5 画面卡住 / 一动就断

- **熄屏会暂停 MediaProjection**：点磁贴「唤醒」；
- MIUI 冻结后台服务：投屏中尽量让伴侣留在前台或上后台锁；
- 触控首次点击被吃：Android 输入设备挂载竞态，连点两次即可；
- MIUI 弹「已拦截 USB 输入设备」：必须在手机上点允许（磁贴「通知栏」按钮可远程拉下通知栏去点）。

### 5.6 机型限制（定案，勿再排查）

| 机型 | 状态 | 原因 |
|---|---|---|
| 小米 8（MIUI 免调试） | **不可用** | MIUI 拒绝 AOA 配件切换（重枚举 45s 超时，与 PC/APK 无关），升级系统才可解 |
| 小米 10 / 华为 Mate40 Pro | ✅ 全链验证通过 | —— |

### 5.7 日志采集

- **PC 侧**：`viewer.log`（exe 工作目录）。关键行：`入池 槽N [序列号] 产品名` / `槽N open [...]` / `槽N ch=N`（通道句柄）/ `槽N openfail 原因` / `槽N 掉线 原因` / `槽N 待重试自动重接` / `槽N 拔线`。
- **手机侧**：app「日志」按钮，最近 300 条（`[USB直传]` 标签是自动接通链路）。

## 6. 分发与构建（开发者）

### 6.1 分享包（.lcpppkg）

`companion/aoa-viewer-USB多机投屏群控.lcpppkg` 内含：全部源码 + 设计器模型 + **捆绑 lingbuilder.aoahid 模块（含 libusb 运行库与 WinUSB 驱动包 `driver/`）** + **投屏伴侣 APK v1.4.3**。收包方：IDE（0.8.30+）打开源码包 → F5 构建（需 MSVC）→ 按 §2 部署。

### 6.2 构建布局与产物

- F5/导出产物：`.lingbuilder-build\aoa-viewer\x64\Debug\bin\LingBuilderPreview.exe`（bin 每次构建清空；页面靠向上查找回退到源码根，帧文件按 exe 目录绝对路径落盘）。
- 可复制 VS 工程：`generated\cpp\aoa-viewer`。
- 审码红线：源码内**禁止出现本机绝对路径**（分享包便携性）；带参方法必须放功能库；带初始化局部声明在函数入口按声明序求值；`数组_取成员/置成员` 访问池状态。

### 6.3 APK 构建配方

```
cd companion/aoa-companion
JAVA_HOME=T:/android-build/jdk-17.0.2 gradle assembleRelease   # release 用 debug 密钥可直接装
# 制品 app/build/outputs/apk/release/app-release.apk → 版本推进后拷为 lingbuilder-companion-vX.Y.Z.apk
```

版本推进点：`app/build.gradle` 的 versionCode/versionName；USB 直传行为在 `StreamService.kt`（`maybeAutoOpenUsbDirect` / `openUsbDirect(auto)` / `ACTION_AUTO_USB`）。

### 6.4 页面压测 / RPA 钩子

- `?mock=N`：生成 N 台假设备（上限 600）压设备墙；
- `?auto=assign&serial=X`：2 秒后自动「接收全部」（带 serial 只接指定台）。

## 7. FAQ

**Q：必须关 Wi-Fi 吗？**
不需要。USB 链路自成一体，手机连不连 Wi-Fi 都不影响；文档强调「不连」是因为这套形态专为零网络环境设计。

**Q：几十台上百台怎么接？**
带独立供电的 USB Hub（每台手机 0.5~1.5A）。软件侧已做预算巡游+可视区节流，几十台无感；上百台建议分控。

**Q：第一次接某台手机时手机弹「允许 USB 配件访问？」**
点允许（可勾默认）。这是 Android 配件权限，装驱动/重插后可能再弹一次。

**Q：手机需要 root / USB 调试 / 厂商授权吗？**
都不需要。三不原则（免调试/免 root/免辅助功能）是本方案的设计前提；反过来，**开着 USB 调试反而连不上**（FF48 复合设备），见 §5.1-4。

**Q：为什么插上后「接通中」要好几秒？**
普通模式 → 配件模式的切换是手机端重新枚举 USB，模块预算最长 45 秒（典型 5~7 秒）。切过一次之后，手机保持配件状态，重连是秒级。
