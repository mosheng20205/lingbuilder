# ListBox 完整接口示例

这是 LingBuilder `lingbuilder.new_emoji.ui/ListBox` 的可运行源码示例。

## 覆盖范围

- 设计器初始化：创建、简单项目、高级 TSV 项目、默认索引、选中 Key、选择模式、尺寸、边框、斑马纹、紧凑行距、图标/描述/标签、树形/分组/拖拽排序、编辑选项、样式、滚动位置、虚拟项目数。
- 项目数据：设置项目、异步设置、追加、插入、更新、删除、清空、项目数、读取单项、读取全部项目。
- 选择与状态：设置/读取选中索引、设置/读取选中 Key、读取选中项目、禁用、展开、分组折叠。
- 编辑与显示：开始/提交/取消编辑、编辑选项、滚动、选项读取、样式、完整状态。
- 虚拟数据：虚拟行数、虚拟项目提供器注册、同步/异步刷新。
- 事件：选择变化、项目点击、双击、编辑、重排、右键菜单，以及鼠标进入/离开/按下/抬起/双击/移动/滚轮和焦点变化。

右侧按钮按功能组执行接口；按钮中的 `@` 行是直接调用模块导出的 `EU_*` ABI，便于核对生成的 C++ 代码。虚拟项目提供器示例使用 `nullptr` 演示解绑/清空提供器；需要真正提供虚拟内容时，应在隔离原生扩展中实现 `ListBoxVirtualItemCallback`。

项目使用 `new_emoji` 后端，运行需要 MSVC/Visual Studio Build Tools，并确保 `new_emoji.dll` 与生成的 exe 位于同一目录。
