# Win32 月历完整接口示例

这是 LingBuilder `lingbuilder.win32.common-controls` 的 `MonthCalendar / 月历` 完整能力示例。

## 覆盖范围

月历当前正式公开并由设计器、模块清单和 Win32 生成器共同支持的能力如下：

| 类型 | 能力 | 示例位置 |
| --- | --- | --- |
| 属性 | `value`：当前日期 | “1 基础属性”中的单选月历 |
| 属性 | `multiSelect`：允许范围选择 | “2 范围与外观”中的范围月历 |
| 事件 | `ValueChanged`：日期被改变 | 四个月历均绑定真实事件处理器 |
| 通用控件能力 | 显示/隐藏、启用/禁用、位置大小 | “3 事件与通用操作” |
| 视觉能力 | 独立宽高、背景色、文字色、真实独立 HWND | “2 范围与外观”中的外观月历 |

## 使用方式

1. 在解决方案资源管理器中将“Win32 月历完整接口示例”设为启动项目。
2. 打开 `MainWindow.lcpp`，按 F5 运行。
3. 在“1 基础属性”观察单日期选择；在“2 范围与外观”拖动选择日期范围；在“3 事件与通用操作”逐项点击按钮并观察状态栏和输出面板。
4. 四个月历都是独立的 `SysMonthCal32` 控件实例，日期改变会分别进入各自的事件处理器。

## 能力边界

当前模块没有公开 `月历_*` 运行时命令。Windows SDK 中依赖原始指针、结构体或未封装消息的 `MCM_*` 能力不属于 LingBuilder 的正式 DSL 接口，本示例不会伪造这些命令。需要新增月历运行时 API 时，应先加入模块 v2 的 `contributes.commands`、`bindings.commands`、后端命令契约和真实 C++ 运行时，再扩展示例。
