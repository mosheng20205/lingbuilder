# ContextMenu 上下文菜单完整接口示例

这是一个可直接在 LingBuilder 中打开、编辑和构建的 Win32 `ContextMenu` 非可视资源示例项目。

## 覆盖范围

- 设计器属性：所属窗口、右键目标、菜单项集合。
- 菜单项模型：稳定项目 ID、显示文字、分隔线、启用状态、勾选状态。
- 触发方式：绑定到选项卡页内真实按钮后自动响应右键；也可以通过 `上下文菜单_显示` 在鼠标位置主动显示。
- 运行时接口：`上下文菜单_显示`、`菜单_取最后项目`。
- 事件能力：每个非分隔线菜单项都绑定独立的“菜单项被选择”事件，并在状态区显示稳定菜单项 ID。
- 布局能力：使用 `TabControl` 把使用方式、运行时接口和菜单项能力分组，避免窗口拥挤。

## 使用方式

1. 进入“使用方式”页，在“右键目标按钮”上点击鼠标右键，验证绑定目标自动弹出菜单。
2. 进入“运行时接口”页，点击“主动显示上下文菜单”，验证 `上下文菜单_显示`。
3. 在菜单中选择“复制”“切换高亮”或“查看日志”，再点击“读取最后项目”，验证 `菜单_取最后项目` 返回稳定项目 ID。
4. “菜单项能力”页列出设计器中保存的启用、勾选和分隔线配置；“撤销”菜单项故意禁用，用于验证不可选状态。

所有演示代码都使用当前 Win32 模块提供的确定性中文命令，没有把原生 C++ 语句或隐藏的 React 模拟逻辑写入项目。
