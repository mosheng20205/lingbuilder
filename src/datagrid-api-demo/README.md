# Win32 DataGrid 新手逐项实验室

这是一个从未使用过 LingBuilder 的新手也能逐项操作的 `DataGrid / 数据表格` 示例，覆盖全部 92 条公开中文命令、16 类事件和 10 种列类型。

## 第一次运行

1. 在解决方案资源管理器中把本项目设为启动项目。
2. 打开 `MainWindow.lcpp`，按 F5 生成并运行。
3. 先观察左侧静态表格中的选择框、Switch、图片、进度条、组合框和按钮列。
4. 打开右侧选项卡，从编号较小的按钮开始逐个点击。
5. 每次点击后查看左下角“操作结果”和 IDE 底部“输出”面板。

本项目没有“运行全部接口”按钮。86 个普通接口各有一个独立按钮，每个按钮处理器只调用一条 `表格_` 命令，并在源码上方写明签名和用途。

可直接分享或双击导入的完整源码包已导出到项目根目录 `exports/LingBuilder-DataGrid-All-APIs.lcpppkg`。导入后会创建独立工作区，不覆盖现有项目。

## 九个选项卡

- `1 列管理`：添加、插入、删除列以及标题、宽度、对齐、只读、显示、冻结和格式。
- `2 特殊列`：组合框选项、三态选择框、Switch 文字、图片模式、进度范围和列按钮。
- `3 行与导入`：行操作、批量更新、TSV、CSV、Excel 导入导出。
- `4 基础单元格`：文本、整数、小数、逻辑和日期的读取与写入。
- `5 特殊单元格`：图片、进度状态、组合框稳定值及按钮覆盖。
- `6 编辑选择`：编辑、当前单元格、行选择、撤销和重做。
- `7 排序筛选`：单列/多列排序、列筛选和全文搜索。
- `8 校验虚拟`：列校验、100 万虚拟行、请求范围和虚拟缓存。
- `9 事件上下文`：说明如何通过真实表格操作触发行键、列 ID、按钮 ID、旧值和新值。

## 事件类接口为什么没有普通按钮

`表格_取事件行键/列ID/按钮ID/旧值/新值` 只能在 DataGrid 正在派发事件时读取，`表格_拒绝本次编辑` 只能在“正在验证”事件中使用。因此这些接口放在独立事件处理器中，不用会返回空值的假按钮误导新手。

体验方法：

- 单击或双击单元格：观察事件行键和列 ID。
- 点击图片或“操作”列按钮：观察图片、按钮事件上下文。
- 点击 Switch、选择框或组合框：观察改变事件。
- 双击订单号进入编辑，输入“禁止”：触发校验并拒绝提交。
- 滚动下方虚拟表格：触发请求范围读取和可见行提交。

## 使用注意

- 橙色按钮代表删除、清空、加载或导入等会改变大量示例数据的操作。
- 某些接口有前后顺序，例如先“开始批量更新”再“结束批量更新”，先导出 Excel 再导入 Excel。
- 执行删除、清空或导入后，其他按钮可能找不到原来的 `order-1001`。直接关闭窗口并重新按 F5，即可恢复设计器中的三行初始数据。
- Excel 示例文件名为 `DataGrid导出示例.xlsx`，不要求安装 Microsoft Excel。
- 图片资源位于 `assets/datagrid-api-demo/datagrid-demo.png`，F5 和源码导出都会保持相对路径复制。
