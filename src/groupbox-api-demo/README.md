# 分组框 GroupBox 全能力演示

这是一个可直接在 LingBuilder 中打开的 Win32 中文源码示例，使用选项卡把分组框的能力分为四组：

1. 属性外观：标题居左、居中、居右，边框显示/隐藏，边框粗细和边框颜色。
2. 容器布局：分组框承载标签、按钮、复选框、单选框，并演示分组框嵌套分组框。
3. 运行时接口：调用通用控件接口设置/读取标题、启用/禁用、显示/隐藏和调整位置大小。
4. 边界状态：零宽边框、隐藏边框、禁用状态、初始隐藏状态和工具提示。

分组框当前没有专属事件或专属命令；它的专属能力由设计器属性实现，运行期使用通用控件接口。分组框本身是容器，子控件事件仍可正常绑定。

## 打开和运行

- 打开 `分组框接口完整演示.lbsln`，或直接打开本目录。
- 使用 F5 构建运行。
- 点击“运行时接口”页的按钮，观察分组框标题、状态和位置变化。
- 源码分享包位于 `exports/分组框接口完整演示.lcpppkg`。

## 能力清单

| 类型 | 能力 |
| --- | --- |
| 设计属性 | 标题文本、标题对齐（居左/居中/居右）、显示边框、边框粗细（0～8）、边框颜色 |
| 通用属性 | 位置、大小、字体、前景色、背景色、启用状态、可见状态、工具提示 |
| 容器能力 | 子控件承载、子控件事件、分组框嵌套 |
| 通用接口 | `控件_设置文本`、`控件_取文本`、`控件_设置启用`、`控件_设置可见`、`控件_设置位置大小` |
