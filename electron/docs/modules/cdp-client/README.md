# CDP 客户端模块 3.0 使用说明

`lingbuilder.cdp.client` 是 LingBuilder 内置的 Chrome DevTools Protocol（CDP）受管客户端模块。它让 LingBuilder 生成的程序通过 WebSocket 连接 Chrome/Edge 的调试端口，完成浏览器自动化、页面监听与数据采集。异步命令通过 `&处理器名` 在 UI 线程回调。

## 支持范围（阶段 3 实施中）

已支持阶段 1/2 的多连接、页面自动化、Fetch、对话框、下载、上传、仿真与输出；阶段 3 已新增 Target/Session/Frame/ExecutionContext 注册表与自动附加、OOPIF/Worker 会话执行、Runtime binding、Overlay 高亮、多点触控、Debugger 断点/暂停/单步/调用帧/作用域、Performance 指标、Storage usage/清理、严格证书错误逐次裁决，以及版本化录制文件地基。当前清单共 144 条命令、14 个受管类型。

仍在实施和真实 smoke 验收：screencast、Tracing/CPU Profile/精确覆盖率/Heap 完整任务输出、录制自动采集与确定性回放执行器。阶段 3 尚未标记完成，完整路线见仓库 `doc/CDP模块开发.md`。

## 多开与连接

CDP 模块支持同时连接多个调试端口。每个 `CDP_连接` 调用创建独立的受管连接（独立 WebSocket、独立消息编号、独立回调表），连接之间互不干扰；`CDP_取连接数量()` 可查询当前并存连接数。

```lcpp
CDP连接 连接A ＝ CDP_连接("http://127.0.0.1:9222", &连接A就绪)
CDP连接 连接B ＝ CDP_连接("http://127.0.0.1:9333", &连接B就绪)
```

## 安全边界

- `CDP_连接` 只允许本机 `127.0.0.1`、`localhost` 或 `::1`；连接远程地址必须显式使用 `CDP_连接远程`，并自行确认目标主机与网络链路可信。
- 调试端口拥有浏览器完整控制权。请只对自己显式以 `--remote-debugging-port` 启动的浏览器开放连接。
- Cookie 读取结果属于敏感数据，不得写入日志或项目分享包。

## 启动浏览器调试端口

```text
chrome.exe --remote-debugging-port=9222 --user-data-dir=C:\CDPProfile
msedge.exe --remote-debugging-port=9222 --user-data-dir=C:\CDPProfile
```

headless 模式：追加 `--headless=new --disable-gpu`。

## 调用方式与处理器

全部异步命令提交后立即返回（`逻辑型` 表示是否成功提交），结果通过完成处理器通知。处理器内使用 `CDP_取当前事件类型()` 判断成败，用 `CDP_取当前事件文本()` 读取结果，用 `CDP_取当前错误()` 读取中文错误（保留 CDP 原始信息）。

事件类型清单：`已就绪`、`连接失败`、`已断开`、`页面就绪`、`页面失败`、`加载完成`、`页面销毁`、`命令完成`、`命令失败`、`网络请求`、`网络响应`、`网络完成`、`网络失败`、`请求被拦截`、`需要认证`、`对话框出现`、`下载开始`、`下载进度`、`下载完成`、`下载取消`、`新页面出现`、`控制台`、`页面异常`。

## 命令超时

每个连接的异步命令默认 30 秒超时（导航与就绪等待使用两倍上限），超时以“命令失败”事件通知并保留原始命令名。`CDP_设置命令超时(连接, 毫秒)` 可调整（1000-600000）。

## 请求拦截（Fetch 域）

`CDP_拦截开始(页面, 网址模式, &处理器)` 后，匹配模式（如 `*://api.example.com/*`，`*` 匹配全部）的请求会暂停并触发“请求被拦截”事件。**拦截期间浏览器网络挂起**，处理器内必须尽快用 `CDP_取当前拦截()` 取得的句柄做一次裁决：

- `CDP_拦截继续(拦截)` —— 原样放行；
- `CDP_拦截改写(拦截, 网址, 头JSON)` —— 改写 URL 和/或请求头后放行（头为 `[{名称, 值}]` JSON 数组整体替换）；
- `CDP_拦截模拟响应(拦截, 状态码, 头JSON, 响应体)` —— 不发往服务器直接返回 mock 响应；
- `CDP_拦截终止(拦截, 失败原因)` —— 以网络错误终止（Failed/Aborted/TimedOut 等）；
- “需要认证”事件用 `CDP_拦截应答认证(拦截, 用户名, 密码)`，用户名为空表示取消。

快照：网址/方法/请求编号用 `CDP_取当前网络网址/方法/编号`，请求头 JSON 用 `CDP_取当前事件文本`，详情（请求阶段/响应阶段）用 `CDP_取当前事件详情`；请求体用 `CDP_取拦截请求体(拦截, &完成)`。页面释放时未裁决拦截会自动终止。`CDP_拦截停止(页面)` 停止拦截。

## 对话框与下载

对话框：`CDP_绑定对话框事件(页面, &处理器)` 订阅 alert/confirm/prompt/beforeunload；**对话框打开期间页面脚本阻塞**，处理器内必须尽快 `CDP_应答对话框(页面, 接受, 提示文本)`。快照：`CDP_取当前对话框消息/类型/默认文本`。未绑定时运行时自动拒绝。

下载：`CDP_设置下载目录(连接, 目录, 真)` 允许下载到已存在的目录，`CDP_绑定下载事件(连接, &处理器)` 订阅下载开始/进度/完成/取消。快照：`CDP_取当前下载文件名`、`CDP_取当前下载进度`。

## 文件上传与等待

`CDP_设置元素文件(元素, 文件路径, &完成)` 为文件选择控件设置上传文件（文件必须真实存在）。`CDP_等待加载(页面, 事件类型, 超时秒, &完成)` 等待生命周期事件：0=load、1=DOMContentLoaded、2=networkIdle、3=networkAlmostIdle。

## 设备与网络仿真

`CDP_设置视口(页面, 宽, 高)`、`CDP_设置UserAgent`、`CDP_设置触摸`、`CDP_设置地理位置(页面, 纬度, 经度)`、`CDP_设置时区`、`CDP_设置语言`、`CDP_设置暗色模式`、`CDP_设置CPU节流(页面, 倍率)`、`CDP_重置仿真(页面)`；网络：`CDP_设置离线`、`CDP_设置限速(页面, 延迟毫秒, 下行, 上行)`（字节每秒，-1 不限）、`CDP_禁用缓存`。

## 阶段 3 Target、调试与安全

- `CDP_设置自动附加` + `CDP_绑定目标事件` 管理 OOPIF 和 Worker；用 `CDP_枚举目标JSON`、`CDP_附加目标`、`CDP_会话执行脚本` 操作独立会话，不能把 Worker 伪装成页面。
- `CDP_添加页面绑定` 接收页面 `Runtime.bindingCalled`；事件载荷从 `CDP_取当前事件文本` 读取。`CDP_高亮元素` 使用 Overlay，`CDP_派发触摸` 接收最多 16 个触点的严格 JSON。
- Debugger 使用 `CDP_启用调试器`、`CDP_设置断点`、暂停/恢复/单步；暂停事件中用 `CDP_取当前调用帧数量` 和 `CDP_取当前调用帧` 获取 generation 受限句柄，恢复后旧句柄失效。
- Storage 清理必须调用 `CDP_清理来源数据` 并传 exact origin、allowlist storageTypes 和显式确认。
- 证书错误接管只能使用 advanced 命令 `CDP_开启证书错误接管`：白名单必须是 exact origin、期限 1–600 秒，每个错误必须用 `CDP_裁决证书错误` 单独决定；未应答、超时、关闭或断线一律取消，不提供通配符或全局忽略开关。
- `CDP_开始录制` / `CDP_记录步骤` / `CDP_停止录制` 写入 `lingbuilder.cdp.recording`、`schemaVersion:1` JSON；敏感字段会替换为 `${SECRET:REDACTED}`。当前 `CDP_加载回放` 只建立受管回放状态，确定性执行器仍在实施。

## 完整示例

```lcpp
CDP连接 浏览器 ＝ 0
CDP页面 页面 ＝ 0

空 启动自动化()
    浏览器 ＝ CDP_连接("http://127.0.0.1:9222", &连接就绪)
    如果 (浏览器 == 0)
        调试输出("连接创建失败，请确认调试端口地址")
    如果结束
结束

空 连接就绪()
    如果 (CDP_取当前事件类型() == "已就绪")
        调试输出("浏览器版本：" + CDP_取浏览器版本(浏览器))
        CDP_设置命令超时(浏览器, 60000)
        CDP_设置下载目录(浏览器, "C:/CDPDownloads", 真)
        CDP_绑定下载事件(浏览器, &下载事件)
        页面 ＝ CDP_新建页面(浏览器, "https://example.com", &页面就绪)
    否则
        调试输出("连接失败：" + CDP_取当前错误())
    如果结束
结束

空 页面就绪()
    如果 (CDP_取当前事件类型() == "页面就绪")
        CDP_绑定网络事件(页面, &网络事件)
        CDP_绑定控制台事件(页面, &控制台消息)
        CDP_绑定对话框事件(页面, &对话框出现)
        CDP_拦截开始(页面, "*://api.example.com/*", &请求被拦截)
        CDP_执行脚本(页面, "document.title", &取得标题)
    否则
        调试输出("页面失败：" + CDP_取当前错误())
    如果结束
结束

空 请求被拦截()
    调试输出("拦截到：" + CDP_取当前网络方法() + " " + CDP_取当前网络网址())
    CDP_拦截模拟响应(CDP_取当前拦截(), 200, "", "{\"ok\":true}")
结束

空 对话框出现()
    调试输出("对话框：" + CDP_取当前对话框消息())
    CDP_应答对话框(CDP_取当前页面(), 真, "")
结束

空 下载事件()
    如果 (CDP_取当前事件类型() == "下载完成")
        调试输出("下载完成：" + CDP_取当前下载文件名())
    如果结束
结束

空 取得标题()
    如果 (CDP_取当前事件类型() == "命令完成")
        调试输出("标题：" + CDP_取当前事件文本())
    如果结束
结束

空 网络事件()
    如果 (CDP_取当前事件类型() == "网络响应")
        调试输出(CDP_取当前网络方法() + " " + CDP_取当前网络网址() + " 状态 " + 到文本(CDP_取当前网络状态()))
    如果结束
结束

空 控制台消息()
    调试输出("[" + CDP_取当前事件详情() + "] " + CDP_取当前事件文本())
结束
```

## 依赖与平台限制

- 目标平台：Windows MSVC（win32 与 x64），依赖 `winhttp.lib`、`crypt32.lib`（系统库）。
- WebSocket 通过 WinHTTP 协议扩展实现，不引入第三方运行库；JSON 编解码内嵌在模块运行时中。
- 浏览器要求：Chrome/Edge 78+ 或同源 Chromium（含 FBro 内嵌浏览器，可用 `FBro_取调试端口` 获取地址后连接）。
- 已知限制：拦截与对话框事件期间浏览器/页面会挂起，处理器必须尽快裁决；网络事件高频页面下事件队列超过 65536 条会丢弃最旧事件；`CDP_绑定新页面事件` 的“新页面出现”包含 `CDP_新建页面` 自己创建的标签页；headless 模式下部分浏览器窗口边界（`CDP_设置窗口边界`）不生效。
