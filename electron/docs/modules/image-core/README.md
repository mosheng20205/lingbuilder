## 命令参考（共 7 条）

### 全部命令

#### 图像_取宽度

- 签名：`图像_取宽度(路径)`
- 返回值：整数型
- 说明：返回图片像素宽度，失败返回 0。
- 参数：
  - 路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。

#### 图像_取高度

- 签名：`图像_取高度(路径)`
- 返回值：整数型
- 说明：返回图片像素高度，失败返回 0。
- 参数：
  - 路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。

#### 图像_转换格式

- 签名：`图像_转换格式(来源, 目标, 格式)`
- 返回值：逻辑型
- 说明：转换为 png、jpg、bmp、gif 或 tif。
- 参数：
  - 来源（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 目标（文本型）：输出图片路径；保存格式按扩展名识别 png、jpg、jpeg、bmp、gif、tif、tiff，无法识别时按 PNG 保存。
  - 格式（文本型）：目标编码名，支持 png、jpg、jpeg、bmp、gif、tif、tiff；空文本或不识别时按 PNG 保存。

#### 图像_缩放

- 签名：`图像_缩放(来源, 目标, 宽度, 高度)`
- 返回值：逻辑型
- 说明：高质量缩放并按目标扩展名保存。
- 参数：
  - 来源（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 目标（文本型）：输出图片路径；保存格式按扩展名识别 png、jpg、jpeg、bmp、gif、tif、tiff，无法识别时按 PNG 保存。
  - 宽度（整数型）：缩放后的目标宽度，像素；小于等于 0 返回假。
  - 高度（整数型）：缩放后的目标高度，像素；小于等于 0 返回假。

#### 图像_裁剪

- 签名：`图像_裁剪(来源, 目标, 横坐标, 纵坐标, 宽度, 高度)`
- 返回值：逻辑型
- 说明：裁剪图像区域。
- 参数：
  - 来源（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 目标（文本型）：输出图片路径；保存格式按扩展名识别 png、jpg、jpeg、bmp、gif、tif、tiff，无法识别时按 PNG 保存。
  - 横坐标（整数型）：裁剪起点列坐标，从 0 起；与宽度之和越过图片宽度时返回假。
  - 纵坐标（整数型）：裁剪起点行坐标，从 0 起；与高度之和越过图片高度时返回假。
  - 宽度（整数型）：裁剪区域宽度，像素；小于等于 0 返回假。
  - 高度（整数型）：裁剪区域高度，像素；小于等于 0 返回假。

#### 图像_旋转90度

- 签名：`图像_旋转90度(来源, 目标, 顺时针)`
- 返回值：逻辑型
- 说明：顺时针或逆时针旋转 90 度。
- 参数：
  - 来源（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 目标（文本型）：输出图片路径；保存格式按扩展名识别 png、jpg、jpeg、bmp、gif、tif、tiff，无法识别时按 PNG 保存。
  - 顺时针（逻辑型）：传真顺时针旋转 90 度，传假逆时针旋转 90 度。

#### 图像_取错误

- 签名：`图像_取错误()`
- 返回值：文本型
- 说明：返回最近图像错误。
