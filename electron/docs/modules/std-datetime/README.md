# 日期时间模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.datetime` |
| 版本 | 1.1.0 |
| 分类 | 其他 |
| 命令数 | 22 |

提供日期时间值（64 位打包的本地年月日时分秒）与时间戳、格式化、分量读取、增减、间隔和高精度计时。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 22 条）

### 全部命令

#### 时间_当前时间戳

- 签名：`时间_当前时间戳()`
- 返回值：长整数型
- 说明：返回当前 Unix 秒级时间戳。
- 示例：

```
时间_当前时间戳()
```


#### 时间_当前毫秒

- 签名：`时间_当前毫秒()`
- 返回值：长整数型
- 说明：返回当前 Unix 毫秒级时间戳。
- 示例：

```
时间_当前毫秒()
```


#### 时间_单调毫秒

- 签名：`时间_单调毫秒()`
- 返回值：长整数型
- 说明：返回适合计算耗时的单调时钟毫秒值。

#### 时间_格式化当前

- 签名：`时间_格式化当前(格式)`
- 返回值：文本型
- 说明：使用 wcsftime 格式格式化当前本地时间。
- 参数：
  - 格式（文本型）：wcsftime 格式串，例如 %Y-%m-%d %H:%M:%S；输出上限 256 个字符，格式化失败返回空文本。

#### 时间_格式化时间戳

- 签名：`时间_格式化时间戳(时间戳, 格式)`
- 返回值：文本型
- 说明：格式化指定 Unix 秒级时间戳。
- 参数：
  - 时间戳（长整数型）：要格式化的 Unix 秒级时间戳，按系统本地时区换算。
  - 格式（文本型）：wcsftime 格式串，例如 %Y-%m-%d %H:%M:%S；空文本时使用 %Y-%m-%d %H:%M:%S。

#### 时间_取现行

- 签名：`时间_取现行()`
- 返回值：日期时间
- 说明：返回当前系统日期及时间（本地时区）。
- 示例：

```
局部 日期时间 当前时间
当前时间 = 时间_取现行()
```


#### 时间_置现行

- 签名：`时间_置现行(时间)`
- 返回值：逻辑型
- 说明：设置当前系统日期及时间（本地时区）；需要系统权限，普通权限下返回假。
- 参数：
  - 时间（长整数型）：要写入系统时钟的日期时间值；无效值（0）返回假。修改系统时钟通常需要管理员权限，失败返回假。
- 示例：

```
局部 日期时间 新时间
新时间 = 时间_指定(2026, 9, 16, 12, 0, 0)
```


#### 时间_从文本

- 签名：`时间_从文本(文本)`
- 返回值：日期时间
- 说明：把文本解析为日期时间；支持“2026年9月16日12时30分25秒”“2026-09-16 12:30:25”“20260916123025”等书写格式，时间部分可以省略。
- 参数：
  - 文本（文本型）：要解析的时间文本，支持 年月日时分秒 中文格式、斜杠/连字符/点号分隔格式和 8 位或 14 位纯数字格式；格式不符或数值非法时返回 0（无效时间）。
- 示例：

```
局部 日期时间 已解析
已解析 = 时间_从文本("2026-09-16 12:30:25")
```


#### 时间_到文本

- 签名：`时间_到文本(时间, 转换部分)`
- 返回值：文本型
- 说明：把日期时间转为“2026年09月16日12时30分25秒”风格的中文文本。
- 参数：
  - 时间（长整数型）：要转换的日期时间值；无效值返回空文本。
  - 转换部分（整数型）：0 全部转换，1 只取日期部分，2 只取时间部分；省略时为 0。
- 示例：

```
局部 日期时间 当前时间
当前时间 = 时间_取现行()
```


#### 时间_指定

- 签名：`时间_指定(年, 月, 日, 小时, 分钟, 秒)`
- 返回值：日期时间
- 说明：用指定年月日时分秒构造日期时间；超出范围的分量自动取最相近的有效值。
- 参数：
  - 年（整数型）：年份，100 到 9999；超出范围自动取边界值。
  - 月（整数型）：月份 1 到 12，省略默认 1；超出范围自动取边界值。
  - 日（整数型）：日 1 到该月天数，省略默认 1；超出该月天数时自动取该月最后一天。
  - 小时（整数型）：小时 0 到 23，省略默认 0；超出范围自动取边界值。
  - 分钟（整数型）：分钟 0 到 59，省略默认 0；超出范围自动取边界值。
  - 秒（整数型）：秒 0 到 59，省略默认 0；超出范围自动取边界值。
- 示例：

```
局部 日期时间 指定值
指定值 = 时间_指定(2026, 9, 16, 8, 30, 0)
```


#### 时间_取年份

- 签名：`时间_取年份(时间)`
- 返回值：整数型
- 说明：返回日期时间中的年份。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。
- 示例：

```
局部 日期时间 当前时间
当前时间 = 时间_取现行()
```


#### 时间_取月份

- 签名：`时间_取月份(时间)`
- 返回值：整数型
- 说明：返回日期时间中的月份（1～12）。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_取日

- 签名：`时间_取日(时间)`
- 返回值：整数型
- 说明：返回日期时间中的日（1～31）。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_取星期几

- 签名：`时间_取星期几(时间)`
- 返回值：整数型
- 说明：返回日期时间是星期几：星期日为 1，星期一为 2，依此类推，星期六为 7。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_取小时

- 签名：`时间_取小时(时间)`
- 返回值：整数型
- 说明：返回日期时间中的小时（0～23）。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_取分钟

- 签名：`时间_取分钟(时间)`
- 返回值：整数型
- 说明：返回日期时间中的分钟（0～59）。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_取秒

- 签名：`时间_取秒(时间)`
- 返回值：整数型
- 说明：返回日期时间中的秒（0～59）。
- 参数：
  - 时间（长整数型）：要读取分量的日期时间值；无效值返回 0。

#### 时间_增减

- 签名：`时间_增减(时间, 被增减部分, 增减值)`
- 返回值：日期时间
- 说明：返回增减一段时间间隔后的新时间；结果无效时自动靠拢到最近的有效时间。
- 参数：
  - 时间（长整数型）：起始日期时间值；无效值返回 0。
  - 被增减部分（整数型）：增减的单位：1 年份、2 季度、3 月份、4 周、5 日、6 小时、7 分钟、8 秒；其它值返回 0。
  - 增减值（整数型）：增减的数量，可为负表示减少；例如 月份 单位下 1月31日 加 1 得 2月28日。
- 示例：

```
局部 日期时间 当前时间
当前时间 = 时间_取现行()
```


#### 时间_取间隔

- 签名：`时间_取间隔(时间一, 时间二, 间隔单位)`
- 返回值：双精度小数型
- 说明：返回“时间一”减去“时间二”的间隔数量；按指定单位取完整间隔数。
- 参数：
  - 时间一（长整数型）：被减数日期时间值；无效值返回 0。
  - 时间二（长整数型）：减数日期时间值；无效值返回 0。
  - 间隔单位（整数型）：间隔的单位：1 年份、2 季度、3 月份、4 周、5 日、6 小时、7 分钟、8 秒；年季月取完整单位数，其余按秒差换算取整。
- 示例：

```
局部 日期时间 早期
早期 = 时间_指定(2026, 1, 1, 0, 0, 0)
```


#### 时间_取某月天数

- 签名：`时间_取某月天数(年份, 月份)`
- 返回值：整数型
- 说明：返回指定月份的天数；月份无效返回 0。
- 参数：
  - 年份（整数型）：年份，用于判断闰年二月。
  - 月份（整数型）：月份 1 到 12；超出范围返回 0。
- 示例：

```
时间_取某月天数(2026, 2)
```


#### 时间_取日期

- 签名：`时间_取日期(时间)`
- 返回值：日期时间
- 说明：返回日期时间值的日期部分，时分秒固定为 0 时 0 分 0 秒。
- 参数：
  - 时间（长整数型）：源日期时间值；无效值返回 0。

#### 时间_取时间

- 签名：`时间_取时间(时间)`
- 返回值：日期时间
- 说明：返回日期时间值的时间部分，年月日固定为 2000 年 1 月 1 日。
- 参数：
  - 时间（长整数型）：源日期时间值；无效值返回 0。
