## 命令参考（共 4 条）

### 全部命令

#### 设备_打开

- 签名：`设备_打开(设备路径, 允许写入)`
- 返回值：长整数型
- 说明：打开 \.\DeviceName 形式设备。
- 参数：
  - 设备路径（文本型）：系统给出的设备接口路径，不是普通文件名；打不开时返回 0 并可用 设备_取错误码 查看原因。
  - 允许写入（逻辑型）：传真时以读写方式打开，执行会改变设备状态的 IOCTL 才需要。

#### 设备_无参数控制

- 签名：`设备_无参数控制(设备句柄, 控制码)`
- 返回值：逻辑型
- 说明：执行无输入输出缓冲区 DeviceIoControl。
- 参数：
  - 设备句柄（句柄）：设备_打开 返回的设备句柄。
  - 控制码（整数型）：IOCTL 控制码；本命令不带任何输入输出缓冲区。

#### 设备_关闭

- 签名：`设备_关闭(设备句柄)`
- 返回值：逻辑型
- 说明：关闭设备句柄。
- 参数：
  - 设备句柄（句柄）：设备_打开 返回的设备句柄；传 0 直接返回假。

#### 设备_取错误码

- 签名：`设备_取错误码()`
- 返回值：整数型
- 说明：返回最近设备操作 Win32 错误码。
