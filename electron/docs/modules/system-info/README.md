# 系统信息模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.system.info` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 8 |

读取当前 Windows、计算机、用户、处理器和内存信息。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 8 条）

### 全部命令

#### 系统_取用户名

- 签名：`系统_取用户名()`
- 返回值：文本型
- 说明：返回当前登录用户名。
- 示例：

```
系统_取用户名()
```


#### 系统_取计算机名

- 签名：`系统_取计算机名()`
- 返回值：文本型
- 说明：返回本机计算机名。

#### 系统_取Windows版本

- 签名：`系统_取Windows版本()`
- 返回值：文本型
- 说明：返回真实 Windows 主版本、次版本和内部版本号。

#### 系统_取处理器数量

- 签名：`系统_取处理器数量()`
- 返回值：整数型
- 说明：返回系统逻辑处理器数量。

#### 系统_取内存总量MB

- 签名：`系统_取内存总量MB()`
- 返回值：长整数型
- 说明：返回物理内存总量，单位 MB。

#### 系统_取内存可用MB

- 签名：`系统_取内存可用MB()`
- 返回值：长整数型
- 说明：返回当前可用物理内存，单位 MB。

#### 系统_取环境变量

- 签名：`系统_取环境变量(名称)`
- 返回值：文本型
- 说明：读取当前进程可见的环境变量。
- 参数：
  - 名称（文本型）：环境变量名称，Windows 下不区分大小写；变量不存在时返回空文本。

#### 系统_是否管理员

- 签名：`系统_是否管理员()`
- 返回值：逻辑型
- 说明：判断当前进程是否以管理员组身份运行（AllocateAndInitializeSid + CheckTokenMembership）。读取系统进程内存、关机等受保护操作前建议先自检，避免把“没权限”误判为“没有数据”。
- 示例：

```
系统_是否管理员()
```
