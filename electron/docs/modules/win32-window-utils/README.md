# Win32窗口操作模块使用说明

`Win32窗口操作模块`（模块 ID：`lingbuilder.win32.window-utils`）通过 HWND 句柄安全封装常用窗口操作：查找窗口、读取/设置标题、按 Win32 `SW_*` 编号显示/隐藏/最小化/最大化、移动窗口、切换前台，以及面向**无边框窗口**（`WS_POPUP` 自绘标题栏应用）的系统拖拽与边缘缩放入口。

## 适用场景

- 桌面工具需要按标题找到别的窗口并前置/移动。
- **网页 UI 自绘标题栏的无边框应用**（例如内嵌 FBro/CEF 浏览器控件的全幅界面）：网页标题栏的 `mousedown` 事件经浏览器桥（如 cefQuery）调用本模块命令，把操作转交系统原生移动/缩放循环。

## 命令清单

| 命令 | 签名 | 说明 |
| --- | --- | --- |
| 窗口_按标题查找 | 窗口_按标题查找(标题) → 长整数型 | 按完整窗口标题查找顶层窗口，返回 HWND（0 表示未找到）。 |
| 窗口_句柄是否有效 | 窗口_句柄是否有效(窗口句柄) → 逻辑型 | 判断 HWND 是否仍有效。 |
| 窗口_取标题 | 窗口_取标题(窗口句柄) → 文本型 | 读取窗口标题。 |
| 窗口_设置标题 | 窗口_设置标题(窗口句柄, 标题) → 逻辑型 | 设置窗口标题。 |
| 窗口_显示 | 窗口_显示(窗口句柄, 显示方式) → 逻辑型 | 按 `SW_*` 编号执行：0 隐藏、3 最大化、5 显示、6 最小化、9 还原。 |
| 窗口_移动 | 窗口_移动(窗口句柄, 横坐标, 纵坐标, 宽度, 高度) → 逻辑型 | 移动窗口并设置尺寸（物理像素）。 |
| 窗口_置前台 | 窗口_置前台(窗口句柄) → 逻辑型 | 请求切换到前台。 |
| 窗口_是否最大化 | 窗口_是否最大化(窗口句柄) → 逻辑型 | 窗口是否处于最大化（`IsZoomed`）。用于网页最大化按钮的切换判定。 |
| 窗口_取边界JSON | 窗口_取边界JSON(窗口句柄) → 文本型 | 返回 `{"x":..,"y":..,"width":..,"height":..}`（屏幕物理像素）；窗口无效返回 `{}`。用于记住还原边界。 |
| 窗口_开始拖拽 | 窗口_开始拖拽(窗口句柄) → 逻辑型 | 发送 `WM_NCLBUTTONDOWN(HTCAPTION)` 进入系统移动循环，直到用户松开鼠标。调用会阻塞到拖拽结束，必须在用户交互处理器（如 cefQuery 事件）中调用；拖拽期间系统自行泵送界面消息。 |
| 窗口_开始边缘缩放 | 窗口_开始边缘缩放(窗口句柄, 边缘代码) → 逻辑型 | 发送 `WM_NCLBUTTONDOWN` 并携带 Win32 命中代码进入系统缩放循环。边缘代码：10 左、11 右、12 上、13 左上、14 右上、15 下、16 左下、17 右下；其它值返回假。 |

## 无边框网页标题栏范式（配合 FBro 浏览器控件）

1. 窗口边框样式选「无边框」，FBroBrowser 控件铺满客户区。
2. 页面标题栏区域监听 `mousedown`（排除按钮等交互元素），通过 cefQuery 发送 `{"action":"win.drag"}`；原生取 `FBro_取父窗口句柄(控件名)` 得到主窗口句柄后调用 `窗口_开始拖拽`。
3. 窗口四边布置 2~6px 隐藏拉伸热区，`mousedown` 时发送 `{"action":"win.resize","edge":17}`（右下角示例）；原生调用 `窗口_开始边缘缩放`。
4. 最小化/最大化/关闭按钮分别走 `窗口_显示(句柄, 6)`、`窗口_是否最大化` + `窗口_显示(句柄, 3/9)` 切换、以及 `结束()`。
5. 最大化状态下建议隐藏边缘热区并切换还原图标；最大化图标状态以每次点击时 `窗口_是否最大化` 的返回为准，避免窗口被拖拽还原后图标状态不同步。

## 注意事项

- 所有句柄参数都是 `FBro_取窗口句柄/取父窗口句柄` 等命令返回的长整数句柄，不要传入自造数值。
- `窗口_开始拖拽/开始边缘缩放` 进入的是系统模态循环：从网页 `mousedown` 到用户松开鼠标期间，调用方线程（CEF UI 线程）由系统移动循环接管消息泵，这是该范式的预期行为。
- 坐标与边界一律是物理像素；与 DPI 相关的换算配合「显示器与DPI模块」使用。
