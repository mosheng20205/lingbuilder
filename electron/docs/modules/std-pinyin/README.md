# 拼音处理模块

模块 ID：`lingbuilder.std.pinyin`  
版本：`1.0.0`  
适用平台：Windows / MSVC Win32、x64；普通 Win32 与 new_emoji 后端共用同一确定性 C++17 运行时。

拼音处理模块内置约 2.6 万汉字的读音码表（含多音字全部读音，按常用度排序），提供全拼、首字母、声母韵母与发音比较能力，典型场景：联系人首字母检索、拼音排序、中文输入联想。

码表来源于开源项目 [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data)（MIT 许可），随模块编译进生成的 C++ 工程，无运行时外部依赖。拼音统一输出小写、不带声调，韵母保留 ü。

## 命令一览

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `拼音_取全拼(文本, 分隔符)` | 文本型 | 逐字转小写全拼，多音字取最常用读音；分隔符可省略（连写） |
| `拼音_取首字母(文本)` | 文本型 | 每个汉字读音的首字母（无声母音节跳过） |
| `拼音_取所有发音(汉字, 结果数组)` | 整数型 | 单个汉字全部读音写入文本数组，返回数量 |
| `拼音_取发音数目(汉字)` | 整数型 | 单个汉字读音数量 |
| `拼音_取声母(文本)` | 文本型 | 逐字声母（zh/ch/sh 算一个），无声母输出空 |
| `拼音_取韵母(文本)` | 文本型 | 逐字韵母 |
| `拼音_发音比较(汉字一, 汉字二)` | 整数型 | 按最常用读音比较：-1 / 0 / 1 |
| `拼音_首字母匹配(文本, 首字母序列)` | 逻辑型 | 首字母序列前缀匹配（不区分大小写），用于检索 |

非汉字字符在取全拼/首字母/声母/韵母中**原样保留**（首字母匹配序列中跳过）。

## 基本用法

```lcpp
调试输出(拼音_取全拼("中文编程", "-"))
调试输出(拼音_取首字母("中文编程"))
调试输出(拼音_取声母("中文编程"))
调试输出(拼音_取韵母("中文编程"))
调试输出(拼音_首字母匹配("你好世界", "nhsj"))

局部 文本型 读音[]
拼音_取所有发音("重", 读音)
调试输出(数组_取成员数(读音))
调试输出(数组_取成员(读音, 0))
```

## 注意事项

- 多音字在取全拼/首字母/声母/韵母中一律取**最常用读音**；需要全部读音用 `拼音_取所有发音`。
- 发音比较只取每个文本的首字符参与比较，用于两个汉字的排序。
- 码表随 IDE 内置，生成的 exe 不需要额外数据文件。
