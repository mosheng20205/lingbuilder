# 控制台模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.console` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 12 |

为控制台程序提供标准输入输出、光标与文本颜色控制；命令只能在控制台程序（含「整数型 启动()」入口）中使用，窗口应用中会给出阻断诊断。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 12 条）

### 全部命令

#### 控制台_输出

- 签名：`控制台_输出(内容)`
- 返回值：空
- 说明：向控制台标准输出写入文本（不换行）。
- 参数：
  - 内容（文本型）：要写入控制台的文本；不附加换行，输出后光标停在文本末尾。

#### 控制台_输出行

- 签名：`控制台_输出行(内容)`
- 返回值：空
- 说明：向控制台标准输出写入一行文本并换行。
- 参数：
  - 内容（文本型）：要写入控制台的文本；写入后光标移动到下一行行首。

#### 控制台_读行

- 签名：`控制台_读行()`
- 返回值：文本型
- 说明：从控制台读取一行输入，遇到回车返回（结果不含回车）；流被重定向或读取失败返回空文本。
- 示例：

```
控制台_读行()
```


#### 控制台_清屏

- 签名：`控制台_清屏()`
- 返回值：空
- 说明：清空控制台屏幕并把光标移回左上角。

#### 控制台_置光标位置

- 签名：`控制台_置光标位置(列, 行)`
- 返回值：空
- 说明：把控制台光标移动到指定字符位置（后续输出从该位置开始）。
- 参数：
  - 列（整数型）：目标列号，从 0 起；超出屏幕宽度时取边界值。
  - 行（整数型）：目标行号，从 0 起；超出屏幕高度时取边界值。

#### 控制台_取光标列

- 签名：`控制台_取光标列()`
- 返回值：整数型
- 说明：返回控制台光标当前列号（从 0 起）。

#### 控制台_取光标行

- 签名：`控制台_取光标行()`
- 返回值：整数型
- 说明：返回控制台光标当前行号（从 0 起）。

#### 控制台_取宽度

- 签名：`控制台_取宽度()`
- 返回值：整数型
- 说明：返回控制台屏幕缓冲区的字符宽度。

#### 控制台_取高度

- 签名：`控制台_取高度()`
- 返回值：整数型
- 说明：返回控制台屏幕窗口的字符高度。

#### 控制台_显示光标

- 签名：`控制台_显示光标(可见)`
- 返回值：空
- 说明：设置控制台光标是否可见。
- 参数：
  - 可见（逻辑型）：真显示光标，假隐藏光标。

#### 控制台_置颜色

- 签名：`控制台_置颜色(前景色, 背景色)`
- 返回值：空
- 说明：设置控制台后续输出的前景色与背景色（0～15 编号组合）。
- 参数：
  - 前景色（整数型）：前景色编号 0～15：0 黑、1 深蓝、2 深绿、3 青灰、4 深红、5 紫、6 橄榄、7 灰白、8 深灰、9 蓝、10 绿、11 浅青、12 红、13 粉、14 黄、15 白。
  - 背景色（整数型）：背景色编号 0～15，取值同前景色。

#### 控制台_恢复颜色

- 签名：`控制台_恢复颜色()`
- 返回值：空
- 说明：把控制台颜色恢复为默认（灰字黑底）。
