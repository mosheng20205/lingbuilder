# 键盘Hook模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.advanced.hook` |
| 版本 | 1.0.0 |
| 分类 | 系统 |

提供当前桌面低级键盘 Hook 状态读取；不支持注入或修改其他进程。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 4 条）

### 全部命令

#### 键盘钩子_启动

- 签名：`键盘钩子_启动()`
- 返回值：逻辑型
- 说明：启动 WH_KEYBOARD_LL 钩子。

#### 键盘钩子_取最后键码

- 签名：`键盘钩子_取最后键码()`
- 返回值：整数型
- 说明：读取最近键盘消息虚拟键码。

#### 键盘钩子_取消息数量

- 签名：`键盘钩子_取消息数量()`
- 返回值：长整数型
- 说明：读取钩子收到的消息数量。

#### 键盘钩子_停止

- 签名：`键盘钩子_停止()`
- 返回值：空
- 说明：卸载键盘钩子。
