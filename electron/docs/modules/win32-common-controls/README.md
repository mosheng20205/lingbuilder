# Win32 高级控件运行时创建

模块 ID：`lingbuilder.win32.common-controls`

本模块的 20 个当前公开可视控件都可在 `.lcpp` 中创建：列表视图、数据表格、树形视图、选项卡、表头、增强组合框、超链接、日期时间选择器、月历、颜色选择器、滑块、数值调节器、热键输入框、IP 地址框、工具栏、状态栏、富文本框、动画控件、视频播放器、平面滚动条。旧项目兼容 ReBar 和 Pager 不在运行时创建目录中，文件对话框、菜单、图像列表等非可视对象也不纳入。

## 创建与查找

每种控件提供具体类型、创建命令、文本标记查找和整数标记查找。例如：

```lcpp
局部 列表视图 动态列表 = 控件_创建列表视图(当前窗口, 20, 20, 360, 220, "任务", "主列表", 2001)
局部 列表视图 查找列表 = 通过标记文本获取列表视图("主列表")
局部 树形视图 查找树 = 通过标记整数获取树形视图(2002)
```

创建签名统一为“父级、横坐标、纵坐标、宽度、高度、文本、可选标记文本、可选标记整数”。两个标记可空；只传整数标记时在文本位置传 `""`。文本标记 trim 后为空即未设置并区分大小写，整数标记接受 `0` 和负数。非空标记在当前窗口、具体控件类型和标记类别内唯一。

## 引用、专属能力与事件

所有实例进入同一窗口级注册表，并遵守“一实例一独立主 `HWND`”。设计器控件与代码控件共用查找、通用操作、专属操作、事件分发和失效规则。复合控件可以拥有辅助窗口，但不能借用其他设计器控件的主句柄。

```lcpp
如果 (控件_是否有效(动态列表))
    列表视图_添加行(动态列表, "第一项")
    控件_设置可见(动态列表, 真)
    列表视图_绑定选择项被改变(动态列表, &动态列表选择变化)
如果结束
```

具体事件命令名称以模块补全和事件目录为准，处理器必须写成 `&处理器名`。无效或类型不兼容引用会安全失败并产生中文诊断，不会访问悬空 `HWND`。

代码创建控件不写回设计器。控件引用只允许局部变量、方法参数和返回值，禁止常量、数组、程序集成员、项目全局变量和工作线程传递。

## 运行期专属能力（2026-10-17 第三批）

| 命令 | 适用控件 | 说明 |
| --- | --- | --- |
| `滑块_置刻度间隔(控件名, 刻度间隔)` | 滑块 | 每隔多少单位画一刻度，小于 1 按 1 处理。 |
| `滑块_取刻度间隔(控件名)` | 滑块 | Win32 没有刻度读取消息，按设计器属性与最近一次运行期覆盖口径返回。 |
| `日期时间选择器_置日期(控件名, 日期文本)` | 日期时间选择器 | `"yyyy-MM-dd"`；time 格式控件写 `"HH:mm"` 或 `"HH:mm:ss"`，解析失败返回假。 |
| `日期时间选择器_取日期(控件名)` | 日期时间选择器 | 返回 `"yyyy-MM-dd HH:mm:ss"`，未设置返回空文本。 |
| `日期时间选择器_置显示格式(控件名, 格式文本)` | 日期时间选择器 | DTM 格式串（yyyy/MM/dd/HH/mm/ss，字面字符用单引号包裹）；空文本恢复默认显示。 |
| `月历_置日期(控件名, 日期文本)` | 月历 | 多选月历置为单日选区，普通月历直接选中。 |
| `月历_取日期(控件名)` | 月历 | 返回 `"yyyy-MM-dd"`；多选月历返回选区起始日。 |
| `月历_置选中范围(控件名, 起始日期, 结束日期)` | 月历 | 起止自动按先后排序；仅多选月历生效。 |
| `富文本框_置RTF文本(控件名, RTF文本)` | 富文本框 | EM_STREAMIN，与设计器「RTF 格式化文本」属性同一条流式链路；空文本清空。 |
| `富文本框_取RTF文本(控件名)` | 富文本框 | EM_STREAMOUT，返回含颜色字体格式的 RTF 文本。 |

补充口径：

- 滑块/数值调节器的最小值、最大值运行期改写由基础模块的 `控件_设置数值范围` 直接支持（进度条/滚动条/滑块/数值调节器同一入口），不要重复造命令。
- **富文本红线**：RTF 文本含大量 `\rtf1`、`\par` 序列，禁止在 `.lcpp` 里手写 RTF 字面量（源码转义会把 `\r` 变成回车字符破坏 RTF 结构），正确写法是 `富文本框_置RTF文本(富文本框1, 文件_读入文本("模板.rtf"))` 从文件读入，或经字节集解码后传入。
- 日期时间选择器的「短日期/长日期/时间」切换是创建期样式，运行期改不了；`置显示格式` 用 DTM 格式串改写显示效果，不改控件样式。
- 以上命令仅普通 Win32 后端有运行时实现；new_emoji 后端项目调用会在生成 C++ 前给出中文阻断诊断。

平台限制：Windows、MSVC、Win32/x64。F5、原生预览和 Visual Studio 导出消费同一模块 binding 与控件注册结果。
