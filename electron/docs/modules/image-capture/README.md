## 命令参考（共 3 条）

### 全部命令

#### 截图_主屏到PNG

- 签名：`截图_主屏到PNG(目标路径)`
- 返回值：逻辑型
- 说明：截取主显示器并保存 PNG。
- 参数：
  - 目标路径（文本型）：保存截图的目标 PNG 路径；所在目录必须已存在。

#### 截图_区域到PNG

- 签名：`截图_区域到PNG(目标路径, 横坐标, 纵坐标, 宽度, 高度)`
- 返回值：逻辑型
- 说明：截取指定屏幕区域。
- 参数：
  - 目标路径（文本型）：保存截图的目标 PNG 路径；所在目录必须已存在。
  - 横坐标（整数型）：截取区域左上角的屏幕横坐标，物理像素，可为负值以覆盖副屏。
  - 纵坐标（整数型）：截取区域左上角的屏幕纵坐标，物理像素。
  - 宽度（整数型）：截取区域宽度，像素；小于等于 0 返回假。
  - 高度（整数型）：截取区域高度，像素；小于等于 0 返回假。

#### 截图_窗口到PNG

- 签名：`截图_窗口到PNG(目标路径, 窗口句柄)`
- 返回值：逻辑型
- 说明：截取窗口边界区域。
- 参数：
  - 目标路径（文本型）：保存截图的目标 PNG 路径；所在目录必须已存在。
  - 窗口句柄（句柄）：要截取窗口的外框边界区域，含标题栏和边框；窗口被遮挡时结果同样被遮挡。
