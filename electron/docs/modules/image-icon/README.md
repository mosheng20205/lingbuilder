# 图标处理模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.image.icon` |
| 版本 | 1.0.0 |
| 分类 | 图像 |
| 命令数 | 3 |

提取 EXE/DLL 图标并保存为 PNG，同时提供图标数量查询。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 3 条）

### 全部命令

#### 图标_取数量

- 签名：`图标_取数量(文件路径)`
- 返回值：整数型
- 说明：返回 EXE、DLL 或 ICO 中可提取图标数量。
- 参数：
  - 文件路径（文本型）：含图标的 EXE、DLL 或 ICO 文件路径。

#### 图标_提取大图标到PNG

- 签名：`图标_提取大图标到PNG(文件路径, 索引, 目标路径)`
- 返回值：逻辑型
- 说明：提取大图标并保存 PNG。
- 参数：
  - 文件路径（文本型）：含图标的 EXE、DLL 或 ICO 文件路径。
  - 索引（整数型）：图标序号，从 0 起，必须小于 图标_取数量 返回的数量。
  - 目标路径（文本型）：保存图标的目标 PNG 路径。

#### 图标_提取小图标到PNG

- 签名：`图标_提取小图标到PNG(文件路径, 索引, 目标路径)`
- 返回值：逻辑型
- 说明：提取小图标并保存 PNG。
- 参数：
  - 文件路径（文本型）：含图标的 EXE、DLL 或 ICO 文件路径。
  - 索引（整数型）：图标序号，从 0 起，必须小于 图标_取数量 返回的数量。
  - 目标路径（文本型）：保存图标的目标 PNG 路径。
