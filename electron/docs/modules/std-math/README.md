# 数学与随机模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.math` |
| 版本 | 1.2.0 |

提供常用数学函数、三角对数、取整舍入、范围限制、线程安全随机整数和 64 位位运算（与/或/异或/取反/移位/循环移位/取字节/位测试）。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 数学_绝对值

- 签名：`数学_绝对值(数值)`
- 返回值：双精度小数型
- 说明：返回数值的绝对值。
- 参数：
  - 数值（小数型）：参与计算的双精度数值，正负不限。
- 示例：

```
数学_绝对值(-3.14)
```


#### 数学_最小值

- 签名：`数学_最小值(数值一, 数值二)`
- 返回值：双精度小数型
- 说明：返回两个数值中的较小值。
- 参数：
  - 数值一（小数型）：参与比较的第一个双精度数值。
  - 数值二（小数型）：参与比较的第二个双精度数值。

#### 数学_最大值

- 签名：`数学_最大值(数值一, 数值二)`
- 返回值：双精度小数型
- 说明：返回两个数值中的较大值。
- 参数：
  - 数值一（小数型）：参与比较的第一个双精度数值。
  - 数值二（小数型）：参与比较的第二个双精度数值。

#### 数学_限制范围

- 签名：`数学_限制范围(数值, 最小值, 最大值)`
- 返回值：双精度小数型
- 说明：将数值限制在指定闭区间内。
- 参数：
  - 数值（小数型）：要限制到区间内的双精度数值。
  - 最小值（小数型）：闭区间下界；大于上界时运行时自动交换两个界限。
  - 最大值（小数型）：闭区间上界；小于下界时与下界自动交换。

#### 数学_平方根

- 签名：`数学_平方根(数值)`
- 返回值：双精度小数型
- 说明：返回非负数值的平方根，负数返回 0。
- 参数：
  - 数值（小数型）：被开方数；为负时返回 0 而不是报错。

#### 数学_乘方

- 签名：`数学_乘方(底数, 指数)`
- 返回值：双精度小数型
- 说明：返回底数的指定次方。
- 参数：
  - 底数（小数型）：乘方的底数。
  - 指数（小数型）：乘方的指数，允许小数和负数。

#### 数学_随机整数

- 签名：`数学_随机整数(最小值, 最大值)`
- 返回值：整数型
- 说明：返回指定闭区间内的随机整数，参数顺序可交换。
- 参数：
  - 最小值（整数型）：随机闭区间的下界；大于上界时两者自动交换。
  - 最大值（整数型）：随机闭区间的上界，可以等于下界。
- 示例：

```
数学_随机整数(1, 100)
```


#### 数学_取整

- 签名：`数学_取整(数值)`
- 返回值：整数型
- 说明：返回不大于数值的最大整数（向下取整）：-7.8 得 -8，7.8 得 7。
- 参数：
  - 数值（小数型）：要取整的双精度数值；负数按向下取整（floor），例如 -7.8 返回 -8。
- 示例：

```
数学_取整(-7.8)
```


#### 数学_绝对取整

- 签名：`数学_绝对取整(数值)`
- 返回值：整数型
- 说明：返回数值的整数部分（向零取整）：-7.8 得 -7，7.8 得 7。
- 参数：
  - 数值（小数型）：要取整的双精度数值；负数丢弃小数部分向零靠拢（trunc），例如 -7.8 返回 -7。
- 示例：

```
数学_绝对取整(-7.8)
```


#### 数学_四舍五入

- 签名：`数学_四舍五入(数值, 舍入位置)`
- 返回值：双精度小数型
- 说明：按指定位置四舍五入：位置大于 0 保留小数位，等于 0 舍入到整数，小于 0 舍入到整数侧。
- 参数：
  - 数值（小数型）：要舍入的双精度数值；采用四舍五入（远离零）规则，例如 1056.65 舍入到整数得 1057。
  - 舍入位置（整数型）：舍入的位置：大于 0 表示小数点右边保留的位数，等于 0 舍入到整数，小于 0 表示小数点左边舍入到的位置（-1 表示舍入到十位）；省略时为 0。
- 示例：

```
数学_四舍五入(1056.65, 0)
```


#### 数学_取符号

- 签名：`数学_取符号(数值)`
- 返回值：整数型
- 说明：返回数值的符号：正数得 1，零得 0，负数得 -1。
- 参数：
  - 数值（小数型）：要判断符号的双精度数值；无法与零比较的非数值按 0 处理。
- 示例：

```
数学_取符号(-3.2)
```


#### 数学_正弦

- 签名：`数学_正弦(角度)`
- 返回值：双精度小数型
- 说明：返回指定弧度的正弦值。
- 参数：
  - 角度（小数型）：以弧度为单位的角；角度转弧度可乘以 3.14159… 再除以 180。
- 示例：

```
数学_正弦(0)
```


#### 数学_余弦

- 签名：`数学_余弦(角度)`
- 返回值：双精度小数型
- 说明：返回指定弧度的余弦值。
- 参数：
  - 角度（小数型）：以弧度为单位的角。
- 示例：

```
数学_余弦(0)
```


#### 数学_正切

- 签名：`数学_正切(角度)`
- 返回值：双精度小数型
- 说明：返回指定弧度的正切值。
- 参数：
  - 角度（小数型）：以弧度为单位的角；接近 ±π/2 的奇数倍时结果会非常大。
- 示例：

```
数学_正切(0)
```


#### 数学_反正切

- 签名：`数学_反正切(数值)`
- 返回值：双精度小数型
- 说明：返回数值的反正切值（弧度），结果在 -π/2 到 π/2 之间。
- 参数：
  - 数值（小数型）：正切值；返回其对应的角度（弧度），例如 1 返回约 0.785398。
- 示例：

```
数学_反正切(1)
```


#### 数学_自然对数

- 签名：`数学_自然对数(数值)`
- 返回值：双精度小数型
- 说明：返回数值的自然对数（以 e 为底）。
- 参数：
  - 数值（小数型）：必须大于 0；0 或负数返回 0。例如 2.718281828… 返回约 1。
- 示例：

```
数学_自然对数(1)
```


#### 数学_反对数

- 签名：`数学_反对数(数值)`
- 返回值：双精度小数型
- 说明：返回 e 的指定次方（e≈2.718281828）。
- 参数：
  - 数值（小数型）：指数；结果溢出时返回 0。例如 1 返回约 2.718282。
- 示例：

```
数学_反对数(1)
```


#### 数学_置随机种子

- 签名：`数学_置随机种子(种子)`
- 返回值：空
- 说明：为随机数生成器设置种子；相同种子将得到相同的随机数序列。
- 参数：
  - 种子（整数型）：种子数值；-1 表示使用系统时钟作为种子（省略时的默认行为），其它数值原样作为种子。影响 数学_随机整数 的后续序列。
- 示例：

```
数学_置随机种子(1)
```


#### 位_与

- 签名：`位_与(甲, 乙)`
- 返回值：长整数型
- 说明：按 64 位位模式返回「甲 AND 乙」；操作数按补码解释，结果位模式原样作为长整数型返回。
- 参数：
  - 甲（长整数型）：第一个操作数，按 64 位补码位模式参与运算。
  - 乙（长整数型）：第二个操作数，按 64 位补码位模式参与运算。

#### 位_或

- 签名：`位_或(甲, 乙)`
- 返回值：长整数型
- 说明：按 64 位位模式返回「甲 OR 乙」；操作数按补码解释，结果位模式原样作为长整数型返回。
- 参数：
  - 甲（长整数型）：第一个操作数，按 64 位补码位模式参与运算。
  - 乙（长整数型）：第二个操作数，按 64 位补码位模式参与运算。

#### 位_异或

- 签名：`位_异或(甲, 乙)`
- 返回值：长整数型
- 说明：按 64 位位模式返回「甲 XOR 乙」；操作数按补码解释，结果位模式原样作为长整数型返回。protobuf zigzag 编码可写成 位_异或(位_左移(n, 1), 位_算术右移(n, 63))。
- 参数：
  - 甲（长整数型）：第一个操作数，按 64 位补码位模式参与运算。
  - 乙（长整数型）：第二个操作数，按 64 位补码位模式参与运算。
- 示例：

```
位_异或(240, 15)
```


#### 位_取反

- 签名：`位_取反(甲)`
- 返回值：长整数型
- 说明：按 64 位位模式返回逐位取反（NOT）的结果；结果位模式原样作为长整数型返回。
- 参数：
  - 甲（长整数型）：要取反的 64 位操作数，按补码位模式处理。

#### 位_左移

- 签名：`位_左移(甲, 位数)`
- 返回值：长整数型
- 说明：按 64 位位模式左移，右侧补 0；位数对 64 取模（与 x86 机器语义一致），结果位模式原样作为长整数型返回。
- 参数：
  - 甲（长整数型）：要移位的 64 位数值。
  - 位数（整数型）：左移位数；按补码对 64 取模（0 到 63 生效）。

#### 位_右移

- 签名：`位_右移(甲, 位数)`
- 返回值：长整数型
- 说明：逻辑右移：按 64 位位模式右移，左侧恒补 0（把操作数当无符号数处理）；位数对 64 取模。例如 位_右移(-1, 1) 得 9223372036854775807。
- 参数：
  - 甲（长整数型）：要移位的 64 位数值。
  - 位数（整数型）：右移位数；按补码对 64 取模（0 到 63 生效）。

#### 位_算术右移

- 签名：`位_算术右移(甲, 位数)`
- 返回值：长整数型
- 说明：算术右移：按有符号语义右移，左侧补符号位；位数对 64 取模。例如 位_算术右移(-1, 1) 仍得 -1。protobuf zigzag 解码用 位_异或(位_右移(z, 1), 取负(位_与(z, 1)))。
- 参数：
  - 甲（长整数型）：要移位的 64 位数值，按有符号数处理。
  - 位数（整数型）：右移位数；按补码对 64 取模（0 到 63 生效）。

#### 位_循环左移32

- 签名：`位_循环左移32(甲, 位数)`
- 返回值：整数型
- 说明：取操作数低 32 位做循环左移（SM3/MD5 等轮函数用），返回 32 位结果；位数对 32 取模。64 位循环请用 lingbuilder.advanced.assembly 的 位运算_循环左移。
- 参数：
  - 甲（长整数型）：要循环移位的 64 位数值；只使用低 32 位，高位忽略。
  - 位数（整数型）：循环左移位数；按补码对 32 取模（0 到 31 生效）。
- 示例：

```
位_循环左移32(1, 1)
```


#### 位_取字节

- 签名：`位_取字节(数值, 序号)`
- 返回值：整数型
- 说明：取出 64 位位模式中第 序号 个字节（0=最低位字节，7=最高位字节）；序号对 8 取模，返回 0 到 255。
- 参数：
  - 数值（长整数型）：源 64 位数值，按位模式处理。
  - 序号（整数型）：字节序号 0 到 7（0 为最低位字节）；对 8 取模。
- 示例：

```
位_取字节(-1, 7)
```


#### 位_测试

- 签名：`位_测试(数值, 位序)`
- 返回值：逻辑型
- 说明：测试 64 位位模式中第 位序 位是否为 1（0=最低位）；位序对 64 取模。
- 参数：
  - 数值（长整数型）：源 64 位数值，按位模式处理。
  - 位序（整数型）：位序号 0 到 63（0 为最低位）；对 64 取模。
- 示例：

```
位_测试(5, 2)
```
