# 哈希表与栈模块

模块 ID：`lingbuilder.std.map`  
版本：`1.0.0`  
适用平台：Windows / MSVC Win32、x64；普通 Win32 与 new_emoji 后端共用同一确定性 C++17 运行时。

哈希表与栈模块提供两个句柄制容器：**哈希表**（文本键到值的映射，键查找为常数级）与**栈**（后进先出）。两者都支持 文本 / 整数（64 位）/ 逻辑 / 字节集 四种值类型，值按类型标签存储，写什么类型就用对应的取命令读回。

句柄规则与缓冲区模块一致：`哈希表_创建` / `栈_创建` 返回 64 位句柄（0 表示失败），`销毁` 回收句柄，销毁后句柄不可再用。容器内部自带互斥锁，多线程环境下单个容器操作是线程安全的（与多线程模块的协作式线程配合使用）。

## 命令一览

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `哈希表_创建(初始容量)` | 哈希表 | 创建空哈希表，0 表示失败 |
| `哈希表_销毁(哈希表)` | 逻辑型 | 回收句柄 |
| `哈希表_取数量(哈希表)` | 整数型 | 键值对数量，句柄无效返回 -1 |
| `哈希表_是否包含(哈希表, 键)` | 逻辑型 | 键是否存在 |
| `哈希表_删除(哈希表, 键)` | 逻辑型 | 删除键值对 |
| `哈希表_清空(哈希表)` | 逻辑型 | 清空全部键值对 |
| `哈希表_置文本/取文本` | 逻辑型 / 文本型 | 写入 / 读取文本值 |
| `哈希表_置整数/取整数` | 逻辑型 / 长整数型 | 写入 / 读取 64 位整数 |
| `哈希表_置逻辑/取逻辑` | 逻辑型 / 逻辑型 | 写入 / 读取逻辑值 |
| `哈希表_置字节集/取字节集` | 逻辑型 / 字节集 | 写入 / 读取字节集 |
| `哈希表_取全部键(哈希表, 结果数组)` | 整数型 | 全部键写入文本数组，返回数量 |
| `哈希表_上次操作是否成功()` | 逻辑型 | 本线程上一次取命令是否取到有效值 |
| `栈_创建(初始容量)` | 栈 | 创建空栈 |
| `栈_销毁(栈)` | 逻辑型 | 回收句柄 |
| `栈_取数量(栈)` | 整数型 | 元素数量 |
| `栈_是否为空(栈)` | 逻辑型 | 是否为空 |
| `栈_清空(栈)` | 逻辑型 | 清空全部元素 |
| `栈_压入/弹出` | 逻辑型 / 文本型 | 压入 / 弹出文本 |
| `栈_压入整数/弹出整数` | 逻辑型 / 长整数型 | 压入 / 弹出整数 |
| `栈_压入字节集/弹出字节集` | 逻辑型 / 字节集 | 压入 / 弹出字节集 |
| `栈_上次弹出是否成功()` | 逻辑型 | 上一次弹出是否真的弹出元素 |

取值类命令在键不存在或类型不符时返回该类型默认值（空文本 / 0 / 假 / 空字节集），并用 `哈希表_上次操作是否成功`（栈为 `栈_上次弹出是否成功`）报告真实结果——两种失败可区分。

## 基本用法

```lcpp
局部 哈希表 成绩表
成绩表 = 哈希表_创建(16)
哈希表_置文本(成绩表, "张三", "96")
哈希表_置整数(成绩表, "学分", 128)

调试输出(哈希表_取文本(成绩表, "张三"))
调试输出(哈希表_取整数(成绩表, "学分"))
调试输出(哈希表_上次操作是否成功())

局部 文本型 键列表[]
哈希表_取全部键(成绩表, 键列表)
调试输出(数组_取成员数(键列表))
哈希表_销毁(成绩表)
```

```lcpp
局部 栈 撤销栈
撤销栈 = 栈_创建(16)
栈_压入(撤销栈, "第一步")
栈_压入(撤销栈, "第二步")
调试输出(栈_弹出(撤销栈))
调试输出(栈_弹出(撤销栈))
调试输出(栈_上次弹出是否成功())
栈_销毁(撤销栈)
```

## 注意事项

- 同一个键重复写入会覆盖旧值；取值类型必须与写入类型一致，跨类型读取按默认值处理并报告失败。
- 键区分大小写；键顺序在 `哈希表_取全部键` 中不保证与插入顺序一致。
- 句柄族命令请在事件/处理器之间传递句柄值本身，跨线程使用没有问题（内部互斥），但请保证先创建后使用、用完销毁。
