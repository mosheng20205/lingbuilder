# 磁盘信息模块使用说明

| 项目 | 内容 |
| --- | --- |

完整读取逻辑驱动器、卷、容量、文件系统、物理磁盘、SSD/TRIM、扇区和分区信息。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 容量

#### 磁盘_总容量MB

- 签名：`磁盘_总容量MB(路径)`
- 返回值：长整数型
- 说明：返回路径所在卷的总容量 MB，失败返回 -1；兼容旧源码。
- 参数：
  - 路径（文本型）：用于定位所属卷的路径，可以是文件、目录或盘符根，空文本按当前目录处理；解析失败时命令按说明返回失败值。

```
磁盘_总容量MB("C:\")
```

### 物理磁盘

#### 磁盘_枚举物理磁盘

- 签名：`磁盘_枚举物理磁盘()`
- 返回值：物理磁盘信息列表
- 说明：枚举 Windows PhysicalDrive 设备并返回只读存储描述、容量、扇区、分区、SSD 和 TRIM 信息。

#### 磁盘_取物理磁盘信息

- 签名：`磁盘_取物理磁盘信息(磁盘编号)`
- 返回值：物理磁盘信息
- 说明：按 PhysicalDrive 编号查询物理磁盘；不请求写权限。
- 参数：
  - 磁盘编号（整数型）：PhysicalDrive 编号，从 0 开始，与 磁盘_枚举物理磁盘 返回的磁盘编号一致；查询只申请只读权限。

### 分区

#### 磁盘_取分区列表

- 签名：`磁盘_取分区列表(磁盘编号)`
- 返回值：磁盘分区信息列表
- 说明：读取物理磁盘的 MBR/GPT/RAW 分区布局，失败返回空数组并记录错误。
- 参数：
  - 磁盘编号（整数型）：PhysicalDrive 编号，从 0 开始，与 磁盘_枚举物理磁盘 返回的磁盘编号一致；查询只申请只读权限。

### 诊断

#### 磁盘_取最近错误码

- 签名：`磁盘_取最近错误码()`
- 返回值：整数型
- 说明：返回当前线程最近一次磁盘模块失败的 Win32 错误代码；成功调用会清零。

#### 磁盘_取最近错误

- 签名：`磁盘_取最近错误()`
- 返回值：文本型
- 说明：返回当前线程最近一次磁盘模块失败的中文上下文和系统错误文本。
