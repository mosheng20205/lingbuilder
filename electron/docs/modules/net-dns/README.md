## 命令参考（共 9 条）

### 全部命令

#### DNS_解析首个地址

- 签名：`DNS_解析首个地址(主机名)`
- 返回值：文本型
- 说明：解析并返回首个 IPv4 或 IPv6 地址。
- 参数：
  - 主机名（文本型）：要解析的域名或 IP 文本；解析失败返回空文本。
- 示例：

```
DNS_解析首个地址("example.com")
```


#### DNS_反向查询

- 签名：`DNS_反向查询(IP地址)`
- 返回值：文本型
- 说明：对 IP 地址执行反向名称查询。
- 参数：
  - IP地址（文本型）：点分 IPv4 或标准 IPv6 文本；传入域名等非法地址直接返回空文本，没有 PTR 记录同样返回空文本。

#### 网络_取本机名

- 签名：`网络_取本机名()`
- 返回值：文本型
- 说明：返回 Winsock 本机主机名。

#### 网络_是否IPv4

- 签名：`网络_是否IPv4(地址)`
- 返回值：逻辑型
- 说明：检查是否为合法 IPv4 文本。
- 参数：
  - 地址（文本型）：待检查的地址文本，必须是点分十进制 IPv4，不接受前导零之外的空格或端口写法。

#### 网络_是否IPv6

- 签名：`网络_是否IPv6(地址)`
- 返回值：逻辑型
- 说明：检查是否为合法 IPv6 文本。
- 参数：
  - 地址（文本型）：待检查的地址文本，必须是冒号分隔的 IPv6，允许双冒号缩写形式。

#### 网络_取MAC地址

- 签名：`网络_取MAC地址()`
- 返回值：文本型
- 说明：返回首个非环回网卡的物理地址，格式如 00-1A-2B-3C-4D-5E；读取失败返回空文本。
- 示例：

```
网络_取MAC地址()
```


#### 网络_取网卡名称列表

- 签名：`网络_取网卡名称列表(结果数组)`
- 返回值：整数型
- 说明：把本机全部网卡的名称写入文本数组，返回网卡数量。
- 参数：
  - 结果数组（数组）：接收网卡友好名称的文本型数组变量，调用前会先清空原有内容。

#### 网络_取IP地址列表

- 签名：`网络_取IP地址列表(结果数组)`
- 返回值：整数型
- 说明：把本机全部网卡的 IPv4 与 IPv6 地址写入文本数组，返回地址数量。
- 参数：
  - 结果数组（数组）：接收 IP 地址的文本型数组变量，调用前会先清空原有内容。

#### 网络_取DNS后缀

- 签名：`网络_取DNS后缀()`
- 返回值：文本型
- 说明：返回首个配置了主 DNS 后缀的网卡后缀文本；没有配置返回空文本。
