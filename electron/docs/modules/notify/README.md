# 消息推送模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.notify` |
| 版本 | 1.0.0 |
| 分类 | 网络 |
| 命令数 | 17 |

把文本、Markdown、图文、文件等消息主动 POST 到国内主流群机器人 webhook：企业微信群机器人、钉钉自定义机器人、飞书自定义机器人，另提供万能 推送_发JSON 兜底 Server酱/Bark/Qmsg/自建服务。内容转义、@ 人、钉钉/飞书 HMAC-SHA256 加签、企微图片 Base64/MD5 与文件 multipart 上传全部由运行时代劳，失败返回假并经 推送_取错误() 给出中文原因。只做出站推送，不做消息接收。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 推送_发JSON

- 签名：`推送_发JSON(地址, JSON文本, 超时毫秒)`
- 返回值：逻辑型
- 说明：把一段现成 JSON 以 POST（Content-Type: application/json）发给任意 webhook 地址。三平台结构化命令（发企业微信文本/发钉钉文本等）能满足的场景优先用它们——内容转义、@ 人和加签都由运行时代劳；本命令是万能兜底：企微模板卡片、飞书交互卡片、Server酱/Bark/Qmsg 等第三方服务都走这里。成功指 HTTP 200，业务层是否送达请读 推送_取响应文本() 核对。
- 参数：
  - 地址（文本型）：任意 HTTP/HTTPS webhook 地址：Server酱、Bark、Qmsg酱、自建服务等。
  - JSON文本（文本型）：完整请求体 JSON。⚠️ 本命令不转义：JSON 里的引号/换行必须自己按 JSON 规则写，内容里的中文按 UTF-8 提交。
  - 超时毫秒（整数型）：请求超时毫秒数，省略时使用 #推送_默认超时毫秒（10000）。
- 示例：

```
推送_发JSON("https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx", "{\"msgtype\":\"text\",\"text\":{\"content\":\"构建完成\"}}")
```


#### 推送_取错误

- 签名：`推送_取错误()`
- 返回值：文本型
- 说明：返回最近一次推送命令失败或被平台拒绝时的中文原因（参数校验、网络错误、HTTP 非 200、平台 errcode 非 0、加签失败等）；最近一次成功时为空文本。所有推送命令失败都返回假、不抛异常，错误一律到这里读。
- 示例：

```
如果(推送_发钉钉文本(地址, "构建失败", "", 假, 密钥) = 假)
    调试输出(推送_取错误())
```

- 签名：`推送_取响应文本()`
- 返回值：文本型

- 示例：

```

```


#### 推送_发企业微信文本

- 签名：`推送_发企业微信文本(地址, 内容, 手机号列表, 是否所有人)`
- 返回值：逻辑型
- 说明：发企业微信群机器人文本消息，可按手机号 @ 人或 @ 所有人。红线：文本上限 2048 字节（UTF-8）；@ 只支持手机号（mentioned_mobile_list）；带引号/换行的内容由运行时自动转义，直接给原文即可。
- 参数：
  - 地址（文本型）：机器人 webhook 完整地址（https:// 开头），由各平台群设置里「添加机器人」获得。
  - 内容（文本型）：消息正文（原文即可，不必转义）；上限 2048 字节（UTF-8 字节不是字数，约 680 个汉字），超长直接失败并给中文原因。
  - 手机号列表（文本型）：要 @ 的手机号列表，多行或逗号分隔均可，如 "13800000001,13800000002"；空文本表示不 @ 指定人。
  - 是否所有人（逻辑型）：真时 @ 群内所有人（同时占用一条限流额度），假时不 @ 所有人。
- 示例：

```
推送_发企业微信文本(地址, "构建完成：" + 工程名, "", 假)
```

- 示例：

#### 推送_上传企业微信文件

- 签名：`推送_上传企业微信文件(地址, 文件路径)`
- 返回值：文本型
- 说明：上传本地文件到企业微信临时素材，返回 media_id（供 推送_发企业微信文件 发送）；multipart/form-data 组包由运行时完成。失败返回空文本，原因读 推送_取错误()。media_id 三天有效，过期需重新上传。
- 参数：
  - 地址（文本型）：企业微信群机器人 webhook 地址（从中提取 key 参数调官方 upload_media 接口）。
  - 文件路径（文本型）：本地文件完整路径；不超过 20MB。media_id 有效期 3 天。
- 示例：

```
局部 文本型 编号\n编号 = 推送_上传企业微信文件(地址, "D:\\报告\\月报.pdf")\n推送_发企业微信文件(地址, 编号)
```

#### 推送_发钉钉文本

#### 推送_发飞书文本

- 签名：`推送_发飞书文本(地址, 内容, 用户ID列表, 是否所有人, 加签密钥)`
- 返回值：逻辑型
- 说明：发飞书自定义机器人文本消息。@ 人语义与另两家都不同：飞书按 open_id 内联标签（<at user_id="...">），不是手机号——运行时把列表包成标签追加到正文末尾，@ 所有人追加 <at user_id="all">所有人</at>。签名校验的密钥（开启时）由运行时计算并写进请求体 timestamp/sign 字段。
- 参数：
  - 地址（文本型）：机器人 webhook 完整地址（https:// 开头），由各平台群设置里「添加机器人」获得。
  - 内容（文本型）：消息正文（原文即可）。要 @ 人也可以直接在正文里写内联标签 <at user_id="open_id"></at>。
  - 用户ID列表（文本型）：要 @ 的用户 open_id 列表，多行或逗号分隔均可；空文本表示不 @ 指定人。
  - 是否所有人（逻辑型）：真时 @ 群内所有人（同时占用一条限流额度），假时不 @ 所有人。
  - 加签密钥（文本型）：飞书机器人「签名校验」的密钥；空文本表示机器人未开启签名校验。签名由运行时按 HMAC-SHA256 自动计算并写进请求体。
- 示例：

```
推送_发飞书文本(地址, "部署完成", "", 假, "")
```


#### 推送_发飞书富文本

- 签名：`推送_发飞书富文本(地址, 多行文本)`
- 返回值：逻辑型
- 说明：发飞书自定义机器人富文本（post）消息，本命令封装「每行一个文本段落」的最常用形态：一行变一个 text 元素，段落转义由运行时完成。链接、图片、@ 提醒等嵌套元素走 推送_发JSON。
- 参数：
  - 地址（文本型）：机器人 webhook 完整地址（https:// 开头），由各平台群设置里「添加机器人」获得。
  - 多行文本（文本型）：每行一个段落的纯文本（原文即可）；空行自动忽略。需要超链接/图片/@ 元素的复杂富文本改用 推送_发JSON 直发 post 结构。
- 示例：

```
推送_发飞书富文本(地址, "构建完成\n工程：" + 工程名)
```
