# 进程通信模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.ipc` |
| 版本 | 1.0.0 |
| 分类 | 系统 |

提供单连接命名管道 UTF-8 文本通信和命名互斥体单实例判断。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 8 条）

### 全部命令

#### IPC_创建管道服务端

- 签名：`IPC_创建管道服务端(名称)`
- 返回值：逻辑型
- 说明：创建本机命名管道服务端。
- 参数：
  - 名称（文本型）：自定义管道或互斥体名称，不要包含反斜杠；运行时会自动加上 LingBuilder 前缀。重复创建会先关闭上一个管道实例。

#### IPC_等待管道客户端

- 签名：`IPC_等待管道客户端()`
- 返回值：逻辑型
- 说明：等待一个管道客户端连接。

#### IPC_连接管道

- 签名：`IPC_连接管道(名称, 超时毫秒)`
- 返回值：逻辑型
- 说明：连接本机命名管道。
- 参数：
  - 名称（文本型）：自定义管道或互斥体名称，不要包含反斜杠；运行时会自动加上 LingBuilder 前缀。
  - 超时毫秒（整数型）：等待管道出现的超时毫秒数；小于 0 时按 0 处理，即不等待直接尝试。

#### IPC_发送文本

- 签名：`IPC_发送文本(文本)`
- 返回值：逻辑型
- 说明：发送一条长度前缀 UTF-8 文本。
- 参数：
  - 文本（文本型）：要发送的文本，按 UTF-8 编码并附带 4 字节长度前缀；未建立连接时返回假。

#### IPC_接收文本

- 签名：`IPC_接收文本()`
- 返回值：文本型
- 说明：接收一条长度前缀 UTF-8 文本。

#### IPC_创建单实例锁

- 签名：`IPC_创建单实例锁(名称)`
- 返回值：逻辑型
- 说明：创建命名互斥体；首次创建返回真。
- 参数：
  - 名称（文本型）：自定义管道或互斥体名称，不要包含反斜杠；运行时会自动加上 LingBuilder 前缀。同名互斥体已被其它实例占用时返回假。

#### IPC_取错误

- 签名：`IPC_取错误()`
- 返回值：文本型
- 说明：返回最近 IPC 错误。

#### IPC_关闭

- 签名：`IPC_关闭()`
- 返回值：空
- 说明：关闭管道和单实例锁。
