## 命令参考（共 5 条）

### 全部命令

#### CPU_取厂商

- 签名：`CPU_取厂商()`
- 返回值：文本型
- 说明：返回 CPUID 厂商标识。

#### CPU_是否支持SSE2

- 签名：`CPU_是否支持SSE2()`
- 返回值：逻辑型
- 说明：检查 SSE2。

#### CPU_是否支持AVX

- 签名：`CPU_是否支持AVX()`
- 返回值：逻辑型
- 说明：检查 CPU 和操作系统是否启用 AVX。

#### 位运算_统计一位数量

- 签名：`位运算_统计一位数量(数值)`
- 返回值：整数型
- 说明：统计 64 位数值中的 1 位数量。
- 参数：
  - 数值（长整数型）：要统计的 64 位数值；负数按补码的置位数量统计。

#### 位运算_循环左移

- 签名：`位运算_循环左移(数值, 位数)`
- 返回值：长整数型
- 说明：执行 64 位循环左移。
- 参数：
  - 数值（长整数型）：要移位的 64 位数值。
  - 位数（整数型）：循环左移的位数；实际位移取该值与 63 按位与的结果，负数同样按补码取模。
