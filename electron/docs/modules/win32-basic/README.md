# Win32 基础控件运行时创建

模块 ID：`lingbuilder.win32.basic`

本模块的 12 个当前公开可视控件都可在 `.lcpp` 中创建：按钮、编辑框、标签、复选框、单选框、列表框、组合框、分组框、滚动条、图片框、动态图像控件、进度条。旧项目兼容 Grid 不在运行时创建目录中。

设计器外观属性在运行时如实渲染：列表框表项文字对齐支持左对齐（默认）、居中、右对齐，F5、原生预览与导出工程行为一致。

## 创建与查找

每种控件提供具体类型、创建命令和两种查找命令。例如：

```lcpp
局部 按钮 动态按钮 = 控件_创建按钮(当前窗口, 20, 20, 120, 36, "确定", "确认", 1002)
局部 按钮 文本查找 = 通过标记文本获取按钮("确认")
局部 编辑框 整数查找 = 通过标记整数获取编辑框(1001)
```

创建签名统一为“父级、横坐标、纵坐标、宽度、高度、文本、可选标记文本、可选标记整数”。两个标记均可省略；只传整数时在文本标记位置传 `""`。父级可使用只读 `当前窗口` 或兼容容器引用。代码创建控件只存在于本次窗口运行时，不写回设计器。

文本标记去除首尾空白后为空即未设置，匹配区分大小写。整数标记为有符号 32 位整数，`0` 和负数有效。非空标记在“当前窗口 + 具体控件类型 + 标记类别”范围内唯一；重复创建会返回无效引用并输出中文运行日志。

## 引用、操作与事件

窗口拥有控件和主 `HWND` 生命周期，每个控件实例始终具有独立主 `HWND`。窗口销毁后引用自动失效。操作查找结果前可调用：

```lcpp
如果 (控件_是否有效(动态按钮))
    控件_设置启用(动态按钮, 真)
    动态按钮.内容 = "继续"
    按钮_绑定被单击(动态按钮, &动态按钮被单击)
如果结束
```

通用命令、控件专属命令和成员语法同时接受设计器裸控件名、控件变量、创建结果和查找结果。每个已声明事件都有按具体控件类型生成的绑定/解绑命令，处理器必须使用 `&处理器名`。无效引用上的操作安全失败，不访问悬空句柄。

控件引用可用作局部变量、方法参数和返回值；禁止控件常量、数组、程序集成员、项目全局变量及工作线程传递。非可视组件不使用本契约。

## 运行期专属属性与项目操作

设计器「专属属性」里有一部分支持运行期改写，全部走 `控件_` 通用族（首参为裸控件名），不支持类型返回假并输出中文日志：

| 命令 | 适用控件 | 说明 |
| --- | --- | --- |
| `控件_设置只读(控件名, 是否只读)` | 编辑框（富文本框同函数） | 只读时用户不能输入，程序仍可用 控件_设置文本 写入；传假解除。 |
| `控件_设置密码输入(控件名, 是否密码)` | 编辑框 | 真=以 `*` 掩码回显，假=明文。 |
| `控件_设置提示文字(控件名, 占位文本)` | 编辑框 | 内容为空时显示灰字；传空文本清除。 |
| `编辑框_滚动(控件名, 行数)` | 多行编辑框 | 按行滚动：正数向下、负数向上；单行编辑框返回假。 |
| `编辑框_滚动到底(控件名)` | 多行编辑框 | 滚动到内容末尾（无需焦点），日志追加后定位最新一行。 |
| `控件_设置数值范围(控件名, 最小值, 最大值)` | 进度条、滚动条、滑块、数值调节器 | 当前值自动钳制；`控件_设置数值` 之后也按新范围钳制。 |
| `控件_设置不确定进度(控件名, 是否)` | 进度条 | 跑马灯往复动画；传假恢复确定进度。 |
| `控件_设置表项高度(控件名, 表项高度)` | 列表框、组合框 | 设计器逻辑坐标，自动按窗口 DPI 缩放。 |

```lcpp
控件_设置只读(结果框, 真)
控件_设置密码输入(密码框, 真)
控件_设置提示文字(搜索框, "输入关键字...")
控件_设置数值范围(进度条1, 0, 1000)
控件_设置不确定进度(进度条1, 真)
```

列表框与组合框的项目操作补齐了插、删、改、读：

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `控件_插入项目(控件名, 索引, 文本)` | 整数型 | 零基索引插入；-1 追加到末尾，返回实际插入索引。 |
| `控件_删除项目(控件名, 索引)` | 逻辑型 | 删除零基索引项目，越界返回假。 |
| `控件_修改项目(控件名, 索引, 文本)` | 逻辑型 | 整行替换指定项目文本，选中项按位移保持。 |
| `控件_取项目文本(控件名, 索引)` | 文本型 | 读取零基索引项目文本，越界返回空文本。 |
| `控件_取项目数量(控件名)` | 整数型 | 当前项目数量。 |
| `列表框_滚动到项(控件名, 索引)` | 逻辑型 | 把该行滚成顶部可见项（LB_SETTOPINDEX），越界返回假。 |

列表框是单列控件，没有行×列单元格；要修改某行某列的单元格请用「列表视图」的 `列表视图_设置单元格` 或「数据表格」的 `表格_置文本`。

### 自绘层运行期属性（第二批）

颜色参数统一 `#RRGGBB` 文本（可省略 `#`），传空文本表示保持该色不变：

| 命令 | 适用控件 | 说明 |
| --- | --- | --- |
| `控件_设置选中颜色(控件名, 起始颜色, 结束颜色, 边框颜色)` | 列表框、组合框 | 选中项渐变三色。 |
| `控件_设置选中标记颜色(控件名, 选中颜色, 标记颜色)` | 复选框、单选框 | 选中底色与对勾/圆点颜色。 |
| `控件_设置边框(控件名, 是否显示, 粗细, 颜色)` | 列表框、分组框、组合框 | 传假隐藏边框。 |
| `控件_设置标题对齐(控件名, 对齐方式)` | 分组框 | 0 居左、1 居中、2 居右。 |
| `控件_设置文本对齐(控件名, 对齐方式)` | 列表框、组合框 | 0 居左、1 居中、2 居右；编辑框/标签的对齐是创建期窗口样式，运行期改写不支持（返回假）。 |
| `控件_设置填充方式(控件名, 方式)` | 图片框、动态图像控件 | 0 原始大小、1 拉伸填满、2 等比适应、3 等比填满；图片框当前图片立即按新方式重载。 |

### 动态图像（GIF）播放控制

| 命令 | 说明 |
| --- | --- |
| `控件_播放(控件名)` | 从当前帧开始/继续播放；已在播放时返回真。 |
| `控件_暂停(控件名)` | 暂停并保留当前帧；未在播放时返回真。 |
| `控件_设置循环播放(控件名, 是否循环)` | 不循环时播完停在末帧并触发「播放完毕」事件。 |

注意：编辑框的「多行」「仅数字」与按钮样式、标签静态样式、滚动条方向、允许多选、自动排序、组合框允许编辑、编辑框/标签文本对齐等属于创建期样式，运行期不能改，请在设计器属性面板设置。以上命令当前仅普通 Win32 后端提供运行时实现；new_emoji 后端项目调用会在生成 C++ 前给出中文阻断诊断。

## 当前窗口自身

窗口代码经常需要操作「自己这个窗口」（改标题、移动、置顶、拖拽）。本模块提供三条免句柄命令，直接作用于当前窗口，无需先知道它是谁：

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `窗口_取自身句柄()` | 长整数型 | 当前窗口的 HWND；窗口尚未创建时返回 0。 |
| `窗口_取自身标题()` | 文本型 | 当前窗口标题栏文本；窗口尚未创建时返回空文本。 |
| `窗口_设置自身标题(标题)` | 逻辑型 | 直接改写当前窗口标题栏文本，传空文本清空。 |

```lcpp
类 MainWindow
    事件 _按钮1_被单击()
        问候按钮点击次数 = 问候按钮点击次数 + 1
        窗口_设置自身标题(格式化文本("已点击 {} 次", 问候按钮点击次数))
    结束
结束类
```

`窗口_取自身句柄()` 是纯 Win32 窗口项目取得自身 HWND 的唯一入口：`lingbuilder.win32.window-utils` 的 `窗口_设置标题`、`窗口_移动`、`窗口_置前台`、`窗口_开始拖拽` 等命令首参都是 HWND，句柄只能由它提供。句柄只在窗口存活期间有效，窗口销毁后失效；跨处理器长期保存句柄不推荐，改用 `窗口_取自身句柄()` 现取现用。禁止用 `窗口_按标题查找("设计器里的标题文本")` 反查自身句柄——一旦画布上改了标题，功能会静默失效。

## 文本到数值的类型转换

初级命令族统一接收单个 `文本` 参数，反向转换由 `到文本` 的多重载承担。转换失败一律降级返回 0/假，不会抛异常：

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `到整数(文本)` | 整数型 | 空文本或无法转换返回 0；超出 32 位范围按最值截断。 |
| `到长整数(文本)` | 长整数型 | 空文本或无法转换返回 0；不做 32 位截断，时间戳、文件大小、地址等大数值用它。 |
| `到小数(文本)` | 小数型 | 忽略首尾空白，空文本或无法转换返回 0。 |
| `到单精度小数(文本)` | 单精度小数型 | 忽略首尾空白，空文本或无法转换返回 0；精度低于 `到小数`。 |
| `到逻辑(文本)` | 逻辑型 | 空文本、“0”、“假” 返回假；非零数值与“真”返回真，其余非空文本（如“是”）也为真。 |

```lcpp
局部 长整数型 文件大小 = 到长整数(编辑框_大小.内容)
局部 小数型 折扣 = 到小数(" 0.85 ")
如果 (到逻辑(编辑框_启用.内容))
    控件_设置文本(状态标签, 格式化文本("{} 字节，折扣 {}", 文件大小, 折扣))
如果结束
```

五条命令都由基础模块 binding 在普通 Win32 与 new_emoji 两个后端确定性生成本地 C++，不是编辑器关键字。参数口径与 `到整数` 完全一致：只接收单个 `文本` 参数，本期不提供数值重载，数值实参必须先显式 `到文本(数值)`（与 `到整数` 一样不会自动补转换）。

平台限制：Windows、MSVC、Win32/x64。F5、原生预览和 Visual Studio 导出使用同一生成与注册逻辑。
