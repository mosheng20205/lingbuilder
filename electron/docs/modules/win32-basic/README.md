# Win32 基础控件运行时创建

模块 ID：`lingbuilder.win32.basic`

本模块的 12 个当前公开可视控件都可在 `.lcpp` 中创建：按钮、编辑框、标签、复选框、单选框、列表框、组合框、分组框、滚动条、图片框、动态图像控件、进度条。旧项目兼容 Grid 不在运行时创建目录中。

## 创建与查找

每种控件提供具体类型、创建命令和两种查找命令。例如：

```lcpp
局部 按钮 动态按钮 = 控件_创建按钮(当前窗口, 20, 20, 120, 36, "确定", "确认", 1002)
局部 按钮 文本查找 = 通过标记文本获取按钮("确认")
局部 编辑框 整数查找 = 通过标记整数获取编辑框(1001)
```

创建签名统一为“父级、横坐标、纵坐标、宽度、高度、文本、可选标记文本、可选标记整数”。两个标记均可省略；只传整数时在文本标记位置传 `""`。父级可使用只读 `当前窗口` 或兼容容器引用。代码创建控件只存在于本次窗口运行时，不写回设计器。

文本标记去除首尾空白后为空即未设置，匹配区分大小写。整数标记为有符号 32 位整数，`0` 和负数有效。非空标记在“当前窗口 + 具体控件类型 + 标记类别”范围内唯一；重复创建会返回无效引用并输出中文运行日志。

## 引用、操作与事件

窗口拥有控件和主 `HWND` 生命周期，每个控件实例始终具有独立主 `HWND`。窗口销毁后引用自动失效。操作查找结果前可调用：

```lcpp
如果 (控件_是否有效(动态按钮))
    控件_设置启用(动态按钮, 真)
    动态按钮.内容 = "继续"
    按钮_绑定被单击(动态按钮, &动态按钮被单击)
如果结束
```

通用命令、控件专属命令和成员语法同时接受设计器裸控件名、控件变量、创建结果和查找结果。每个已声明事件都有按具体控件类型生成的绑定/解绑命令，处理器必须使用 `&处理器名`。无效引用上的操作安全失败，不访问悬空句柄。

控件引用可用作局部变量、方法参数和返回值；禁止控件常量、数组、程序集成员、项目全局变量及工作线程传递。非可视组件不使用本契约。

平台限制：Windows、MSVC、Win32/x64。F5、原生预览和 Visual Studio 导出使用同一生成与注册逻辑。
