# 用户注册表模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.config.registry` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 6 |

只访问当前用户 HKEY_CURRENT_USER 下的注册表键值，避免默认要求管理员权限。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 6 条）

### 全部命令

#### 注册表_读文本

- 签名：`注册表_读文本(子键, 值名, 默认值)`
- 返回值：文本型
- 说明：读取当前用户注册表字符串值。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：子键下的值名称；读文本只接受 REG_SZ 与 REG_EXPAND_SZ，读整数只接受 REG_DWORD。
  - 默认值（文本型）：值不存在、类型不符或内容为空时返回的兜底文本。

#### 注册表_读整数

- 签名：`注册表_读整数(子键, 值名, 默认值)`
- 返回值：整数型
- 说明：读取当前用户注册表 DWORD 值。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：子键下的值名称；读文本只接受 REG_SZ 与 REG_EXPAND_SZ，读整数只接受 REG_DWORD。
  - 默认值（整数型）：值不存在或不是 REG_DWORD 时返回的兜底整数。

#### 注册表_写文本

- 签名：`注册表_写文本(子键, 值名, 值)`
- 返回值：逻辑型
- 说明：写入当前用户注册表字符串值。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：要写入的值名称。
  - 值（文本型）：保存的字符串，以 REG_SZ 类型写入，读取时不做环境变量展开。

#### 注册表_写整数

- 签名：`注册表_写整数(子键, 值名, 值)`
- 返回值：逻辑型
- 说明：写入当前用户注册表 DWORD 值。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：要写入的值名称。
  - 值（整数型）：保存的整数，以 REG_DWORD 类型写入。

#### 注册表_删除值

- 签名：`注册表_删除值(子键, 值名)`
- 返回值：逻辑型
- 说明：删除当前用户注册表值。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：要删除的值名称；子键本身保留。

#### 注册表_值是否存在

- 签名：`注册表_值是否存在(子键, 值名)`
- 返回值：逻辑型
- 说明：判断当前用户注册表值是否存在。
- 参数：
  - 子键（文本型）：HKEY_CURRENT_USER 下的子键路径，不带根键名前缀；写入时子键不存在会自动创建。
  - 值名（文本型）：要检查的值名称，任意数据类型都算存在。
