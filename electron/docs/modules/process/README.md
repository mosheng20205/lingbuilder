# 进程管理模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.process` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 9 |

提供受控的程序启动、等待、进程状态、按名称枚举进程 ID 和显式进程终止能力。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 9 条）

### 全部命令

#### 程序_启动

- 签名：`程序_启动(命令行, 工作目录)`
- 返回值：整数型
- 说明：启动程序并返回进程 ID，失败返回 0。
- 参数：
  - 命令行（文本型）：完整的命令行文本，含可执行文件和参数，不能为空；路径中有空格时必须用双引号包住该段。
  - 工作目录（文本型）：新进程的当前工作目录；空文本表示沿用本进程的工作目录。

#### 程序_启动并等待

- 签名：`程序_启动并等待(命令行, 工作目录, 超时毫秒)`
- 返回值：整数型
- 说明：启动程序并等待，返回退出码；超时或失败返回 -1。
- 参数：
  - 命令行（文本型）：完整的命令行文本，含可执行文件和参数，不能为空；路径中有空格时必须用双引号包住该段。
  - 工作目录（文本型）：新进程的当前工作目录；空文本表示沿用本进程的工作目录。
  - 超时毫秒（整数型）：等待进程退出的最长毫秒数；小于 0 表示一直等待。超时或启动失败返回 -1；在界面事件里等待会卡住界面。

#### 进程_取当前ID

- 签名：`进程_取当前ID()`
- 返回值：整数型
- 说明：返回当前进程 ID。

#### 进程_是否运行

- 签名：`进程_是否运行(进程ID)`
- 返回值：逻辑型
- 说明：判断指定进程是否仍在运行。
- 参数：
  - 进程ID（整数型）：要检查的进程 ID，必须大于 0；进程已退出或无权打开时返回假。

#### 进程_终止

- 签名：`进程_终止(进程ID, 退出码)`
- 返回值：逻辑型
- 说明：显式终止指定进程；不能用于当前进程。
- 参数：
  - 进程ID（整数型）：要终止的进程 ID，必须大于 0 且不能等于当前进程自身。
  - 退出码（整数型）：强制写入被终止进程的退出码。

#### 进程_按名称取ID列表

- 签名：`进程_按名称取ID列表(进程名, 结果数组)`
- 返回值：整数型
- 说明：按 exe 名称枚举匹配进程的 ID 列表，返回命中数量。
- 参数：
  - 进程名（文本型）：要匹配的可执行文件名（如 "explorer.exe"），不区分大小写，按完整文件名匹配而非子串；空文本直接返回 0。
  - 结果数组（数组）：接收十进制进程 ID 文本的数组变量（如 "4321"），调用前会先清空原有内容；同名多实例进程全部返回，可用 到整数 转回整数。
- 示例：

```
局部 文本型 名单[]
进程_按名称取ID列表("explorer.exe", 名单)
```


#### 进程_按名称取ID列表JSON

- 签名：`进程_按名称取ID列表JSON(进程名)`
- 返回值：文本型
- 说明：按 exe 名称枚举进程 ID 并返回 JSON 数组文本（如 ["4321","890"]），可直接落盘或交给 JSON 模块解析。
- 参数：
  - 进程名（文本型）：要匹配的可执行文件名，不区分大小写，允许带或不带 .exe 后缀；空文本返回空数组 JSON "[]"。
- 示例：

```
进程_按名称取ID列表JSON("explorer.exe")
```


#### 程序_执行并取输出

- 签名：`程序_执行并取输出(命令行, 超时毫秒)`
- 返回值：文本型
- 说明：执行命令行并等待结束，把标准输出与错误输出合并读回为文本；命令无法启动返回空文本，用 程序_上次执行退出码 查询退出码。
- 参数：
  - 命令行（文本型）：要执行的完整命令行，例如 cmd /c ping 127.0.0.1；输出与错误回显合并读回，中文按系统 OEM 代码页解码。
  - 超时毫秒（整数型）：最长等待毫秒数，超时强制结束子进程并返回已捕获的输出；小于 0 表示无限等待，省略默认 30000。
- 示例：

```
程序_执行并取输出("cmd /c echo 你好")
```


#### 程序_上次执行退出码

- 签名：`程序_上次执行退出码()`
- 返回值：整数型
- 说明：返回本线程上一次 程序_执行并取输出 的子进程退出码；尚未执行过或命令无法启动返回 -1。
