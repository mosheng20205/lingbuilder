## 命令参考（共 7 条）

### 全部命令

#### FTP_连接

- 签名：`FTP_连接(主机, 端口, 用户名, 密码, 安全连接)`
- 返回值：逻辑型
- 说明：连接 FTP 或 FTPS 服务端。
- 参数：
  - 主机（文本型）：FTP 服务器主机名或 IP。
  - 端口（整数型）：控制端口；小于等于 0 时使用 FTP 默认端口 21。
  - 用户名（文本型）：登录账号；空文本按匿名登录处理。
  - 密码（文本型）：登录密码；空文本表示不提交密码。
  - 安全连接（逻辑型）：传真按 FTPS 建立加密控制连接，传假使用明文 FTP。

#### FTP_上传文件

- 签名：`FTP_上传文件(本地文件, 远程文件)`
- 返回值：逻辑型
- 说明：以二进制模式上传文件。
- 参数：
  - 本地文件（文本型）：要上传的本机文件路径，文件必须已存在。
  - 远程文件（文本型）：服务器上的目标路径，相对当前登录目录，以二进制方式传输。

#### FTP_下载文件

- 签名：`FTP_下载文件(远程文件, 本地文件, 允许覆盖)`
- 返回值：逻辑型
- 说明：以二进制模式下载文件。
- 参数：
  - 远程文件（文本型）：服务器上的源文件路径，相对当前登录目录，以二进制方式传输。
  - 本地文件（文本型）：保存到本机的路径；所在目录必须已存在。
  - 允许覆盖（逻辑型）：传真时本地同名文件会被覆盖，传假时本地文件已存在则下载失败。

#### FTP_删除文件

- 签名：`FTP_删除文件(远程文件)`
- 返回值：逻辑型
- 说明：删除远程文件。
- 参数：
  - 远程文件（文本型）：服务器上要删除的文件路径。

#### FTP_重命名

- 签名：`FTP_重命名(原名称, 新名称)`
- 返回值：逻辑型
- 说明：重命名远程文件。
- 参数：
  - 原名称（文本型）：服务器上的原文件路径。
  - 新名称（文本型）：服务器上的新文件路径，只能在同一台服务器上改名。

#### FTP_取错误

- 签名：`FTP_取错误()`
- 返回值：文本型
- 说明：返回最近 FTP 中文错误。

#### FTP_关闭

- 签名：`FTP_关闭()`
- 返回值：空
- 说明：关闭 FTP 连接和会话。
