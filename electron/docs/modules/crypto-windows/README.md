## 命令参考（共 6 条）

### 全部命令

#### 数据保护_加密文本

- 签名：`数据保护_加密文本(文本)`
- 返回值：文本型
- 说明：使用当前用户 DPAPI 加密 UTF-8 文本并返回 Base64。
- 参数：
  - 文本（文本型）：要保护的文本，按 UTF-8 加密后返回 Base64；密文只能在本机当前 Windows 用户下解开。

#### 数据保护_解密文本

- 签名：`数据保护_解密文本(Base64密文)`
- 返回值：文本型
- 说明：解密当前用户 DPAPI Base64 密文。
- 参数：
  - Base64密文（文本型）：数据保护_加密文本 返回的 Base64 密文，必须是 4 的倍数长度的合法 Base64；跨用户或跨机器解密会失败并返回空文本。

#### 数据保护_加密字节集

- 签名：`数据保护_加密字节集(数据)`
- 返回值：字节集
- 说明：使用当前用户 DPAPI 加密原始字节集，返回未经 Base64 包装的密文字节集。
- 参数：
  - 数据（字节集）：要保护的原始字节集，内容原样送入 DPAPI，不做 Base64 也不做 UTF-8 解释；适合随机密钥等非文本二进制数据。空字节集返回空字节集。
- 示例：

```
数据保护_加密字节集(密钥字节集)
```


#### 数据保护_解密字节集

- 签名：`数据保护_解密字节集(密文)`
- 返回值：字节集
- 说明：解密 DPAPI 原始密文字节集并返回原始明文字节集，不做 UTF-8 解释；自动剥离 Chromium 的 "DPAPI" 前缀。二进制密钥必须用本命令，不要用 数据保护_解密文本。
- 参数：
  - 密文（字节集）：DPAPI 原始密文字节集，不需要 Base64。开头若为 ASCII "DPAPI" 5 字节（Chromium Local State 中 os_crypt.encrypted_key 去掉 Base64 后的形态），会自动剥离再解密；跨用户、跨机器或密文被改动时返回空字节集。
- 示例：

```
局部 字节集 主密钥
主密钥 = 数据保护_解密字节集(去前缀密文)
```


#### 数据保护_机器级加密文本

- 签名：`数据保护_机器级加密文本(文本)`
- 返回值：文本型
- 说明：使用本机范围 DPAPI 加密文本。
- 参数：
  - 文本（文本型）：要保护的文本，按 UTF-8 用本机范围 DPAPI 加密；同机任意用户可解，仅限非个人敏感数据。

#### 数据保护_取错误

- 签名：`数据保护_取错误()`
- 返回值：文本型
- 说明：返回最近一次文本或字节集数据保护命令的中文错误。
