# 非对称密码模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.crypto.asymmetric` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 27 |

提供 RSA、ECDSA P-256、ECDH P-256、X25519、SM2 和 ElGamal 的密钥、加密、签名或协商能力。私钥使用 PKCS#8 PEM，公钥使用 X.509 PEM。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 非对称_RSA生成私钥

- 签名：`非对称_RSA生成私钥(位数)`
- 返回值：文本型
- 说明：生成 RSA PKCS#8 PEM 私钥。
- 参数：
  - 位数（整数型）：允许 2048、3072 或 4096。
- 示例：

```
非对称_RSA生成私钥(3072)
```


#### 非对称_RSA取公钥

- 签名：`非对称_RSA取公钥(私钥PEM)`
- 返回值：文本型
- 说明：从 RSA 私钥导出 X.509 PEM 公钥。
- 参数：
  - 私钥PEM（文本型）：PKCS#8 格式的 PEM 私钥文本；必须与算法和位数匹配，解析失败返回空文本并记录中文错误。

#### 非对称_RSA_OAEP_SHA256加密

- 签名：`非对称_RSA_OAEP_SHA256加密(明文, 公钥PEM)`
- 返回值：文本型
- 说明：使用 RSA-OAEP(SHA-256) 加密短文本并返回 Base64。
- 参数：
  - 明文（文本型）：要加密的短文本，按 UTF-8 处理；长度超过密钥的 OAEP 容量时返回空文本并记录错误。
  - 公钥PEM（文本型）：X.509 格式的 PEM 公钥文本；算法必须与密钥类型一致，解析失败返回空文本并记录中文错误。

#### 非对称_RSA_OAEP_SHA256解密

- 返回值：文本型
- 说明：使用 RSA-OAEP(SHA-256) 解密短文本。
- 参数：
  - Base64密文（文本型）：对应 加密命令 返回的 Base64 密文文本；被改动或密钥不匹配时解密失败返回空文本。
  - 私钥PEM（文本型）：PKCS#8 格式的 PEM 私钥文本；必须与算法和位数匹配，解析失败返回空文本并记录中文错误。
