# 文本处理模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.text` |
| 版本 | 1.2.0 |
| 分类 | 其他 |
| 命令数 | 29 |

提供 Unicode 文本查找、截取、替换、修剪、大小写转换、定宽填充（按显示列数）与数组合并能力。索引统一从 0 开始。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 文本_取长度

- 签名：`文本_取长度(文本)`
- 返回值：整数型
- 说明：返回 Unicode 文本的字符数量。
- 参数：
  - 文本（文本型）：要处理的源文本，字符位置一律从 0 开始计数。
- 示例：

```
文本_取长度("LingBuilder")
```


#### 文本_寻找

- 签名：`文本_寻找(文本, 目标)`
- 返回值：整数型
- 说明：返回目标文本首次出现的从 0 开始索引，未找到返回 -1。
- 参数：
  - 文本（文本型）：要处理的源文本，字符位置一律从 0 开始计数。
  - 目标（文本型）：要查找的子文本，区分大小写。空文本时返回 0。
- 示例：

```
文本_寻找("中文编程", "编程")
```


#### 文本_是否包含

- 签名：`文本_是否包含(文本, 目标)`
- 返回值：逻辑型
- 说明：判断文本是否包含目标内容。
- 参数：
  - 文本（文本型）：要处理的源文本，字符位置一律从 0 开始计数。
  - 目标（文本型）：要查找的子文本，区分大小写。空文本时恒判为包含。

#### 文本_开头为

- 参数：
  - 文本（文本型）：要处理的源文本，字符位置一律从 0 开始计数。
  - 前缀（文本型）：要比较的开头内容，区分大小写；空文本时恒判为真。

#### 文本_结尾为

- 签名：`文本_结尾为(文本, 后缀)`

- 说明：判断文本是否以指定后缀结尾。
- 参数：
  - 文本（文本型）：要处理的源文本，字符位置一律从 0 开始计数。
  - 后缀（文本型）：要比较的结尾内容，区分大小写；空文本时恒判为真。

#### 文本_取中间

- 签名：`文本_取中间(文本, 起始位置, 长度)`
- 返回值：文本型
- 说明：按从 0 开始的索引截取文本，超出范围时安全截断。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 起始位置（整数型）：截取起始索引，从 0 起；为负或已到达文本末尾时返回空文本。
  - 长度（整数型）：要截取的字符数；小于等于 0 返回空文本，越过末尾时只取到末尾。

#### 文本_替换

- 返回值：文本型
- 说明：替换文本中的全部匹配内容。
- 参数：

  - 查找内容（文本型）：要被替换掉的子文本，区分大小写；空文本时不替换，原样返回。
  - 替换内容（文本型）：替换后写入的文本；空文本表示删除匹配内容。

#### 文本_转大写

#### 文本_分割

- 签名：`文本_分割(文本, 分隔符, 结果数组, 忽略末尾空段)`
- 返回值：整数型
- 说明：把文本按分隔符拆分写入文本数组，返回分段数量；分隔符为空时整段作为一条返回。文本以分隔符结尾时默认会多出一段空文本（"a|b|" 得 3 段），累积拼接场景请传 真 忽略它。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 分隔符（文本型）：分段依据，按完整子文本匹配；连续分隔符会产生空分段，空分隔符时整段作为唯一分段返回。
  - 结果数组（数组）：接收分段结果的文本型数组变量，调用前会先清空原有内容。
  - 忽略末尾空段（逻辑型）：传 假（省略时）保留尾部空段："a|b|" 拆成 "a"、"b"、"" 三段；传 真 丢弃末尾连续的空分段："a|b|" 拆成 "a"、"b" 两段。中间的空分段（"a||b"）不受影响，两种取值都保留。累积拼接串（串 = 串 + 字段 + "|"）应传真，否则段数比实际记录多 1。

#### 文本_倒找

- 签名：`文本_倒找(文本, 目标)`
- 返回值：整数型
- 说明：从末尾向开头查找目标文本首次出现的位置（从 0 起）；未找到返回 -1。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 目标（文本型）：要查找的子文本，区分大小写；空文本时返回文本末尾位置。

#### 文本_替换子文本

- 签名：`文本_替换子文本(文本, 查找内容, 替换内容, 起始位置, 次数)`
- 返回值：文本型
- 说明：从起始位置（从 0 起）开始替换查找内容；次数小于等于 0 表示全部替换；起始位置越界或查找内容为空时原样返回。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 查找内容（文本型）：要被替换掉的子文本，区分大小写；空文本时原样返回。
  - 替换内容（文本型）：替换后写入的文本；空文本表示删除匹配内容。
  - 起始位置（整数型）：开始替换的字符索引，从 0 起；为负或不小于文本长度时原样返回。
  - 次数（整数型）：最多替换的匹配个数；小于等于 0 表示从起始位置起全部替换。

#### 文本_删全部空白

#### 文本_到全角

#### 文本_重复

- 签名：`文本_重复(文本, 次数)`
- 返回值：文本型

  - 文本（文本型）：要重复拼接的源文本；空文本直接返回空文本。

#### 文本_插入

#### 文本_取左边

#### 文本_填充右边

- 签名：`文本_填充右边(文本, 目标显示宽度, 填充字符)`
- 返回值：文本型
- 说明：左对齐补齐：按显示宽度在右侧补到目标宽度，已够宽时原样返回且不截断，表格排版用它对齐每一列。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 目标显示宽度（整数型）：目标显示宽度，单位是显示列数而不是字符数：中日韩全角字符占 2 列、组合符号占 0 列、其余占 1 列（例如"莫生网店"是 8 列）；文本当前显示宽度已达到或超过该值时原样返回。
  - 填充字符（文本型）：补在右侧的文本，省略时为半角空格；只取首个字符重复，剩余列数不足一个填充字符宽度时少补一次（结果不会超过目标宽度）。
- 示例：

```
调试输出("[" + 文本_填充右边("莫生网店", 12) + "]")
```

#### 文本_居中

- 说明：居中补齐：按显示宽度在两侧补到目标宽度，左侧分到多余的半列（左侧宽度取剩余列数的一半向下取整），已够宽时原样返回。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 目标显示宽度（整数型）：目标显示宽度，单位是显示列数而不是字符数：中日韩全角字符占 2 列、组合符号占 0 列、其余占 1 列；文本当前显示宽度已达到或超过该值时原样返回。

#### 文本_取显示宽度

- 签名：`文本_取显示宽度(文本, 中日韩按 2 列)`
- 返回值：整数型
- 说明：返回文本在等宽字体下占用的显示列数（不是字符数）；制表符和换行等控制字符按 0 列计算。
- 参数：
  - 文本（文本型）：要处理的源文本，按 UTF-16 字符计数，位置与长度均从 0 起算。
  - 中日韩按 2 列（逻辑型）：传真（省略时）按终端惯例计算：中日韩全角字符 2 列、组合符号 0 列、其余 1 列；传假时每个字符一律算 1 列（等价于 文本_取长度，用于只按字符数对齐的场合）。
- 示例：

```
调试输出(文本_取显示宽度("莫生网店"))
```


#### 文本_连接

- 签名：`文本_连接(文本数组, 分隔符, 起始下标, 数量)`
- 返回值：文本型
- 说明：用分隔符把数组区间内的成员依次连成一段文本（文本_分割 的反向操作），拼接 JSON/CSV 记录时不必再手写「首个元素不加逗号」的累加逻辑。
- 参数：
  - 文本数组（数组）：要操作的目标数组变量，元素类型不限；位置参数一律按成员索引从 0 计数。
  - 分隔符（文本型）：连接各成员时插入的文本，允许空文本；分隔符不参与成员内容。
  - 起始下标（整数型）：从哪个成员开始连接，索引从 0 起；省略或小于 0 时按 0 处理，不小于成员数时返回空文本。
  - 数量（整数型）：最多连接的成员个数；省略或小于等于 0 表示从起始下标一直连到末尾，超出时只连到末尾。
- 示例：

```
局部 文本型 名单[]
数组_加入成员(名单, "a")
调试输出(文本_连接(名单, ","))
```
