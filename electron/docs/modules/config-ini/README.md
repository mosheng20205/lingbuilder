# INI 配置模块使用说明

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### INI_读文本

- 签名：`INI_读文本(文件, 节, 键, 默认值)`
- 返回值：文本型
- 说明：读取 INI 文本值。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：中括号里的节名，不含方括号，必须与文件中的节名一致。
  - 键（文本型）：节内的键名，等号左侧的部分。
  - 默认值（文本型）：键或文件不存在时返回的兜底文本，可以传空文本；读取缓冲区上限 32768 字符。

#### INI_读整数

- 签名：`INI_读整数(文件, 节, 键, 默认值)`
- 返回值：整数型
- 说明：读取 INI 整数值。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：中括号里的节名，不含方括号，必须与文件中的节名一致。
  - 键（文本型）：节内的键名，等号左侧的部分。
  - 默认值（整数型）：取不到值或值不是十进制整数时返回的兜底整数。

#### INI_写文本

- 签名：`INI_写文本(文件, 节, 键, 值)`
- 返回值：逻辑型
- 说明：写入 INI 文本值。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：中括号里的节名，不含方括号，必须与文件中的节名一致。
  - 键（文本型）：节内的键名，等号左侧的部分。
  - 值（文本型）：写入的文本值，落在等号右边；含换行会破坏 INI 结构，应避免。

#### INI_写整数

- 签名：`INI_写整数(文件, 节, 键, 值)`
- 返回值：逻辑型
- 说明：写入 INI 整数值。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：中括号里的节名，不含方括号，必须与文件中的节名一致。
  - 键（文本型）：节内的键名，等号左侧的部分。
  - 值（整数型）：写入的整数值，以十进制文本形式保存。

#### INI_删除键

- 签名：`INI_删除键(文件, 节, 键)`
- 返回值：逻辑型
- 说明：删除指定 INI 键。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：中括号里的节名，不含方括号，必须与文件中的节名一致。
  - 键（文本型）：要删除的键名；底层用写空值的方式删除该键。

#### INI_删除节

- 签名：`INI_删除节(文件, 节)`
- 返回值：逻辑型
- 说明：删除整个 INI 节。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：要整节删除的节名；底层以空键名方式删除整节。

#### INI_枚举节

- 签名：`INI_枚举节(文件, 结果数组)`
- 返回值：整数型
- 说明：把 INI 文件中的全部节名写入文本数组，返回节的数量。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 结果数组（数组）：接收全部节名的文本型数组变量，调用前会先清空原有内容。

#### INI_枚举键

- 签名：`INI_枚举键(文件, 节, 结果数组)`
- 返回值：整数型
- 说明：把指定节中的全部键名写入文本数组，返回键的数量。
- 参数：
  - 文件（文本型）：INI 文件路径；相对路径会先转成绝对路径再读写，文件不存在时读取返回默认值。
  - 节（文本型）：要枚举键名的节名。
  - 结果数组（数组）：接收该节全部键名的文本型数组变量，调用前会先清空原有内容。
