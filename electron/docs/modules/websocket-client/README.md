# WebSocket 客户端模块 2.0

模块 ID：`lingbuilder.websocket.client`
当前版本：`2.0.0`
最低 LingBuilder：`0.2.8`

WebSocket 客户端模块提供 Windows/MSVC 下基于 WinHTTP 的受管 WebSocket 客户端。模块支持多个独立连接、后台握手与接收、`ws://`/`wss://`、文本和二进制消息、代理、HTTP Basic 凭据、证书验证与 SHA-256 固定、自动重连、资源限制、事件快照和运行统计。

## 适用场景

- 桌面程序连接实时消息、协作、行情、设备或业务通知服务。
- 同一进程维护多个互不共享状态的 WebSocket 连接。
- 需要 `wss://`、代理、Origin、子协议、Authorization 等握手配置。
- 需要断线重连、中文错误、消息限额和可观测统计的长期连接。

不适用于浏览器 JavaScript WebSocket、QUIC/WebTransport，也不提供裸 `HINTERNET` 或任意 WinHTTP 句柄访问。

## 平台与依赖

- `windows-msvc-win32`
- `windows-msvc-x64`
- Windows 8/Server 2012 或更高版本的 WinHTTP WebSocket API
- 链接 `winhttp.lib`、`crypt32.lib` 和 LingBuilder 生成工程已有的 `bcrypt.lib`
- C++17

普通 Win32 与 New_Emoji 后端复用同一个 `LingWebSocketClientRuntime`。New_Emoji 使用独立消息窗口把事件送回 UI 线程，不复制第二套网络协议实现。

## 运行模型

`WS_创建连接` 返回稳定的 `WebSocket连接` ID。每个已启动连接拥有独立后台线程，负责握手、阻塞接收和自动重连；窗口/UI 线程不会执行网络接收。

每个连接同一时间只允许一个发送操作和一个接收操作。发送操作由连接级互斥锁串行化；多个连接可以并行工作。事件先保存为不可变快照，再通过窗口消息调用 `&处理器名`。处理器必须无参数，处理器内使用 `WS_取当前事件*` 命令读取快照。

连接对象必须由 `WS_销毁连接` 释放。窗口销毁时运行时会停止并回收仍存活的连接和后台线程。

## 完整示例

```text
类 MainWindow
    WebSocket连接 业务连接 = 0

    事件 _MainWindow_创建完毕()
        业务连接 = WS_创建连接()
        WS_配置连接(业务连接, "wss://example.com/realtime")
        WS_设置资源限制(业务连接, 15000, 60000, 16, 8)
        WS_设置UserAgent(业务连接, "LingBuilderDemo/2.0")
        WS_设置请求头(业务连接, "Authorization: Bearer token")
        WS_设置Origin(业务连接, "https://example.com")
        WS_设置子协议(业务连接, "chat.v2, chat.v1")
        WS_设置自动重连(业务连接, 真, 8, 500, 30000)
        WS_绑定已连接处理器(业务连接, &连接成功)
        WS_绑定消息处理器(业务连接, &收到消息)
        WS_绑定已断开处理器(业务连接, &连接断开)
        WS_绑定错误处理器(业务连接, &连接错误)
        WS_绑定重连处理器(业务连接, &准备重连)
        WS_开始连接(业务连接)
    结束

    事件 连接成功()
        调试输出("已连接，子协议：", WS_取协商子协议(WS_取当前连接()))
        WS_发送文本到连接(WS_取当前连接(), "你好")
    结束

    事件 收到消息()
        如果 (WS_取当前消息类型() == "文本")
            调试输出(WS_取当前文本())
        否则
            调试输出("收到二进制消息")
        如果结束
    结束

    事件 连接断开()
        调试输出(WS_取当前关闭代码(), WS_取当前关闭原因())
    结束

    事件 连接错误()
        调试输出(WS_取当前错误())
    结束

    事件 准备重连()
        调试输出("第", WS_取当前重连次数(), "次重连")
    结束
结束类
```

## 连接与生命周期

| 命令 | 说明 |
| --- | --- |
| `WS_创建连接()` | 创建受管连接 ID。 |
| `WS_配置连接(连接, 地址)` | 设置 `ws://` 或 `wss://` 地址，保留路径、查询参数和端口。 |
| `WS_开始连接(连接)` | 后台启动握手和接收，不阻塞 UI。 |
| `WS_等待连接(连接, 超时毫秒)` | 等待连接或失败，主要用于测试/命令行。 |
| `WS_关闭连接(连接, 状态码, 原因)` | 发送关闭帧并停止自动重连。 |
| `WS_强制断开(连接)` | 立即关闭 WinHTTP 句柄并停止重连。 |
| `WS_销毁连接(连接)` | 回收连接、线程、事件和凭据内存。 |

主动调用关闭、强制断开或销毁不会触发自动重连。网络错误、接收超时或服务端关闭会按配置进入重连。

## 握手配置

| 命令 | 说明 |
| --- | --- |
| `WS_设置UserAgent` | 设置握手 User-Agent。 |
| `WS_设置请求头` | 每行一个 `名称: 值`，适合 Authorization 和业务头。 |
| `WS_设置Origin` | 设置 Origin；空文本不发送。 |
| `WS_设置子协议` | 发送逗号分隔的子协议列表，并拒绝服务端返回未请求的协议。 |
| `WS_设置代理` | `0` 系统代理、`1` 直连、`2` 固定代理。 |
| `WS_设置服务器凭据` | 配置服务器 HTTP Basic 用户名和密码。 |
| `WS_设置代理凭据` | 配置代理 HTTP Basic 用户名和密码。 |

自定义请求头禁止覆盖 `Upgrade`、`Connection`、`Host`、`Origin`、`Sec-WebSocket-Key`、`Sec-WebSocket-Version`、`Sec-WebSocket-Extensions` 和 `Sec-WebSocket-Protocol`。这些字段由运行时的专用配置和 WinHTTP 维护，避免握手状态不一致或请求头注入。

凭据只保存在连接对象内存中，不写入模块清单、日志或项目文件。生产项目仍应从系统凭据存储读取秘密，不要把密码或长期 token 写进 `.lcpp` 源码。

## TLS 与证书固定

`wss://` 默认使用 Windows 证书链、主机名、有效期和用途验证。生产环境应保持：

```text
WS_设置TLS验证(连接, 真, 假, "")
```

`证书SHA256` 接受 64 位十六进制证书 DER SHA-256，可带冒号或空格。设置后，系统证书验证成功之外还必须匹配固定值：

```text
WS_设置TLS验证(连接, 真, 假, "AA:BB:...:FF")
```

`允许自签名=真` 只忽略未知 CA，仍检查主机名、有效期和用途。`验证证书=假` 会同时忽略 CA、主机名、有效期和用途错误，只能用于隔离开发环境，命令在模块中标记为高级能力。即使关闭系统验证，只要设置了 SHA-256 固定值，固定校验仍然执行。

证书轮换时应预先更新固定值。当前命令只接受一个证书固定值；需要双证书平滑轮换的系统应在业务配置层安排切换窗口。

## 资源限制与重连

`WS_设置资源限制(连接, 连接超时毫秒, 接收超时毫秒, 消息上限MB, 单次发送上限MB)` 的有效范围：

- 连接超时：1 秒到 5 分钟。
- 接收超时：1 秒到 1 小时。
- 单条接收消息：1MB 到 1024MB。
- 单次发送：1MB 到 1024MB。

文本按严格 UTF-8/UTF-16 转换。无效文本、超大消息和跨类型分片会产生中文错误事件，并结束当前连接。

`WS_设置自动重连(连接, 启用, 最大次数, 初始延迟毫秒, 最大延迟毫秒)` 使用有上限的指数退避。最大次数为 1 到 1000，初始延迟至少 100 毫秒。每次重连会重新执行 DNS、代理、TLS、请求头和子协议握手，不复用失效 WinHTTP 句柄。

自动重连不等同于业务会话恢复。登录态、订阅、游标、幂等消息和离线补偿必须在“已连接”处理器中由应用协议恢复。

## 事件

| 绑定命令 | 事件类型 | 快照内容 |
| --- | --- | --- |
| `WS_绑定已连接处理器` | `已连接` | 连接 ID、协商子协议和握手信息可通过状态命令读取。 |
| `WS_绑定消息处理器` | `文本` / `二进制` | 消息类型、文本或字节集。 |
| `WS_绑定已断开处理器` | `已断开` | 关闭代码和 UTF-8 原因；异常中断使用 1006 快照。 |
| `WS_绑定错误处理器` | `错误` | 中文错误和 WinHTTP 错误码。 |
| `WS_绑定重连处理器` | `重连` | 当前重试序号。 |

所有绑定必须使用 `&处理器名`，不能写成字符串。事件快照只在处理器调用期间有效；文本和字节集返回值会复制到 LingCpp 值，不应保存运行时内部指针。

## 消息

- `WS_发送文本到连接(连接, 内容)`：严格转换 UTF-16 到 UTF-8。
- `WS_发送二进制到连接(连接, 数据)`：发送独立字节集。
- `WS_取当前消息类型()`：返回 `文本` 或 `二进制`。
- `WS_取当前文本()`：只在文本消息处理器内有内容。
- `WS_取当前二进制()`：返回二进制消息副本。

WinHTTP WebSocket API 自动处理协议 Ping/Pong，但不公开应用主动发送 Ping 的接口。本模块不伪造文本“ping”冒充 RFC 6455 Ping。需要应用层心跳时，应由业务协议定义消息格式和超时语义。

## 状态与统计

| 命令 | 返回内容 |
| --- | --- |
| `WS_是否已连接` | 是否完成握手且仍在线。 |
| `WS_取连接状态` | 未配置、已停止、连接中、已连接、重连等待、关闭中或错误。 |
| `WS_取连接地址` | 当前配置地址。 |
| `WS_取协商子协议` | 服务端选择的子协议。 |
| `WS_取握手响应头` | 完整响应头。输出日志前应脱敏。 |
| `WS_取握手状态码` | 最近一次 HTTP 握手状态码，成功为 101。 |
| `WS_取连接错误` | 最近一次中文错误。 |
| `WS_取连接时长` | 当前在线毫秒数。 |
| `WS_取发送字节数` / `WS_取接收字节数` | 累计应用负载字节数。 |
| `WS_取发送消息数` / `WS_取接收消息数` | 累计完整消息数。 |
| `WS_取重连次数` | 当前启动周期已执行的重连次数。 |

统计是进程内观测值，不持久化，也不代表服务端已经处理业务消息。需要可靠投递时，应用协议必须提供消息 ID、确认和重放。

## 安全部署清单

- 公网连接优先使用 `wss://`，保持系统证书验证开启。
- 高风险系统同时启用 SHA-256 证书固定，并制定证书轮换流程。
- 令牌和密码来自凭据存储，不写入源码、调试输出或握手响应日志。
- 配置合理的连接/接收超时和消息上限。
- 自动重连必须设置次数和最大延迟，避免故障时形成重连风暴。
- “已连接”后重新认证和恢复订阅；不要假设 TCP/WebSocket 重连会恢复业务会话。
- 服务端消息必须继续经过业务 schema、权限和大小校验。
- 代理和自签名证书策略按部署环境显式设置，不在生产代码中关闭验证。

## 旧版迁移

旧版 5 条命令仍保留为高级兼容入口：

- `WS_连接`
- `WS_发送文本`
- `WS_接收到调试输出`
- `WS_接收文本`
- `WS_关闭`

兼容入口内部使用默认受管连接，但仍包含同步等待行为，不适合 UI 主线程和长期生产连接。新代码应迁移到 `WS_创建连接`、事件处理器、指定连接发送和显式销毁流程。
