# TCP通信模块使用说明

| 项目 | 内容 |

提供单连接 TCP 客户端的连接、UTF-8 文本收发、超时和关闭能力。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 6 条）

### 全部命令

#### TCP_连接

- 签名：`TCP_连接(主机, 端口, 超时毫秒)`
- 返回值：逻辑型
- 说明：连接 TCP 服务端。
- 参数：
  - 主机（文本型）：目标主机名或 IP 文本；同时按 IPv4 和 IPv6 尝试，逐个地址直到连上为止。
  - 端口（整数型）：服务端端口，1 到 65535；超范围直接判为参数无效。
  - 超时毫秒（整数型）：连接以及后续收发的超时毫秒数；小于 1 时按 1 毫秒处理。
- 示例：

```
TCP_连接("127.0.0.1", 9000, 5000)
```


#### TCP_发送文本

- 签名：`TCP_发送文本(内容)`
- 返回值：整数型
- 说明：发送完整 UTF-8 文本，返回字节数，失败返回 -1。
- 参数：
  - 内容（文本型）：要发送的文本，按 UTF-8 编码后循环发送直到全部发出；未连接或发送中断返回 -1。

#### TCP_接收文本

- 签名：`TCP_接收文本(最大字节数)`
- 返回值：文本型
- 说明：接收一批 UTF-8 文本。
- 参数：
  - 最大字节数（整数型）：单次最多接收的字节数，上限 16 MiB；小于 1 时按 1 处理，收到的字节按 UTF-8 严格解码。

#### TCP_是否已连接

- 签名：`TCP_是否已连接()`
- 返回值：逻辑型
- 说明：判断当前 TCP 句柄是否处于连接状态。

#### TCP_取错误

- 签名：`TCP_取错误()`
- 返回值：文本型
- 说明：返回最近 TCP 中文错误。

#### TCP_关闭

- 签名：`TCP_关闭()`
- 返回值：空
- 说明：关闭当前 TCP 连接。
