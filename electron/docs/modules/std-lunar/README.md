# 农历日期模块

模块 ID：`lingbuilder.std.lunar`  
版本：`1.0.0`  
适用平台：Windows / MSVC Win32、x64；普通 Win32 与 new_emoji 后端共用同一确定性 C++17 运行时。

农历日期模块提供中文传统历法能力：公历农历互转（含闰月）、月天数与年天数、属相、干支、六十甲子、**二十四节气**（天文算法计算，精确到分钟）与四柱（生辰八字）。年历表覆盖 1900–3000 年，节气表覆盖 1901–2100 年。数据与算法全部编译进生成的 C++ 工程，无运行时外部依赖。

日期时间值与 `日期时间模块`（`时间_取现行` 等）使用同一 64 位编码，可直接互传。

## 命令一览

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `农历_公历转农历年(时间)` | 整数型 | 农历年份 |
| `农历_公历转农历月(时间)` | 整数型 | 农历月 1～12，闰月为负数（闰六月 = -6） |
| `农历_公历转农历日(时间)` | 整数型 | 农历日 1～30 |
| `农历_农历转公历(农历年, 农历月, 农历日)` | 日期时间 | 农历月负数表示闰月；非法日期返回 0 |
| `农历_公历转农历文本(时间, 是否含属相)` | 文本型 | 如「丙午年七月初五」 |
| `农历_取闰月月份(公历年)` | 整数型 | 闰月月份，无闰月返回 0 |
| `农历_取月天数(公历年, 农历月)` | 整数型 | 29 或 30 |
| `农历_取年天数(公历年)` | 整数型 | 全年天数（353～355） |
| `农历_取属相(公历年)` | 文本型 | 鼠牛虎兔龙蛇马羊猴鸡狗猪 |
| `农历_取天干地支(公历年)` | 文本型 | 如「丙午」 |
| `农历_取六十甲子(公历年)` | 文本型 | 如「第43丙午」 |
| `农历_取节气(公历年, 节气序号)` | 日期时间 | 序号 1～24：小寒…冬至，北京时间精确到分钟 |
| `农历_取节气名称(节气序号)` | 文本型 | 序号对应名称 |
| `农历_取四柱(时间)` | 文本型 | 生辰八字，年月柱按节气分界 |

## 基本用法

```lcpp
局部 日期时间 春节
春节 = 农历_农历转公历(2026, 1, 1)
调试输出(时间_到文本(春节, 1))
调试输出(农历_公历转农历文本(春节, 真))
调试输出(农历_取闰月月份(2025))
调试输出(农历_取天干地支(2026))

局部 日期时间 立春
立春 = 农历_取节气(2026, 3)
调试输出(时间_到文本(立春, 0))
调试输出(农历_取四柱(时间_从文本("2026-08-15 10:30:00")))
```

## 注意事项

- 农历月用负数表示闰月，与易语言惯例一致；`农历_农历转公历` 对不存在的日期（如非闰年传闰月）返回 0。
- 节气序号固定为 1 小寒、2 大寒、3 立春……24 冬至；节气时刻由天文算法（Meeus 太阳视黄经）计算并按北京时间取整到分钟，与《中国天文年历》逐日核对一致。
- `农历_取四柱` 仅支持 1901–2100 年（需要节气表）；年柱、月柱严格按节气（立春、十二节）分界，日柱以 1949-10-01 甲子日为锚。
- 年份干支与属相命令按公历年份序号计算；严格命理口径请使用 `农历_取四柱`。
