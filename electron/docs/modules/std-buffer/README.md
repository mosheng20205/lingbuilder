# 缓冲区模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.buffer` |
| 版本 | 1.0.0 |
| 分类 | 其他 |
| 命令数 | 17 |

提供句柄制可增长二进制缓冲区：顺序读写游标、字节集/文本/整数编解码与文件互转；单缓冲区上限 256 MiB，跨线程传递请先转为字节集。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 17 条）

### 全部命令

#### 缓冲区_创建

- 签名：`缓冲区_创建(初始容量)`
- 返回值：长整数型
- 说明：创建可增长二进制缓冲区；初始容量 0～268435456，返回缓冲区句柄（0 表示失败）。
- 参数：
  - 初始容量（整数型）：预分配的字节容量，0 到 268435456；负数表示创建失败并返回句柄 0。
- 示例：

```
缓冲区_创建(1024)
```


#### 缓冲区_销毁

- 签名：`缓冲区_销毁(缓冲区)`
- 返回值：逻辑型
- 说明：销毁缓冲区并回收句柄；销毁后句柄不可再用。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建等命令返回的缓冲区句柄；句柄不存在或已销毁时返回假。

#### 缓冲区_取长度

- 签名：`缓冲区_取长度(缓冲区)`
- 返回值：长整数型
- 说明：返回缓冲区当前总字节数；句柄无效返回 -1。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建等命令返回的缓冲区句柄；句柄无效时返回 -1。

#### 缓冲区_写字节集

- 签名：`缓冲区_写字节集(缓冲区, 字节集)`
- 返回值：逻辑型
- 说明：把字节集追加到缓冲区末尾；单个缓冲区上限 268435456 字节。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 字节集（字节集）：要追加到缓冲区末尾的字节集；与已有内容合计超过 268435456 字节时返回假且不写入。

#### 缓冲区_写文本

- 签名：`缓冲区_写文本(缓冲区, 文本)`
- 返回值：逻辑型
- 说明：把文本按 UTF-8 编码追加到缓冲区末尾。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 文本（文本型）：要按 UTF-8 追加写入的文本；受单缓冲区 268435456 字节上限约束。

#### 缓冲区_写整数

- 签名：`缓冲区_写整数(缓冲区, 整数, 字节数, 大端)`
- 返回值：逻辑型
- 说明：把整数按指定字节数（1/2/4/8）写入缓冲区末尾；超出范围的字节数返回假。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 整数（长整数型）：要写入的整数值，只取指定位宽对应的低位字节。
  - 字节数（整数型）：整数的字节宽度，只允许 1、2、4、8；其它值不写入也不读取。
  - 大端（逻辑型）：传真表示高位字节在前（大端），传假表示低位字节在前（小端）。

#### 缓冲区_读字节集

- 签名：`缓冲区_读字节集(缓冲区, 长度)`
- 返回值：字节集
- 说明：从读取游标处取出字节集并前进游标；长度小于 0 表示读取全部剩余字节。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 长度（整数型）：要读取的字节数；小于 0 表示读取到缓冲区末尾，超出剩余时只取剩余部分，读取后游标前进。

#### 缓冲区_读文本

- 签名：`缓冲区_读文本(缓冲区, 长度)`
- 返回值：文本型
- 说明：从读取游标处按 UTF-8 解码文本并前进游标；长度小于 0 表示读取全部剩余字节。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 长度（整数型）：要读取的字节数，读出的字节按 UTF-8 解码为文本；小于 0 表示读取全部剩余字节。

#### 缓冲区_读整数

- 签名：`缓冲区_读整数(缓冲区, 字节数, 大端)`
- 返回值：长整数型
- 说明：从读取游标处按指定字节数（1/2/4/8）读取整数并前进游标；数据不足返回 0。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 字节数（整数型）：整数的字节宽度，只允许 1、2、4、8；其它值返回 0。
  - 大端（逻辑型）：传真表示高位字节在前（大端），传假表示低位字节在前（小端）。

#### 缓冲区_取剩余

- 签名：`缓冲区_取剩余(缓冲区)`
- 返回值：长整数型
- 说明：返回读取游标到缓冲区末尾的剩余字节数；句柄无效返回 -1。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建等命令返回的缓冲区句柄；句柄无效时返回 -1。

#### 缓冲区_重置读取

- 签名：`缓冲区_重置读取(缓冲区)`
- 返回值：逻辑型
- 说明：把读取游标移回缓冲区开头。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。

#### 缓冲区_到字节集

- 签名：`缓冲区_到字节集(缓冲区)`
- 返回值：字节集
- 说明：把缓冲区全部内容复制为字节集。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建等命令返回的缓冲区句柄；句柄无效时返回空字节集。

#### 缓冲区_从字节集

- 签名：`缓冲区_从字节集(字节集)`
- 返回值：长整数型
- 说明：用字节集内容创建新缓冲区并返回句柄。
- 参数：
  - 字节集（字节集）：用作缓冲区初始内容的字节集；超过 268435456 字节时返回句柄 0。

#### 缓冲区_清空

- 签名：`缓冲区_清空(缓冲区)`
- 返回值：逻辑型
- 说明：清空缓冲区内容并把读取游标归零。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。

#### 缓冲区_保存文件

- 签名：`缓冲区_保存文件(缓冲区, 路径)`
- 返回值：逻辑型
- 说明：把缓冲区全部内容写入目标文件（覆盖写入）。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 路径（文本型）：目标文件路径，不能为空文本；以二进制方式整文件覆盖写入。

#### 缓冲区_从文件

- 签名：`缓冲区_从文件(路径)`
- 返回值：长整数型
- 说明：读取文件内容创建新缓冲区；失败或超过 268435456 字节返回 0。
- 参数：
  - 路径（文本型）：要读取的文件路径，不能为空文本；打不开或文件超过 268435456 字节时返回句柄 0。

#### 缓冲区_寻找

- 签名：`缓冲区_寻找(缓冲区, 欲寻找, 起始位置)`
- 返回值：整数型
- 说明：在缓冲区全部内容中从起始位置（从 0 起）查找字节集，返回内容中的位置；读取游标不动；未找到或句柄无效返回 -1。
- 参数：
  - 缓冲区（长整数型）：缓冲区_创建、缓冲区_从字节集 或 缓冲区_从文件 返回的缓冲区句柄；句柄无效时命令按说明返回失败值。
  - 欲寻找（字节集）：要查找的目标字节集；为空时按命令说明返回 -1 或原样处理。
  - 起始位置（整数型）：查找起始的字节索引，从 0 起；不影响读取游标。
