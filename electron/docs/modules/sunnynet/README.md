# 网络中间件模块使用说明

网络中间件模块（`lingbuilder.sunnynet`）基于开源库 [SunnyNet](https://github.com/qtgolang/SunnyNet)（MIT 协议，版权「秦天」）封装，让中文程序以确定性 C++ 代码捕获、查看并修改本机 HTTP/HTTPS、WebSocket、TCP、UDP 收发数据。适用于调试自有程序的网络通信、接口联调、自动化测试与授权范围内的数据分析。

## 适用场景

- 抓取本机程序经代理发出的 HTTP/HTTPS 请求与响应，查看明文内容。
- 在请求/响应事件中修改请求头、请求体、响应头、响应体、状态码或重定向 URL。
- 监听并改写 WebSocket 消息、TCP/UDP 数据流。
- 按进程捕获指定程序流量（进程代理驱动，高级能力，见下文警示）。

## 依赖与安装

- 模块依赖 `lingbuilder.sunnynet.sdk`（SunnyNet 官方 Win32/x64 DLL，MIT）。SDK 体积约 81 MB，**不随 IDE 安装包分发**，请在模块管理中按提示按需下载，或本地执行：

  ```text
  cd electron
  npm run module:sunnynet-sdk -- --source <SunnyNet [Full]SDK 解压后的 windows 目录> --install
  ```

- 平台支持：仅 Windows（MSVC，Win32 与 x64）。其它平台会得到中文阻断诊断。
- 构建时 SDK 会按 runtime-manifest.json 逐文件校验 SHA-256，缺失或不一致时构建阻断。

## 最小示例（HTTP 抓包）

```text
.版本 2
.程序集 窗口程序集_启动窗口

.子程序 _启动窗口_创建完毕
    网络中间件 中间件 = 网络中间件_创建()
    网络中间件_设置HTTP事件(中间件, &HTTP事件处理)
    网络中间件_设置端口(中间件, 8888)
    网络中间件_启动(中间件)
    网络中间件_设置系统代理(中间件)

.子程序 HTTP事件处理
    调试输出(网络中间件_取当前方法(), 网络中间件_取当前URL())
```

## HTTPS 解密

1. `网络中间件_创建证书管理器()` 创建证书管理器（内部自动生成根证书 `LingBuilder.Sunny.Root`）。
2. `网络中间件_绑定证书(中间件, 证书)` 绑定到中间件。
3. `网络中间件_安装根证书(中间件)` 安装根证书到系统。**系统级操作**：已安装时静默返回真；首次安装会弹出中文确认对话框，用户点击「是」才执行。本地计算机证书库需要管理员权限。
4. 用 `网络中间件_卸载根证书()` 可同时从当前用户与本地计算机两处移除（同样需要管理员权限移除本地计算机部分）。
5. `网络中间件_导出根证书(中间件, 路径)` 导出 PEM 供 curl、Python 等工具信任。

## 事件模型

- 事件处理器必须使用 `&处理器` 引用、无参数、无返回值；处理器在**窗口 UI 线程**执行（底层回调线程只做投递，30 秒内未被处理则按原样放行）。
- HTTP/HTTPS：请求与响应各触发一次，用 `网络中间件_取当前事件类型()` 区分 `#HTTP事件_请求`（1）与 `#HTTP事件_响应`（2）。请求头/请求体/URL/Cookie 修改只在请求事件中生效，响应头/响应体/状态码修改只在响应事件中生效。
- TCP/UDP：用 `网络中间件_取当前连接ID()`、`网络中间件_取当前本地地址()`、`网络中间件_取当前对端地址()`、`网络中间件_取当前TCP数据()` 等读取上下文，用 `网络中间件_TCP发送数据()` 等主动收发。
- 事件处理器内不要执行长时间阻塞操作，否则超过 30 秒后本次数据将按未修改放行。

## 进程代理驱动（高级能力，谨慎使用）

- `网络中间件_加载进程代理驱动(中间件, 模式)` 加载内核级驱动（0=Proxifier，1=NFAPI/netfilter2，2=Tun/WinDivert 推荐），使指定进程流量无需系统代理即可被捕获。
- **警示**：需要管理员权限；会安装内核驱动服务（驱动文件内嵌于 SDK，运行时释放到系统 drivers 目录）；同一时刻只允许一个中间件使用驱动；安全软件可能提示。加载前程序会弹出中文确认对话框。
- `网络中间件_重启计算机并完成驱动卸载(中间件)`：**调用后程序会弹出确认对话框，用户点击「是」将立即重启计算机**（底层库的设计即「驱动卸载必须重启完成」）；点击「否」不执行任何操作并返回假。
- `网络中间件_卸载进程代理文件(中间件)`：不重启的清理路径（停止并删除驱动服务、把驱动文件移入临时目录），通常够用，建议优先使用。
- 已加载驱动的中间件调用 `网络中间件_停止` 会得到中文错误；`网络中间件_销毁` 会跳过底层 Close（规避底层双关闭缺陷）并改为清理驱动文件后释放。

## 上游代理（多进程分流的标准做法）

- `网络中间件_设置上游代理(中间件, 代理地址, 超时毫秒)`：给中间件实例设置全局上游代理，地址支持 `socks5://用户名:密码@主机:端口`（带账密）、`http://`、`https://`；`网络中间件_取消上游代理(中间件)` 恢复直连。
- **不同进程走不同上游 SOCKS5**：创建多个中间件实例，各自 `设置端口` 到不同端口、各自 `设置上游代理` 绑不同上游；在 Proxifier 类工具里把进程 A 的代理指向 `127.0.0.1:端口1`、进程 B 指向 `端口2`，即实现按进程分流，无驱动、无管理员、无重启。
- `网络中间件_设请求代理(消息ID, 代理地址, 超时毫秒)`：只在 HTTP 请求事件处理器内有效，给当前单个请求指定上游（可与 `网络中间件_取当前进程ID()` 配合按进程决定上游）；消息ID 用 `网络中间件_取当前事件ID()` 取得。
- 注意：代理地址必须用合法 URL（账号密码含非 ASCII 字符时需先做百分号编码），非法地址会导致设置失败并保持直连。
- 真机验证口径（2026-09-21）：正确账密上游连通、错误账密请求失败且上游记录认证失败、按请求代理命中走上游/未命中直连、取消上游后直连——五相位全过。

## 系统代理

`网络中间件_设置系统代理` 把 Windows 系统代理指向本中间件（系统级操作）。**停止（`网络中间件_停止`）、销毁（`网络中间件_销毁`）与程序正常退出（窗口关闭）都会自动还原系统代理**，与底层官方 Stop 语义一致；也可随时用 `网络中间件_取消系统代理` 手动还原。已知边界：进程被强杀（任务管理器结束进程、taskkill /F）或崩溃时来不及执行还原，系统代理会残留——此时在系统设置的代理里手动关闭，或重新运行任一使用了本模块的程序后正常退出即可自动还原。`网络中间件_卸载根证书` 只处理证书，不改动系统代理。

## 命令与参数

完整命令清单、参数与返回值见模块详情页；`#HTTP事件_请求`、`#HTTP事件_响应`、`#进程代理_模式_*` 为模块公开常量，以 `#` 前缀引用。

## 已知边界

- HTTPS 解密依赖客户端信任本模块根证书；不信任证书的程序会握手失败（可用「强制 TCP」思路自行扩展）。
- 请求/响应体的文本命令按 UTF-8 解码；二进制内容使用字节集命令族（`设响应体字节集` 等）。
- 底层为第三方开源库，随 SDK 附带其 API 参考文档与 LICENSE。
