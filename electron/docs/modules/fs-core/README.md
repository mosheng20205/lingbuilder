# 文件目录模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.fs.core` |
| 版本 | 1.3.0 |
| 分类 | 系统 |
| 命令数 | 42 |

提供 UTF-8 文本文件、常用文件目录操作、句柄式文件流读写、文件目录枚举和文件时间读取，所有路径均使用 Unicode。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 42 条）

### 全部命令

#### 文件_是否存在

- 签名：`文件_是否存在(路径)`
- 返回值：逻辑型
- 说明：判断指定路径是否为普通文件。
- 参数：
  - 路径（文本型）：要判断的 Unicode 路径；只有普通文件返回真，目录、不存在或非法路径都返回假。
- 示例：

```
文件_是否存在("配置.json")
```


#### 目录_是否存在

- 签名：`目录_是否存在(路径)`
- 返回值：逻辑型
- 说明：判断指定路径是否为目录。
- 参数：
  - 路径（文本型）：要判断的 Unicode 路径；只有真实目录返回真，文件和不存在路径返回假。

#### 文件_读取文本

- 签名：`文件_读取文本(路径, 编码名称)`
- 返回值：文本型
- 说明：按指定编码读取完整文本，缺省 UTF-8；失败返回空文本。
- 参数：
  - 路径（文本型）：要读取的文件路径；打不开时返回空文本。
  - 编码名称（文本型）：省略或传 "UTF-8" 时按 UTF-8 严格解码（开头 BOM 自动剥离，不做其它编码猜测），解码失败返回空文本；GBK 等中文文件必须显式传 GBK、GB18030 或 ANSI，也可传 AUTO 按「BOM → 严格 UTF-8 → GB18030」三级自动识别。

#### 文件_写入文本

- 签名：`文件_写入文本(路径, 内容)`
- 返回值：逻辑型
- 说明：按 UTF-8 覆盖写入文本文件。
- 参数：
  - 路径（文本型）：要写入的文件路径；所在目录必须已存在，打不开文件时返回假。
  - 内容（文本型）：要写入的文本，按 UTF-8 编码落盘且不附加 BOM；空文本写入空内容。

#### 文件_追加文本

- 签名：`文件_追加文本(路径, 内容)`
- 返回值：逻辑型
- 说明：按 UTF-8 向文件末尾追加文本。
- 参数：
  - 路径（文本型）：要追加的文件路径；所在目录必须已存在，文件不存在时会自动新建。
  - 内容（文本型）：追加到文件末尾的文本，按 UTF-8 编码且不附加 BOM。

#### 文件_复制

- 签名：`文件_复制(来源, 目标, 允许覆盖)`
- 返回值：逻辑型
- 说明：复制文件并可选择是否覆盖。
- 参数：
  - 来源（文本型）：要复制的源文件路径，必须是已存在的普通文件。
  - 目标（文本型）：复制得到的目标路径。
  - 允许覆盖（逻辑型）：传真时已存在的目标会被覆盖，传假时目标已存在则操作失败返回假。

#### 文件_移动

- 签名：`文件_移动(来源, 目标, 允许覆盖)`
- 返回值：逻辑型
- 说明：移动或重命名文件。
- 参数：
  - 来源（文本型）：要移动或重命名的源路径，文件和目录都可以。
  - 目标（文本型）：移动后的目标路径；跨卷移动可能失败返回假。
  - 允许覆盖（逻辑型）：传真时已存在的目标会被覆盖，传假时目标已存在则操作失败返回假。

#### 文件_删除

- 签名：`文件_删除(路径)`
- 返回值：逻辑型
- 说明：删除一个普通文件。
- 参数：
  - 路径（文本型）：要删除的文件路径；只有普通文件会被删除，目录返回假。

#### 文件_取大小

- 签名：`文件_取大小(路径)`
- 返回值：长整数型
- 说明：返回文件字节数，失败返回 -1。
- 参数：
  - 路径（文本型）：要统计的文件路径；路径不存在或不是文件时返回 -1。

#### 目录_创建

- 签名：`目录_创建(路径)`
- 返回值：逻辑型
- 说明：递归创建目录；目录已经存在也返回真。
- 参数：
  - 路径（文本型）：要创建的目录路径；缺失的父目录会逐级一起创建，目录已存在也算成功返回真。

#### 目录_删除空目录

- 签名：`目录_删除空目录(路径)`
- 返回值：逻辑型
- 说明：只删除空目录，不执行递归删除。
- 参数：
  - 路径（文本型）：要删除的目录路径；目录内仍有条目时返回假，不会递归删除内容。

#### 目录_删除树

- 签名：`目录_删除树(路径)`
- 返回值：逻辑型
- 说明：递归删除整个目录树（目录自身及全部子目录和文件）；这是危险操作，调用前请确认路径。
- 参数：
  - 路径（文本型）：要删除的目录路径；目录自身与其下全部内容一起删除，删除后不可恢复。路径为空、盘符根（如 C:\）或网络共享根时拒绝执行返回假，目录不存在也返回假。

#### 文件_打开

- 签名：`文件_打开(路径, 打开方式, 共享方式)`
- 返回值：文件号
- 说明：打开一个普通文件供句柄式读写，成功返回文件号，失败返回 0。
- 参数：
  - 路径（文本型）：要打开的文件路径；路径为空或打不开时返回 0。
  - 打开方式（整数型）：对文件的操作方式，对齐易语言编号：1 读入（不存在则失败）、2 写出（不存在则失败）、3 读写（不存在则失败）、4 重写（清空后写入，不存在则新建）、5 改写（不存在则新建，保留已有内容）、6 改读（读写，不存在则新建）；省略默认 3。
  - 共享方式（整数型）：限制其它进程操作此文件的方式：1 无限制、2 禁止其它进程写、3 禁止其它进程读、4 禁止其它进程读写；省略默认 1。
- 示例：

```
局部 文件号 号
号 = 文件_打开("data.txt", 6, 1)
文件_关闭(号)
```

- 说明：拒绝其它进程读写文件指定区域，用于多进程共享文件；成功返回真。
- 参数：
  - 文件号（长整数型）：文件_打开 返回的文件号；句柄无效或文件已关闭时命令按说明返回失败值。
  - 位置（长整数型）：加锁区域的起始字节位置，从 0 起；不能为负。
  - 长度（长整数型）：加锁区域的字节长度；不能为负。
  - 重试毫秒（整数型）：加锁失败后的重试毫秒数；0 表示失败立即返回（省略时同为 0），-1 表示一直重试直到成功，其它正值在时限内每 10 毫秒重试一次。
- 示例：

```
局部 文件号 号
号 = 文件_打开("data.txt", 6, 1)
```

#### 文件_枚举

- 签名：`文件_枚举(目录, 通配符, 含子目录, 结果数组)`
- 返回值：整数型
- 说明：枚举目录下的文件（含隐藏、系统文件），返回命中数量。
- 参数：
  - 目录（文本型）：要枚举的目录路径；目录不存在时返回 0。
  - 通配符（文本型）：文件名匹配模式，支持 * 和 ? 通配符，例如 "*.txt"；空文本匹配全部文件。只按文件名匹配，不含目录前缀。
  - 含子目录（逻辑型）：传真时递归枚举全部子目录下的匹配文件，传假只枚举当前一层。
  - 结果数组（数组）：接收匹配文件完整路径的文本数组变量，调用前会先清空原有内容；结果不保证排序。
- 示例：

