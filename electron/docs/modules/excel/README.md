# Excel 表格模块 1.0 使用说明

Excel 表格模块（`lingbuilder.data.excel`）让中文程序直接读写 `.xlsx` 工作簿：多工作表、按单元格坐标读写、公式、日期、整行追加、常用格式和插入删除行列。运行时随附 `LingBuilderExcel.dll`，**无需安装 Microsoft Excel 或 WPS**。

## 适用场景

- 导出数据报表：把程序中的查询结果、统计汇总写成带表头、格式和公式的 .xlsx 文件。
- 修改既有报表：打开 Excel/WPS 生成的 .xlsx，改写指定单元格后保存，原有样式、列宽、公式结构保真保留。
- 表格文件互通：读取用户手工维护的 .xlsx 数据文件；与 DataGrid 控件的 `表格_导入Excel` / `表格_导出Excel` 命令互通。

## 两种工作模式

模块用一个受管句柄类型 `Excel工作簿`（`long long`，0 表示无效）表示工作簿，分两种模式：

| | 创建模式（`Excel_创建工作簿`） | 打开模式（`Excel_打开工作簿`） |
| --- | --- | --- |
| 引擎 | 内存文档模型 + libxlsxwriter 序列化 | OpenXLSX 原文件保真修改 |
| 读写 | 写入在内存中，`Excel_保存` 才写出文件；保存后可继续修改再保存 | 直接读写文件文档，`Excel_保存` 原地写回 |
| 格式与结构命令（置列宽/行高/合并/冻结/格式/插入删除行列） | 全部可用 | 不可用，调用返回假并给出中文诊断 |
| 公式 | 可写；Excel/WPS 打开文件时自动计算，无缓存值 | 可写可读；读数值返回缓存值 |
| 另存为 | 支持；保存目标随之切换 | 支持 |

格式族命令在打开模式会**明确失败并记录中文错误**，不会静默丢弃格式；需要设置格式时请用创建模式重建或在 Excel/WPS 中调整。

## 调用方式

所有命令以 `Excel_` 为前缀，坐标一律使用 Excel 地址文本（`"A1"`、`"AB12"`、区域 `"A1:C10"`）。典型流程：

```lcpp
局部 Excel工作簿 报表 = Excel_创建工作簿("报表/月度报表.xlsx")
如果 报表 != 0
    Excel_写一行(报表, "A1", "姓名\t销量\t金额", "\t")
    Excel_置加粗(报表, "A1", 真)
    Excel_追加行(报表, "张三\t12\t980.5", "\t")
    如果 Excel_保存(报表)
        调试输出("已保存")
    否则
        调试输出(Excel_取错误())
    结束
    Excel_关闭(报表)
否则
    调试输出(Excel_取错误())
结束
```

批量行命令 `Excel_写一行` / `Excel_追加行` 用分隔符文本表达一行数据（分隔符为空时按制表符处理）：纯数字片段自动写成数值，空片段跳过。`Excel_追加行` 返回写入的 1 起始行号，失败返回 -1。`Excel_读区域` 返回多行文本：行之间用换行、单元格之间用指定分隔符拼接，可逐行解析或配合 CSV/JSON 模块加工。

## 命令与返回值

45 条命令分九族：

- 工作簿生命周期（5）：`Excel_创建工作簿` `Excel_打开工作簿` `Excel_保存` `Excel_另存为` `Excel_关闭`
- 工作表（6）：`Excel_取工作表数量` `Excel_取工作表名(工作簿, 序号)` `Excel_取当前工作表` `Excel_置当前工作表` `Excel_添加工作表` `Excel_删除工作表`
- 单元格写入（6）：`Excel_写文本` `Excel_写数值` `Excel_写布尔` `Excel_写公式` `Excel_写日期` `Excel_清除单元格`
- 单元格读取（5）：`Excel_读单元格文本` `Excel_读单元格数值` `Excel_读单元格公式` `Excel_取单元格类型` `Excel_是否为空单元格`
- 行列批量（4）：`Excel_写一行` `Excel_追加行` `Excel_读区域` `Excel_取已用范围`
- 结构与格式，仅创建模式（10）：`Excel_置列宽` `Excel_置行高` `Excel_合并单元格` `Excel_冻结窗格` `Excel_置数字格式` `Excel_置加粗` `Excel_置字号` `Excel_置字体颜色` `Excel_置背景色` `Excel_置水平对齐`
- 插入/删除行列，仅创建模式（4）：`Excel_插入行` `Excel_删除行` `Excel_插入列` `Excel_删除列`
- 日期换算（2）：`Excel_日期转序列` `Excel_序列转日期`
- 诊断（3）：`Excel_取错误` `Excel_取版本` `Excel_是否可用`

失败约定：返回句柄的命令失败返回 0；返回布尔的命令失败返回假；`Excel_追加行` 失败返回 -1；所有失败都可用 `Excel_取错误()` 读取当前线程的中文错误说明。

## 参数与返回值细节

- `Excel_写日期` 接受 `"2026-01-31"` 或 `"2026-01-31 08:30:00"`；创建模式自动套用日期显示格式，打开模式只写日期序列值（显示格式需在 Excel/WPS 中设置或改用创建模式）。
- `Excel_取单元格类型` 返回 0=空、1=文本、2=数值、3=布尔、4=公式。
- `Excel_置数字格式` 的格式索引：0=文本、1=整数、2=两位小数、3=百分比、4=日期时间；`Excel_置字体颜色` / `Excel_置背景色` 颜色值用 `0xRRGGBB`（如 `0xFF0000` 红色）。
- `Excel_日期转序列` 对 1900-03-01 之前的日期与 Excel 相差 1（Excel 1900 年闰年历史缺陷）；1900-03-01 起完全一致。

## 依赖和平台限制

- 仅支持 `.xlsx`（Office Open XML）格式；不支持 1997-2003 的 `.xls` 二进制格式，传入 `.xls` 路径会得到中文诊断。
- 随附运行桥 `LingBuilderExcel.dll` 仅提供 Windows x86 / x64 版本；F5 构建、AI Bridge 构建和 Visual Studio 工程导出会自动把它复制到 exe 同目录，缺文件时构建日志给出中文诊断。
- 运行桥由 libxlsxwriter 1.2.3（BSD-2-Clause）、zlib 1.3.1（zlib License）、OpenXLSX 0.5.1（MIT）等组件静态链接而成，来源与许可见随附运行桥目录的 `NOTICE.md`。
- 大区域读取上限为 100000 行 × 4096 列；写入超大公式或循环引用的行为由 Excel/WPS 打开时决定。

## 迁移说明

本模块为 1.0 首次发布。此前围绕 DataGrid 表格的 `表格_导入Excel` / `表格_导出Excel` 命令继续可用：它们面向表格控件整体导入导出，本模块面向单元格级任意读写，两者可共存于同一项目。
