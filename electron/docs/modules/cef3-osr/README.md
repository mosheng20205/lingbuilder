### 全部命令

#### CEF3OSR_请求重绘

- 签名：`CEF3OSR_请求重绘(浏览器句柄, 元素类型)`
- 返回值：整数型
- 说明：请求无窗口浏览器按元素类型重新绘制（0 视图、1 弹窗）；改完视口或页面状态后调用，促使 CEF 立刻重查 GetViewRect 并出一帧。成功返回 1，句柄为空、元素类型非法或桥接层拒绝返回 0 并给中文诊断。
- 别名：`CefBrowserHost::Invalidate`（兼容旧写法，生成代码使用主名）。
- 高级命令：需在设置中开启「显示高级 API」后才会进入补全。
- 参数：
  - 浏览器句柄（长整数型）：取自「CEF3无头_取浏览器句柄(实例编号)」的受管浏览器句柄，仅对无窗口/OSR 浏览器有意义；句柄由运行时托管，不得手动释放，实例关闭后失效。句柄是 64 位受管值、在 .lcpp 里通常显示为负数，判断有效只用「!= 0」。取页面内容请改用 CEF3无头_取主框架 的框架句柄链路。
  - 元素类型（整数型）：重绘范围：0=视图（PET_VIEW），1=弹窗（PET_POPUP）；其余取值命令直接拒绝。

#### CEF3OSR_设置窗口外帧率

- 签名：`CEF3OSR_设置窗口外帧率(浏览器句柄, 帧率)`
- 返回值：整数型
- 说明：设置无窗口浏览器的绘制帧率；0 表示不限制、由 CEF 自行决定。返回 1 表示桥接层已接受。
- 别名：`CefBrowserHost::SetWindowlessFrameRate`（兼容旧写法，生成代码使用主名）。
- 高级命令：需在设置中开启「显示高级 API」后才会进入补全。
- 参数：
  - 浏览器句柄（长整数型）：取自「CEF3无头_取浏览器句柄(实例编号)」的受管浏览器句柄，仅对无窗口/OSR 浏览器有意义；句柄由运行时托管，不得手动释放，实例关闭后失效。句柄是 64 位受管值、在 .lcpp 里通常显示为负数，判断有效只用「!= 0」。取页面内容请改用 CEF3无头_取主框架 的框架句柄链路。
  - 帧率（整数型）：无窗口浏览器的绘制帧率（每秒帧数）；传 0 表示不限制、由 CEF 自行决定，负数直接拒绝。
