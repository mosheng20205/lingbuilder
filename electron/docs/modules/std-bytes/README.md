# 字节与十六进制模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.bytes` |
| 版本 | 1.2.0 |
| 分类 | 其他 |
| 命令数 | 26 |

通过安全文本接口提供 UTF-8 字节长度、十六进制编解码和数值进制文本转换。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 26 条）

### 全部命令

#### 字节_UTF8长度

- 签名：`字节_UTF8长度(文本)`
- 返回值：整数型
- 说明：返回文本编码为 UTF-8 后的字节数。
- 参数：
  - 文本（文本型）：要统计的文本；返回其 UTF-8 编码后的字节数，编码失败返回 0。
- 示例：

```
字节_UTF8长度("中文")
```


#### 字节_文本转十六进制

- 签名：`字节_文本转十六进制(文本)`
- 返回值：文本型
- 说明：把文本的 UTF-8 字节转换为大写十六进制文本。
- 参数：
  - 文本（文本型）：要转换的文本；输出大写十六进制文本，编码失败时返回空文本。
- 示例：

```
字节_文本转十六进制("Ling")
```


#### 字节_十六进制转文本

- 签名：`字节_十六进制转文本(十六进制)`
- 返回值：文本型
- 说明：把十六进制字节文本按 UTF-8 解码，格式错误返回空文本。
- 参数：
  - 十六进制（文本型）：十六进制字节文本，长度必须为偶数且每个字符只允许 0-9、a-f、A-F；格式非法按命令说明返回失败值。；解码或转码失败时返回空文本。

#### 字节_十六进制是否有效

- 签名：`字节_十六进制是否有效(十六进制)`
- 返回值：逻辑型
- 说明：判断文本是否由偶数个十六进制字符组成。
- 参数：
  - 十六进制（文本型）：待校验的文本；要求长度为偶数且每个字符都是 0-9、a-f、A-F。

#### 数值_到十六进制文本

- 签名：`数值_到十六进制文本(数值)`
- 返回值：文本型
- 说明：返回整数的十六进制文本形式：非负数为大写十六进制（无前缀），负数为 8 位 32 位补码形式。
- 参数：
  - 数值（整数型）：要转换的整数；例如 255 得 FF，-1 得 FFFFFFFF。
- 示例：

```
数值_到十六进制文本(255)
```


#### 数值_到八进制文本

- 签名：`数值_到八进制文本(数值)`
- 返回值：文本型
- 说明：返回整数的八进制文本形式（无前缀）；负数按 32 位补码的八进制输出。
- 参数：
  - 数值（整数型）：要转换的整数；例如 8 得 10，-1 得 37777777777。
- 示例：

```
数值_到八进制文本(8)
```


#### 数值_十六进制解析

- 签名：`数值_十六进制解析(十六进制文本)`
- 返回值：整数型
- 说明：把十六进制文本解析为整数；可带 0x/0X 前缀，非法内容返回 0。
- 参数：
  - 十六进制文本（文本型）：只含十六进制字符的文本，允许首尾空白和可选 0x/0X 前缀；超过 8 位取低 32 位（按补码解释），没有有效字符时返回 0。
- 示例：

```
数值_十六进制解析("FF")
```


#### 数值_八进制解析

- 签名：`数值_八进制解析(八进制文本)`
- 返回值：整数型
- 说明：把八进制文本解析为整数；非法内容返回 0。
- 参数：
  - 八进制文本（文本型）：只含八进制字符（0-7）的文本，允许首尾空白；超过位数取低 32 位（按补码解释），没有有效字符时返回 0。
- 示例：

```
数值_八进制解析("10")
```


#### 字节集_长度

- 签名：`字节集_长度(数据)`
- 返回值：整数型
- 说明：返回字节集长度。
- 参数：
  - 数据（字节集）：要统计的字节集；字节数超过整数上限时返回 2147483647。

#### 字节集_截取

- 签名：`字节集_截取(数据, 起始位置, 长度)`
- 返回值：字节集
- 说明：按 0 起始位置安全截取字节集。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 起始位置（整数型）：截取起始字节索引，从 0 起；为负或已到达末尾时返回空字节集。
  - 长度（整数型）：要截取的字节数；小于等于 0 返回空字节集，越过末尾时只取到末尾。

#### 字节集_拼接

- 签名：`字节集_拼接(前段, 后段)`
- 返回值：字节集
- 说明：拼接两个字节集，溢出时返回空字节集。
- 参数：
  - 前段（字节集）：作为前半部分的字节集，字节顺序保持不变。
  - 后段（字节集）：追加到前段之后的字节集；两段总长度溢出时返回空字节集。

#### 字节集_取字节

- 签名：`字节集_取字节(数据, 位置)`
- 返回值：整数型
- 说明：读取指定位置的 0～255 字节，越界返回 -1。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 位置（整数型）：要读取的字节位置，从 0 起；越界返回 -1。

#### 字节集_置字节

- 签名：`字节集_置字节(数据, 位置, 数值)`
- 返回值：逻辑型
- 说明：写入一个字节，位置或数值无效时返回假。
- 参数：
  - 数据（字节集）：要修改的字节集；只改动指定位置，长度不变。
  - 位置（整数型）：要写入的字节位置，从 0 起；越界返回假且不改动数据。
  - 数值（整数型）：写入的字节值，必须在 0 到 255 之间；超范围返回假。

#### 字节集_Base64编码

- 签名：`字节集_Base64编码(数据)`
- 返回值：文本型
- 说明：把字节集编码为 Base64 文本。
- 参数：
  - 数据（字节集）：要编码的原始字节集；输出标准 Base64 字母表并以等号补齐。

#### 字节集_Base64解码

- 签名：`字节集_Base64解码(Base64文本)`
- 返回值：字节集
- 说明：把 Base64 文本解码为字节集，格式错误返回空字节集。
- 参数：
  - Base64文本（文本型）：标准 Base64 文本，长度必须是 4 的倍数，只含字母表字符和末尾补齐等号；格式错误返回空字节集。

#### 字节集_到十六进制字节集

- 签名：`字节集_到十六进制字节集(数据)`
- 返回值：字节集
- 说明：把字节集编码为 ASCII 十六进制字节集。⚠️ 返回的是字节集而不是文本：要直接得到可显示的十六进制文本请用 字节集_到十六进制文本，或对结果再调 编码_字节集转文本(结果, "ANSI")。
- 别名：`字节集_十六进制编码`（兼容旧写法，生成代码使用主名）。
- 参数：
  - 数据（字节集）：要编码的字节集；输出由大写十六进制字符组成的 ASCII 字节集。

#### 字节集_到十六进制文本

- 签名：`字节集_到十六进制文本(数据)`
- 返回值：文本型
- 说明：把字节集编码为大写十六进制并直接返回文本（字节集_到十六进制字节集 的文本版），一步得到可直接显示或拼接的结果。
- 参数：
  - 数据（字节集）：要编码的字节集；输出由大写十六进制字符组成的文本，空字节集返回空文本。
- 示例：

```
调试输出(字节集_到十六进制文本(字节集_从文本("Ling")))
```


#### 字节集_十六进制解码

- 签名：`字节集_十六进制解码(十六进制)`
- 返回值：字节集
- 说明：把十六进制文本解码为字节集。
- 参数：
  - 十六进制（文本型）：十六进制字节文本；长度必须为偶数且逐字符合法，否则返回空字节集。

#### 字节集_寻找

- 签名：`字节集_寻找(数据, 欲寻找, 起始位置)`
- 返回值：整数型
- 说明：从起始位置（从 0 起）向后查找字节集首次出现的位置；未找到、欲寻找为空或起始位置越界返回 -1。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 欲寻找（字节集）：要查找的目标字节集；为空时按命令说明返回 -1 或原样处理。
  - 起始位置（整数型）：开始查找的字节索引，从 0 起；为负或剩余长度不足时返回 -1。

#### 字节集_倒找

- 签名：`字节集_倒找(数据, 欲寻找, 起始位置)`
- 返回值：整数型
- 说明：从起始位置（含）向左查找字节集最后一次出现的位置；起始位置小于 0 或越界时按末尾处理；未找到返回 -1。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 欲寻找（字节集）：要查找的目标字节集；为空时返回 -1。
  - 起始位置（整数型）：查找窗口的右端字节索引，含该位置，从 0 起；小于 0 或不小于字节集长度时按整个字节集查找。

#### 字节集_替换

- 签名：`字节集_替换(数据, 欲寻找, 替换内容, 次数)`
- 返回值：字节集
- 说明：把字节集中的欲替换内容替换为替换内容；次数小于等于 0 表示全部替换；欲替换为空时原样返回。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 欲寻找（字节集）：要被替换掉的目标字节集；为空时原样返回。
  - 替换内容（字节集）：替换写入的字节集，长度可以和目标不同，空字节集表示删除匹配。
  - 次数（整数型）：最多替换次数；小于等于 0 表示全部替换。

#### 字节集_插入

- 签名：`字节集_插入(数据, 位置, 插入内容)`
- 返回值：字节集
- 说明：在指定位置（从 0 起）插入字节集；位置小于 0 原样返回，超过长度时追加到末尾。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 位置（整数型）：插入点字节索引，从 0 起；小于 0 原样返回，大于长度时追加到末尾。
  - 插入内容（字节集）：要插入的字节集；空字节集时结果与源字节集相同。

#### 字节集_删除

- 签名：`字节集_删除(数据, 位置, 长度)`
- 返回值：字节集
- 说明：从指定位置（从 0 起）删除指定长度的字节；长度小于 0 表示删除到末尾；位置越界时原样返回。
- 参数：
  - 数据（字节集）：要操作的字节集；位置与长度均按字节计，索引从 0 起。
  - 位置（整数型）：起始删除的字节索引，从 0 起；为负或不小于长度时原样返回。
  - 长度（整数型）：要删除的字节数；小于 0 表示删除到末尾，超出剩余时删除到末尾。

#### 字节集_从文本

- 签名：`字节集_从文本(文本)`
- 返回值：字节集
- 说明：把文本按 UTF-8 编码转为字节集。
- 参数：
  - 文本（文本型）：要转换的文本；按 UTF-8 编码为字节序列，空文本返回空字节集。
- 示例：

```
字节集_从文本("你好")
```


#### 字节集_重复

- 签名：`字节集_重复(次数, 数据)`
- 返回值：字节集
- 说明：把字节集重复拼接指定次数；次数小于等于 0 或源为空时返回空字节集。
- 参数：
  - 次数（整数型）：重复次数；小于等于 0，或重复结果超过 268435456 字节时返回空字节集。
  - 数据（字节集）：要重复的字节集；空字节集直接返回空字节集。
- 示例：

```
局部 字节集 原始数据
原始数据 = 字节集_从文本("AB")
```


#### 字节集_分割

- 签名：`字节集_分割(数据, 分隔字节集, 结果数组, 数目)`
- 返回值：整数型
- 说明：把字节集按分隔字节集切分为多段写入字节集数组，返回分段数量；分隔字节集为空时按单个字节 0 分割。
- 参数：
  - 数据（字节集）：待分割的字节集；空字节集返回 0 且不写数组。
  - 分隔字节集（字节集）：分段边界的字节集；为空时按单个字节 0 分割，连续分隔符会产生空分段。
  - 结果数组（数组）：接收分段结果的字节集数组变量，调用前会先清空原有内容。
  - 数目（整数型）：最多返回的分段数；小于等于 0 表示返回全部分段，达到数目后剩余内容整体作为最后一段。
