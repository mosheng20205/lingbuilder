# Checkbox 复选框 Checkbox · 惯用要点与红线

- 只有两个自有属性：`checked`（勾选）与 `indeterminate`（半选，用于「全选」这类父项状态）。
- 读状态一律 `控件_取勾选(控件)`，写状态 `控件_设置勾选(控件, 真)`；不要用文本或颜色去「表示」勾选态。
- `数值变化` 事件清单里不带参数——想知道变成什么值，处理器内再 `控件_取勾选` 读一次，不要凭「应该被点了」推断。
- 「全选/反选」必须同时维护子项与父项的 `indeterminate`：子项部分选中时父项置半选，否则用户看不出组内状态。
- 依赖勾选结果做耗时动作时，把动作放工作线程（`线程_提交完成` + 完成处理器回界面），界面事件里不做同步等待。

```lcpp
局部 NE复选框 加急勾选 = 控件_创建NE复选框(当前窗口, 150, 182, 220, 34, "需要加急", "加急勾选", 5)
控件_设置勾选(加急勾选, 真)
局部 逻辑型 加急 = 控件_取勾选(加急勾选)
```
