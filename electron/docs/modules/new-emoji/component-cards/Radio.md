# Radio 单选框 Radio · 惯用要点与红线

- 清单只暴露 `checked` 一个自有属性：单选互斥不是靠本控件自己实现，而是由业务侧在 `数值变化` 里把同组其他项置为假，或改用 `Select`/`Tabs` 表达「N 选 1」。
- 选项超过 3 个优先换 `Select`（选择器）或 `ListBox`，别在窗口里铺一排单选框占坐标。
- 读态用 `控件_取勾选(控件)`；`数值变化` 事件不带参数，处理器内需重新取值。
- 跨事件引用同组控件时按「标记文本」逐个 `通过标记文本获取NE单选框("…")`，把组关系写成一个中文数组遍历，比复制粘贴 N 段处理器更容易保持一致。
- 组内「当前选中项」应存成窗口成员（如 `整数型 当前方案 = 0`），不要靠反复读多个控件的勾选态拼状态。

```lcpp
事件 方案被切换()
  局部 NE单选框 方案甲 = 通过标记文本获取NE单选框("方案甲")
  局部 NE单选框 方案乙 = 通过标记文本获取NE单选框("方案乙")
  控件_设置勾选(方案乙, 控件_取勾选(方案甲) == 假)
结束
```
