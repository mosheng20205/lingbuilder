# Switch 开关 Switch · 惯用要点与红线

- 用于「立即生效」的二态设置（总开关、自动刷新、防撤回）；确认后才生效的选项请用 `Checkbox` + 提交按钮，语义不同。
- 自有属性只有 `checked` 与 `loading`：动作耗时（写文件、连设备、请求网络）时先 `loading` 置真，落地后再回写 `checked`，避免用户连点。
- 读态 `控件_取勾选(控件)`，写态 `控件_设置勾选(控件, 真/假)`；`数值变化` 事件不带参数，处理器内重新取值再决定分支。
- 开关的真实动作必须放在工作线程或模块命令里完成，界面侧只反映状态；禁止在 `数值变化` 里做同步阻塞等待（会冻结界面线程）。
- 失败回滚要显式：动作失败时把 `checked` 改回原值并给出状态提示，不能只报错不改界面，否则开关长期与实际状态不一致。

```lcpp
事件 总开关被切换()
  局部 NE开关 防撤回总开关 = 通过标记文本获取NE开关("防撤回总开关")
  局部 逻辑型 目标 = 控件_取勾选(防撤回总开关)
  调试输出("总开关=" + 到文本(目标))
结束
```

> 真实动作交给模块命令或工作线程完成（命令与参数以 `lingbuilder.module.info` 为准），开关控件本身只负责反映状态。
