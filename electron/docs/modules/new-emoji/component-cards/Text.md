# Text 文本 Text · 惯用要点与红线

- 标题、说明、状态行都用它；正文优先走「创建时传文本」，事后更新用 `控件_设置文本(控件, "…")`，读取用 `控件_取文本(控件)`。
- 枚举属性按清单取值：`align` 0=左对齐 1=居中 2=右对齐，`valign` 0=上 1=居中 2=底部；`wrap` + `ellipsis` 决定长文本是否换行或截断，说明性长句要显式 `wrap=真`。
- 中文与 emoji 可直接写进文本参数，不需要额外编码转换；不要为了换行去拼 `\n` 之外的转义技巧。
- 状态提示控件的「标记文本」要取个稳定名字（如 `状态`），事件里靠 `通过标记文本获取NE文本("状态")` 重新取引用；把局部变量当跨事件成员用是 new_emoji 项目最常见的空白/不更新根因。
- 界面文本不要塞进 `@` 内嵌 C++ 里手工拼；需要格式化文本用基础命令 `格式化文本("…{}", 值)` 或 `到文本(值)`。

```lcpp
局部 NE文本 标题 = 控件_创建NE文本(当前窗口, 24, 24, 620, 30, "🧩 组件总览", "标题", 1)
局部 NE文本 状态 = 控件_创建NE文本(当前窗口, 24, 260, 620, 26, "等待操作", "状态", 2)
控件_设置文本(状态, "已点击 " + 到文本(计数) + " 次")
```
