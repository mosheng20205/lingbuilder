# ListBox 列表框 ListBox · 惯用要点与红线

- 简单列表只写 `items`；**只有确实需要 TSV 字段（图标/描述/标签/分组/树层级）时才写 `listBoxItemsEx`**，两者不要混用，Ex 形态由生成器下发。
- 选择形态看 `selectionMode`（0=单选 1=多选 2=扩展多选），选中项用 `selectedIndex` / `selectedKeys` 表达；跨事件取选中结果用 `控件_取选择项(列表)` 或对应取值命令，参数形态以本卡「本控件命令族」为准。
- 条目点击/双击/编辑/重排/右键都是独立事件，处理器参数各不相同（例：`项目重排(原索引, 新索引, 数量)`），不要按 `Button` 的空参数习惯写。
- 拖拽排序要显式 `dragSort`，可编辑字段要声明 `editableFields`；两者都关着时用户拖拽/双击不会有任何反应，不要误判成 bug。
- 树形与分组用 `treeMode` / `groupMode` + `indentWidth`，比嵌两层 `Container` 手动缩进更省，滚动条外观用 `scrollbarWidth`/`scrollY` 调。
- 超大批量条目用 `virtualItemCount` 走虚拟形态（与 `RichList` 同一思路），逐条添加会压死界面线程。

```lcpp
局部 NE列表框 城市列表 = 控件_创建NE列表框(当前窗口, 24, 120, 280, 320, "城市列表", "城市列表", 6)
控件_添加项目(城市列表, "杭州")
控件_添加项目(城市列表, "上海")
控件_设置选择项(城市列表, 0)
```
