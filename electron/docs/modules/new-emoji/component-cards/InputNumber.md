# InputNumber 数字输入框 InputNumber · 惯用要点与红线

- 数值型录入用它，不要用 `Input` 再手工 `到整数`：`min`/`max`/`step`/`precision`/`stepStrictly` 由控件自己约束，越界与步长行为一致。
- 读写走通用命令 `控件_取数值(控件)`（返回 `整数型`）与 `控件_设置数值(控件, 值)`；需要小数精度时按清单 `precision` 配置，字符串转换只在展示层做。
- 空文本/无法转换的内容经 `到整数` 会得到 0——校验「用户是否真的填了」要看控件取值与业务初值，不要拿 0 直接当有效输入。
- `数值变化` 事件不带参数，处理器内重新 `控件_取数值`；用它做即时搜索时必须节流，别每次击键都触发查询或重建表格。
- 步进按钮触发的变化与键盘输入触发的变化在清单里是同一个 `数值变化`，需要区分来源时用「是否失焦」或提交按钮确认，而不是猜。

```lcpp
局部 NE数字输入框 数量输入 = 控件_创建NE数字输入框(当前窗口, 150, 130, 280, 40, "1", "数量输入", 4)
局部 整数型 数量 = 控件_取数值(数量输入)
如果 (数量 <= 0)
  控件_设置数值(数量输入, 1)
如果结束
```
