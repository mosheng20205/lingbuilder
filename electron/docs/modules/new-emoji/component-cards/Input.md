# Input 输入框 Input · 惯用要点与红线

- 单行录入用 `Input`，多行长文本用 `EditBox`（`multiline` 语义不同，别在 `Input` 上硬撑多行）。
- 读值统一走通用命令 `控件_取文本(控件)`；设计器模型控件可用成员语法 `控件名.内容`。写值用 `控件_设置文本(控件, "…")`。
- 校验回显用清单属性 `validateState`：0=普通 1=成功 2=警告 3=错误；配合 `placeholder` 提示、`clearable` 一键清空、`maxLength` 限长、`password` 遮罩，比自己截字符串可靠。
- `文本变化` 事件在清单里不带参数，处理器写空括号；需要「输入即时过滤」时把重活放到工作线程，界面侧只做计数或节流刷新，禁止在事件里做同步等待。
- 只读回显（比如把计算结果给用户看）改用 `Text`，别用 `readonly` 输入框冒充标签，键盘焦点顺序会变脏。

```lcpp
局部 NE输入框 姓名输入 = 控件_创建NE输入框(当前窗口, 150, 26, 280, 40, "", "姓名输入", 2)
局部 文本型 姓名 = 控件_取文本(姓名输入)
```
