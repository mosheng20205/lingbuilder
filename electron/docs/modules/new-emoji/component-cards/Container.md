# Container 容器 Container · 惯用要点与红线

- 容器是**相对坐标**：子控件的 `x/y` 相对容器左上角，所以整块界面可以只搬容器一个坐标。绝对坐标一律按 DPI 后的逻辑像素（dip）写，不是物理像素。
- 根容器建议先建满窗尺寸，再把后续控件都挂在它下面，滚动区域与主题换肤都只需处理一个节点：`控件_创建NE容器(当前窗口, 0, 0, 宽, 高, "根容器", "MKROOT", 1)`。
- 声明了 `flowEnabled`/流式布局的容器不要再手工摆子控件坐标，两者混用会让重排结果与画布不一致。
- 跨父容器移动/复制子控件必须保持子树与同级顺序；需要「挪到别的面板」时用统一布局操作，不要在源码里删了重建（会丢事件绑定与标记）。
- 容器可以嵌在标签页里（父级支持 `tabPage`），但不要把整窗都塞进一个 `TabPage` 又同时开根容器，页面切换与初始可见性会互相覆盖。
- 滚动与虚拟列表场景优先用 `RichList`/`Table` 的虚拟化，`Container` 自造滚动会在高分屏与滚轮增量上反复出问题。

```lcpp
局部 NE容器 根容器 = 控件_创建NE容器(当前窗口, 0, 0, 900, 560, "根容器", "MKROOT", 1)
局部 NE文本 标题 = 控件_创建NE文本(根容器, 24, 18, 400, 30, "🧩 组件总览", "标题文本", 2)
```
