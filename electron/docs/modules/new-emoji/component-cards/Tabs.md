# Tabs 标签页 Tabs · 惯用要点与红线

- Tabs 是**分页容器**：页面内容用 `父级=页签` 的后代控件表达，切换页签即显隐该页；不要「切页签时手工 `控件_设置可见` 一堆控件」模拟分页，那会与设计器行为冲突。
- 页面集合属性 `items` 每项带 `id`：**不要手写或猜测页面元素 ID**，由设计器/生成器维护；代码里只按索引或标题定位。跨页共享的控件放在 Tabs 之外。
- 外观与行为属性各有默认：`tabType` 0=线条 1=卡片 2=边框卡片；`position` 0=顶部 1=右侧 2=底部 3=左侧；`headerAlign` 0=左 1=中 2=右；`closable`/`addable`/`editable`/`reorderEnabled`/`detachEnabled` 控制关闭、新增、重排与拖出。
- `contentVisible` 有副作用（早期 setter 会连带改内容可见性），只通过设计器属性设置，不要用 `@` 内嵌 C++ 直接调 `EU_Set*` 绕过顺序。
- 代码路径设置标签项用 `NE标签页_设置标签项(页签, "标签页 1|标签页 2|标签页 3")`（竖线分隔）；空 Tabs 上屏时原生会把默认项的 kv 文本画成可见文字，示例侧一律显式 `设置标签项` 规避。
- 自有事件参数较全：`选择变化(整数型 选中索引, 整数型 项目数量, 整数型 动作)`、`关闭标签页(整数型 项目索引)`、`新增标签页(整数型 新项目索引)`、`拖拽重排(整数型 原索引, 整数型 新索引, 整数型 项目总数)`；`动作` 语义见本卡事件表说明。

```lcpp
局部 NE标签页 页签 = 控件_创建NE标签页(当前窗口, 24, 64, 840, 60, "页签", "页签", 2)
NE标签页_设置标签项(页签, "标签页 1|标签页 2|标签页 3")
NE标签页_绑定选择变化(页签, &页签选择变化)
```
