# Menu 菜单 Menu · 惯用要点与红线

- 菜单项是**换行分隔的文本协议**，前缀 `>` 表示下一级子菜单：`NE菜单_设置项目(菜单, “🏠 首页\n📊 项目\n>📋 设计稿\n⚙️ 设置”)`；整串用中文引号 `“ ”` 包裹（内含换行与引号时最稳）。
- 菜单项的图标/快捷键/元数据用独立命令按**索引**设置：`NE菜单_设置项目图标(菜单, 0, "⭐")`、`NE菜单_设置项目快捷键(菜单, 5, "F1")`；索引随 `设置项目` 变化，重设项目后要一并重设这些附属信息。
- 弹出形态由属性决定：`popupTrigger` = `none`（仅代码控制）/`dropdown`（按钮下拉）/`right_click`/`left_click`/`hover`；绑按钮触发时用 `NE_EU_SetElementPopup(当前窗口, 按钮, 菜单, 触发方式)`，代码里主动开关用 `NE_EU_SetPopupOpen(当前窗口, 菜单, 1/0)`。
- 两个自有事件签名不同，别混用：`菜单命令(整数型 项目索引, 文本型 菜单路径, 文本型 命令)` 用于选择项落地，`右键菜单(整数型 项目索引, 整数型 附加值一, 整数型 附加值二)` 用于右键派发。
- 菜单只负责「选了哪项」，动作仍走 `CommandService` 风格的中文命令或子程序；不要在 `菜单命令` 处理器里内嵌大段业务逻辑，超过约 30 行就下沉到功能库。
- 跨事件读状态用 `NE菜单_取状态` / `NE菜单_取活动路径`；工作线程要改菜单只能走 `NE菜单_投递*` 族，禁止把控件引用传进线程。

```lcpp
局部 NE菜单 主菜单 = 控件_创建NE菜单(当前窗口, 24, 60, 260, 420, "主菜单", "主菜单", 1)
NE菜单_设置项目(主菜单, “🏠 首页\n📊 项目\n⚙️ 设置”)
NE菜单_绑定菜单命令(主菜单, &菜单命令被选择)
```
