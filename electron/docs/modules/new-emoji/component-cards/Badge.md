# Badge 徽标 Badge · 惯用要点与红线

- 徽标是**挂在别的控件角上的计数/状态标记**：`placement` 决定贴哪条边，`offsetX`/`offsetY` 做像素微调，`standalone` 用于不依附宿主单独显示。
- 数值与阈值：`value` 是当前值，`max` 是封顶（超过显示 `99+` 这类形态），`showZero` 控制 0 是否还画出来；清零要显式设 0，别靠隐藏宿主控件。
- 类型 `badgeType`：0=信息 1=成功 2=警告 3=错误；纯代码路径已验证 `NE_EU_SetBadgeType(当前窗口, 徽标, 1)`，语义与设计器属性同一套取值。
- `dot` 只留小红点不带数字，适合「有未读」这种二态提示；需要计数的场景不要滥用点态。
- 徽标本身可交互：`NE徽标_绑定鼠标抬起(徽标, &徽标被抬起)` 处理器参数为 `(整数型 横坐标, 整数型 纵坐标, 整数型 鼠标按钮)`，鼠标按下/双击同形；徽标没有「被点击」事件，别按按钮习惯写。
- 徽标文本用 `NE徽标_设置文本(徽标, 到文本(计数))`；跨事件先 `通过标记文本获取NE徽标("…")` 重取引用。工作线程要改徽标只能走投递族 `NE徽标_投递设置文本`，禁止把控件引用传进线程。

```lcpp
局部 NE徽标 购物车徽标 = 控件_创建NE徽标(当前窗口, 24, 70, 72, 44, "3", "购物车徽标", 2)
NE_EU_SetBadgeType(当前窗口, 购物车徽标, 1)
NE徽标_绑定鼠标抬起(购物车徽标, &徽标被抬起)
```
