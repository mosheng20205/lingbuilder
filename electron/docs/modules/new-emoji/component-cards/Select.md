# Select 选择器 Select · 惯用要点与红线

- 这是 new_emoji 的「下拉选择」控件（中文类型 `NE选择器`），不是 `NE列表框`，也不是 `NE下拉菜单`（后者是弹出菜单触发器）。
- 选项用 `NE选择器_设置选项(控件, "杭州 🌸|上海 🏙️|北京 🏛️")`，**竖线分隔**；设计器模型里对应 `options` 属性。海量选项改用 `NE虚拟选择器`。
- 取值是索引不是文本：`控件_取选择项(控件)` 返回 `整数型`（从 0 开始，未选为 -1），默认项用 `控件_设置选择项(控件, 0)` 显式设置，别假设自动选中。
- 需要「选中项文本」时用索引去查自己那份竖线文本（或经 `格式化文本` 组装），不要猜存在 `控件_取选择文本` 这类命令——以 `lingbuilder.module.info` 的 `query` 结果为准。
- `选择变化` 事件清单里不带参数，处理器内重新 `控件_取选择项`；联动刷新多个控件时把索引存成窗口成员，避免各处重复读界面。

```lcpp
局部 NE选择器 城市选择 = 控件_创建NE选择器(当前窗口, 150, 78, 280, 40, "选择城市", "城市选择", 3)
NE选择器_设置选项(城市选择, "杭州 🌸|上海 🏙️|北京 🏛️")
控件_设置选择项(城市选择, 0)
局部 整数型 城市序号 = 控件_取选择项(城市选择)
```
