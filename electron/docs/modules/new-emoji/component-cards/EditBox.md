# EditBox 编辑框 EditBox · 惯用要点与红线

- 定位是多行文本编辑（日志、备注、脚本片段）；`multiline` 决定多行行为，`readonly` 用于只读长文本展示。
- 内容读写同样走 `控件_取文本` / `控件_设置文本`；要往里塞带引号、反斜杠或大段 HTML/JSON 的固定文本，用 `.lcpp` 的多行文本块（`变量 = """` 起、单独一行 `"""` 结束），不要在字符串里手工拼 `\n` 与转义。
- `文本变化` 事件不带参数；高频写入（比如工作线程逐行追加日志）必须节流，界面线程逐条追加会直接卡死。
- 中文内容一律走宽字符通用命令；不要为了「绕编码」把文本先转成字节集再塞进编辑框。
- 需要语法高亮/诊断的编辑器场景不属于本控件，应该让用户在 IDE 编辑器里做，运行时界面只放纯文本域。

```lcpp
局部 NE编辑框 日志区 = 控件_创建NE编辑框(当前窗口, 24, 120, 840, 300, "启动完成", "日志区", 5)
控件_设置文本(日志区, 日志区文本)
```
