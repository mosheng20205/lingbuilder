# Progress 进度条 Progress · 惯用要点与红线

- 值用通用命令读写：`控件_设置数值(进度条, 60)`、`控件_取数值(进度条)`；模型属性里 `percentage` 是同一语义的声明式写法，两者不要一边设一边读导致回跳。
- `status` 0=信息 1=成功 2=警告 3=错误：任务结束务必显式置成功/错误态，停在百分比数字上会让用户以为还在跑。
- `progressType` 支持条形/环形等形态，环形与子弹进度另有 `RingProgress`、`BulletProgress` 专用控件，别用 `strokeWidth`+裁剪去仿。
- 文本显示由 `showText`/`textInside`/`textTemplate` 控制；需要「构建中 3/8」这类自定义文案用 `textTemplate`，不要另外盖一个 `NE文本` 手工同步（必然漏更新）。
- 高频进度（每秒几十次）不要逐次刷界面：工作线程只推进 `原子整数_增加` 计数，界面侧用 `线程_取进度`/`线程_报告进度` 的低频读取或 80ms 节流更新。
- 进度与真实工作必须同源：只有任务真的推进才改数值，禁止用定时器「假进度」凑动画。

```lcpp
局部 NE进度条 构建进度 = 控件_创建NE进度条(当前窗口, 24, 72, 520, 36, "构建进度", "构建进度", 1)
控件_设置数值(构建进度, 35)
```
