# Button 按钮 Button · 惯用要点与红线

- 事件绑定用 `NE按钮_绑定被点击(控件, &处理器)`；清单里 `被点击` 事件无参数，处理器就写空括号，处理器名前置 `&`。鼠标类事件（按下/抬起/双击/滚轮）才有 `横坐标/纵坐标/鼠标按钮` 参数。
- 样式属性 `variant` 按清单取值：0=默认 1=主要 2=成功 3=警告 4=危险 5=文本 6=信息；纯代码路径已验证用 `NE_EU_SetButtonVariant(当前窗口, 控件, 1)`（1 主按钮、2/3 强调、5 弱化），同一屏最多一个「主要」。尺寸用 `size`（0=默认 1=中等 2=小型 3=超小）。
- 状态切换用通用命令：`控件_设置启用(控件, 假)`、`控件_设置可见(控件, 真)`；不要用「换个文本」假装禁用，那会让用户继续点到。
- 按钮文本更新走 `控件_设置文本`；需要「加载中」反馈时改 `loading` 属性（设计器模型）或用 `NE_EU_SetButtonVariant` 切到弱化样式，别自建定时器。
- 无边框窗口上的「最小化/关闭」不要写 Win32 消息，改用 `NE图标按钮` + `NE_设置元素窗口命令(窗口, 按钮, 命令编号)`（见 IconButton 卡）。
- 一个窗口里按钮超过四五个就按功能分组到 `Tabs` 或 `Container`，别用绝对坐标硬排；坐标一律窗口左上角 DIP。

```lcpp
局部 NE按钮 提交按钮 = 控件_创建NE按钮(当前窗口, 150, 228, 180, 44, "✅ 提交", "提交", 11)
NE_EU_SetButtonVariant(当前窗口, 提交按钮, 1)
NE按钮_绑定被点击(提交按钮, &提交被点击)
```
