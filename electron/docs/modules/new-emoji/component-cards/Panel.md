# Panel 面板 Panel · 惯用要点与红线

- 定位是**带样式的可视分组容器**（背景/边框/圆角/内边距五个属性），子控件用 `父级=面板` 挂进去；纯布局流排交给 `Container`/`Layout`，别把 Panel 当弹性容器。
- 面板自身没有专属事件，交互（点击/悬停）仍挂在里面的按钮或文本上；需要整块可点时，用同坐标的 `NE图标按钮` 覆盖热区（画廊里的横幅热区就是这么做的），不要给 Panel 编造 `绑定被点击`。
- 坐标是**相对父级**的：面板移动后其子控件随动；跨面板引用子控件仍按「标记文本」查，标记在同一窗口 + 同一具体控件类型内唯一。
- 嵌套层级控制在 2~3 层内：`Container → Panel → 控件` 足够；再深会让滚动、裁剪和 DPI 换算难以排查。
- 复用一组卡片样式时把「面板 + 内部控件」抽成函数库里的一个创建函数（参数化坐标与文本），不要在事件里复制粘贴二十遍创建语句。

```lcpp
局部 NE面板 主题卡 = 控件_创建NE面板(当前窗口, 22, 112, 380, 70, "主题卡", "主题卡", 7)
局部 NE文本 主题标题 = 控件_创建NE文本(主题卡, 14, 12, 76, 24, "🎨 主题", "主题标题", 8)
```
