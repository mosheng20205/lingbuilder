# 剪贴板模块 1.1 使用说明

模块 ID：`lingbuilder.system.clipboard`
目标：Windows Win32、Windows x64（MSVC）
依赖：无额外 DLL

本模块同时提供 Unicode 文本、静态图片和原始 GIF 字节集剪贴板能力。图片参数和返回值都是 `字节集`，在生成的 C++ 中对应 `std::vector<unsigned char>`。

## 命令

| 命令 | 返回值 | 说明 |
|---|---|---|
| `剪贴板_置文本(文本)` | 逻辑型 | 写入 Unicode 文本。成功返回真。 |
| `剪贴板_取文本()` | 文本型 | 读取 Unicode 文本；没有文本或无法打开剪贴板时返回空文本。 |
| `剪贴板_是否有文本()` | 逻辑型 | 判断是否存在 `CF_UNICODETEXT`。 |
| `剪贴板_置图片字节集(图片数据)` | 逻辑型 | 自动识别 GIF、DIB/DIBV5 或 BMP 文件字节；GIF 会走动画路径。 |
| `剪贴板_取图片字节集()` | 字节集 | 优先取原始 GIF，其次取 DIB/DIBV5；只有 `CF_BITMAP` 时转换为 32 位 DIB。 |
| `剪贴板_是否有图片()` | 逻辑型 | 判断是否有 GIF、DIB、DIBV5 或位图格式。 |
| `剪贴板_取图片格式()` | 文本型 | 返回 `GIF`、`CF_DIBV5`、`CF_DIB`、`CF_BITMAP` 或空文本。 |
| `剪贴板_置GIF字节集(GIF数据)` | 逻辑型 | 校验 GIF87a/GIF89a 头和尺寸后，原样写入 GIF、`image/gif` 和 HTML 格式。 |
| `剪贴板_取GIF字节集()` | 字节集 | 读取 GIF 或 `image/gif` 格式中的原始 GIF 字节；没有 GIF 时返回空字节集。 |
| `剪贴板_清空()` | 逻辑型 | 清空当前系统剪贴板。 |

## 图片格式

`剪贴板_置图片字节集` 接受两种静态图片输入：

- 原始 DIB/DIBV5：字节集第一项是 `BITMAPINFOHEADER`、`BITMAPV4HEADER` 或 `BITMAPV5HEADER` 的大小。
- BMP 文件：带 `BM` 文件头的完整 BMP。写入时去掉 `BITMAPFILEHEADER`，按 `CF_DIB` 或 `CF_DIBV5` 提供给剪贴板。

单个图片或 GIF 字节集上限为 256 MB。格式不完整、尺寸为零、尺寸为负或超过上限时返回假，不会清空原剪贴板。

从其它程序复制的 `CF_BITMAP` 没有可直接复制的原始 DIB，读取时会转换成 32 位、未压缩、底部向上的 DIB。需要保存 alpha、调色板或其它原始信息时，应优先使用 `CF_DIBV5` 或 GIF。

## GIF 动图

`剪贴板_置GIF字节集` 不解码、不重编码 GIF，因此 GIF 中的全部帧、帧延时和循环信息都会保留。写入时提供三个剪贴板格式：

1. 注册的 `GIF` 格式，供支持原始 GIF 的图像软件读取。
2. 标准 MIME `image/gif` 格式，供按 MIME 查询剪贴板的程序读取。
3. `HTML Format`，其中包含 `data:image/gif;base64,...` 图片，供浏览器和网页编辑器粘贴。

`剪贴板_置图片字节集` 检测到 `GIF87a` 或 `GIF89a` 头时会自动使用同一动画路径。目标程序如果只请求静态 `CF_DIB`，它可能只显示静态预览；这是目标程序的剪贴板格式选择，不是模块丢帧。

```lcpp
// 需要同时启用 lingbuilder.std.bytes，以便构造字节集。
局部 字节集 动图数据 = 字节集_Base64解码("R0lGODlhAQABAIAAAAAAAP///ywAAAAAAQABAAACAUwAOw==")
如果 剪贴板_置GIF字节集(动图数据)
    调试输出("GIF 已写入剪贴板，原始帧不会被转换")
否则
    调试输出("GIF 数据无效或系统剪贴板当前不可用")
如果结束

局部 字节集 剪贴板图片 = 剪贴板_取图片字节集()
调试输出(剪贴板_取图片格式())
```

上例使用一个最小 GIF 作为可复制的完整输入；替换为任意合法 GIF 字节集（包括多帧 GIF）即可保留动画。`剪贴板_取GIF字节集` 只读取原始 GIF，不会把 HTML 或静态 DIB 误报为 GIF。

## 失败与线程边界

Windows 剪贴板由系统桌面共享。打开剪贴板失败、数据格式不受支持、内存不足或目标程序占用剪贴板时，写入命令返回假，读取命令返回空值。命令应在窗口 UI 线程或应用自己的串行任务中调用；不要在高频工作线程中反复抢占系统剪贴板。
