# 大数运算模块

模块 ID：`lingbuilder.std.bigint`  
版本：`1.0.0`  
适用平台：Windows / MSVC Win32、x64；普通 Win32 与 new_emoji 后端共用同一确定性 C++17 运行时。

大数运算模块提供**任意长度整数的精确运算**，突破 64 位整数约 19 位的上限：乘方累乘、金融大额计算、哈希/进制中间值等场景都不会再溢出。数值内部按十进制存储，除法向零取整，余数符号与被除数一致。

句柄规则与缓冲区模块一致：`大数_创建` / `大数_从整数` 返回 64 位句柄（0 表示失败），`大数_销毁` 回收。四则运算**不修改操作数**，每次返回新大数句柄。

## 命令一览

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `大数_创建(十进制文本)` | 大数 | 解析十进制整数字符串，格式非法返回 0 |
| `大数_从整数(整数)` | 大数 | 64 位整数转大数 |
| `大数_到文本(大数)` | 文本型 | 十进制文本，句柄无效返回空文本 |
| `大数_销毁(大数)` | 逻辑型 | 回收句柄 |
| `大数_加(左值, 右值)` | 大数 | 和 |
| `大数_减(左值, 右值)` | 大数 | 差 |
| `大数_乘(左值, 右值)` | 大数 | 积 |
| `大数_除(被除数, 除数)` | 大数 | 商（向零取整），除数为 0 返回 0 |
| `大数_求余(被除数, 除数)` | 大数 | 余数（符号同被除数），除数为 0 返回 0 |
| `大数_取符号(大数)` | 整数型 | 1 / 0 / -1，句柄无效返回 -2 |
| `大数_是否等于/大于/小于/大于等于/小于等于` | 逻辑型 | 六向比较 |

## 基本用法

```lcpp
局部 大数 天文数字
天文数字 = 大数_创建("123456789012345678901234567890")
局部 大数 基数
基数 = 大数_从整数(1)

调试输出(大数_到文本(大数_加(天文数字, 基数)))
调试输出(大数_到文本(大数_乘(天文数字, 大数_从整数(3))))
调试输出(大数_是否大于(天文数字, 大数_从整数(0)))

局部 大数 商
商 = 大数_除(天文数字, 大数_从整数(7))
调试输出(大数_到文本(商))
大数_销毁(天文数字)
```

## 注意事项

- 本模块只支持**整数**：小数场景请用文本或 `double`（会损失精度）。
- 四则运算产生新句柄，长循环里注意用 `大数_销毁` 回收不再使用的中间结果。
- 输入文本只允许开头一个正负号加数字；其余字符视为格式非法，命令返回句柄 0。
