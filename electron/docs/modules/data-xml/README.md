提供 XML 文本转义、节点生成和简单节点内容读取，不执行外部实体。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 5 条）

### 全部命令

#### XML_转义文本

- 签名：`XML_转义文本(文本)`
- 返回值：文本型
- 说明：转义 XML 文本节点中的特殊字符。
- 参数：
  - 文本（文本型）：要写入 XML 文本节点的原始内容；与号、尖括号、双引号和单引号会被替换为实体。
- 示例：

```
XML_转义文本("<中文>")
```


#### XML_反转义文本

- 签名：`XML_反转义文本(文本)`
- 返回值：文本型
- 说明：还原本模块支持的五种预定义 XML 实体。
- 参数：
  - 文本（文本型）：要还原的文本，仅处理与号、lt、gt、quot、apos 五种预定义实体。

#### XML_生成节点

- 签名：`XML_生成节点(节点名, 内容)`
- 返回值：文本型
- 说明：生成包含安全转义文本的简单 XML 节点；非法节点名返回空文本。
- 参数：
  - 节点名（文本型）：XML 元素名，首字符只能是字母、下划线或冒号，其余可含字母数字、下划线、冒号、点和短横；非法时命令返回空文本或假。
  - 内容（文本型）：节点内的文本内容，运行时自动做 XML 转义，可以传空文本生成空节点。

#### XML_是否包含节点

- 签名：`XML_是否包含节点(XML文本, 节点名)`
- 返回值：逻辑型
- 说明：判断 XML 文本是否包含指定简单节点。
- 参数：
  - XML文本（文本型）：要搜索的 XML 文本，按 <节点名> 开始标签做字符串匹配，不做完整 XML 解析。
  - 节点名（文本型）：XML 元素名，首字符只能是字母、下划线或冒号，其余可含字母数字、下划线、冒号、点和短横；非法时命令返回空文本或假。

#### XML_取节点文本

- 签名：`XML_取节点文本(XML文本, 节点名)`
- 返回值：文本型
- 说明：读取第一个指定简单节点的文本内容并反转义。
- 参数：
  - XML文本（文本型）：要搜索的 XML 文本，按 <节点名> 开始标签做字符串匹配，不做完整 XML 解析。
  - 节点名（文本型）：要读取的元素名，命名规则同生成节点；只返回首个匹配节点的内容并自动反转义。
