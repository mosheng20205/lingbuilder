# 邮件接收模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.net.pop3` |
| 版本 | 1.0.0 |
| 分类 | 网络 |
| 命令数 | 18 |

通过 POP3 协议接收邮件：连接后取回邮件并解析主题、发件人、日期、正文与附件，支持 SSL(TLS) 加密连接（不校验服务器证书）。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 18 条）

### 全部命令

#### POP3_连接

- 签名：`POP3_连接(服务器, 端口, 用户名, 密码, 是否SSL)`
- 返回值：逻辑型
- 说明：连接 POP3 收信服务器并完成登录；失败返回假，用 POP3_取错误 查看原因。
- 参数：
  - 服务器（文本型）：POP3 服务器主机名或 IP。
  - 端口（整数型）：服务端口：明文 110、SSL 995；1 到 65535。
  - 用户名（文本型）：登录账号。
  - 密码（文本型）：登录密码。
  - 是否SSL（逻辑型）：真使用 SSL/TLS 加密连接（不校验服务器证书），假使用明文。
- 示例：

```
POP3_连接("pop.example.com", 995, "user@example.com", "密码", 真)
```


#### POP3_断开

- 签名：`POP3_断开()`
- 返回值：空
- 说明：断开与收信服务器的连接。

#### POP3_是否已连接

- 签名：`POP3_是否已连接()`
- 返回值：逻辑型
- 说明：判断当前是否已连接收信服务器。

#### POP3_取邮件数量

- 签名：`POP3_取邮件数量()`
- 返回值：整数型
- 说明：返回邮箱中的邮件数量；未连接返回 -1。

#### POP3_取邮箱总大小

- 签名：`POP3_取邮箱总大小()`
- 返回值：整数型
- 说明：返回邮箱中全部邮件的总字节数；未连接返回 -1。

#### POP3_取邮件大小

- 签名：`POP3_取邮件大小(序号)`
- 返回值：整数型
- 说明：返回指定邮件的字节数。
- 参数：
  - 序号（整数型）：邮件序号，从 1 起。

#### POP3_接收邮件

- 签名：`POP3_接收邮件(序号)`
- 返回值：逻辑型
- 说明：取回指定邮件的完整内容并解析为当前邮件上下文，之后用 取主题/取发件人/取正文文本/附件族 命令读取。
- 参数：
  - 序号（整数型）：邮件序号，从 1 起。

#### POP3_删除邮件

- 签名：`POP3_删除邮件(序号)`
- 返回值：逻辑型
- 说明：把指定邮件标记为删除；真正删除发生在 QUIT 时，可用 POP3_复位删除 撤销。
- 参数：
  - 序号（整数型）：要删除的邮件序号，从 1 起。

#### POP3_复位删除

- 签名：`POP3_复位删除()`
- 返回值：逻辑型
- 说明：撤销本次连接中所有删除标记。

#### POP3_取主题

- 签名：`POP3_取主题()`
- 返回值：文本型
- 说明：返回已接收邮件的主题（自动解码编码字）。

#### POP3_取发件人

- 签名：`POP3_取发件人()`
- 返回值：文本型
- 说明：返回已接收邮件的发件人。

#### POP3_取日期

- 签名：`POP3_取日期()`
- 返回值：文本型
- 说明：返回已接收邮件的日期头。

#### POP3_取正文文本

- 签名：`POP3_取正文文本()`
- 返回值：文本型
- 说明：返回已接收邮件的纯文本正文。

#### POP3_取网页正文

- 签名：`POP3_取网页正文()`
- 返回值：文本型
- 说明：返回已接收邮件的 HTML 正文。

#### POP3_取附件个数

- 签名：`POP3_取附件个数()`
- 返回值：整数型
- 说明：返回已接收邮件的附件数量。

#### POP3_取附件名称

- 签名：`POP3_取附件名称(附件序号)`
- 返回值：文本型
- 说明：返回指定附件的文件名。
- 参数：
  - 附件序号（整数型）：附件序号，从 0 起。

#### POP3_保存附件

- 签名：`POP3_保存附件(附件序号, 保存路径)`
- 返回值：逻辑型
- 说明：把指定附件内容写入目标文件。
- 参数：
  - 附件序号（整数型）：附件序号，从 0 起。
  - 保存路径（文本型）：保存的完整文件路径，所在目录必须已存在。

#### POP3_取错误

- 签名：`POP3_取错误()`
- 返回值：文本型
- 说明：返回最近一次 POP3 错误或服务端响应。
