## 命令参考（共 8 条）

### 全部命令

#### 菜单_创建

- 签名：`菜单_创建()`
- 返回值：长整数型
- 说明：创建菜单栏。

#### 菜单_创建弹出菜单

- 签名：`菜单_创建弹出菜单()`
- 返回值：长整数型
- 说明：创建弹出菜单。

#### 菜单_添加项目

- 签名：`菜单_添加项目(菜单句柄, 命令ID, 标题)`
- 返回值：逻辑型
- 说明：添加普通菜单项。
- 参数：
  - 菜单句柄（句柄）：菜单_创建 或 菜单_创建弹出菜单 返回的菜单句柄；已销毁或仍挂在窗口上的菜单不要重复使用。
  - 命令ID（整数型）：菜单项被点击时由 WM_COMMAND 收到的命令 ID，同一菜单内应唯一。
  - 标题（文本型）：菜单项显示的文本。

#### 菜单_添加子菜单

- 签名：`菜单_添加子菜单(菜单句柄, 子菜单句柄, 标题)`
- 返回值：逻辑型
- 说明：添加子菜单。
- 参数：
  - 菜单句柄（句柄）：菜单_创建 或 菜单_创建弹出菜单 返回的菜单句柄；已销毁或仍挂在窗口上的菜单不要重复使用。
  - 子菜单句柄（句柄）：作为子菜单挂载的弹出菜单句柄；挂载后不要单独销毁它。
  - 标题（文本型）：父菜单上显示的子菜单标题。

#### 菜单_添加分隔线

- 签名：`菜单_添加分隔线(菜单句柄)`
- 返回值：逻辑型
- 说明：添加分隔线。
- 参数：
  - 菜单句柄（句柄）：菜单_创建 或 菜单_创建弹出菜单 返回的菜单句柄；已销毁或仍挂在窗口上的菜单不要重复使用。

#### 菜单_设置到窗口

- 签名：`菜单_设置到窗口(窗口句柄, 菜单句柄)`
- 返回值：逻辑型
- 说明：把菜单设置为窗口菜单栏。
- 参数：
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。
  - 菜单句柄（句柄）：菜单_创建弹出菜单 返回的弹出菜单句柄。传 0 表示移除窗口现有菜单。

#### 菜单_弹出并取命令

- 签名：`菜单_弹出并取命令(菜单句柄, 窗口句柄, 横坐标, 纵坐标)`
- 返回值：整数型
- 说明：显示弹出菜单并返回选择的命令 ID。
- 参数：
  - 菜单句柄（句柄）：菜单_创建弹出菜单 返回的弹出菜单句柄。
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。用于确定菜单所属线程。
  - 横坐标（整数型）：菜单左上角的屏幕横坐标，物理像素。
  - 纵坐标（整数型）：菜单左上角的屏幕纵坐标，物理像素。

#### 菜单_销毁

- 签名：`菜单_销毁(菜单句柄)`
- 返回值：逻辑型
- 说明：销毁未附加或不再使用的菜单。
- 参数：
  - 菜单句柄（句柄）：菜单_创建 或 菜单_创建弹出菜单 返回的菜单句柄；已销毁或仍挂在窗口上的菜单不要重复使用。仍挂在窗口上的菜单不能销毁。
