# SMTP邮件模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.net.mail` |
| 版本 | 1.0.0 |
| 分类 | 网络 |

提供普通 SMTP 或局域网调试服务发送；当前版本不支持 TLS，遇到要求 STARTTLS 的服务会明确失败。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### SMTP_发送普通邮件

- 签名：`SMTP_发送普通邮件(主机, 端口, 用户名, 密码, 发件人, 收件人, 主题, 正文)`
- 返回值：逻辑型
- 说明：通过不加密 SMTP 发送 UTF-8 文本邮件。
- 参数：
  - 主机（文本型）：SMTP 服务器主机名或 IP，同时尝试 IPv4 与 IPv6。
  - 端口（整数型）：SMTP 端口，1 到 65535；本模块不启用 TLS，服务端强制 STARTTLS 时会失败。
  - 用户名（文本型）：登录账号；空文本表示跳过 AUTH LOGIN 匿名发送。
  - 密码（文本型）：登录密码，随 AUTH LOGIN 以 Base64 明文传输，仅在可信内网或回环服务上使用。
  - 发件人（文本型）：MAIL FROM 使用的发件地址，不写尖括号。
  - 收件人（文本型）：RCPT TO 使用的单个收件地址；需要多个收件人时自行循环发送。
  - 主题（文本型）：邮件主题，按 UTF-8 Base64 编码为编码字形式写入标题头。
  - 正文（文本型）：纯文本正文，按 UTF-8 以 8bit 传输；每步服务响应等待超时固定 30 秒。

#### SMTP_发送HTML邮件

- 签名：`SMTP_发送HTML邮件(主机, 端口, 用户名, 密码, 发件人, 收件人, 主题, HTML正文)`
- 返回值：逻辑型
- 说明：发送正文为 HTML 格式的邮件（Content-Type: text/html），收件端以富文本呈现。
- 参数：
  - 主机（文本型）：SMTP 服务器主机名或 IP。
  - 端口（整数型）：SMTP 端口，1 到 65535；本模块不启用 TLS。
  - 用户名（文本型）：登录账号；空文本跳过认证。
  - 密码（文本型）：登录密码。
  - 发件人（文本型）：发件地址，不写尖括号。
  - 收件人（文本型）：收件地址，不写尖括号。
  - 主题（文本型）：邮件主题，按 UTF-8 Base64 编码字写入。
  - HTML正文（文本型）：完整 HTML 文档或片段，按 UTF-8 传输。

#### SMTP_取错误

- 签名：`SMTP_取错误()`
- 返回值：文本型
- 说明：返回最近 SMTP 错误或服务端响应。

#### SMTP_发送附件邮件

- 签名：`SMTP_发送附件邮件(主机, 端口, 用户名, 密码, 发件人, 收件人, 主题, 正文, 是否HTML, 附件列表)`
- 返回值：逻辑型
- 说明：发送带附件的邮件（multipart/mixed，正文可选纯文本或 HTML），全部附件上传成功才返回真。
- 参数：
  - 主机（文本型）：SMTP 服务器主机名或 IP。
  - 端口（整数型）：SMTP 端口，1 到 65535；本模块不启用 TLS。
  - 用户名（文本型）：登录账号；空文本跳过认证。
  - 密码（文本型）：登录密码。
  - 发件人（文本型）：发件地址，不写尖括号。
  - 收件人（文本型）：收件地址，不写尖括号。
  - 主题（文本型）：邮件主题，按 UTF-8 Base64 编码字写入。
  - 正文（文本型）：邮件正文；按 是否HTML 参数决定按纯文本或 HTML 解析。
  - 是否HTML（逻辑型）：真时正文按 text/html 传输，假时按 text/plain。
  - 附件列表（数组）：附件完整路径的文本型数组；每个文件按 Base64 编码为独立附件部分，路径中不能含有英文双引号。
