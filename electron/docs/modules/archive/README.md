# ZIP压缩模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.archive` |
| 版本 | 1.1.0 |
| 分类 | 系统 |
| 命令数 | 9 |

通过 Windows 自带 tar.exe 的受控参数封装创建、解压和列出 ZIP，不开放任意命令行；内存字节集形态的 DEFLATE/ZLIB/GZIP 压缩解压由随包公共域 miniz 3.0.2 静态内联实现（随包 Botan 未编译 zlib、Windows 无系统 zlib，故不新增任何 DLL 依赖），失败统一返回空字节集并用 压缩_取错误() 给出中文原因。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 9 条）

### 全部命令

#### 压缩_ZIP创建

- 签名：`压缩_ZIP创建(来源路径, ZIP路径)`
- 返回值：逻辑型
- 说明：把文件或目录创建为 ZIP。
- 参数：
  - 来源路径（文本型）：要打包的文件或目录路径；以它的父目录为工作目录、文件名作为条目写入 ZIP。路径不能含双引号、回车或换行。
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。目标已存在时会被覆盖。

#### 压缩_ZIP解压

- 签名：`压缩_ZIP解压(ZIP路径, 目标目录)`
- 返回值：逻辑型
- 说明：解压 ZIP 到目标目录。
- 参数：
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。
  - 目标目录（文本型）：解压目标目录；目录不存在时会递归创建，路径不能含双引号、回车或换行。

#### 压缩_ZIP列出

- 签名：`压缩_ZIP列出(ZIP路径)`
- 返回值：文本型
- 说明：返回 ZIP 内文件列表。
- 参数：
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。返回的条目按行分隔，失败返回空文本。

#### 压缩_取错误

- 签名：`压缩_取错误()`
- 返回值：文本型
- 说明：返回最近压缩错误。

#### 压缩_DEFLATE解压

- 签名：`压缩_DEFLATE解压(数据)`
- 返回值：字节集
- 说明：把 raw deflate 字节流解压回原始字节集；失败返回空字节集，中文原因用 压缩_取错误() 查看。与 压缩_DEFLATE压缩 互为逆操作。
- 参数：
  - 数据（字节集）：raw deflate 流（RFC1951，无 zlib/gzip 容器头）；空字节集或截断流返回空字节集，解压输出超过 67108864 字节（#压缩_解压上限字节）时中止并返回空字节集。
- 示例：

```
局部 字节集 压缩流
压缩流 = 压缩_DEFLATE压缩(字节集_从文本("LingBuilder"))
调试输出(字节集_长度(压缩_DEFLATE解压(压缩流)))
```


#### 压缩_ZLIB解压

- 签名：`压缩_ZLIB解压(数据)`
- 返回值：字节集
- 说明：解压 zlib 容器字节流为原始字节集（Adler32 自动校验）；失败返回空字节集，原因用 压缩_取错误() 查看。
- 参数：
  - 数据（字节集）：zlib 容器流（RFC1950，CMF/FLG 头 + Adler32 校验，不支持 FDICT 预设字典）；头无效、截断或校验失败返回空字节集。
- 示例：

```
局部 字节集 明文
明文 = 压缩_ZLIB解压(压缩包数据)
调试输出(字节集_长度(明文))
```


#### 压缩_GZIP解压

- 签名：`压缩_GZIP解压(数据)`
- 返回值：字节集
- 说明：解压 gzip 容器字节流为原始字节集（CRC32 与 ISIZE 自动校验）；失败返回空字节集，原因用 压缩_取错误() 查看。与 压缩_GZIP压缩 互为逆操作。
- 参数：
  - 数据（字节集）：gzip 容器流（RFC1952，10 字节头 + deflate 正文 + CRC32/ISIZE 尾；FEXTRA/FNAME/FCOMMENT/FHCRC 可选字段自动跳过）；魔数、校验或长度不符时返回空字节集。
- 示例：

```
调试输出(字节集_长度(压缩_GZIP解压(压缩_GZIP压缩(字节集_从文本("压缩往返测试")))))
```


#### 压缩_DEFLATE压缩

- 签名：`压缩_DEFLATE压缩(数据)`
- 返回值：字节集
- 说明：把字节集压缩为 raw deflate 流（RFC1951，级别 6，无容器头）；失败返回空字节集，原因用 压缩_取错误() 查看。
- 参数：
  - 数据（字节集）：要压缩的原始字节集；空字节集返回标准空 deflate 流（03 00），不是错误。
- 示例：

```
局部 字节集 压缩流
压缩流 = 压缩_DEFLATE压缩(字节集_从文本("LingBuilder"))
```


#### 压缩_GZIP压缩

- 签名：`压缩_GZIP压缩(数据)`
- 返回值：字节集
- 说明：把字节集压缩为 gzip 容器（RFC1952，MTIME=0/OS=255 的确定性输出，便于逐字节对拍）；失败返回空字节集，原因用 压缩_取错误() 查看。
- 参数：
  - 数据（字节集）：要压缩的原始字节集；空字节集产出的仍是合法 gzip（空 deflate 流）。
- 示例：

```
局部 字节集 压缩包
压缩包 = 压缩_GZIP压缩(字节集_从文本("LingBuilder 压缩演示"))
```
