# ZIP压缩模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.archive` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 4 |

通过 Windows 自带 tar.exe 的受控参数封装创建、解压和列出 ZIP，不开放任意命令行。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 4 条）

### 全部命令

#### 压缩_ZIP创建

- 签名：`压缩_ZIP创建(来源路径, ZIP路径)`
- 返回值：逻辑型
- 说明：把文件或目录创建为 ZIP。
- 参数：
  - 来源路径（文本型）：要打包的文件或目录路径；以它的父目录为工作目录、文件名作为条目写入 ZIP。路径不能含双引号、回车或换行。
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。目标已存在时会被覆盖。

#### 压缩_ZIP解压

- 签名：`压缩_ZIP解压(ZIP路径, 目标目录)`
- 返回值：逻辑型
- 说明：解压 ZIP 到目标目录。
- 参数：
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。
  - 目标目录（文本型）：解压目标目录；目录不存在时会递归创建，路径不能含双引号、回车或换行。

#### 压缩_ZIP列出

- 签名：`压缩_ZIP列出(ZIP路径)`
- 返回值：文本型
- 说明：返回 ZIP 内文件列表。
- 参数：
  - ZIP路径（文本型）：ZIP 文件路径，不能包含双引号、回车或换行，否则直接判为非法参数。返回的条目按行分隔，失败返回空文本。

#### 压缩_取错误

- 签名：`压缩_取错误()`
- 返回值：文本型
- 说明：返回最近压缩错误。
