# 数组操作模块

模块 ID：`lingbuilder.std.array`  
版本：`1.0.0`  
适用平台：Windows / MSVC Win32、x64；普通 Win32 与 new_emoji 后端共用同一确定性 C++17 运行时。

数组操作模块补齐 LingCpp 数组一直缺失的运行时能力：取成员数、增删改查、排序和重定义。此前数组只能声明、传参和用 `枚举循环首` 遍历，没有任何命令可以读取长度或追加成员。

模块不引入新的数组类型。它直接作用于语言原有的数组声明（`局部 文本型 名单[]`、`全局 整数型 编号[]`、参数 `整数型[] 编号集合`、记录字段的数组维度），在生成的 C++ 中对应 `std::vector<T>`。

## 命令一览

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `数组_取成员数(数组)` | 整数型 | 当前成员数量 |
| `数组_是否为空(数组)` | 逻辑型 | 是否没有任何成员 |
| `数组_取成员(数组, 索引)` | 元素类型 | 越界返回元素类型默认值 |
| `数组_置成员(数组, 索引, 值)` | 逻辑型 | 越界返回假且不修改 |
| `数组_加入成员(数组, 值)` | 整数型 | 末尾追加，返回追加后的成员数 |
| `数组_插入成员(数组, 索引, 值)` | 逻辑型 | 索引等于成员数时等价于追加 |
| `数组_删除成员(数组, 索引)` | 逻辑型 | 后续成员依次前移 |
| `数组_清空(数组)` | 逻辑型 | 删除全部成员 |
| `数组_查找(数组, 值)` | 整数型 | 首个相等成员索引，未找到返回 -1 |
| `数组_是否包含(数组, 值)` | 逻辑型 | 是否存在相等成员 |
| `数组_排序(数组, 升序)` | 逻辑型 | 按元素自身顺序稳定排序 |
| `数组_倒序(数组)` | 逻辑型 | 整体反转当前顺序 |
| `数组_重定义(数组, 新成员数)` | 逻辑型 | 截断或用默认值补齐 |

索引统一从 0 开始。所有越界索引都安全返回失败值，不抛异常、不崩溃。

## 基本用法

```lcpp
局部 文本型 名单[]
数组_加入成员(名单, "张三")
数组_加入成员(名单, "李四")
数组_加入成员(名单, "王五")

调试输出("成员数", 数组_取成员数(名单))
调试输出("第一个", 数组_取成员(名单, 0))

数组_排序(名单, 真)
枚举循环首 (名单, 当前项)
    调试输出(当前项)
枚举循环尾 ()

判断(数组_查找(名单, "李四") >= 0)
    数组_删除成员(名单, 数组_查找(名单, "李四"))
结束
```

数组下标 `名单[0]` 仍然可用，并且现在参与类型推断；但它不做越界检查。需要安全读取时使用 `数组_取成员`。

## 数组参数必须是变量本身

数组命令就地读写调用方的数组，因此数组参数只接受变量名或记录字段路径：

```lcpp
数组_加入成员(名单, "张三")            ' 正确：局部、程序集或项目全局数组变量
数组_加入成员(用户.标签, "VIP")        ' 正确：记录字段数组
数组_加入成员(取名单(), "张三")        ' 错误：命令结果不是可写数组
数组_加入成员(名单[0], "张三")         ' 错误：下标取到的是成员，不是数组
```

成员值也必须与数组元素类型一致，语言服务会在编辑期直接报错：

```lcpp
局部 整数型 编号[]
数组_加入成员(编号, "abc")             ' 错误：编号 的成员类型是 整数型
```

## 元素类型限制

命令对元素类型透明，基础类型、文本型、字节集、项目自定义记录和模块公开记录都可以作为成员。两条命令依赖元素类型自身的能力：

- `数组_查找`、`数组_是否包含` 需要元素类型支持相等比较。不支持时返回 -1 / 假，不会编译失败。
- `数组_排序` 需要元素类型支持大小比较。不支持时返回假并保持数组原样。

记录型默认不带比较运算，所以对记录数组调用这三条命令会稳定返回失败值。需要按字段查找或排序时，请自己用 `计次循环首` 配合字段比较实现。

## 与 JSON 数组的区别

`lingbuilder.data.json` 的 `JSON_数组_*` 操作的是受管 `JSON值` 句柄，用于解析和生成 JSON 文本，需要 `JSON_释放`。本模块操作的是语言原生数组值，采用值语义、随作用域自动释放，两者不能混用。
