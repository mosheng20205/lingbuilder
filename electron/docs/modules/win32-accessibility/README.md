# 辅助功能模块使用说明

| 项目 | 内容 |

通过 Microsoft Active Accessibility 读取窗口对象名称、值、角色和状态。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 4 条）

### 全部命令

#### 辅助_取名称

- 签名：`辅助_取名称(窗口句柄)`
- 返回值：文本型
- 说明：读取窗口可访问对象名称。
- 参数：
  - 窗口句柄（句柄）：要读取的窗口句柄；无法取得可访问对象时返回空文本。

#### 辅助_取值

- 签名：`辅助_取值(窗口句柄)`
- 返回值：文本型
- 说明：读取窗口可访问对象值。
- 参数：
  - 窗口句柄（句柄）：要读取的窗口句柄；对象没有值或无法访问时返回空文本。

#### 辅助_取角色

- 签名：`辅助_取角色(窗口句柄)`
- 返回值：文本型
- 说明：返回本地化角色文本。
- 参数：
  - 窗口句柄（句柄）：要读取的窗口句柄；返回系统本地化的角色文本，无法访问时返回空文本。

#### 辅助_取状态值

- 签名：`辅助_取状态值(窗口句柄)`
- 返回值：长整数型
- 说明：返回 MSAA 状态位。
- 参数：
  - 窗口句柄（句柄）：要读取的窗口句柄；返回 MSAA 状态位按位或的结果，无法访问时返回 0。
