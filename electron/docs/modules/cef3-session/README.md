提供每实例RequestContext、缓存和Cookie隔离会话能力。

> 本模块是 CEF3 浏览器内核（`lingbuilder.cef3.browser`）的子能力模块：浏览器的创建、导航与生命周期入口命令见主模块文档，本模块命令通常与主模块创建的实例或会话配合使用，具体以各命令说明为准。

#### CEF3会话_Cookie设置

- 签名：`CEF3会话_Cookie设置(上下文句柄, 地址, 名称, 值, 域, 路径, 安全, HttpOnly, 过期Unix秒)`
- 返回值：长整数型
- 说明：异步写入Cookie；过期时间小于等于0时创建会话Cookie。
- 别名：`CefCookieManager::SetCookie`（兼容旧写法，生成代码使用主名）。
- 高级命令：需在设置中开启「显示高级 API」后才会进入补全。
- 参数：
  - 上下文句柄（长整数型）：CEF3会话_取上下文 返回的 RequestContext 受管句柄；用 CEF3会话_释放上下文 释放。
  - 地址（文本型）：Cookie 目标的完整 URL（含协议），如 "https://example.com/"。
  - 名称（文本型）：Cookie 名称；删除命令传空文本时删除该地址全部 Cookie。
  - 值（文本型）：Cookie 内容文本。
  - 域（文本型）：Cookie 归属域，如 "example.com"。
  - 路径（文本型）：Cookie 生效路径，如 "/"。
  - 安全（逻辑型）：真=仅 HTTPS 传输（Secure）。
  - HttpOnly（逻辑型）：真=禁止页面脚本读取（HttpOnly）。
  - 过期Unix秒（长整数型）：过期时间 Unix 秒；小于等于 0 创建会话 Cookie（关闭浏览器即失效）。
