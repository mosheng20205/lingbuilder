# 对称加密模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.crypto.symmetric` |
| 版本 | 1.0.0 |
| 分类 | 系统 |
| 命令数 | 30 |

提供认证加密、传统分组加密和兼容流加密；普通命令密钥使用严格十六进制文本、密文使用带算法和随机数的自描述封装，带 裸 后缀的 AES-GCM 命令密钥/随机数/密文全部使用字节集且不含自描述头，用于兼容 Chromium 等外部密文格式。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 30 条）

### 全部命令

#### 对称_生成密钥

- 签名：`对称_生成密钥(字节数)`
- 返回值：文本型
- 说明：使用系统密码学随机源生成大写十六进制密钥。
- 参数：
  - 字节数（整数型）：密钥字节数，范围 1～1024。
- 示例：

```
对称_生成密钥(32)
```


#### 对称_AES256GCM加密

- 签名：`对称_AES256GCM加密(明文, 密钥十六进制, 附加数据)`
- 返回值：文本型
- 说明：使用 AES-256/GCM 加密并返回自描述密文。加密时自动生成随机 nonce，并验证认证标签。
- 参数：
  - 明文（文本型）：按 UTF-8 编码的明文。
  - 密钥十六进制（文本型）：必须恰好为 32 字节的十六进制密钥。
  - 附加数据（文本型）：参与认证但不加密的 UTF-8 文本，可传空文本。

#### 对称_AES256GCM解密

- 返回值：文本型

#### 对称_AES256GCM加密裸

- 签名：`对称_AES256GCM加密裸(密钥, 随机数, 明文, 附加数据)`
- 返回值：字节集
- 说明：使用 AES-256-GCM 加密原始字节集，返回 密文 || 标签(16 字节) 的裸格式；不含算法名、不自动加随机数，也不做 UTF-8 或 Base64 转换。需要自描述封装时改用同名的非 裸 命令。
- 参数：
  - 密钥（字节集）：必须恰好 32 字节的原始密钥字节集；不要用 对称_生成密钥 的十六进制文本，需要时先 字节集_十六进制解码。
  - 随机数（字节集）：必须恰好 12 字节的随机数字节集，由调用方提供，命令不会自动生成或写入头部；长度不符直接返回空字节集。
  - 明文（字节集）：要加密的原始字节集，原样参与运算，不做 UTF-8 转换；空字节集只输出 16 字节标签。
  - 附加数据（字节集）：参与认证但不加密的附加数据字节集；不需要附加数据时传空字节集。
- 示例：

```
局部 字节集 密文与标签
密文与标签 = 对称_AES256GCM加密裸(密钥, 随机数, 明文字节集, 空附加数据)
```


#### 对称_AES256GCM解密裸

- 签名：`对称_AES256GCM解密裸(密钥, 随机数, 密文与标签, 附加数据)`
- 返回值：字节集
- 说明：使用 AES-256-GCM 解密 32 字节密钥保护的裸 密文 || 标签(16 字节)，返回原始明文字节集；标签校验失败、长度不符或密钥字节数不对都返回空字节集，用 对称_取错误 查看原因。
- 参数：
  - 密钥（字节集）：必须恰好 32 字节的原始密钥字节集；不要用 对称_生成密钥 的十六进制文本，需要时先 字节集_十六进制解码。
