## 命令参考（共 5 条）

### 全部命令

#### 位图_取像素ARGB

- 签名：`位图_取像素ARGB(路径, 横坐标, 纵坐标)`
- 返回值：长整数型
- 说明：返回 ARGB 颜色值，失败返回 -1。
- 参数：
  - 路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 横坐标（整数型）：像素列坐标，从 0 起；超出图片宽度时按说明返回 -1 或假。
  - 纵坐标（整数型）：像素行坐标，从 0 起；超出图片高度时按说明返回 -1 或假。

#### 位图_置像素ARGB

- 签名：`位图_置像素ARGB(来源, 目标, 横坐标, 纵坐标, ARGB)`
- 返回值：逻辑型
- 说明：修改一个像素并保存到目标文件。
- 参数：
  - 来源（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 目标（文本型）：输出图片路径；保存格式按扩展名识别 png、jpg、jpeg、bmp、gif、tif、tiff，无法识别时按 PNG 保存。
  - 横坐标（整数型）：像素列坐标，从 0 起；超出图片宽度时按说明返回 -1 或假。
  - 纵坐标（整数型）：像素行坐标，从 0 起；超出图片高度时按说明返回 -1 或假。
  - ARGB（长整数型）：写入后的 ARGB 颜色值，按 位图_取像素ARGB 的编码格式给出。

#### 位图_取像素红色

- 签名：`位图_取像素红色(ARGB)`
- 返回值：整数型
- 说明：从 ARGB 值读取红色分量。
- 参数：
  - ARGB（长整数型）：一个 ARGB 颜色值，高位到低位依次为 Alpha、红、绿、蓝，通常来自 位图_取像素ARGB。

#### 位图_取像素绿色

- 签名：`位图_取像素绿色(ARGB)`
- 返回值：整数型
- 说明：从 ARGB 值读取绿色分量。
- 参数：
  - ARGB（长整数型）：一个 ARGB 颜色值，高位到低位依次为 Alpha、红、绿、蓝，通常来自 位图_取像素ARGB。

#### 位图_取像素蓝色

- 签名：`位图_取像素蓝色(ARGB)`
- 返回值：整数型
- 说明：从 ARGB 值读取蓝色分量。
- 参数：
  - ARGB（长整数型）：一个 ARGB 颜色值，高位到低位依次为 Alpha、红、绿、蓝，通常来自 位图_取像素ARGB。
