# OP 后台图色模块 1.0 使用说明

OP 后台图色模块（`lingbuilder.op`）把开源项目 [WallBreaker2/op](https://github.com/WallBreaker2/op)（MIT 协议，随包内置 0.4.8.3 版 C API 运行库）的 Windows 后台自动化能力带进 LingBuilder：**窗口后台绑定、后台键鼠模拟、找色找图、OpenCV 高级匹配、大漠兼容点阵字库识字、进程内存读写、YOLO 检测与 A 星寻路**，共 214 条命令。它是大漠插件的开源替代——窗口最小化、被遮挡、不在前台，脚本照样对它截图找图、收发键鼠。

## 适用场景与选型

| 场景 | 用什么 |
| --- | --- |
| 后台挂机：窗口被遮挡/最小化时截图、找图、点击 | **本模块**（`后台_绑定窗口` + 图色/键鼠族） |
| 多开：几十个模拟器/客户端同时操作 | **本模块**（一机一句柄，`后台_按进程枚举窗口` + `后台_排列窗口`） |
| 游戏特制点阵字体识别（有 .txt 字库） | **本模块**（字库识字族，兼容大漠字库格式） |
| 照片、截图里的自然文字识别（无字库） | 微信OCR识别模块（`lingbuilder.ocr`） |
| 前台一次性找图找色（无需绑定、图要轻） | 识图/截图/opencv 模块 |
| 手机真机自动化（非模拟器） | AOA HID 模块（USB 硬件级，与本模块互补） |

## 快速上手：后台找图点击

```lcpp
局部 OP句柄 句柄 = 后台_创建()
如果 句柄 != 0
    局部 长整数型 窗口句柄 = 后台_找窗口(句柄, "", "雷电模拟器")
    如果 窗口句柄 != 0
        ' 绑定：gdi 截图 + windows 消息键鼠（最通用组合）
        后台_绑定窗口(句柄, 窗口句柄, "gdi", "windows", "windows", 0)
        局部 整数型 按钮横 = 0
        局部 整数型 按钮纵 = 0
        如果 后台_找图(句柄, 0, 0, 399, 299, "开始按钮.bmp", "", 0.9, 0, 按钮横, 按钮纵)
            后台_移动到(句柄, 按钮横 + 5, 按钮纵 + 5)
            后台_左键单击(句柄)
        否则
            调试输出(后台_取错误())
        结束
    结束
    后台_销毁(句柄)
结束
```

## 后台绑定：显示后端怎么选

`后台_绑定窗口` 的「显示后端」决定截图通道，按目标渲染方式选：

| 后端 | 适用 |
| --- | --- |
| `gdi` / `gdi2` | 普通 GDI 刷新窗口；gdi2 兼容性更强但更慢 |
| `dxgi` / `wgc` | DXGI 桌面复制（快、省 CPU）；wgc 需 Win10 1903+ |
| `dx.d3d9` ~ `dx.d3d12` | 对应 D3D 版本渲染的游戏/模拟器（钩住交换链截帧） |
| `opengl` / `opengl.nox` | OpenGL 渲染窗口；`opengl.nox` 专配夜神模拟器 |
| `normal.auto` | 不确定时让引擎自动选型 |
| `normal` | 前台屏幕截图（非真正后台） |

键鼠模式：`windows`=后台窗口消息（最稳，优先试）、`dx`=注入式（目标过滤消息时用，杀软可能报注入行为）、`normal`=前台真实输入、键盘另有 `normal.hd` 硬件级。绑定失败先用 `后台_取错误` / `后台_取错误码` 排查，再换后端（gdi2 → dx.d3d11 → normal.auto 逐个试）。

模拟器多层窗口（画面窗口和收消息窗口不是同一个）用 `后台_绑定窗口扩展` 分别指定。

## 与大漠插件的差异对照（迁移必读）

| 项 | 大漠 | 本模块（op） |
| --- | --- | --- |
| 颜色格式 | BBGGRR（`"0000FF"`=红） | **RRGGBB**（`"FF0000"`=红） |
| 截图区域 | 闭区间（含右下行） | **开区间**（右/下不含，`0,0,399,299` 得 399×299） |
| 找图返回值 | 大于等于 0（0 也算成功） | 命令层已翻译为 **真/假**（`后台_找图`）；多模板区分用 `后台_找图全部`（返回 `文件名,x,y|...`）或 `后台_找图全部编号`（`序号,x,y|...`） |
| 附件 | regsvr32 注册、付费注册码 | **免注册免安装**，随包运行库自动就位 |
| 字库 | dm.txt 格式 | **直接兼容**，`后台_加载字库` 喂现有字库文件即可 |

- **OpenCV（35）**：模板库管理、掩码模板、多尺度匹配、特征点/边缘/形状匹配、14 种图像预处理与管线。

## 输出参数（byRef）用法

找色找图族把命中坐标写回传入的变量，直接传整数型变量即可：

```lcpp
局部 整数型 血条横 = 0
局部 整数型 血条纵 = 0
后台_找色(句柄, 0, 0, 399, 299, "FF0000", 0.9, 0, 血条横, 血条纵)
调试输出("血条在 " + 到文本(血条横) + "," + 到文本(血条纵))
```

同类出参还有 `后台_运行程序` 的进程ID（长整数型）、`后台_取窗口客户区` 的四边、`后台_读内存整数/单精度/小数` 的数值等。

## 多开模式

每个引擎句柄独立绑定一个窗口，互不干扰：

```lcpp
局部 文本型 句柄列表 = 后台_按进程枚举窗口(句柄, "game.exe", "", "", 1)
' 解析 "句柄1|句柄2|..."，为每个窗口创建独立引擎句柄并绑定
后台_排列窗口(句柄, 句柄列表, 0, 4, 0, 0, 10, 10, 0, 0, 0, 0)   ' 4 列网格摆位
```

## 错误排查

- `后台_取错误()`：模块层中文错误（运行库加载失败、句柄无效等）。
- `后台_取错误码(句柄)`：上游原始错误码（即 Windows GetLastError 值，0=无错误）。
- 绑定失败：确认目标进程位数与本程序构建位数无强约束（截图均支持），重点换显示后端；`dx` 键鼠注入模式可能被杀软提示，属注入类行为正常现象。
- 找图不中：先用 `后台_截图` 把当前画面存下来，确认模板是从当前后端画面裁的（不同后端色彩/缩放有差异）；相似度从 0.9 起调。
