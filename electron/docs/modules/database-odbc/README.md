## 命令参考（共 8 条）

### 全部命令

#### ODBC_连接

- 签名：`ODBC_连接(连接字符串)`
- 返回值：逻辑型
- 说明：使用 ODBC 连接字符串打开数据库。
- 参数：
  - 连接字符串（文本型）：ODBC 连接字符串，例如 Driver={...};Server=...;Database=...;Uid=...;Pwd=...;；连接不弹驱动配置对话框，缺失字段直接失败。重复连接会先断开上一连接。

#### ODBC_执行

- 签名：`ODBC_执行(SQL语句)`
- 返回值：整数型
- 说明：执行 SQL 并返回受影响行数，失败返回 -1。
- 参数：
  - SQL语句（文本型）：要执行的 SQL 文本，一次一条语句；没有参数绑定入口，取值需自行拼接并确保来源可信。

#### ODBC_查询首值

- 签名：`ODBC_查询首值(SQL语句)`
- 返回值：文本型
- 说明：执行查询并返回首行首列文本。
- 参数：
  - SQL语句（文本型）：要执行的 SQL 文本，一次一条语句；没有参数绑定入口，取值需自行拼接并确保来源可信。

#### ODBC_设置自动提交

- 签名：`ODBC_设置自动提交(启用)`
- 返回值：逻辑型
- 说明：启用或禁用自动提交。
- 参数：
  - 启用（逻辑型）：传真恢复默认逐语句提交，传假进入显式事务模式，之后的 提交 或 回滚 才生效。

#### ODBC_提交

- 签名：`ODBC_提交()`
- 返回值：逻辑型
- 说明：提交当前事务。

#### ODBC_回滚

- 签名：`ODBC_回滚()`
- 返回值：逻辑型
- 说明：回滚当前事务。

#### ODBC_取错误

- 签名：`ODBC_取错误()`
- 返回值：文本型
- 说明：返回最近 ODBC 错误。

#### ODBC_关闭

- 签名：`ODBC_关闭()`
- 返回值：空
- 说明：关闭 ODBC 连接和环境。
