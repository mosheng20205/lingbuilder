# ODBC数据库模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.database.odbc` |
| 版本 | 1.1.0 |
| 分类 | 数据库 |
| 命令数 | 15 |

提供单连接 ODBC 打开、执行、查询首值、多行结果集遍历、SQL 文本转义、事务和错误状态。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 15 条）

### 全部命令

#### ODBC_连接

- 签名：`ODBC_连接(连接字符串)`
- 返回值：逻辑型
- 说明：使用 ODBC 连接字符串打开数据库。
- 参数：
  - 连接字符串（文本型）：ODBC 连接字符串，例如 Driver={...};Server=...;Database=...;Uid=...;Pwd=...;；连接不弹驱动配置对话框，缺失字段直接失败。重复连接会先断开上一连接，同时作废全部已打开的结果集编号。

#### ODBC_执行

- 签名：`ODBC_执行(SQL语句)`
- 返回值：整数型
- 说明：执行 SQL 并返回受影响行数，失败返回 -1。
- 参数：
  - SQL语句（文本型）：要执行的 SQL 文本，一次一条语句；没有参数绑定入口，文本值先用 ODBC_转义文本 转义再拼接，来源不可信的输入禁止直接拼进 SQL。

#### ODBC_转义文本

- 签名：`ODBC_转义文本(文本)`
- 返回值：文本型
- 说明：把文本中的半角单引号成对翻倍，用于把用户输入安全拼进 SQL 字符串字面量；数值等非文本值直接拼接即可，不需要转义。
- 参数：
  - 文本（文本型）：要拼进 SQL 字符串字面量的原始文本。

#### ODBC_查询首值

- 签名：`ODBC_查询首值(SQL语句)`
- 返回值：文本型
- 说明：执行查询并返回首行首列文本；超长值自动分段读取，没有固定长度上限。失败或查询无结果行时返回空文本，失败原因用 ODBC_取错误 读取。
- 参数：
  - SQL语句（文本型）：要执行的 SQL 文本，一次一条语句；没有参数绑定入口，文本值先用 ODBC_转义文本 转义再拼接，来源不可信的输入禁止直接拼进 SQL。

#### ODBC_查询打开

- 签名：`ODBC_查询打开(SQL语句)`
- 返回值：长整数型
- 说明：执行查询并返回结果集编号（从 1 起，0 表示失败，失败原因用 ODBC_取错误 读取）。配合 ODBC_取下一行/ODBC_取列文本 逐行读取，用完必须 ODBC_查询关闭；重新 ODBC_连接 或 ODBC_关闭 会作废全部已打开编号。
- 参数：
  - SQL语句（文本型）：要执行的 SQL 文本，一次一条语句；没有参数绑定入口，文本值先用 ODBC_转义文本 转义再拼接，来源不可信的输入禁止直接拼进 SQL。

#### ODBC_取下一行

- 签名：`ODBC_取下一行(结果集编号)`
- 返回值：逻辑型
- 说明：把结果集游标推进到下一行；有下一行返回真，正常读完返回假（此时 ODBC_取错误 为空），失败也返回假（ODBC_取错误 给中文原因）。
- 参数：
  - 结果集编号（长整数型）：ODBC_查询打开 返回的结果集编号；编号不存在或已关闭时按各命令说明返回失败值，原因用 ODBC_取错误 读取。

#### ODBC_取列文本

- 签名：`ODBC_取列文本(结果集编号, 列序号)`
- 返回值：文本型
- 说明：读取当前行指定列的文本值；NULL 与失败都返回空文本，失败用 ODBC_取错误 区分；超长列自动分段读取，没有固定长度上限。
- 参数：
  - 结果集编号（长整数型）：ODBC_查询打开 返回的结果集编号；编号不存在或已关闭时按各命令说明返回失败值，原因用 ODBC_取错误 读取。
  - 列序号（整数型）：列序号，从 1 起，须不超过结果集列数（ODBC_取列数 可查）。

#### ODBC_取列数

- 签名：`ODBC_取列数(结果集编号)`
- 返回值：整数型
- 说明：返回当前结果集的列数，编号无效返回 0。
- 参数：
  - 结果集编号（长整数型）：ODBC_查询打开 返回的结果集编号；编号不存在或已关闭时按各命令说明返回失败值，原因用 ODBC_取错误 读取。

#### ODBC_取列名

- 签名：`ODBC_取列名(结果集编号, 列序号)`
- 返回值：文本型
- 说明：返回当前结果集指定列的列名，编号无效或列不存在返回空文本。
- 参数：
  - 结果集编号（长整数型）：ODBC_查询打开 返回的结果集编号；编号不存在或已关闭时按各命令说明返回失败值，原因用 ODBC_取错误 读取。
  - 列序号（整数型）：列序号，从 1 起，须不超过结果集列数（ODBC_取列数 可查）。

#### ODBC_查询关闭

- 签名：`ODBC_查询关闭(结果集编号)`
- 返回值：逻辑型
- 说明：关闭 ODBC_查询打开 返回的结果集并释放资源；编号无效返回假。
- 参数：
  - 结果集编号（长整数型）：ODBC_查询打开 返回的结果集编号；编号不存在或已关闭时按各命令说明返回失败值，原因用 ODBC_取错误 读取。

#### ODBC_设置自动提交

- 签名：`ODBC_设置自动提交(启用)`
- 返回值：逻辑型
- 说明：启用或禁用自动提交。
- 参数：
  - 启用（逻辑型）：传真恢复默认逐语句提交，传假进入显式事务模式，之后的 提交 或 回滚 才生效。

#### ODBC_提交

- 签名：`ODBC_提交()`
- 返回值：逻辑型
- 说明：提交当前事务。

#### ODBC_回滚

- 签名：`ODBC_回滚()`
- 返回值：逻辑型
- 说明：回滚当前事务。

#### ODBC_取错误

- 签名：`ODBC_取错误()`
- 返回值：文本型
- 说明：返回最近 ODBC 错误。

#### ODBC_关闭

- 签名：`ODBC_关闭()`
- 返回值：空
- 说明：关闭 ODBC 连接和环境，同时作废全部已打开的结果集编号。

### ODBC 多行结果集遍历

打开查询后逐行读取、用完必须关闭的骨架；打开失败读 ODBC_取错误。

```
局部 长整数型 结果集 = ODBC_查询打开("$1")
如果 (结果集 == 0)
    调试输出(ODBC_取错误())
如果结束
判断循环首 (ODBC_取下一行(结果集))
    调试输出(ODBC_取列文本(结果集, 1))
判断循环尾()
ODBC_查询关闭(结果集)
```
