# 编码转换模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.std.encoding` |
| 版本 | 1.0.0 |
| 分类 | 其他 |
| 命令数 | 32 |

通过十六进制字节文本安全提供 UTF-8、UTF-16、UTF-32、ANSI、GBK、GB2312、GB18030、RAW（按码点低 8 位截断）、BOM、Base64、URL 与 HTML 编解码。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 编码_文本转UTF8

- 签名：`编码_文本转UTF8(文本)`
- 返回值：文本型
- 说明：把 Unicode 文本编码为 UTF-8 字节，返回大写十六进制文本。
- 参数：
  - 文本（文本型）：要编码的源文本；出现未配对的 UTF-16 代理时返回空文本。
- 示例：

```
编码_文本转UTF8("你好")
```


#### 编码_UTF8转文本

- 签名：`编码_UTF8转文本(UTF8十六进制)`
- 返回值：文本型
- 说明：把十六进制表示的 UTF-8 字节解码为 Unicode 文本；无效输入返回空文本。
- 参数：
  - UTF8十六进制（文本型）：十六进制字节文本，长度必须为偶数且每个字符只允许 0-9、a-f、A-F；格式非法按命令说明返回失败值。；解码或转码失败时返回空文本。
- 示例：

```
编码_UTF8转文本("E4BDA0E5A5BD")
```

- 参数：
  - 文本（文本型）：要编码的源文本；当前系统 ANSI 代码页无法无损表示的字符会导致返回空文本。

- 参数：
  - ANSI十六进制（文本型）：待解码的十六进制字节文本，长度必须为偶数；按当前系统 ANSI 代码页解码，失败返回空文本。

#### 编码_文本转GBK

- 签名：`编码_文本转GBK(文本)`
- 返回值：文本型
- 说明：按 Windows CP936 把文本编码为 GBK 字节，返回大写十六进制文本；无法无损表示时返回空文本。
- 参数：
  - 文本（文本型）：要编码的源文本；Windows CP936 无法无损表示的字符会导致返回空文本。

#### 编码_GBK转文本

- 签名：`编码_GBK转文本(GBK十六进制)`
- 返回值：文本型
- 说明：按 Windows CP936 解码十六进制表示的 GBK 字节。
- 参数：
  - GBK十六进制（文本型）：待解码的十六进制字节文本，长度必须为偶数；按 Windows CP936 解码，失败返回空文本。

#### 编码_文本转GB2312

- 签名：`编码_文本转GB2312(文本)`
- 返回值：文本型
- 说明：把文本编码为严格 GB2312 双字节范围，返回大写十六进制文本；GBK 扩展字符或无法表示的字符返回空文本。
- 参数：
  - 文本（文本型）：要编码的源文本；只能表示 GB2312 双字节范围，含 GBK 扩展字符或不可表示字符时返回空文本。

#### 编码_GB2312转文本

- 签名：`编码_GB2312转文本(GB2312十六进制)`
- 返回值：文本型
- 说明：校验 GB2312 字节范围后按 Windows CP936 解码为 Unicode 文本。
- 参数：
  - GB2312十六进制（文本型）：待解码的十六进制字节文本，长度必须为偶数；先校验每个双字节落在 GB2312 范围，再按 Windows CP936 解码，超范围返回空文本。

#### 编码_文本转GB18030

- 参数：
  - 文本（文本型）：要编码的源文本；按 Windows CP54936 严格编码，编码失败返回空文本。

#### 编码_GB18030转文本

- 签名：`编码_GB18030转文本(GB18030十六进制)`
- 返回值：文本型
- 说明：按 Windows CP54936 解码十六进制表示的 GB18030 字节。
- 参数：
  - GB18030十六进制（文本型）：待解码的十六进制字节文本，长度必须为偶数；按 Windows CP54936 严格解码，失败返回空文本。

#### 编码_字节集转文本

- 签名：`编码_字节集转文本(数据, 编码名称)`
- 返回值：文本型
- 说明：把字节集按指定编码解码为 Unicode 文本，不经十六进制中介；读中文 CSV/文本文件时直接用它。
- 参数：
  - 数据（字节集）：要解码的原始字节集，例如 文件_读入字节集 的结果；空字节集返回空文本。
  - 编码名称（文本型）：字节当前的编码名称，忽略大小写与空格、连字符、下划线；支持 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE、UTF-32BE、ANSI、GBK、GB2312、GB18030、RAW（别名 LATIN1：按码点低 8 位截断/还原，不查任何代码页），传 AUTO 按「BOM → 严格 UTF-8 → GB18030」自动识别。名称无法识别或字节不是该编码合法序列时返回空文本。
- 示例：

```
调试输出(编码_字节集转文本(文件_读入字节集(号, 长度), "AUTO"))
```


#### 编码_文本转字节集

- 签名：`编码_文本转字节集(文本, 编码名称)`
- 返回值：字节集
- 说明：把 Unicode 文本按指定编码编码为字节集，用于写出 GBK 等中文编码文件。
- 参数：
  - 文本（文本型）：要编码的源文本；空文本返回空字节集。
  - 编码名称（文本型）：目标编码名称，取值同 编码_字节集转文本（含 RAW：按码点低 8 位截断，签名算法里的逐字符截断语义用它），但必须显式指定（AUTO 返回空字节集）；当前代码页无法无损表示该文本时返回空字节集，RAW 永远不失败。

#### 编码_转换

- 签名：`编码_转换(字节十六进制, 来源编码, 目标编码)`
- 返回值：文本型
- 说明：在支持的字符编码间转换十六进制字节；编码名支持 UTF-8、UTF-16LE/BE、UTF-32LE/BE、ANSI、GBK、GB2312、GB18030。输出不自动添加 BOM。
- 参数：
  - 字节十六进制（文本型）：待转换的十六进制字节文本，长度必须为偶数且只含合法十六进制字符。
  - 来源编码（文本型）：这些字节当前的编码名称，忽略大小写和空格、连字符、下划线；支持 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE、UTF-32BE、ANSI、GBK、GB2312、GB18030、RAW（按码点低 8 位截断/还原），无法识别时返回空文本。
  - 目标编码（文本型）：要转换到的编码名称，取值范围同来源编码；无法识别时返回空文本，输出不自动附加 BOM。

#### 编码_添加BOM

- 签名：`编码_添加BOM(字节十六进制, 编码名称)`
- 返回值：文本型
- 说明：为 UTF-8、UTF-16LE/BE 或 UTF-32LE/BE 十六进制字节添加匹配 BOM；已有 BOM 不重复添加。
- 参数：
  - 字节十六进制（文本型）：待补 BOM 的十六进制字节文本，长度必须为偶数。
  - 编码名称（文本型）：要补加 BOM 的编码名称，仅支持 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE、UTF-32BE；名称无法识别或字节已带不同 BOM 时返回空文本，已带相同 BOM 时原样返回。

#### 编码_删除BOM

- 签名：`编码_删除BOM(字节十六进制)`
- 返回值：文本型
- 说明：识别并删除 UTF-8、UTF-16 或 UTF-32 BOM，返回剩余大写十六进制字节。
- 参数：
  - 字节十六进制（文本型）：待处理的十六进制字节文本，长度必须为偶数；没有 BOM 时原样返回。

#### 编码_是否有BOM

- 签名：`编码_是否有BOM(字节十六进制)`
- 返回值：逻辑型
- 说明：判断十六进制字节是否以受支持的 BOM 开头。
- 参数：
  - 字节十六进制（文本型）：待检测的十六进制字节文本，长度必须为偶数；格式非法时返回假。

#### 编码_检测BOM

- 签名：`编码_检测BOM(字节十六进制)`
- 返回值：文本型
- 说明：根据 BOM 返回 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE 或 UTF-32BE；没有 BOM 返回空文本。
- 参数：
  - 字节十六进制（文本型）：待检测的十六进制字节文本，长度必须为偶数；无 BOM 或格式非法时返回空文本。

#### 编码_检测

- 签名：`编码_检测(字节十六进制)`
- 返回值：文本型
- 说明：先检测 BOM；无 BOM 时仅在字节是严格 UTF-8 时返回 UTF-8，否则返回“未知”，不猜测 ANSI 或中文代码页。
- 参数：
  - 字节十六进制（文本型）：待检测的十六进制字节文本，长度必须为偶数；优先看 BOM，无 BOM 时只有严格合法的 UTF-8 才返回 UTF-8，其余返回未知。

#### 编码_Base64编码

- 签名：`编码_Base64编码(文本)`
- 返回值：文本型
- 说明：将 Unicode 文本按 UTF-8 编码为 Base64。
- 参数：
  - 文本（文本型）：要编码的源文本，先按 UTF-8 转字节再编码，输出可含补齐等号。
- 示例：

```
编码_Base64编码("你好")
```


#### 编码_Base64解码

- 签名：`编码_Base64解码(Base64文本)`
- 返回值：文本型
- 说明：将 Base64 解码为 UTF-8 文本，格式错误返回空文本。
- 参数：
  - Base64文本（文本型）：标准 Base64 文本，长度必须是 4 的倍数；含非法字符或等号位置错误时返回空文本，结果按 UTF-8 解码为文本。
- 示例：

```
编码_Base64解码("5L2g5aW9")
```


#### 编码_URL编码

- 签名：`编码_URL编码(文本)`
- 返回值：文本型
- 说明：按 UTF-8 对 URL 参数内容进行百分号编码。
- 参数：
  - 文本（文本型）：要编码的源文本；字母、数字和 - _ . ~ 保持不变，其余字节按 UTF-8 做百分号编码。

#### 编码_URL解码

- 签名：`编码_URL解码(文本)`
- 返回值：文本型
- 说明：解码 URL 百分号编码和加号空格。
- 参数：
  - 文本（文本型）：已百分号编码的文本；加号会还原为空格，百分号之后不是两位合法十六进制时返回空文本。

#### 编码_HTML转义

- 签名：`编码_HTML转义(文本)`
- 返回值：文本型
- 说明：转义 HTML 中的与号、尖括号、引号和单引号。
- 参数：
  - 文本（文本型）：要转义的源文本；与号、尖括号、双引号和单引号替换为对应实体。

#### 编码_HTML反转义

- 签名：`编码_HTML反转义(文本)`
- 返回值：文本型
- 说明：还原本模块支持的常用 HTML 实体。
- 参数：
  - 文本（文本型）：要还原的文本，仅处理与号、lt、gt、quot、#39 五种实体。
