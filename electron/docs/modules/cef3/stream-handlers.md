# CEF3 受管读写流处理器

适用于需要把二进制数据交给 CEF 读取，或接收 CEF 写入结果的场景。模块 ID 为 `lingbuilder.cef3.transfer`，依赖 `lingbuilder.cef3.objects` 提供受管缓冲。

本专题覆盖 CEF 150 的 `cef_read_handler_t`、`cef_write_handler_t`、`cef_stream_reader_create_for_handler` 和 `cef_stream_writer_create_for_handler`。它们已经进入 C ABI v3、固定 v4 操作 ID、中文命令、生成工程和原生测试；官方逐项映射见 [传输官方接口参考](transfer.md)。

## 安全模型

- `.lcpp` 只接触类型化句柄和 Bridge 受管缓冲，不会取得 `CefRefPtr`、STL 对象、裸内存地址或任意 CEF 回调地址。
- 读取处理器创建时保留源缓冲。释放原始缓冲或处理器句柄不会中断已经创建的读取流，CEF 引用计数会保持所需对象有效。
- 写入处理器是线程安全的内存接收端。每次写入和总内容都受 `64 MiB` 上限保护；超出上限、错误类型、越界范围或已释放句柄都返回稳定错误。
- `可能阻塞` 仅向 CEF 声明调度提示，不会把同步 I/O 放到 UI 线程。内存处理器通常传 `假`。
- `定位` 的基准固定为 `0=开头`、`1=当前位置`、`2=结尾`。官方 `Seek` 的成功返回值是 `0`，不能把它当作 Bridge 通用成功值 `1`。

## 读取流程

1. 用 `CEF3缓冲_从十六进制` 或受管文件缓冲获得源缓冲。
2. 调用 `CEF3传输_从缓冲创建读取处理器`，再调用 `CEF3传输_从读取处理器创建流`。
3. 通过 `CEF3传输_读取流` 或 `CEF3传输_读取处理器读取` 取得新的受管缓冲。
4. 释放读取结果缓冲、流和处理器。原始缓冲可在流创建后释放，但推荐在流程收尾时统一释放，便于排查错误。

```text
类 MainWindow : 公开 窗口
    长整数型 源缓冲 = 0
    CEF3读取处理器句柄 读取处理器 = 0
    CEF3读取流句柄 读取流 = 0
    长整数型 读取结果 = 0

    事件 _MainWindow_创建完毕()
        源缓冲 = CEF3缓冲_从十六进制("48656C6C6F20434546")
        读取处理器 = CEF3传输_从缓冲创建读取处理器(源缓冲, 假)
        读取流 = CEF3传输_从读取处理器创建流(读取处理器)
        读取结果 = CEF3传输_读取流(读取流, 64)
        调试输出(CEF3缓冲_到十六进制(读取结果))
    结束

    事件 _MainWindow_将被销毁()
        CEF3缓冲_释放(读取结果)
        CEF3传输_释放读取流(读取流)
        CEF3传输_释放读取处理器(读取处理器)
        CEF3缓冲_释放(源缓冲)
    结束
结束类
```

## 写入流程

1. 创建 `CEF3传输_创建写入处理器`，或以现有处理器创建写入流。
2. 从受管缓冲写入。`起始偏移` 与 `写入字节数` 必须落在缓冲范围内。
3. 对内存处理器使用 `CEF3传输_取写入处理器缓冲` 取得内容快照；对文件写入流先调用 `CEF3传输_刷新写入流`。
4. 释放快照、流、处理器和输入缓冲。

```text
类 MainWindow : 公开 窗口
    长整数型 输入缓冲 = 0
    CEF3写入处理器句柄 写入处理器 = 0
    CEF3写入流句柄 写入流 = 0
    长整数型 写入快照 = 0

    事件 _MainWindow_创建完毕()
        输入缓冲 = CEF3缓冲_从十六进制("4C696E674275696C646572")
        写入处理器 = CEF3传输_创建写入处理器(假)
        写入流 = CEF3传输_从写入处理器创建流(写入处理器)
        CEF3传输_写入流(写入流, 输入缓冲, 0, CEF3缓冲_取大小(输入缓冲))
        CEF3传输_刷新写入流(写入流)
        写入快照 = CEF3传输_取写入处理器缓冲(写入处理器)
        调试输出(CEF3缓冲_到十六进制(写入快照))
    结束

    事件 _MainWindow_将被销毁()
        CEF3缓冲_释放(写入快照)
        CEF3传输_释放写入流(写入流)
        CEF3传输_释放写入处理器(写入处理器)
        CEF3缓冲_释放(输入缓冲)
    结束
结束类
```

## 接口速查

| 分类 | 接口 | 返回值 | 说明 |
|---|---|---|---|
| 读取处理器 | `CEF3传输_从缓冲创建读取处理器(缓冲句柄, 可能阻塞)` | `CEF3读取处理器句柄` | 创建保留源缓冲的读取处理器。 |
| 读取处理器 | `CEF3传输_读取处理器读取(读取处理器句柄, 最大字节数)` | `长整数型` | 返回新受管缓冲句柄。 |
| 读取处理器 | `CEF3传输_定位读取处理器`、`CEF3传输_取读取处理器位置`、`CEF3传输_读取处理器是否结束`、`CEF3传输_读取处理器是否可能阻塞` | 整数或长整数 | 查询或调整处理器位置和状态。 |
| 读取流 | `CEF3传输_从读取处理器创建流(读取处理器句柄)` | `CEF3读取流句柄` | 创建真实 `CefStreamReader`。 |
| 写入处理器 | `CEF3传输_创建写入处理器(可能阻塞)` | `CEF3写入处理器句柄` | 创建最多 64 MiB 的内存写入接收端。 |
| 写入处理器 | `CEF3传输_写入处理器写入`、`CEF3传输_定位写入处理器`、`CEF3传输_取写入处理器位置`、`CEF3传输_刷新写入处理器` | 整数或长整数 | 直接访问内存处理器。 |
| 写入处理器 | `CEF3传输_取写入处理器缓冲(写入处理器句柄)` | `长整数型` | 复制当前内容为新的受管缓冲。 |
| 写入流 | `CEF3传输_从写入处理器创建流(写入处理器句柄)` | `CEF3写入流句柄` | 创建真实 `CefStreamWriter`。 |
| 释放 | `CEF3传输_释放读取处理器`、`CEF3传输_释放写入处理器`、`CEF3传输_释放读取流`、`CEF3传输_释放写入流` | 整数型 | 仅释放相应类型的受管句柄；重复释放返回错误。 |

## 平台与限制

- 当前仅支持 Windows MSVC x64 与固定 CEF `150.0.14+g7c1aa68` 基线。
- 文件创建流接口仅可访问项目允许根目录，不能传任意绝对路径或目录穿越路径。
- 流处理器用于二进制传输，不是通用脚本回调机制。后续资源拦截应使用请求/资源处理器接口，不能通过伪造裸指针接入。
