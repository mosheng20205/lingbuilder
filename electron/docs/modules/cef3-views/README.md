### 全部命令

#### CEF3视图_打开Chrome窗口

- 签名：`CEF3视图_打开Chrome窗口(控件名, 地址)`
- 返回值：整数型
- 说明：使用实例会话创建Chrome Runtime独立顶层窗口。
- 别名：`CefBrowserHost::CreateBrowser`（兼容旧写法，生成代码使用主名）。
- 参数：
  - 控件名（控件引用）：裸写的可视控件名称（不能加引号），只在当前窗口内解析、且类型必须是 CefBrowser；生成 C++ 时按对象名定位。对象不存在、同名歧义或类型不兼容会给出中文诊断，按住 Ctrl 单击可跳转到设计器选中该对象。
  - 地址（文本型）：新窗口要打开的完整 URL（含协议）。
  - 控件引用参数必须传设计器中的裸控件名（不带引号），例如 `控件_设置文本(操作结果, "完成")`。
