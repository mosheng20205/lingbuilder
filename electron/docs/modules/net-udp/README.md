# UDP通信模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.net.udp` |

提供 UDP 绑定、广播开关、端口复用、UTF-8 数据报发送接收和关闭能力，可支撑局域网自动发现与局域网文本消息。

## 命令参考（共 9 条）

### 全部命令

#### UDP_绑定

- 签名：`UDP_绑定(端口)`
- 返回值：逻辑型
- 说明：在本机全部接口绑定 UDP 端口。
- 参数：
  - 端口（整数型）：要绑定的本机 UDP 端口，0 到 65535；0 表示由系统分配端口，绑定在本机全部接口上。

#### UDP_允许广播

- 签名：`UDP_允许广播(允许)`
- 返回值：逻辑型
- 说明：允许 UDP 套接字发送广播数据报（局域网自动发现的前提）；绑定前后调用均可。
- 参数：
  - 允许（逻辑型）：传真开启 SO_BROADCAST；发送到 255.255.255.255 等广播地址前必须先开启，否则 Windows 直接拒绝发送。默认关闭。

#### UDP_允许端口复用

- 签名：`UDP_允许端口复用(允许)`
- 返回值：逻辑型
- 说明：允许多个程序绑定同一 UDP 端口（本机多开联调必需）。
- 参数：
  - 允许（逻辑型）：传真开启 SO_REUSEADDR；必须在 UDP_绑定 之前调用才生效。开启后同一台机器的多个程序可以绑定同一 UDP 端口，广播包每个套接字都能收到，适合本机多开联调。默认关闭。

#### UDP_发送文本

- 签名：`UDP_发送文本(主机, 端口, 内容)`
- 返回值：整数型
- 说明：发送一条 UTF-8 UDP 数据报。
- 参数：
  - 主机（文本型）：目标主机名或地址；只按 IPv4 解析，解析失败返回 -1。
  - 端口（整数型）：目标端口，1 到 65535；超范围返回 -1。
  - 内容（文本型）：数据报正文，按 UTF-8 编码为一条数据报发出，不保证到达也不自动分片重发。

#### UDP_接收文本

- 签名：`UDP_接收文本(最大字节数, 超时毫秒)`
- 返回值：文本型
- 说明：接收一条 UDP 数据报，超时返回空文本。
- 参数：
  - 最大字节数（整数型）：单个数据报最多接收的字节数，上限 65507；小于 1 时按 1 处理，超出部分会被丢弃。
  - 超时毫秒（整数型）：等待数据报的超时毫秒数；小于 1 时按 1 处理，超时返回空文本。

#### UDP_取来源地址

- 签名：`UDP_取来源地址()`
- 返回值：文本型
- 说明：返回最近数据报来源 IP。

#### UDP_取来源端口

- 签名：`UDP_取来源端口()`
- 返回值：整数型
- 说明：返回最近数据报来源端口。

#### UDP_取错误

- 签名：`UDP_取错误()`
- 返回值：文本型
- 说明：返回最近 UDP 中文错误。

#### UDP_关闭

- 签名：`UDP_关闭()`
- 返回值：空
- 说明：关闭当前 UDP 套接字。
