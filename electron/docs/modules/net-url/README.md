## 命令参考（共 6 条）

### 全部命令

#### URL_是否有效

- 签名：`URL_是否有效(地址)`
- 返回值：逻辑型
- 说明：判断 URL 是否可被 WinHTTP 解析。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。

#### URL_取协议

- 签名：`URL_取协议(地址)`
- 返回值：文本型
- 说明：返回 http 或 https 等协议名。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。

#### URL_取主机

- 签名：`URL_取主机(地址)`
- 返回值：文本型
- 说明：返回 URL 主机名。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。

#### URL_取端口

- 签名：`URL_取端口(地址)`
- 返回值：整数型
- 说明：返回 URL 端口。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。未显式写端口时返回该协议的默认端口。

#### URL_取路径

- 签名：`URL_取路径(地址)`
- 返回值：文本型
- 说明：返回 URL 路径和附加信息。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。返回值含问号后的查询串和锚点等附加信息。

#### URL_是否HTTPS

- 签名：`URL_是否HTTPS(地址)`
- 返回值：逻辑型
- 说明：判断 URL 是否使用 HTTPS。
- 参数：
  - 地址（文本型）：要解析的完整 URL，必须带协议名；由 WinHTTP 解析，解析失败时文本项返回空文本、端口返回 0。
