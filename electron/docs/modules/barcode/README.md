# 条码模块 1.0 使用说明

条码模块（`lingbuilder.barcode`）提供一维条码的纯本地生成与识别，零第三方运行时依赖（与二维码模块同路线）。支持五种主流码制：**EAN-13、EAN-8、UPC-A、Code128（A/B/C 子集自动择优）、Code39**。

## 生成

```lcpp
局部 条码句柄 条码 = 条码_生成EAN13("590123412345")   ' 12 位自动补校验位
如果 条码 != 0
    条码_保存BMP(条码, "商品条码.bmp", 3)
    条码_释放(条码)
结束
```

- EAN/UPC 输入可带或不带校验位：不带自动补全；带校验位但算错时**明确报错**，不会静默纠正。
- `条码_取位图` 返回 HBITMAP（可交给图片框显示或位图类命令）；`条码_保存BMP` 输出 24 位 BMP 文件。
- 每模块像素建议 3；条高自动取条宽的 1/3（至少 24 像素）。输出为纯条码图形（不含人类可读文本行）。

## 识别

四个入口与二维码模块同构：`条码_识别像素`（字节集免落盘）、`条码_识别位图`（HBITMAP）、`条码_识别屏幕`（屏幕区域）、`条码_识别BMP`（BMP 文件）。

```lcpp
局部 条码识别结果 结果 = 条码_识别屏幕(100, 100, 600, 200)
如果 结果 != 0
    调试输出(条码_识别取码制(结果) + "：" + 条码_识别取文本(结果))
    条码_识别释放(结果)
否则
    调试输出(条码_识别取错误())
结束
```

识别特性：

- **横纵双向扫描**（各三条扫描线），覆盖条码旋转 90° 的场景。
- 自动判定码制；EAN/UPC/Code128 校验位不符的条码**不会被识别成功**（不静默返回错值）。
- UPC-A 与首位 0 的 EAN-13 图形同构，按 UPC-A 语义输出 12 位文本。
- Code128 支持 A/B/C 子集混合内容；Code39 小写自动按大写处理（该码制本身只含大写）。
- PNG 识别输入暂不支持：请先用图像模块转 BMP 或像素字节集（`条码_识别像素`）。

## 自检

`条码_自检()` 执行五码制「生成→渲染→识别」逐字节闭环与校验位异常样本拒绝校验，可用于部署环境快速体检。

## 命令与返回值

25 条命令分四族：生成（五种码制 + 模块数/内容/位图/BMP/释放）、识别（四入口 + 文本/码制/校验/释放）、诊断（自检/取错误/识别取错误/取版本/是否可用）。全部失败路径返回 0/假并给出线程级中文错误。
