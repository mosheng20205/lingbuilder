本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 5 条）

### 全部命令

#### 托盘_添加

- 签名：`托盘_添加(窗口句柄, 编号, 提示文本)`
- 返回值：逻辑型
- 说明：使用应用默认图标添加托盘图标。
- 参数：
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。
  - 编号（整数型）：托盘图标编号，同一窗口内用于区分多个图标，建议从 1 开始。
  - 提示文本（文本型）：鼠标悬停提示文本，空文本时使用 LingBuilder；超出系统长度上限会被截断。

#### 托盘_修改提示

- 签名：`托盘_修改提示(窗口句柄, 编号, 提示文本)`
- 返回值：逻辑型
- 说明：修改托盘提示文本。
- 参数：
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。
  - 编号（整数型）：托盘图标编号，同一窗口内用于区分多个图标；必须与添加时使用的编号一致。
  - 提示文本（文本型）：新的悬停提示文本；空文本会清空提示内容。

#### 托盘_显示通知

- 签名：`托盘_显示通知(窗口句柄, 编号, 标题, 内容)`
- 返回值：逻辑型
- 说明：显示托盘气泡通知。
- 参数：
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。
  - 编号（整数型）：托盘图标编号，同一窗口内用于区分多个图标；必须与添加时使用的编号一致。
  - 标题（文本型）：气泡通知标题，空文本时使用 LingBuilder。
  - 内容（文本型）：气泡正文，空文本时只显示标题；超出系统长度上限会被截断。

#### 托盘_删除

- 签名：`托盘_删除(窗口句柄, 编号)`
- 返回值：逻辑型
- 说明：删除托盘图标。
- 参数：
  - 窗口句柄（句柄）：接收菜单命令或托盘回调消息的窗口句柄。
  - 编号（整数型）：托盘图标编号，同一窗口内用于区分多个图标；必须与添加时使用的编号一致。

#### 托盘_取回调消息号

- 签名：`托盘_取回调消息号()`
- 返回值：整数型
- 说明：返回固定回调消息 WM_APP+77。
