# Word 文档模块 1.0 使用说明

Word 文档模块（`lingbuilder.data.word`）让中文程序直接读写 `.docx` 文档：标题/段落/表格/图片追加、`{{占位符}}` 模板批量替换、一键生成报告、导出 PDF（本模块内容子集）与表格 Excel 互转。运行时随附 `LingBuilderWord.dll`，**无需安装 Microsoft Word**。

## 适用场景

- 批量生成报告：模板里写 `{{客户名称}}`、`{{金额}}` 等占位符，程序按数据批量替换后另存，一条命令完成（`Word_从JSON生成报告`）。
- 程序写文档：从零创建带标题、段落、表格、图片的 .docx，保存后可用 Word/WPS 正常打开编辑。
- 报表导出 PDF：程序生成的文档直接导出 PDF 分发；Excel 侧配对命令 `Excel_导出PDF`。
- 表格互通：文档表格导出 .xlsx，或把 Excel 数据按坐标灌进 Word 模板表格（批量报告主链路）。

## 句柄与模式

模块用一个受管句柄类型 `Word文档`（`long long`，0 表示无效）表示文档：

| | 创建模式（`Word_创建文档`） | 打开模式（`Word_打开文档`） |
| --- | --- | --- |
| 引擎 | 内存 OOXML 模型，`Word_保存文档` 才写出文件 | 解析既有 .docx 的 document.xml，保存时原样改写其余部分 |
| 读取 | 读追加块内容 | 读全部段落、表格、样式 |
| 追加（标题/段落/表格/图片） | 可用 | 可用（追加到正文末尾） |
| 占位符替换 | 可用 | 可用（模板填充主路径） |

旧版 `.doc` 二进制格式会被明确拒绝并提示先另存为 `.docx`。

## 模板占位符（核心能力）

模板中写 `{{占位名}}`（容忍 `{{ 占位名 }}` 的空白变体）。替换采用**段落级 run 合并**：Word 的 IME 输入、拼写检查常把 `{{客户名称}}` 拆进多个文本片段（run），本模块在段落级先合并再按 span 回写，分裂形态同样正确替换；表格单元格内同样生效。

```lcpp
局部 Word文档 报告 = Word_打开文档("模板/催款函.docx")
如果 报告 != 0
    Word_批量替换占位符(报告, "{\"客户名称\":\"张三\",\"金额\":\"998.50\"}")
    Word_保存文档(报告, "输出/催款函-张三.docx")
    Word_导出PDF(报告, "输出/催款函-张三.pdf")
    Word_关闭文档(报告)
否则
    调试输出(Word_取错误())
结束
```

一步版：`Word_从JSON生成报告("模板/催款函.docx", 数据JSON, "输出/催款函-张三.docx")`。

`Word_替换占位符` 返回替换次数，模板里没有该占位符时返回 0（不报错），可据此校验模板完整性。

## 导出 PDF 的能力边界（重要）

`Word_导出PDF` 只对**本模块内容子集**承诺：段落、标题样式、表格（自动分页 + 跨页重复表头）、PNG/JPEG 图片。中文使用 PDF 标准预定义 CID 字体（STSong-Light + UniGB-UCS2-H，不嵌入字体文件，依赖查看器字体替换；Chrome/Edge/WPS 可直接显示）。

文档包含文本框、浮动图形/形状、数学公式等未支持元素时，命令**明确报错并指出元素类型**，不会静默丢内容；此时请在 Word/WPS 中移除该元素，或直接用其「另存为 PDF」。外部复杂 docx 的高保真转 PDF 走 `PDF_外部文档转PDF`（经本机 Office/WPS 自动检测链，见 PDF 文档模块）。

## 表格 Excel 互转

- `Word_表格另存Excel(文档, 表格索引, "输出.xlsx")`：文档表格 → 单工作表 .xlsx。
- `Word_从Excel填充表格(文档, 表格索引, "数据.xlsx")`：Excel 第一个工作表的数据按单元格坐标覆写文档表格（Excel(1,1)→表格(1,1)）；表格行列必须不小于数据区域，超出会明确报错。

## 命令与返回值

28 条命令分七族：文档生命周期（创建/打开/保存/关闭/释放全部）、读取（全文本/段落数/段落文本/段落样式/表格数/行数/列数/单元格文本）、写入（添加标题/段落/表格/设置单元格文本/添加图片）、模板（替换占位符/批量替换/从JSON生成报告）、转换（导出PDF/表格另存Excel/从Excel填充表格）、诊断（取错误/取版本/是否可用）。

全部命令失败时返回 0/假并更新线程级中文错误，`Word_取错误()` 读取最近一次错误说明。

## 运行桥

随附 `LingBuilderWord.dll`（x86/x64）由 LingBuilder 自有 OOXML 模型 + miniz 3.0.2（MIT）静态链接编译；`Word_是否可用()` 可在运行时探测桥是否就位。SHA-256 基线与重新编译说明见 `third_party/word/NOTICE.md`。
