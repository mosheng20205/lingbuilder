# Aria2 下载模块

`lingbuilder.net.aria2` 是 LingBuilder 0.6.0 或更高版本提供的内置 Windows x64 下载模块。它调用随生成项目一同复制的原始 `aria2c.exe 1.37.0`，不读取系统 `PATH`，也不提供任意命令行参数入口。

## 适用范围

- HTTP、HTTPS、FTP、FTPS 和 magnet 下载。
- 多连接、分段下载、失败重试和 aria2 断点续传。
- 在 UI 线程中创建任务后，可通过状态、进度和字节数接口轮询，也可为 `Aria2_下载` 传入 `&下载进度` 实时接收窗口线程回调。

首版只支持 Windows x64 MSVC 项目。启用模块后，F5 运行、原生预览和 Visual Studio 导出都会复制 `aria2c.exe`、`COPYING`（GPLv2）和本文件的来源说明到生成程序目录。

## 命令

| 命令 | 说明 |
| --- | --- |
| `Aria2_下载(地址, 保存目录, 文件名, 连接数, 最小分段MB, [下载进度处理器])` | 创建任务并返回 `Aria2任务`。地址只能是 HTTP(S)、FTP(S) 或 magnet；连接数为 1-16，分段为 1-64 MB。可选处理器必须使用 `&处理器名`。 |
| `Aria2_等待(任务, 超时毫秒)` | 成功完成返回真；超时、失败或停止返回假。`0` 只检查当前状态。 |
| `Aria2_取状态(任务)` | 返回“下载中”“已完成”“已失败”或“已停止”。 |
| `Aria2_取进度(任务)` | 返回已报告的百分比；服务器尚未报告时为 `0`。 |
| `Aria2_取已下载字节(任务)` | 优先返回 aria2 进度输出中的已下载字节；没有进度输出时回退到目标文件大小。 |
| `Aria2_取总字节(任务)` | 返回 aria2 已报告的总字节；未知时为 `0`，成功结束后为最终文件大小。 |
| `Aria2_取错误(任务)` | 返回失败原因或 aria2 输出尾部。 |
| `Aria2_取下载速度(任务)` | 优先解析 aria2 控制台 `DL:` 的实时速度，单位为字节/秒；文件大小采样仅作为没有输出时的回退。 |
| `Aria2_取保存目录(任务)` | 返回任务实际使用的绝对保存目录。 |
| `Aria2_打开目录(任务)` | 用系统文件管理器打开任务保存目录；目录来自任务句柄，不接受任意路径。 |
| `Aria2_停止(任务)` | 停止子进程，保留 `.aria2` 断点续传数据。 |
| `Aria2_释放(任务)` | 停止仍在运行的任务并释放本地句柄。 |

## 完整示例

```lcpp
.版本 2

.子程序 下载示例
    .局部变量 Aria2任务 任务

    任务 = Aria2_下载("https://example.com/file.zip", "downloads", "file.zip", 8, 8, &下载进度)
    如果 (任务 = 0)
        信息框("无法创建下载任务。")
    否则
        如果 (Aria2_等待(任务, 60000))
            信息框("下载完成：" + Aria2_取保存目录(任务))
            调试输出("下载速度：" + Aria2_取下载速度(任务))
        否则
            调试输出("下载状态：" + Aria2_取状态(任务))
            调试输出("下载错误：" + Aria2_取错误(任务))
        如果结束
        Aria2_释放(任务)
    如果结束

.子程序 下载进度(Aria2任务 任务, 整数型 进度, 长整数型 已下载字节, 长整数型 总字节, 长整数型 速度字节每秒, 文本型 状态)
    调试输出("下载进度：", 进度, "%；已下载：", 已下载字节, "/", 总字节, "；速度：", 速度字节每秒, " 字节/秒；状态：", 状态)
```

## 进度处理器

`下载进度处理器` 是 `Aria2_下载` 的可选末尾参数。必须使用 `&下载进度`，不能使用字符串。处理器必须精确声明为：

```lcpp
事件 下载进度(Aria2任务 任务, 整数型 进度, 长整数型 已下载字节, 长整数型 总字节, 长整数型 速度字节每秒, 文本型 状态)
    ' 在窗口线程运行，可直接更新进度条、速度文本和完成目录。
结束
```

回调由后台 aria2 输出合并后通过窗口消息投递，避免下载线程直接操作 UI。开始、下载中、完成、失败或停止时都可能收到快照；完成时可用 `Aria2_取保存目录(任务)` 显示实际目录。调用方仍应在不再使用任务时调用 `Aria2_释放`。

## 完整交互演示项目

仓库提供 `Aria2下载模块-完整交互演示.lcpppkg` 源码包，包含可编辑的窗口设计器、四个 TabControl 页面、实时进度/速度面板、运行日志框和 20 个独立操作按钮：

- HTTP、HTTPS、FTP 与 BT 磁力链接各有独立启动按钮。
- 并发页在 TabControl 可见内容区直接提供公共下载地址、保存目录及 1/8/16 连接的三个独立文件名；每个任务各有实时进度条、速度/状态/完成目录详情框和独立“打开下载目录”按钮；三个任务分别传入独立的 `&下载进度` 处理器，16 是模块上限。
- 断点续传页面分开提供“开始可续传下载”“停止并保留断点”“继续未完成下载”。
- 任务管理页面每 500ms 自动刷新状态、百分比、进度条、已下载/总字节、字节/秒速度和实际保存目录；检测到完成时写入一次完成日志。
- “打开下载目录”按钮只打开当前任务句柄对应的目录，不允许输入任意 shell 或文件系统路径。
- 任务管理页面覆盖等待检查、状态/进度/字节/错误查询、停止、释放和日志清空。

在 `electron/` 目录执行下列命令即可重新生成、校验并回读导入该源码包；输出固定在仓库根目录 `exports/`，脚本不会覆盖同名现有包：

```bash
npm run demo:aria2:export
```

磁力链接文本框只提供可编辑的合法格式提示，请替换为你有权下载的 `magnet:?` 资源。HTTP、HTTPS 和 FTP 默认地址同样可按网络环境替换。
