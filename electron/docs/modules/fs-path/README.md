提供不访问或少量访问文件系统的路径组合、规范化和组成部分读取。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 7 条）

### 全部命令

#### 路径_合并

- 签名：`路径_合并(基础路径, 子路径)`
- 返回值：文本型
- 说明：组合两个路径并进行词法规范化。
- 参数：
  - 基础路径（文本型）：路径的前半段。
  - 子路径（文本型）：接在后面的子路径；为绝对路径时会直接替换前半段，结果已做词法规范化。
- 示例：

```
路径_合并("数据", "配置.json")
```


#### 路径_取文件名

- 签名：`路径_取文件名(路径)`
- 返回值：文本型
- 说明：返回路径中的文件名。
- 参数：
  - 路径（文本型）：要取末段的路径；以分隔符结尾时返回空文本。

#### 路径_取目录

- 签名：`路径_取目录(路径)`
- 返回值：文本型
- 说明：返回路径中的父目录。
- 参数：
  - 路径（文本型）：要取父目录的路径；只有一段时返回空文本。

#### 路径_取扩展名

- 签名：`路径_取扩展名(路径)`
- 返回值：文本型
- 说明：返回包含点号的文件扩展名。
- 参数：
  - 路径（文本型）：要取后缀的路径；返回值含前导点号，没有后缀时返回空文本。

#### 路径_改扩展名

- 签名：`路径_改扩展名(路径, 新扩展名)`
- 返回值：文本型
- 说明：替换文件扩展名。
- 参数：
  - 路径（文本型）：待改后缀的路径，纯词法处理，不校验文件是否存在。
  - 新扩展名（文本型）：新的扩展名，含前导点号例如 .txt；空文本表示去掉原有扩展名。

#### 路径_转绝对路径

- 签名：`路径_转绝对路径(路径)`
- 返回值：文本型
- 说明：以当前工作目录为基准生成绝对路径。
- 参数：
  - 路径（文本型）：要转换的路径；相对路径以当前工作目录为基准，无法解析时返回空文本。

#### 路径_规范化

- 签名：`路径_规范化(路径)`
- 返回值：文本型
- 说明：移除路径中的点段并规范分隔结构。
- 参数：
  - 路径（文本型）：要规范化的路径；只做词法整理，去掉点段和冗余分隔符，不访问文件系统。
