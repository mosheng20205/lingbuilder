# 密码哈希与派生模块使用说明

### 全部命令

#### 密码_Argon2id哈希

- 签名：`密码_Argon2id哈希(密码, 内存KB, 迭代次数, 并行度)`
- 返回值：文本型
- 返回值说明：成功返回 $argon2id$ 自描述哈希，失败返回空文本并可读取“密码_取错误”。
- 说明：生成标准 PHC 格式的 Argon2id 密码哈希。
- 参数：
  - 密码（文本型）：待保护的密码，按 UTF-8 编码。
  - 内存KB（整数型）：内存成本，范围 8192～1048576 KB，推荐至少 65536。
  - 迭代次数（整数型）：时间成本，范围 1～20，推荐 3。
  - 并行度（整数型）：并行度，范围 1～16。
- 示例：

```
密码_Argon2id哈希("密码", 65536, 3, 1)
```


#### 密码_Argon2id验证

- 签名：`密码_Argon2id验证(密码, 已保存哈希)`
- 返回值：逻辑型
- 说明：恒定时间验证 Argon2id PHC 哈希。
- 参数：
  - 密码（文本型）：待验证的密码，按 UTF-8 编码参与运算；空文本同样会执行一次完整哈希比对。
  - 已保存哈希（文本型）：对应哈希算法生成的自描述 PHC 文本，内含算法、参数和随机盐；格式不符时返回假并记录中文错误。

#### 密码_scrypt哈希

- 签名：`密码_scrypt哈希(密码, N, r, p)`
- 返回值：文本型
- 说明：生成包含全部参数和随机盐的 scrypt PHC 哈希。
- 参数：
  - 密码（文本型）：待验证的密码，按 UTF-8 编码参与运算；空文本同样会执行一次完整哈希比对。
  - N（整数型）：CPU/内存成本，必须为 2 的幂，推荐 32768。
  - r（整数型）：块大小参数，推荐 8。
  - p（整数型）：并行参数，推荐 1。
- 示例：

```
密码_scrypt哈希("密码", 32768, 8, 1)
```
