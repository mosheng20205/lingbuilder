# 基础音频模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.media.audio` |
| 版本 | 1.0.0 |
| 分类 | 其他 |

使用 Windows 多媒体 API 异步播放 WAV 文件、系统声音并控制主音量。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

## 命令参考（共 17 条）

### 全部命令

#### 音频_播放WAV

- 签名：`音频_播放WAV(路径, 循环)`
- 返回值：逻辑型
- 说明：异步播放 WAV 文件。
- 参数：
  - 路径（文本型）：WAV 文件路径；文件不存在或格式不被 PlaySound 支持时返回假。
  - 循环（逻辑型）：传真的播放结束后从头循环，需要 音频_停止 才会停止。

#### 音频_停止

- 签名：`音频_停止()`
- 返回值：空
- 说明：停止当前 PlaySound 音频。

#### 音频_播放系统提示

- 签名：`音频_播放系统提示()`
- 返回值：逻辑型
- 说明：播放系统通知声音。

#### 音频_取主音量

- 签名：`音频_取主音量()`
- 返回值：整数型
- 说明：返回 waveOut 主音量 0 到 100。

#### 音频_设置主音量

- 签名：`音频_设置主音量(音量)`
- 返回值：逻辑型
- 说明：设置 waveOut 主音量 0 到 100。
- 参数：
  - 音量（整数型）：目标音量百分比，0 到 100；超出范围会被夹到端点，左右声道同时设置。

#### 音频_置静音

- 签名：`音频_置静音(静音)`
- 返回值：空
- 说明：设置系统默认输出设备的静音状态。
- 参数：
  - 静音（逻辑型）：真静音系统默认输出设备，假解除静音。

#### 音频_取静音

- 签名：`音频_取静音()`
- 返回值：逻辑型
- 说明：返回系统默认输出设备是否处于静音状态。

#### 音频_播放MP3

- 签名：`音频_播放MP3(路径, 循环)`
- 返回值：逻辑型
- 说明：异步播放 MP3 音频文件（同一时间只有一个 MP3 播放通道，再次播放会替换当前曲目）。
- 参数：
  - 路径（文本型）：MP3/音频文件路径；由 MCI 按扩展名自动选择解码器，也支持 WAV 等可解码格式。
  - 循环（逻辑型）：传真时播放结束后从头循环，需要 音频_停止MP3 才会停止。

#### 音频_暂停MP3

- 签名：`音频_暂停MP3()`
- 返回值：逻辑型
- 说明：暂停当前 MP3 播放。

#### 音频_继续MP3

- 签名：`音频_继续MP3()`
- 返回值：逻辑型
- 说明：继续被暂停的 MP3 播放。

#### 音频_停止MP3

- 签名：`音频_停止MP3()`
- 返回值：逻辑型
- 说明：停止当前 MP3 播放（播放位置归零，文件保持打开以便查询状态）。

#### 音频_取MP3状态

- 签名：`音频_取MP3状态()`
- 返回值：文本型
- 说明：返回 MP3 当前状态文本：播放中、已暂停或已停止。

#### 音频_取MP3长度

- 签名：`音频_取MP3长度()`
- 返回值：整数型
- 说明：返回当前 MP3 总时长（毫秒）；未打开文件返回 0。

#### 音频_取MP3位置

- 签名：`音频_取MP3位置()`
- 返回值：整数型
- 说明：返回当前 MP3 播放位置（毫秒）。

#### 音频_跳转MP3

- 签名：`音频_跳转MP3(位置毫秒)`
- 返回值：逻辑型
- 说明：把 MP3 播放位置跳到指定毫秒并继续播放。
- 参数：
  - 位置毫秒（整数型）：要跳转到的位置（毫秒），从 0 起。

#### 音频_播放MIDI

- 签名：`音频_播放MIDI(路径, 循环)`
- 返回值：逻辑型
- 说明：异步播放 MIDI 音乐（同一时间只有一个 MIDI 通道）。
- 参数：
  - 路径（文本型）：MIDI 文件路径。
  - 循环（逻辑型）：传真时播放结束后从头循环。

#### 音频_停止MIDI

- 签名：`音频_停止MIDI()`
- 返回值：逻辑型
- 说明：停止当前 MIDI 播放。
