# 定时任务模块使用说明

定时任务模块（`lingbuilder.cron`）提供标准 cron 表达式的周期调度、crontab 表文件管理、进程内守护线程、开机自启与 MAILTO 邮件通知。纯本地确定性实现，不依赖额外运行时 DLL。与「时钟」组件的分工：时钟是固定毫秒周期的非可视组件；需要按日历时刻调度（每 5 分钟、每天 02:00、工作日 9 点、秒级等）一律用本模块。

## 表达式语法

五段式「分 时 日 月 周」，或六段式「秒 分 时 日 月 周」（首段为秒）：

- `*` 任意值；`*/5` 步进；`1-5` 区间；`1-10/2` 带步进区间；`0,15,30,45` 列表；可组合（`1,5-10/2`）。
- 月可用 `JAN`~`DEC`、周可用 `SUN`~`SAT` 英文名（不区分大小写）；周字段 `0` 与 `7` 都是周日。
- 简写：`@yearly`、`@annually`、`@monthly`、`@weekly`、`@daily`、`@midnight`、`@hourly`、`@reboot`。
- 标准 cron 的「日与周同时受限时命中其一即触发」语义完整保留。
- `cron_定时_校验表达式` 判断合法性，`cron_定时_取表达式错误` 返回中文原因，`cron_定时_表达式说明` 把表达式翻译成人话（如「每天 02:00」）。

## 三条调度路径

**① 处理器型（推荐，UI 线程）**：到点后在注册窗口的 UI 线程执行处理器，可直接更新控件；注册窗口关闭时任务自动停止。

```text
定时任务 任务 = cron_定时_启动("*/5 * * * *", &检查更新)

空 检查更新(定时任务 任务)
    编辑框_置文本(状态框, 时间_到文本(时间_取现行时间()))
结束
```

**② 提交线程型（重活）**：工作处理器在 cron 后台线程执行，禁止调用任何 UI/controlRef 命令；结束后在注册窗口 UI 线程执行完成处理器。

```text
定时任务 任务 = cron_定时_提交线程("0 2 * * *", &夜间备份, &备份完成)
```

**③ crontab 表命令型（系统 cron 等价物）**：表内每行「表达式 命令行」，到点经 `cmd.exe /c` 执行外部命令，输出被捕获。

```text
cron_定时_表添加("0 2 * * *", "D:\tools\backup.bat 备份", "夜间备份")
整数型 数量 = cron_定时_表载入运行()
cron_定时_守护启动()
```

## crontab 表文件

- 默认系统级表：`%APPDATA%\LingBuilder\cron\crontab.txt`（按 Windows 用户隔离，所有应用共用）。表命令带 `路径` 参数时可改用项目私有表。
- 格式与标准 crontab 兼容：`#` 注释、`MAILTO=邮箱` 环境行、五段/六段表达式 + 命令行、`@简写`。UTF-8 编码（支持 BOM）。
- `cron_定时_表载入运行` 按行注册命令任务并返回数量；表达式非法的行跳过并记入 `cron_定时_取错误`；表中的 `@reboot` 行在载入时立即执行一次。
- `cron_定时_表删除` 的行号按「非空且非 # 注释」的任务行从 1 计数。

## 守护进程与开机自启

- `cron_定时_守护启动()` 自动载表并开启 0.5 秒周期的调度线程，命令任务与已注册的处理器任务都由它驱动；同一张系统表全机只允许一个进程持有守护（跨进程命名互斥体），重复启动返回假，原因见 `cron_定时_取错误()`。
- 守护只存在于本进程生命周期内。要随系统常驻：`cron_定时_开机自启(真)` 写当前用户注册表 Run 键（不需要管理员权限），登录后系统以 `--lingbuilder-cron-daemon` 参数隐藏拉起本程序进入守护模式（窗口不显示、守护自动启动）。`cron_定时_是否开机自启()` 查询状态。
- `cron_定时_守护停止()` 停止调度线程；正在执行的外部命令不会被中断。

## MAILTO 邮件通知

与 Linux cron 的关键差异：Windows 没有本机邮件代理（MTA），邮件通知必须配置真实 SMTP 账号（如 QQ 邮箱授权码）：

```text
cron_定时_邮件配置("smtp.qq.com", 465, "账号@qq.com", "授权码", "我@qq.com")
cron_定时_邮件测试()
```

命令型任务退出码非 0 或有输出时发送通知邮件（含表达式、命令行、退出码、耗时与输出截断）。收件地址优先用表内 `MAILTO=` 行，未写时用邮件配置里的收件地址。

## 调度语义与边界

- 周期任务到点后从当前时间重新计算下次触发；错过的时刻不补发（与 cron 一致）。暂停后恢复同样从当前时间重算。
- `cron_定时_暂停/恢复/停止/立即触发` 不影响任务表达式；`cron_定时_停止全部()` 停止本进程内全部任务（含表载入的命令任务），守护线程不受影响。
- `cron_定时_下次触发时间(任务)` 返回 `2026-09-21 18:30:00` 形态的本地时间；已暂停、已停止或不存在时返回空文本。
- 表达式在未来数年内无匹配时刻（如 `0 0 31 2 *`）时注册失败并返回 0。
- 秒级表达式的精度受 0.5 秒（守护）或 1 秒（窗口定时器）tick 影响，±1 秒内漂移属正常。
- 命令任务运行在后台线程，邮件发送亦在其线程内完成，不阻塞界面；处理 `cmd.exe` 输出时按 OEM 代码页解码。
