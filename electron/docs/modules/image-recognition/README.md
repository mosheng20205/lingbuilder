## 命令参考（共 5 条）

### 全部命令

#### 识图_查找颜色

- 签名：`识图_查找颜色(图片路径, ARGB, 容差)`
- 返回值：逻辑型
- 说明：从左到右、从上到下查找接近指定颜色的像素。
- 参数：
  - 图片路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - ARGB（长整数型）：一个 ARGB 颜色值，高位到低位依次为 Alpha、红、绿、蓝，通常来自 位图_取像素ARGB。
  - 容差（整数型）：各颜色通道允许的最大差值；小于 0 按 0、大于 255 按 255 处理。

#### 识图_模板匹配

- 签名：`识图_模板匹配(图片路径, 模板路径, 容差)`
- 返回值：逻辑型
- 说明：执行朴素像素模板匹配，适合小图和测试。
- 参数：
  - 图片路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - 模板路径（文本型）：小模板图片路径；模板不得超过 512×512 像素，也不得大于目标图片。
  - 容差（整数型）：每个通道允许的最大色差；小于 0 按 0、大于 255 按 255 处理。

#### 识图_取结果横坐标

- 签名：`识图_取结果横坐标()`
- 返回值：整数型
- 说明：返回最近识图结果横坐标，失败为 -1。

#### 识图_取结果纵坐标

- 签名：`识图_取结果纵坐标()`
- 返回值：整数型
- 说明：返回最近识图结果纵坐标，失败为 -1。

#### 识图_颜色相似度

- 签名：`识图_颜色相似度(ARGB一, ARGB二)`
- 返回值：整数型
- 说明：返回 RGB 最大通道差值，0 表示完全相同。
- 参数：
  - ARGB一（长整数型）：第一个 ARGB 颜色值。
  - ARGB二（长整数型）：第二个 ARGB 颜色值。
