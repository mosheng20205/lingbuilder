# 基础识图模块使用说明

| 项目 | 内容 |
| --- | --- |
| 模块 ID | `lingbuilder.image.recognition` |
| 版本 | 1.1.0 |
| 分类 | 图像 |
| 命令数 | 16 |

提供文件与字节集（内存图片）两种入口的颜色查找、区域限定模板匹配、多处匹配与轮询等待，结果坐标通过状态命令读取；配合 截图/投屏帧 字节集可做屏幕自动化找图找色。

## 启用方式

本模块为 LingBuilder 内置模块，随 IDE 一起分发，无需单独安装。在「模块」面板或解决方案树的模块节点确认其处于「已启用」状态后，即可在当前项目的 `.lcpp` 代码中直接调用下列命令；未启用时语言服务会给出带启用路径的中文诊断。

### 全部命令

#### 识图_查找颜色

- 签名：`识图_查找颜色(图片路径, ARGB, 容差, 区域X, 区域Y, 区域宽, 区域高)`
- 返回值：逻辑型
- 说明：在指定区域内从左到右、从上到下查找接近指定颜色的像素；结果读 识图_取结果横坐标/纵坐标，找不到返回假。
- 参数：
  - 图片路径（文本型）：图片文件的完整路径；GDI+ 打不开或文件损坏时按说明返回 0、空文本或假。
  - ARGB（长整数型）：一个 ARGB 颜色值，高位到低位依次为 Alpha、红、绿、蓝，通常来自 位图_取像素ARGB。
  - 容差（整数型）：各颜色通道允许的最大差值；小于 0 按 0、大于 255 按 255 处理。
  - 区域X（整数型）：查找区域左上角横坐标（像素，0 起）；省略或 0 表示从图片左边缘开始，超出图片按图片边界钳制。
  - 区域Y（整数型）：查找区域左上角纵坐标（像素，0 起）；省略或 0 表示从图片上边缘开始，超出图片按图片边界钳制。
  - 区域宽（整数型）：查找区域宽度（像素）；省略或 0 表示直到图片右边缘，超出图片按图片边界钳制。
  - 区域高（整数型）：查找区域高度（像素）；省略或 0 表示直到图片下边缘，超出图片按图片边界钳制。模板匹配要求命中位置完整落在区域内。

  - 区域Y（整数型）：查找区域左上角纵坐标（像素，0 起）；省略或 0 表示从图片上边缘开始，超出图片按图片边界钳制。
  - 区域宽（整数型）：查找区域宽度（像素）；省略或 0 表示直到图片右边缘，超出图片按图片边界钳制。
  - 区域高（整数型）：查找区域高度（像素）；省略或 0 表示直到图片下边缘，超出图片按图片边界钳制。模板匹配要求命中位置完整落在区域内。
