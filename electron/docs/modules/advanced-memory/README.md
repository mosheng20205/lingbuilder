## 命令参考（共 6 条）

### 全部命令

#### 内存_申请

- 签名：`内存_申请(字节数)`
- 返回值：长整数型
- 说明：申请清零内存并返回受控句柄。
- 参数：
  - 字节数（整数型）：要申请的字节数，1 到 268435456；超范围返回句柄 0，成功时内容全部清零。

#### 内存_写整数

- 签名：`内存_写整数(内存句柄, 偏移, 数值)`
- 返回值：逻辑型
- 说明：在边界内写入 32 位整数。
- 参数：
  - 内存句柄（句柄）：内存_申请 返回的受控内存句柄；本模块只登记自己分配的内存块，裸地址一律拒绝访问。
  - 偏移（整数型）：块内字节偏移，从 0 起；读写范围越过块尾时按说明返回假或零值。越过块尾放不下 4 个字节时返回假。
  - 数值（整数型）：要写入的 32 位整数值，占 4 个字节。

#### 内存_读整数

- 签名：`内存_读整数(内存句柄, 偏移)`
- 返回值：整数型
- 说明：在边界内读取 32 位整数。
- 参数：
  - 内存句柄（句柄）：内存_申请 返回的受控内存句柄；本模块只登记自己分配的内存块，裸地址一律拒绝访问。
  - 偏移（整数型）：块内字节偏移，从 0 起；读写范围越过块尾时按说明返回假或零值。越界时返回 0。

#### 内存_写UTF8文本

- 签名：`内存_写UTF8文本(内存句柄, 偏移, 文本)`
- 返回值：逻辑型
- 说明：在边界内写入带零结尾 UTF-8 文本。
- 参数：
  - 内存句柄（句柄）：内存_申请 返回的受控内存句柄；本模块只登记自己分配的内存块，裸地址一律拒绝访问。
  - 偏移（整数型）：块内字节偏移，从 0 起；读写范围越过块尾时按说明返回假或零值。
  - 文本（文本型）：要写入的文本，按 UTF-8 编码并自动补一个零结尾；连同结尾零必须完整落在块内。

#### 内存_读UTF8文本

- 签名：`内存_读UTF8文本(内存句柄, 偏移, 最大字节数)`
- 返回值：文本型
- 说明：在边界内读取 UTF-8 文本。
- 参数：
  - 内存句柄（句柄）：内存_申请 返回的受控内存句柄；本模块只登记自己分配的内存块，裸地址一律拒绝访问。
  - 偏移（整数型）：块内字节偏移，从 0 起；读写范围越过块尾时按说明返回假或零值。
  - 最大字节数（整数型）：最多读取的字节数；小于等于 0 或偏移越界返回空文本，遇到零字节提前结束。

#### 内存_释放

- 签名：`内存_释放(内存句柄)`
- 返回值：逻辑型
- 说明：释放受控内存块。
- 参数：
  - 内存句柄（句柄）：内存_申请 返回的受控内存句柄；本模块只登记自己分配的内存块，裸地址一律拒绝访问。
