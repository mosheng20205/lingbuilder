# LingBuilder 快捷键使用文档

本文档记录 LingBuilder 当前约定的常用快捷键。新增编辑器快捷键时，应同步更新本文档，并确认不会破坏中文新手模式、专业 Monaco 编辑器和原生预览之间的基础操作习惯。

## 全局工作台

这些快捷键由工作台 `CommandService` 统一解析，适用于新手模式、专业 Monaco 编辑器和原生预览。输入法正在组词、按键连发或已有编辑器操作接管事件时，工作台不会重复执行。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+P` / `F1` | 打开命令面板。可按中文标题、英文 alias 或命令 ID 搜索，使用 `↑` / `↓` 选择、`Enter` 执行、`Esc` 关闭。 |
| `Ctrl+,` | 打开设置页，可切换用户/工作区作用域并编辑快捷键。 |
| `Ctrl+O` | 打开已有工作区。 |
| `Ctrl+Z` | 撤销当前文件模型中的上一步编辑；新手模式会先把当前正文草稿作为一个事务提交，再撤销该事务。不会修改其他文件标签。 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做当前文件模型中刚撤销的编辑。新编辑会清空当前文件的重做栈。 |
| `Ctrl+Shift+F` | 打开“在文件中查找”，按保存到磁盘的工作区内容执行文本或正则搜索。 |
| `Ctrl+Shift+H` | 打开“在文件中替换”，先预览选中的替换项，再以可撤销事务写入磁盘。 |

macOS 等使用 Command 键的平台同时注册对应的 `Meta+Shift+P`、`Meta+,`、`Meta+O`、`Meta+S`、`Meta+Z`、`Meta+Shift+Z`、`Meta+Shift+F` 和 `Meta+Shift+H` 绑定。

撤销/重做只在专业 Monaco 或新手结构代码表面接管快捷键。若焦点位于设置、设计器属性、AI 输入框等普通 `input` / `textarea` 中，工作台会把快捷键留给该输入控件自身，不会误撤销代码文件。

`.lcpp` 在新手正文与专业 Monaco 之间共用当前文件唯一的规范撤销时间线：两种表面的普通输入都写入该时间线，Monaco 自身的分组撤销/重做事件会同步到相同快照，切换模式不会产生第二套互相竞争的历史。新手结构字段、设置和设计器属性仍保留输入控件的原生撤销；非 `.lcpp` 文本文件继续使用 Monaco 原生撤销栈。

## AI 智能编程助手面板

以下快捷键属于右侧 AI 助手面板的聊天输入框，只在焦点位于该输入框时生效，不会影响代码编辑器的同名按键。

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 发送当前消息给 AI。输入法正在组词时 Enter 仍归输入法确认候选，不会误发送。 |
| `Shift+Enter` | 在输入框内插入换行，可多行描述复杂修改需求。 |

AI 正在回复期间输入框保持可用，可以预先输入下一问题；此时发送按钮变为停止按钮，点击或等待回复完成后再次按 `Enter` 才会发送新消息。

## new_emoji FBro 浏览器外壳模板

以下快捷键属于 `new-emoji-fbro-browser-shell` 生成程序的原生窗口，只在该 exe 获得焦点时生效，不改变 LingBuilder 工作台或编辑器中的同名快捷键。模板通过窗口键盘事件调用统一 `浏览器外壳_*` 命令，不直接操作 FBro 句柄。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+L` | 聚焦并选择 Omnibox 地址栏。 |
| `Ctrl+T` | 新建并选择空白标签页。 |
| `Ctrl+W` | 关闭当前标签页。 |
| `Ctrl+R` | 刷新当前标签页。 |
| `Alt+Left` | 当前标签页后退。 |
| `Alt+Right` | 当前标签页前进。 |

完整源码包 `exports/new_emoji-FBro浏览器外壳完整复刻.lcpppkg` 保留同一份窗口键盘处理器和 `&处理器名` 回调引用；导入后按 F5 与 Visual Studio 导出均使用这些原生快捷键处理器。

快捷键可以在“设置 -> 键盘快捷键”中覆盖。工作区设置优先于用户设置；当前只接受单段快捷键。全局自定义快捷键必须包含 `Ctrl`、`Meta` 或 `Alt`，也可以单独使用 `F1-F24`；裸字母、`Tab` 等会打断输入或焦点导航的按键会被拒绝。格式错误、与默认绑定冲突或与其他自定义命令冲突时都会阻止保存并显示中文诊断。留空表示继续使用命令默认绑定；关闭设置或切换作用域前若仍有未保存修改，会先提示确认。

## 解决方案资源管理器：项目操作

以下入口只在解决方案资源管理器的项目节点上生效：

| 快捷键或入口 | 作用 |
| --- | --- |
| `F2` | 项目节点获得焦点时打开重命名输入；只修改项目显示名称，不改变项目 ID、磁盘目录、源码路径、引用或构建配置。 |
| 项目右键 -> `重命名项目` | 执行与 `F2` 相同的统一命令；空名称、超过 100 个字符、包含换行或与现有项目重名时会显示中文诊断。 |

## 解决方案资源管理器：功能库

以下快捷键只在解决方案资源管理器对应节点获得焦点时生效，不会抢占代码编辑器中的普通复制粘贴：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+C` | 焦点位于“功能代码”中的功能库 `.lcpp` 文件时，复制功能库来源信息；也可使用文件右键“复制功能库”。 |
| `Ctrl+V` | 焦点位于 Visual C++ 项目节点时，预览依赖并粘贴功能库；同名文件不会覆盖，复制结果是目标项目中的独立源码副本。 |

## 解决方案资源管理器：解决方案文件夹

以下操作只改变解决方案中的逻辑分组，不创建磁盘目录，也不会移动项目源码、配置或生成文件：

| 鼠标入口 | 作用 |
| --- | --- |
| 解决方案根节点右键 -> `新建解决方案文件夹` | 输入名称并创建可展开、折叠的解决方案文件夹。该菜单项由统一 `MenuService + CommandService` 注册和执行。 |
| 按住项目节点并拖到解决方案文件夹 | 文件夹高亮后松开鼠标，将整个项目归入该逻辑分组；项目路径、构建和引用保持不变。 |
| 按住已分组项目并拖到解决方案根节点 | 将项目移回根级；仅更新解决方案持久化状态。 |

## 新手模式：结构代码导航

这些快捷键用于新手模式的事件代码和功能代码编辑框，覆盖条件、选择、循环和异常处理结构，解决长控制块中反复滚动的问题。控制结构左侧会显示 `┌ / ├ / │ / └` 括号流程线，`跳出循环`、`继续循环` 和 `抛出` 显示 `↳` 跳转标记。

| 快捷键 | 作用 |
| --- | --- |
| `Alt+↑` | 跳到当前控制分支起点；支持 `如果/否则如果/否则`、`选择/分支/默认`、循环，以及 `尝试/捕获/最终`。 |
| `Alt+↓` | 跳到下一个结构边界；优先跳到下一个分支，没有后续分支时跳到该结构的结束命令。 |
| `Ctrl+Shift+\` | 在当前结构的开始、各分支和结束命令之间循环。 |
| `Alt+Home` | 跳到当前嵌套控制结构的最外层开始行。 |
| `Alt+End` | 跳到当前嵌套控制结构的结束行，例如 `如果结束`、`选择结束`、各类循环尾或 `尝试结束`。 |
| `Ctrl+鼠标左键单击` | 光标指向项目内子程序调用或 `&处理器名` 时，展开目标子程序并跳到其定义；字符串、注释、内置命令和模块命令不会误跳。 |
| `Ctrl+鼠标左键单击`（控件引用） | 光标指向裸写的 `controlRef` 时，切换到对应可视化设计器窗口，并按稳定项目、窗口和控件/资源 ID 选中、聚焦及滚动定位。设计器尚未挂载时会保留导航请求。 |
| 正文右键菜单 -> `转到定义` | 光标位于项目内子程序调用或 `&处理器名` 时跳到其定义；当前引用无法解析时菜单项保持禁用。 |
| 正文右键菜单 / 命令面板 -> `跳转到控件` | 与 Ctrl+单击执行同一工作台命令；只在当前参数可唯一解析为兼容控件、组件或资源时启用。 |

分支结构快捷键跳转后，新手代码编辑器只移动光标，不选中或替换目标行；行号会短暂高亮。转到定义会自动展开并选中目标子程序，立即把定义表头滚动到视口中央，不使用缓动滚动。

## 新手模式：代码输入

以下快捷键只在可写的新手 `.lcpp` 编辑器处于活动状态时生效；正文右键菜单会在对应创建命令右侧显示同一快捷键。`Ctrl+D` 在新手代码区用于新建程序集变量，在窗口设计器中仍用于克隆所选控件。

正文右键菜单还提供一组无快捷键的子程序整理命令（`上移子程序`、`下移子程序`、`剪切子程序`、`复制子程序`、`粘贴子程序`）：上移/下移与剪切/粘贴都只作用于普通子程序，事件处理器和构造、析构子程序不参与；移动和粘贴会保留子程序自身的访问属性，需要时自动补写访问段行，不会改变其他子程序的公开/私有归属。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` | 在当前类或功能库中新建子程序，并展开新子程序供直接编辑。通过子程序右键菜单触发时会插入到当前子程序下方（继承所在访问段）；无当前子程序时追加到类或功能库末尾。 |
| `Ctrl+D` | 在当前类中新建文本型程序集变量。仅适用于新手 `.lcpp` 编辑器，不影响窗口设计器中的控件克隆快捷键。 |
| `Ctrl+Space` | 打开新手代码补全。 |
| `Ctrl+/` | 注释或取消注释光标所在行；选中多行时统一切换整段行注释，空行保持不变。 |
| `Ctrl+L` | 在当前子程序的光标行上方插入可折叠的 `.局部变量` 声明块；插入后会用蓝色虚线定位框标识并自动聚焦变量名。 |
| `Ctrl+B` | 在当前子程序的光标行上方插入可折叠的 `.局部常量` 声明块；插入后会用蓝色虚线定位框标识并自动聚焦常量名。 |
| `F10` | 删除当前在声明表中选中的行。子程序声明行受保护，会短暂红色闪动而不会删除。 |
| `Delete` | 从声明表非输入区域拖选多行后批量删除。焦点位于名称、类型、备注、常量值等输入框时仅执行原生字符删除。 |
| `Enter` | 在子程序参数表的任一参数行输入框按回车：先提交当前修改，再在该行下方插入新参数行（默认 `参数N` + `文本型`）并全选新参数名等待直接改名；当前参数名为空时不插入。参数表底部提供“插入参数”按钮，可在末尾追加首个或下一个参数，子程序不再预置空参数行。 |
| `Enter` | 在完整的“未声明名称 = 表达式”赋值行末按回车，自动在该语句上方声明同名局部变量并继续到下一行；字面量、已知变量、子程序和模块命令会自动推断类型，无法推断时先显示类型选择。已声明变量、成员属性、注释和不完整表达式不会触发。 |
| `Enter` | 在 `计次循环首 (次数, 计次变量)`、`变量循环首 (起始值, 目标值, 递增值, 循环变量)`、`枚举循环首 (集合, 当前项)` 完整语句的行末按回车：循环变量尚未声明时弹出类型选择面板（像易语言一样提示创建）；计次/变量循环的循环变量推荐整数型并已预选，枚举循环的当前项会跟随集合实参的元素类型推断（含字节集 → 字节型），推断不出时由用户自行选择。确认后局部变量声明写入当前子程序并继续到下一行；循环变量已声明、参数缺失、循环变量带引号或不是裸名称时不触发。 |
| `Tab` / `Enter` | 在代码补全、自动声明类型选择或局部变量类型补全弹层打开时接受当前候选；局部变量类型支持 `wb` → `文本型`、`zs` → `整数型` 等拼音/英文别名。没有弹层时，正文中的 `Tab` 插入缩进。 |
| `↑` / `↓` | 在补全弹层中切换候选。 |
| `Esc` | 关闭补全弹层。 |
| `Ctrl+Enter` | 结束当前代码块编辑，触发回写。 |

新手正文按逻辑行显示，长代码行不会软换行覆盖下一行；超出编辑区宽度时使用横向滚动查看完整内容，语法高亮层与光标文本层保持同步。

## 保存、构建与退出

| 快捷键或入口 | 作用 |
| --- | --- |
| `Ctrl+S` | 先提交新手模式中尚未失焦的全部正文草稿，再把最终完整源码和设计器模型写入工作区；只有写入成功才清除脏状态。 |
| `F5` | 严格执行“提交草稿 -> 保存工作区 -> 构建并运行”；任一步保存失败都会中止构建，不会运行旧源码。 |
| `Shift+F5` | 停止当前运行/调试任务，并释放 F5 构建互斥状态。 |
| `保存并退出` | 等待草稿提交和磁盘保存成功后关闭；失败时保持 IDE 窗口并在输出面板显示中文错误。 |

文件、项目、工作区和新手/专业编辑模式切换前也会先提交新手草稿。保存与构建使用互斥事务，连续按快捷键不会产生重叠写入或重复构建。

## 原生调试断点

| 快捷键或入口 | 作用 |
| --- | --- |
| 专业 Monaco 行号左侧圆点区域单击 | 添加或删除当前 `.lcpp` 行的普通断点。 |
| `Shift+单击` 行号左侧圆点区域 | 输入条件表达式并创建条件断点；表达式留空会删除该断点。 |
| 顶部“开始原生调试”虫形图标 | 保存并构建 Debug 目标，通过 LLDB DAP 启动原生调试。没有断点时停在程序入口。 |
| 调试暂停时的“继续 / 单步 / 进入 / 跳出” | 分别继续运行、逐过程、逐语句和跳出当前函数。 |

断点根据生成器 source map 从 `.lcpp` 行映射到真实 C++ 行；无法确定性映射时会拒绝启动并显示中文错误，不会在错误位置静默下断。

## 窗口设计器

| 快捷键或入口 | 作用 |
| --- | --- |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切、复制或粘贴当前控件树。粘贴会经过目标父容器的布局适配器，保留子树、插槽和相对布局；跨项目时先预览模块和事件依赖。 |
| `Ctrl+D` | 通过同一容器感知克隆链路创建副本，不改写系统剪贴板。 |
| `Ctrl+A` | 全选当前窗口设计器中的普通控件。 |
| `Delete` | 删除当前控件或多选控件；已锁定控件不会被删除。焦点位于输入框、文本域、下拉框或可编辑区域时不接管。 |
| 控件右键菜单 | 由统一 `MenuService + CommandService` 生成，提供默认事件、属性、剪贴板、布局、排列、父子层级、锁定和删除。 |
| ListView 数据编辑器中的 `Tab` | 移动到同一行的下一个单元格；由原生表单焦点顺序处理，不触发工作台命令。 |
| ListView 数据编辑器中的 `Enter` / `Shift+Enter` | 移动到同一列的下一行／上一行；在最后一行按 `Enter` 会新增一行并继续输入。 |
| ListView 数据编辑器中的 `Esc` | 关闭集合编辑窗口；已经输入的数据会实时保留在设计器模型中。 |
| ListView 单元格中的 `Ctrl+V` | 可直接粘贴 Excel、CSV 或 TSV 多行多列数据，并从当前单元格开始填充。 |
| DataGrid 中的方向键 / `Tab` | 在可见单元格之间移动当前单元格。 |
| DataGrid 中的 `Enter` / `F2` | 为文本、数值、日期或组合框单元格创建临时原生编辑器。 |
| DataGrid 编辑器中的 `Enter` / `Esc` | 提交或取消当前编辑；校验失败时保持编辑器并显示最后错误。 |
| DataGrid 中的 `Delete` | 清空当前可编辑单元格；必填、只读或禁用单元格会拒绝操作。 |
| DataGrid 中的 `Ctrl+C` / `Ctrl+V` | 复制当前单元格，或从当前单元格开始原子粘贴 TSV 区域；任何越界、只读或类型错误都会取消整次粘贴。 |
| DataGrid 中的 `Ctrl+Z` / `Ctrl+Y` | 撤销或重做最近的数据事务。 |

### 热键输入框属性

选中“热键输入框”后，单击属性面板的“默认热键”字段即可直接按键录入。捕获期间该字段会阻止同一组按键触发工作台命令。

| 按键 | 作用范围与作用 |
| --- | --- |
| `Ctrl` / `Alt` / `Shift` + 字母、数字或 `F1`–`F12` | 设置热键输入框的默认热键；也支持单独的字母、数字或功能键。 |
| `Backspace` / `Delete` | 仅在“默认热键”字段获得焦点时，清空已设置的默认热键。 |
| `Esc` | 退出当前热键字段的捕获状态，不修改原值。 |
| `Tab` | 不捕获，按照属性面板的正常焦点顺序移动。 |

## 维护规则

- 新增快捷键前，优先检查是否和系统、浏览器、Monaco 常用快捷键冲突。
- 新手模式快捷键应优先服务结构阅读和直接输入，不引入确认/取消式流程。
- 专业模式快捷键应尽量复用 Monaco 或 VS Code 用户熟悉的习惯。
- 涉及中文代码结构的快捷键，应优先基于 `.lcpp` AST、结构化行或同等可测试的结构分析，不依赖不可控 DOM hack。
- 运行时创建或按标记查找得到的控件变量没有持久化设计器对象，Ctrl+单击和“跳转到控件”不伪造设计器目标；设计器裸控件引用仍按现有快捷键跳转。本次运行时控件功能未新增或占用快捷键。
