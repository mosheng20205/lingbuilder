## 技术红线备忘（正文必须警示）

- **无头＝官方 OSR 真无头**，不创建任何窗口；取内容走 `CEF3无头_取主框架→CEF3框架_*/CEF3填表_*/CEF3DOM_*` 或 `CEF3无头_执行JS/取页面文本/取页面源码`。
- **等待加载完成 ≠ 已出帧**：先 `CEF3无头_等待加载完成` 再取内容，判渲染用 `CEF3无头_等待出帧`。
- `CEF3无头_执行JS` 返回 **DevTools 信封 JSON** 不是裸值；控制台派发不了事件处理器，只能轮询 `CEF3无头_取事件JSON`。
- 受管句柄判有效**只用 `!= 0`**（按 int64 恒为负数）。
- 页面就绪断言用「当前地址 file:///…」而非裸「加载完成」（about:blank 也触发一次）。
- cefQuery：**每程序一条通道**、必须在 CEF 初始化前经控件属性 `jsQueryFunctions` 注册；120 秒不答页面收 -4；「查询已取消」CEF 150 页面侧不回调。
- @ 行禁 #include（SDK 头文件走 DLL命令声明「头文件 =」行）。
- 一期截图未开放：`CEF3离屏_订阅像素帧` 只点亮订阅位不外发内容。
- 跨域放开走 `CEF3平台_*跨域白名单` 逐条命令。
