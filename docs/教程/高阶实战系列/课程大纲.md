## 依托模块与能力面

- `lingbuilder.notify`（消息推送）：17 条命令＋常量 `#推送_默认超时毫秒`。
  - 企微 6：文本 / Markdown / 图片 / 图文 / 上传文件（→media_id）/ 发文件
  - 钉钉 6：文本 / Markdown / 链接 / 卡片单按钮 / 卡片多按钮 / 图文（FeedCard）
  - 飞书 2：文本 / 富文本
  - 通用 3：`推送_发JSON` / `推送_取错误()` / `推送_取响应文本()`
- DLL 能力面（16~19 集依托）：
  - 项目 DLL 命令声明：系统 / 普通 / 内存（`加载方式 = 内存`）三种来源；隐式链接、中文别名、导出表存在性校验；结构体定长数组、pack 对齐（1/2/4/8/16）、取数据地址（std.bytes·std.text 1.4.0）。
  - `windows-dll` 项目模板：「公开」子程序直接导出为 DLL 接口（extern "C" ＋ __stdcall ＋ exports.def；导出名纯 ASCII＋32 位构建红线）。
  - `lingbuilder.advanced.memorydll`（内存加载 DLL）：`内存DLL_加载/取函数地址/取函数序号地址/取模块大小/已加载/卸载/取错误信息` 7 命令；RCDATA 内嵌 ≤8 个、单个 ≤32MB，exe 同目录 DLL 数为 0（零落盘）。
- 模块封装能力面（20~25 集依托）：
  - 欢迎页「新建模块」两模式：从模板新建（ID/名称/八分类/说明 → `.lingbuilder/module-build/<id>` 骨架：manifest v2＋C++ 源码模板）／打开 .lbmod（解包→自动登记开发源，改动即时生效）。
  - 命令面：contributes.commands/bindings（参数类型/返回类型/控件参数 controlRef/别名）、常量 `#`、代码片段 snippets、功能库（`功能/` 目录一文件一库、`库名.功能()` 限定调用、分类子目录）。
  - 运行时：C++ pragma 链接第三方库、runtimeFiles 随包、双架构 target（Win32+x64）。
  - 生态：随包文档门禁（每模块至少一篇）、contributes.examples 例程（「在新 IDE 窗口打开」）、安装/卸载/启用禁用/修复重装/升级自愈、开发者中心/市场/历史、AI 生成模块（复制规范＋粘贴导入）、外部 AI 六步链 scaffold→writeFiles→validate→pack→installPreview→install。

## 制作规则（每集必须遵守）

1. 面向新手：从「新建项目」截起，每步操作一张配图，命令逐参数解释。
2. 每张标注截图用 Read 目检：红框位置是否对准目标控件/代码行；代码截图必须含完整事件块（事件行＋逻辑行＋结束行），滚动位加密覆盖防漏段。
3. 运行/编译前先看 IDE 底部错误列表，截图「零报错」状态；有报错先修复再继续。
4. 每集导出 `.lcpppkg` 一键分享源码包＋同名预览图（进阶系列分流口径）。
5. 每集独立会话制作，防止上下文撑满；交接以本文件＋项目记忆为准。

## 技术红线备忘（正文必须警示）

- **企微**：webhook 参数名是 `key` 不是 access_token；news 图文 **url 必填**（40039）；Markdown **不能 @**（与钉钉相反）；文本 2048 字节（UTF-8≈680 汉字）、Markdown 4096 字节；图片 ≤2MB 仅 jpg/png（运行时自动 base64＋小写 MD5）；文件 ≤20MB、media_id 3 天有效；语音与 template_card 不做结构化命令（走 `推送_发JSON`）。
- **钉钉**：Markdown **title 必填**（400402，运行时自动取正文首个非空行截 20 字）；Markdown **能 @** 但内容须同时出现 `@手机号` 文本；加签＝毫秒时间戳+"\n"+SEC → HMAC-SHA256(key=SEC) → base64 → urlencode → 拼 URL；webhook 不能直接发图片（接口权限差异）；关键词过滤与加签可叠加（两条都要满足）。
- **飞书**：加签＝**秒**时间戳写进 body 的 `timestamp`/`sign` 字段（与钉钉 URL 拼接不同）；@ 靠 open_id 内联标签 `<at user_id="...">`（不是手机号）；旧版响应格式 `{"StatusCode":0,...,"code":0}`，成功判定 errcode/StatusCode/code 三键兜底。
- **通用**：三家均约 20 条/分钟限流；内容参数收原文文本、JSON 信封由运行时构建（防引号/换行/反斜杠炸裂）；Git Bash 里 curl 内联中文会转 GBK（模块运行时无此问题）。
- **DLL**：「系统 = 真」的库中文命令名必须有英文/拼音别名（缺别名阻断）；普通/内存库的中文导出名合法（物化期导出表校验兜底）。内存加载三致命坑（正文警示）：节区权限必须早于入口调用；TLS 槽位须自行注册；卸载只注销不能 VirtualFree（重载同虚拟名会二次映射；声明内嵌的禁止手工卸载）。内存映射模块内 C++ 异常（throw/catch）不派发（SEH 仅 x64 可用）；`GetModuleHandleW` 查不到内存模块；依赖的系统 DLL 仍由 Windows 加载器从系统目录加载（不算落盘）。构建期中文阻断＝未启用模块/系统与内存混用/超 8 个/位数不符/加壳（过文件校验=真 时识别 UPX 等）/超 32MB。
- **边界**：跨进程 DLL 注入不是 IDE 内置能力（内置只有本进程内存加载，等价易语言「内存加载DLL」），19 集正文说明一句即可，不进新手课表。
- **模块封装**：模块 ID 小写字母/数字开头；分类只允许八类（界面/系统/网络/数据库/图像/AI/构建/其他）；目标目录已存在中文拒绝（绝不覆盖）；内置/项目资源 ID 拒绝；module-build 在工程树不显示（编辑走「文件→打开文件」，新建落在服务端当前工作区的 module-build）；模块必须双 target（Win32+x64）否则原生依赖被跳过报 C1083；runtime pragma 必须放使用它的块顶；随包文档经生成器产出、禁手写整份；测试用 greeter 类假模块禁随包分发（禁入 .lingbuilder/modules 播种源/例程/内置表）。
