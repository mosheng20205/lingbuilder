## 制作规则（每集必须遵守）

1. 面向新手：从「新建项目」截起，每步操作一张配图，命令逐参数解释。
2. 每张标注截图 Read 目检红框位置；代码截图必须含完整事件块（事件行＋逻辑行＋结束行）。
3. 运行/编译前先看 IDE 底部错误列表并截图零报错状态。
4. 每集导出 `.lcpppkg` 源码包＋同名预览图。
5. 每集独立会话制作。

## 技术红线备忘（正文必须警示）

- **NE 组件一律用可视化设计器模型（window-designer.json）承载，禁止在 .lcpp 里用 控件_创建NE\* 代码创建控件**；源码只做事件联动与运行期数据写入（表格行、菜单项文本等运行期数据不算创建控件）。2026-10-04 用户明确。
- NE 窗口恒 WS_POPUP：系统预设也走分层圆角；设计器圆角预设与运行期发射器对应。
- RCDATA 内嵌 DLL：改 NE 引擎后必须重编 exe；随包旧 DLL 须随下次打包替换。
- `EU_SetElementText` 只写基类 text 不写 Input::value——Input 类控件读值/写值注意字段差异。
- 表格命令有 DPI 换算；列宽/行高注意缩放。
- 弹层（下拉/菜单）命中 z 序：两段式绘制已修，压交互控件的下拉项失灵＝旧 DLL 指纹。
- 控件 type 直接存 NE 类型名（EditBox 等）不在 Win32 注册表——混排时属性面板按四级兜底显示。
- variant 语义：设计器画布 Button 预览不读 variant 也不读显式 background（手动改色绕不过），正文演示以运行窗口为准。
