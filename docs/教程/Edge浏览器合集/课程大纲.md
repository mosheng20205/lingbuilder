## 制作规则（每集必须遵守）

1. 面向新手：从「新建项目」截起，每步操作一张配图，命令逐参数解释。
2. 每张标注截图 Read 目检红框位置；代码截图必须含完整事件块（事件行＋逻辑行＋结束行）。
3. 运行/编译前先看 IDE 底部错误列表并截图零报错状态。
4. 每集导出 `.lcpppkg` 源码包＋同名预览图。
5. 每集独立会话制作。

## 技术红线备忘（正文必须警示）

- 无头实例（`EdgeView_创建无头实例`）是**隐窗伪无头**：截图/PDF 类命令不可用（取文本/取数可以，协议级控制走 CDP）；文案禁止「隐藏窗口/后台窗口」话术。
- 跨域放开走创建期属性与 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 环境变量通道。
- WebView2 运行时缺失时的下载提示口径（`edgeview-runtime-download-hint`）。
- 执行JS 返回值是字符串化约定；取数前先等加载完成。
- 控制台项目要用 `EdgeView_泵消息` 派发完成处理器。
- 填表族执行JS 兜底时注意 IIFE 括号坑。
