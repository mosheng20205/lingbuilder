# LingBuilder 零基础入门实战图文教程 · 系列大纲

> 参照系：B 站合集《火山PC(火山视窗)零基础入门实战课程》（快码教育，35 集）。
> 本文档是系列课程的总体设计：先拆解原课程的编排思路，再对照 LingBuilder 现有能力做集级映射，最后给出生产管线与待拍板项。写作每集前先回读本文。

## 一、原课程的编排思路（为什么它真的适合新手）

1. **单集单一主题**：每集 3~20 分钟只讲一件事（一个控件、一类变量、一种流程），讲完立刻上手操作。
2. **第一集就见软件**：01 配环境、02 就见到窗口、04 就写「如果」+ 按钮——从安装到自己写的程序在跑，间隔不超过半小时。
3. **第 6 集出现第一个里程碑**：用前 5 集的知识拼出「登录界面」这个真实感成果，早期成就感拉满。
4. **变量和类型不单独开理论课**：全部跟着控件走——编辑框引出文本变量、计算引出整数小数、数组类引出数组，理论永远是「为了做眼前这个东西」。
5. **循环后置（第 24 集）**：前期用数组命令、时钟等绕开循环需求，先建立「我能做出东西」的信心，再补语法深水区。
6. **中段有一条趣味实战主线**：19~22 集连做「鼠标录制回放」，把前面所有知识串起来，23 集收束成完整办公小软件。
7. **面向对象深水区后置且收敛**：类/对象/继承放 13~17 集，在 UI 和数据都熟练之后才引入。
8. **尾部两个完整项目**：TXT 编辑器（3 集）、画板绘图（3 集），从「跟着做」走向「半独立开发」。

## 二、LingBuilder 能力对照

### 控件与组件（设计器现成，可直接进课程）

| 火山课程用到 | LingBuilder 对应 | 备注 |
| --- | --- | --- |
| 按钮 / 编辑框 / 标签 | Button / TextBox / Label（win32.basic） | 编辑框有密码框、多行、占位提示 |
| 图片框 | Image（图片框）/ AnimatedImage（动态图像） | 图片源 + 填充方式 |
| 组合框 | ComboBox / ComboBoxEx / ListBox | 项目集合属性 |
| 选择框 | CheckBox / RadioButton | 选中/取消事件 |
| 时钟 | 「时钟」非可视组件 + 延时(毫秒) / 延迟调用(毫秒,&处理器) | win32.basic，2026-09-21 落地 |
| 菜单 | 菜单设计器 + win32-menu 命令 | 窗口事件绑定 |
| 托盘图标 | win32-tray（托盘_添加/修改提示/显示通知/删除） | 气泡通知现成 |
| 通用对话框 | 「文件对话框」非可视组件（文件对话框_打开/取文件数量…） | TXT 记事本可用 |
| 多窗口 / 窗口类 | 设计器多窗口 + `打开窗口(窗口类)` | 规则手册 8.2 |
| 画板/绘图 | 仅 位图_取/置像素（image-bitmap）级 | **缺口**，见第六节 |

### 命令与模块

- 基础：`信息框`、`调试输出`、`打开窗口`、`结束`、类型转换（到整数/到小数/到文本…）
- 文本：std-text（取长度/取左边/替换/分割/连接…）；数组：array 模块（取成员/取成员数/加入/查找…）
- 文件与字节集：fs-core（读/写/追加/复制/删除）、std-bytes
- 鼠标/键盘：mouse、keyboard 模块（取坐标、移动、单击、滚轮、按键模拟）
- 进阶衔接：sqlite、qrcode、image-core、threading、http-client

### 结构对照（重要取舍）

火山课程 13~17 集的「类/对象/方法/继承」深讲，LingBuilder 侧对应的主线是：
**项目全局变量与常量 → 自定义数据类型（结构体）→ 功能库（代码复用单元）**，窗口类与事件绑定概念在第 2~3 集顺带建立。三块中前两块与功能库均已有成稿图文教程可重组复用。

## 五、生产管线

- **目录规范**：`docs/教程/零基础入门系列/<NN>_主题/README.md + images/NN.png`，对齐《流程控制图文教程》先例；本大纲文件放系列根目录。
- **截图管线**：复用记忆库 `ide-tutorial-screenshot-pipeline-1003` 全套配方——独立端口组隔离（server PORT + LINGBUILDER_WORKSPACE_ROOT + LINGBUILDER_REC_USER_DATA + 独立 CDP 端口）、先断言再驱动、新手编辑器 `data-beginner-target-key` 驱动、PIL 标注三件套（裁剪→缩放→贴画布，红框/箭头/序号圆标，msyh 字体）。
- **演示工作区**：每阶段建独立演示工作区（Downloads 下），项目命名与集号对应（如 `D06-登录界面`），不污染仓库。
- **文风基线**：对齐流程控制教程——每个知识点「怎么输入 → 长什么样 → 最小示例」，截图全部真机，概念图代码行用 msyh 不用 Consolas。
- **发布**：按 `website-docs-vitepress-pipeline` 上官网 docs，本系列作一级导航分组；成稿节奏建议先做阶段一（6 集）验收文风与图量，再批量推进。

## 六、缺口与待拍板

1. **画板替代方案**：二维码小工具（qrcode 模块现成、趣味性强）vs SQLite 通讯录（更贴办公主线、为进阶铺路），第 30 集二选一。
2. **循环位置**：当前按「数组后、实战线前」（第 11 集）；若想更贴火山的信心优先策略，可再后移到第 17 集后，但第 12~17 集示例需避开手写循环。
3. **类/对象深度**：是否需要一集「窗口类与事件绑定原理」浅讲（不承诺继承），还是维持「自定义数据类型 + 功能库」替代线即可。
4. **每集正文字量**：图文教程建议 1500~2500 字/篇，集均制作成本（真机截图 + 标注）约与《流程控制图文教程》19 图相当，31 集属长线工程，按阶段推进。

## 七、写作规范（每集开工前自查）

- 所有代码在新手模式结构化编辑器里真实输入一遍，截图来自真机，不用摆拍图。
- 每个新命令首次出现时给一句话「什么时候用它」。
- 涉及系统级注入（鼠标/键盘）与文件删除等命令，必须写红线提示。
- 示例代码遵守 `返回(表达式)` 括号口径、`&处理器` 引用语法、控件裸名 controlRef 等规则手册口径。
- 每集结尾给「本集成果 + 下一集预告」。
