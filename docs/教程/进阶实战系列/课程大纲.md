# LingBuilder 进阶实战图文教程 · 系列大纲

> 面向学完《零基础入门实战》31 集的学员：每集围绕**一个内置模块**做出一个能用的成品，延续「一集一个模块、讲完就有东西」的文风。本系列**每集随文提供一键导入的 `.lcpppkg` 源码包**（与官网「示例源码」同步）。

## 生产约定

- **目录规范**：`docs/教程/进阶实战系列/<NN>_主题/README.md + images/NN.png`。
- **源码包**：每集导出 `<成品名>.lcpppkg` + 同名预览图，登记到 `Downloads/图文教程lcpppkg源码包/` 供官网上传。
- **截图管线**：复用零基础系列配方（独立端口组 server 3017 + CDP 9351、隔离 userData、PIL 红框标注、标注逐图目检）；exe 交互用 TOPMOST + 物理坐标（本机 200% DPI，客户区=设计器坐标×2）。
- **写作规范**：沿用零基础七条自查；编译环节**必须先拍错误列表**（含一次真实报错复现）。
- **文风基线**：面向新手全详细；每个命令首现给「什么时候用它」；红线必写；`返回(表达式)` 括号口径、`&处理器` 语法、裸控件名。

## 集级素材底子

- 第 1 集：`sqlite-crud-window` 项目模板（未用，教学从零搭）；SQLite 模块 2.3.0。
- 第 2 集：规则手册「内嵌 C++（@ 行）清零口径」红线清单。
- 第 3 集：web.http 1.3.0（异步 16 参与同步对齐）；JSON 解析讲法开工时核实 `lingbuilder.data.json` 模块后定。
- 第 4 集：`examples/threading-component-demo`、线程池无 64 上限口径。
- 第 5 集：`examples/buffer-queue-regex-demo`、形态校验范式（宽松解码+正则_取首个）。
- 第 6 集：archive 1.1.0（miniz 内联、#压缩_解压上限字节 防炸弹）。
- 第 7 集：`examples/cron-timer-demo`。
- 第 8 集：`examples/mail-transport-demo`（控制台版需改窗口项目教学形态）。
- 第 9 集：http.server 2.2.0（SSE 七命令、静态路由优先）。
- 第 10 集：EdgeView 教程 lcpppkg 与视频系列互链；无头四形态选型口径。
- 第 11 集：零基础 22 集办公小助手 + 本系列 1~10 集成品整合。
