# FBro 合集 14 · 网页填表（二）：取值回读与提交

> 《LingBuilder FBro 指纹浏览器合集》第 14 集（自动化篇）。第 13 集是「写」——把数据填进页面；本集是「读」与「交」：**把页面里已有的值读回来**（取值/取选择项/取选择框），再**点击提交**并读回页面的处理结果。「读页面状态」是自动化判断分支的依据，比「写」更常用。全程约 25 分钟。
>
> **模块获取**：启用 **FBro指纹浏览器模块 + FBro自动化模块**。
>
> 前置要求：学过[第 13 集](../13_网页填表一/README.md)。本集源码包见文末（含登录练习页 login.html）。

## 这一集你将学会

- `FBro填表_取值(框架, "#id", 0)`：读输入框的当前值
- `FBro填表_取选择项(框架, "#id", 0)`：读下拉框当前选中项
- `FBro填表_取选择框(框架, "#id", 0)`：读复选框状态
- `FBro填表_点击元素` + `FBro填表_取内文本`：提交并读回页面的处理结果

## 1. 读回还是写进去？方向决定命令

填表族命令是**成对**的，方向看第一个字：

| 写（第 13 集） | 读（本集） | 读到什么 |
| --- | --- | --- |
| `FBro填表_赋值` | `FBro填表_取值` | 输入框当前值（文本） |
| `FBro填表_置选择项` | `FBro填表_取选择项` | 下拉框选中的选项文本 |
| `FBro填表_置选择框` | `FBro填表_取选择框` | 复选框状态 |
| `FBro填表_置内文本` | `FBro填表_取内文本` | 元素**内部文本**（`innerText`） |
| `FBro填表_置外代码` | `FBro填表_取外代码` | 元素**外部 HTML**（`outerHTML`） |

读类命令的返回值都是**文本型**，直接拼进日志或做字符串比较。

## 2. 界面与代码

练习页 `login.html` 已预填一组账号信息（账号/密码/城市/记住我）。窗口两个按钮：「回读表单四项」「提交登录」：

```
事件 _回读按钮_被单击()
    框架 = FBro框架_取主框架(浏览器1)
    控件_添加项目(日志, "账号 = " + FBro填表_取值(框架, "#user", 0))
    控件_添加项目(日志, "密码 = " + FBro填表_取值(框架, "#pwd", 0))
    控件_添加项目(日志, "城市 = " + FBro填表_取选择项(框架, "#city", 0))
    控件_添加项目(日志, "记住我 = " + FBro填表_取选择框(框架, "#remember", 0))
结束
```

「提交登录」按钮 = `FBro填表_点击元素(框架, "#submit", 0)` → `延时(800)` → `FBro填表_取内文本(框架, "#result", 0)` 读回页面 JS 生成的登录结果。

## 3. 运行验证

点「回读表单四项」：日志逐行显示 `账号 = lingma_user`、`密码 = fbro2026`、`城市 = 杭州`、`记住我 = 1`——**页面里的值被程序读回来了**。

点「提交登录」：页面黄色区显示 `登录成功：账号=lingma_user，密码长度=9，城市=杭州，记住我=1`，日志同步打印这段回显——**「读页面结果」成立**：自动化脚本从此可以依据页面状态走不同分支（登录成功走 A 流程、失败走 B 流程）。

## 4. 实战提示

1. **读的结果做分支**：`如果 (FBro填表_取值(框架, "#status", 0) = "成功")` ——取值+如果 组合是自动化判断的基本形；
2. **密码框读回明文**：`type="password"` 的框 `取值` 返回的也是明文（页面内部值），注意日志脱敏；
3. **取不到先查就绪**：返回空文本可能是页面未加载完——先等就绪再取。

## 5. 课后练习

1. 改掉 login.html 里预填的城市，回读确认变化；
2. 用 `FBro填表_取外代码(框架, "#result", 0)` 读回汇总区的完整 HTML，对比「内文本」差异；
3. 预习：把「读值 → 如果判断 → 提交」串成一个完整的自动登录校验流程（第 15 集 DOM 遍历会读整棵页面树）。
