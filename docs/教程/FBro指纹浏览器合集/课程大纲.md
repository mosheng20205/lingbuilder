## 技术红线备忘（正文必须警示）

- **指纹 JSON 必须是桥 schema**（权威键表＝`LingBuilderFbroBridge.cpp` 的 `LB_FBro_ApplyFingerprintJson`）：UI 表单形状键被静默跳过、**键名错＝没设**；应用返回 ≥0 ≠ 生效。
- `kernel`/`v8Kernel`/`webFeatureKernel`/`cssKernel` 四键取 UA 的 Chrome 版本**钳 116~135**（写死真实内核 135 会被 browserscan 把 Browser 行标红）。
- `webdriver` 是 navigator.webdriver 虚拟值，隐藏自动化传 **false**。
- `clearAllData:true` 只用于槽位重置；独立缓存目录多开要保登录态就**不要发**。
- 纯代码多开五步链：`FBro_后台创建(空地址,独立缓存目录)` → `FBroVIP_实例设置新窗口转标签页(实例,1)` → `FBroVIP_实例应用指纹JSON(实例,…)` → `FBro_实例打开原生UI(实例,"")` 弹 about:blank → **弹窗句柄再应用一次指纹** → `FBro_实例导航(弹窗, 主页)`。
- 后台实例事件不派发，推进一律 `延迟调用` 轮询。
- 宿主进程 `LingBuilderFbroHost.exe`；「FBro框架升级工具」登录弹窗会干扰运行/截图，演示前按标题关闭。
- in-process 冷启动偶发 60s+ 长阻塞，验证按「列表框条目出现」轮询。
- CDP 端口语义：`FBro_取调试端口` 两模式都返回真实端口；端口为 0＝确认开发者工具已开启。
