# FBro 合集 16 · DOM 遍历快照（二）：节点写回改文本

> 《LingBuilder FBro 指纹浏览器合集》第 16 集（自动化篇）。第 15 集把整棵页面树拍成了快照，本集用**快照路径**精准定位节点并**写回修改**——不只读页面，还能改页面。全程约 25 分钟。
>
> **模块获取**：启用 **FBro指纹浏览器模块 + FBro自动化模块**。
>
> 前置要求：学过[第 15 集](../15_DOM遍历快照一/README.md)。本集源码包见文末。

## 这一集你将学会

- `FBro遍历_取节点路径(快照, 序号)`：读节点的**路径 JSON**（精确坐标）
- `FBro遍历_按路径设属性(框架, 路径JSON, 属性名, 值)`：按路径写回节点属性
- 路径写回 vs CSS 选择器写回的适用场景

## 1. 路径写回一分钟

第 13 集的 `FBro填表_赋值` 用 **CSS 选择器**找元素；本集的**路径写回**用快照里的**节点路径 JSON**——它是遍历时记录的树形坐标（父链+序号），**不依赖 id/class**，适合改「没有 id 的动态节点」。

```
路径 = FBro遍历_取节点路径(快照, 5)
结果 = FBro遍历_按路径设属性(框架, 路径, "textContent", "新文本")
```

## 2. 界面与代码

窗口 1300×940：FBroBrowser 加载「节点写回演示页」（含 `#target` 目标节点与还原按钮）；顶部「遍历并写回新文本」按钮：

```
事件 写回按钮_动作()
    框架 = FBro框架_取主框架(浏览器1)
    快照 = FBro框架_遍历DOM(框架, 0, 0)
    路径 = FBro遍历_取节点路径(快照, 5)
    结果 = FBro遍历_按路径设属性(框架, 路径, "textContent", "写回成功：这个节点已被修改")
    控件_设置文本(状态标签, "写回完成——页面上目标节点文本已改变。")
结束
```

注意：本集练习页的目标节点 `#target` **有 id**，CSS 选择器也能改；路径写回的价值在**没有稳定选择器的动态页面**（遍历后按位置定位）。

## 3. 运行验证

点「遍历并写回新文本」后：日志显示目标节点路径与写回结果；页面上 `#target` 框内文本变为「写回成功：这个节点已被 CDP 之外的原生通道修改（灵码教程演示）」——**快照路径写回真机生效**。点页面上的「还原页面」可刷新回原始文本，再次点击按钮可重复演示。

## 4. 两个坑

1. **快照要新鲜**：页面刷新后旧快照的路径可能失效——每次写回前重新遍历取新路径；
2. **写文本用 `textContent`**：要保留子元素结构改文字用 `textContent`；整个替换 HTML 用 `innerHTML`（`FBro填表_置内代码` 同理）。

## 5. 课后练习

1. 把写回内容改成带 HTML 的富文本：`FBro填表_置内代码` 系列；
2. 遍历两次对比两次快照的节点路径是否一致（静态页面应一致）；
3. 预习：第 17 集 JS 交互——直接执行 JS 的「万能通道」。
