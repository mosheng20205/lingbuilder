# CEF3 资源响应正文读取设计

## 目标

为 LingBuilder 的 CEF3 浏览器模块增加一个可在“资源响应到达”事件上下文中调用的高层命令，读取当前浏览器资源的响应正文，并通过完成处理器暴露文本、Base64、长度、截断状态和错误信息。

## 约束

- 不重新发起网络请求；必须读取浏览器正在加载的同一份响应。
- 正文读取只能绑定当前“资源响应到达”处理器中的请求上下文。
- 以最大字节数限制内存占用；超限保留前缀并标记截断。
- 文本与二进制同时可用：文本通过 UTF-8 解码，原始字节通过 Base64 保留。
- 保留现有元数据事件和底层 CEF3 网络 API 的兼容性。

## 接口

```text
CEF3_读资源响应正文(控件名, 最大字节数, 完成处理器)
```

完成处理器通过 `CEF3_取事件字段` 读取：

```text
url
statusCode
mimeType
bodyText
bodyBase64
receivedBytes
truncated
error
```

## 数据流

1. `OnResourceResponse` 为当前 request 建立正文读取请求并记录最大字节数。
2. `GetResourceResponseFilter` 为已标记 request 安装捕获过滤器。
3. `CefResponseFilter::Filter` 逐块收集正文前缀和总字节数。
4. `OnResourceLoadComplete` 完成正文快照，生成文本/Base64字段并触发完成处理器。
5. 请求失败、过滤器未安装或调用时机错误时，完成处理器收到中文错误，不隐式重试网络请求。

## 测试

- 模块清单暴露新命令和完整参数类型。
- 资源响应事件内调用后能产生完成事件字段。
- 文本、二进制、截断、加载失败和非事件上下文错误均有测试。
- 现有 CEF3 事件字段与教程项目验证继续通过。
