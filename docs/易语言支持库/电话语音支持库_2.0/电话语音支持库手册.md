## 支持库基本介绍

**电话语音支持库2.0版**   [返回首页](https://esdn.ijingyi.com/source/plugin/eknow/resource5.3/index.htm)

 本支持库实现了对电话的控制。需要Windows2000以上，DirectX9以上版本支持。如果使用传真功能，需安装Windows的“传真服务”附件。有些功能需要调制解调器的支持（如：语音、传真等），需要本地网络的支持（如：来电显示等）。

操作系统支持： Windows
