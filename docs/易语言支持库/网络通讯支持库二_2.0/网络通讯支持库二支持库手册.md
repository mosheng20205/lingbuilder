## 支持库基本介绍

**网络通讯支持库二2.0版**   [返回首页](https://esdn.ijingyi.com/source/plugin/eknow/resource5.3/index.htm)

本支持库实现了对原始套接字和ARP协议的支持。通过原始套接字，我们可以更加自如地控制多种协议，而且能够对网络底层的传输机制进行控制；ARP（地址解析协议），就是将网络层（IP层，也就是相当于ISO OSI 的第三层）地址解析为数据连接层（MAC层，也就是相当于ISO OSI的第二层）的MAC地址。

操作系统支持： Windows、Linux

**其它数据类型：**

| 原始套接字 | ARP协议 | IP报头 | TCP报头 |
| --- | --- | --- | --- |
| ICMP报头 | 以太网头 | ARP头 | 协议类型常量 |
| ARP常量 |  |  |  |
