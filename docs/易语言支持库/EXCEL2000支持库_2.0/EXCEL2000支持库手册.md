| 参数名 | 是否必填 | 参数类型 | 参数说明 |

| 打印预览 | 必填 | 逻辑型，初始值为“真” | 如果为真则Microsoft Excel 打印指定对象之前进行打印预览。如果为假，或者省略此参数则立即打印该对象。 |

| 输出文件 | 必填 | 逻辑型，初始值为“假” | 如果为真则打印输出到文件。如果没有指定 "输出文件名"，则Microsoft Excel将提示用户输入要输出文件的文件名。 |
| 逐份打印 | 必填 | 逻辑型，初始值为“假” | 如果为真则逐份打印每份副本。 |
| 输出文件名 | 必填 | 文本型，初始值为“” | 如果将"输出文件"设置为 真，则本参数指定要打印到的文件名。 |
